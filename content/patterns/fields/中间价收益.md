## 金融解释

**衡量什么**：相邻两期中间价的相对变动 $r = \text{mid}_t / \text{mid}_{t-1} - 1$，再做保号对数压缩。它度量的是**盘口均衡价格**的变化率，而非成交价的变化率。

**为什么有信息量**：成交价序列含买卖价差反弹（bid-ask bounce）噪声——同一均衡价下，主动买单与主动卖单会交替成交在卖一与买一，制造虚假的来回波动。中间价位于价差中点，天然滤掉这一噪声，因此它构造的收益更接近**真实价格发现**的信号。在订单簿驱动的短周期研究里，中间价收益常被用作比收盘收益更「干净」的价格路径，也是冲击斜率代理的分子。

**方向由外部逻辑决定**：与所有收益率一样，本字段本身不带方向——同一序列在不同窗口与状态下，既可表现为订单簿层面的动量延续，也可表现为冲击后的反转。它是否可交易，取决于下游把它与什么事件、什么聚合方式配对。

**与相邻字段的区别**：

- [[patterns/fields/收益率|收益率]] / [[patterns/fields/收盘收益|收盘收益]]：基于收盘价的 bar 收益，含价差反弹噪声、但不要求盘口数据；
- [[patterns/fields/冲击斜率代理|冲击斜率代理]]：用中间价收益除以订单流失衡，本字段是其分子；
- [[patterns/fields/微价格偏离|微价格偏离]]：数值是相对中间价的**水平偏离**，本字段是中间价自身的**时序变化**；
- [[patterns/fields/中间价|中间价]]：本字段的价格水平来源。

> 说明：本字段为**中性收益变换**——方向由外部逻辑决定，本身不内在偏向某类收益来源，按知识库对「收益 / 价格变换」类的标注标准不标 `return_source`。

## 加工公式

```
mid = (BP1 + SP1) / 2
r = ratio(mid_t − mid_{t−1}, mid_{t−1})      # 仅当两期 mid > 0
middle_price_return = sign(r) * ln(1 + |r|)
# 前值近零或缺失置 null
```

## 适用场景

- **订单簿层面的动量 / 反转**：需要低噪声价格路径时替代收盘收益；
- **微观结构因子的分子**：冲击斜率、价差内收益等以它为原料；
- **高频价量关系建模**：把成交与「公允价」变化配对。

## 可变异维度

- 频率：可调
- lag：1 → 2/5
- transform：可去 signed-log
