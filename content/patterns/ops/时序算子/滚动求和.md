## 金融解释

**做什么**：对窗口 $[t-w+1,t]$ 内序列求和，逐点输出——定长移动窗口的总量。

**为什么有信息量**：对流量（成交额、成交量、净流入、平方收益）求和即「近期累计规模」；对对数收益求和近似区间复合收益，是日度因子做周 / 月低频化的常用手段。窗口总量同时携带「规模」与「近期」两个信息，是区间动量、资金流强度类构造的底座。例如 20 日成交额总和度量近期资金参与规模，20 日对数收益和近似区间复合收益。

**与相邻构件的分工**：三者粒度不同，最易混淆。[[patterns/ops/时序算子/整窗口求和|整窗口求和]] 是整段一个总量（合约级常量）；[[patterns/ops/时序算子/累积求和|累积求和]] 是从头至今的单调路径；本页是**定长移动总量**，随 t 变化且不随样本增长。与 [[patterns/ops/时序算子/滚动均值|滚动均值]] 只差一个归一因子（除以窗口长度），但一个保留规模、一个给出强度。

## 算子定义

```
rolling_sum(x, window, min_samples=window)
```

- 窗口含当前点；窗口不足按 min_samples 置空；
- NaN 跳过或视 0 须显式约定。

## 适用场景

- **区间流量**：周 / 月成交额、成交量、资金流；
- **低频化**：日度值在定长区间求和；
- **区间动量**：区间收益和近似复合；
- **与滚动单位占比配对**：总量加结构两个维度；
- **量价强度**：成交额与收益的区间和组合，可刻画资金推动强度。

## 边界与陷阱

- **窗口长度不可比**：不同窗口的和不可直接比较，须归一或统一窗口；
- **量纲与尺度**：成交额远大于收益率，组合前须对齐；
- **与累积 / 整窗口求和混淆**：移动总量、单调路径、整段常量含义不同；
- **NaN 视 0 的风险**：会把「无数据」当作「零流量」，造成低谷假象，停牌应跳过；
- **与滚动均值的取舍**：若目标是比较活跃程度而非规模，应改用均值，避免被标的规模主导。

## 可变异维度

- 窗口：可调
- 对象：成交额 / 成交量 / 净流入 / 平方收益
- min_samples：严格性
