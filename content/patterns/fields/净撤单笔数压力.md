## 金融解释

**衡量什么**：分别求买侧、卖侧的**撤单笔数率**（买撤单笔数 / 买笔数、卖撤单笔数 / 卖笔数），取差后再做有符号对数压缩。正值表示买侧的撤单次数相对其成交次数更多，即买盘在「次数」意义上更容易反复撤回。

**为什么有信息量**：笔数口径度量的是**动作频率**而非容量。散户与算法的高频挂撤往往表现为「多次挂、多次撤」——一笔资金对应数次报价更新，因此笔数口径的撤单率是对「反复试探」这一行为最直接的刻画；而量口径可能被少数大额撤单主导。两者给出的信号可能不同：一笔大额撤单在量口径下极其显眼，在笔数口径下几乎不可见。用有符号对数压缩是为了抑制极端比值的厚尾，使其在截面排序中不被个别离群股主导。

**与相邻字段的区别**：

- [[patterns/fields/净撤单压力|净撤单压力]]：同一构想的**量口径**版本，对盘口容量被抽走的幅度敏感；本页对撤单**频率**敏感。
- [[patterns/fields/撤单笔数失衡|撤单笔数失衡]]：只比较买撤与卖撤的**笔数差**，不做「撤单/成交」的归一化，因而无法跨股比较撤单强度；本页先归一化再取差。
- [[patterns/fields/大单净撤单笔数压力|大单净撤单笔数压力]]：限定大单/超大单主体，刻画大资金的撤单节奏；本页不区分人群。
- [[patterns/fields/撤单强度时序单位比率|撤单强度时序单位比率]]：只度量笔数维度的撤单**总量**强度，不含方向。

## 收益来源

本页归属 [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：主要赚**信息不对称**的钱——撤单笔数率的净方向暴露了策略性报价的反复程度：一侧的撤单次数相对成交次数异常偏高，说明该侧的名义供给被系统性虚化，真实承接力弱于盘口显示，而这一信息尚未被价格反映。

**对手方**：依据盘口挂单笔数密度判断供需、把高频挂撤当作真实意愿的交易者；以及在高频挂撤中被动成交、付出冲击成本的一方。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（策略性委托与盘口真伪）。

**失效条件**：

- **改价计入撤单**：改价被计为撤单会系统性抬高两侧笔数率，且抬高幅度取决于报价更新的策略差异，净方向可能被扭曲；
- **算法报价全面接管**：当高频报价更新成为所有标的的常态，笔数维度的撤单不再区分人群或意图；
- **撤单成本变化**：撤单费或撤单笔数限制会整体压低两侧撤单笔数，压缩截面差异。

## 加工公式

```
买撤笔数率 = 买撤单笔数 / 买笔数
卖撤笔数率 = 卖撤单笔数 / 卖笔数
净撤单笔数压力 = 有符号对数(买撤笔数率 − 卖撤笔数率)
# 有符号对数(x) = sign(x)·ln(1+|x|)；各分母近零置 null
```

## 可变异维度

- 分母：挂单笔数 → 成交笔数
- 对数：有符号对数压缩 → 原始差

## 适用场景

- **捕捉高频挂撤的意图痕迹**：笔数口径对频繁改价/试探更敏感，适合分钟—日频的短周期信号；
- **与量口径互为稳健性检验**：两口径同号时撤单方向更可信，异号提示存在单笔大额撤单；
- **报价更新频繁的活跃标的**：笔数样本充足，比值的统计稳定性更好。
