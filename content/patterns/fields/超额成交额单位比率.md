## 金融解释

**衡量什么**：先构造 [[patterns/fields/成交额单位比率|成交额单位比率]]（当日成交额增量相对当日峰值，即个股自身的相对量能强度），再在同一时点截面上减去全市场中位数：$\text{ex\_unit\_ratio} = \text{unit\_ratio} - \text{median}_{cs}(\text{unit\_ratio})$。结果表示**剔除市场共同量能后**，该个股相对全市场的量能强弱。

**为什么有信息量**：成交额单位比率本身已是个股的量能相对强度，但其中夹杂着市场层面的共同放量（大盘整体放量时所有股票的量比都高）。减去截面中位数等于剥离这层共动，只留下**个股特有的相对量能**。相对量能高的股票，意味着它有超出市场节奏的资金关注——可能来自个股信息事件、游资异动或情绪涌入；相对量能低则说明在市场放量时它被冷落。因此该字段是「个股关注度 / 资金相对流向」的一个朴素代理。

**与相邻字段的区别**：

- [[patterns/fields/成交额单位比率|成交额单位比率]]：未去市场共同成分的原始量比；本页是它的截面超额版本，更纯粹地刻画个股相对强弱。
- [[patterns/fields/超额收益|超额收益]]：收益端的镜像操作（收益率减截面中位数）；两者分别是「量」与「价」的相对强弱，常配对使用。
- 换手率：用成交量 / 流通股本，带市值归一，是「绝对活跃度」；本字段是「相对自身峰值、再去市场共同成分」的量能强弱，无市值分母。
- 成交额占比：某股成交额占全市场比例的水平量，不涉及增量与截面去中心。

## 加工公式

```
unit_ratio    = ratio(Δ成交额, 当日峰值成交额)        # 成交额单位比率，分母近零置 null
ex_unit_ratio = unit_ratio - median_{cs}(unit_ratio)  # 同一时点截面中位数去中心
```

## 适用场景

- 作为**个股相对量能 / 关注度**的代理，用于量价类因子的输入或条件变量；
- 与 [[patterns/fields/超额收益|超额收益]] 配对，构造「量价背离 / 共振」信号（量走强而价未动，或量价同强）；
- 在**分钟级**捕捉个股资金相对流入的即时变化；日频上可对日内值聚合；
- 需要**剔除大盘整体放量**影响时，截面超额口径优于原始量比。

## 可变异维度

- 基准：中位数 → 均值
- 口径：量比 → 收益
