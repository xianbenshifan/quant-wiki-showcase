## 金融解释

**做什么**：按行业分组，对个股指标做聚合（均值、市值加权、求和等）得到「行业状态」，再广播回行业内个股；或直接用个股减行业聚合值，得到「个股相对行业」的偏离。

**为什么单列一页**：它是把个股信息**投影到行业层面**的基本操作，与「剔除行业影响」方向相反。行业相对强度（个股 − 行业均值）、行业层因子（行业动量）、行业内标准化都以它为基础。把行业聚合单独成页，是为了让「提取行业信息」与 [[patterns/ops/截面算子/行业中性化|行业中性化]] 的「剔除行业信息」有清晰的边界。

## 算子定义

```
ind_stat = aggregate(x | industry)          # 行业内均值 / 市值加权 / 求和
ind_relative = x - ind_stat                 # 广播回个股
# 需要时把行业状态广播给组内每一行
```

## 适用场景

- **行业轮动 / 行业动量**：直接在行业层构造因子；
- **个股相对行业强弱**：个股 − 行业聚合（相对强度、行业内超额）；
- **行业内排名 / 标准化的分母或中枢**；
- **行业层风险暴露估计**：把行业状态作为组合的行业暴露。

## 边界与陷阱

- **行业口径与成分变化**：分类调整、成分股更替会让历史行业序列不可比，须固定口径或做回溯；
- **加权方式改变含义**：等权聚合代表「典型个股」，市值加权聚合接近行业指数；命题是行业整体收益还是典型个股表现，决定用哪种；
- **广播引入行业共线**：把行业常数广播回个股后，直接用该分量做因子等于给同行业股票相同得分，组合会带行业暴露，通常需再做 [[patterns/ops/截面算子/行业中性化|行业中性化]]；
- **小组噪声**：行业内标的少时聚合值不稳，市值加权尤其明显；
- **与行业中性化方向相反**：聚合是「提取行业信息」，中性化是「剔除行业信息」；先聚合再中性化可能把刚提取出来的行业信息又消掉，须按命题顺序设计流水线。

## 可变异维度

- 聚合方式：均值 → 市值加权 / 求和
- 是否广播回个股：是 / 否
- 分组口径：行业 → 行业 × 市值
