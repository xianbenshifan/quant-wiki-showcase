## 金融解释

**衡量什么**：超大单买入的成交均价 $= \text{超大单买额}/\text{超大单买量}$，相对全市场 VWAP 的溢价，再取 signed-log：$x = \text{超大单成交均价}/\text{VWAP} - 1$。正值表示超大买单集中成交在**高于市场均价**的位置。

**为什么有信息量**：溢价度量的是超大买家的**价格激进度**。掌握信息或急于建仓的大资金，愿意连续吃卖盘、把成交价推高到 VWAP 之上，以避免因挂单等待而暴露意图或错失机会；相反，若超大买单成交在 VWAP 之下，说明它更有耐心、在低位承接，或只是被动成交。因此溢价越高，超大买家「以价换量」的意愿越强，是真实需求紧急性与信息优势的直接痕迹。这类急迫的主动买入常推动价格短期过度反应，随后伴随反转或延续，是微观结构因子的重要原料。

**与相邻字段的区别**：

- [[patterns/fields/超大单买撤溢价|超大单买撤溢价]]：用**被撤**委托的报价衡量激进度，测的是意图真伪；本页用**实际成交**衡量，测的是真实需求的紧迫性。两者一虚一实，常配合使用。
- [[patterns/fields/大单买溢价|大单买溢价]]：规模档从超大单降到普通大单，语义同构；超大单更偏机构 / 大资金，冲击力更强、信息含量通常更高。
- [[patterns/fields/超大单卖溢价|超大单卖溢价]]：卖侧镜像，衡量超大卖家愿以多低的价格抛售；买卖两侧溢价同时高企，说明大资金在激烈换手。
- [[patterns/fields/净主动成交量|净主动成交量]]：度量超大单的**方向性净额**；本字段度量**成交价格位置**，是强度而非方向的补充。

## 收益来源

本页归属 [[alpha/超大单冲击回补|超大单冲击回补]]

**赚什么钱**：赚**信息不对称**的钱。超大单愿意支付高于 VWAP 的溢价，反映其对标的有信息优势或强烈看多，且不惜以价格冲击换取建仓速度。若这一信息尚未被市场充分定价，跟随该信号可在信息扩散前获得收益；溢价本身也标记了短期价格冲击与随之而来的过度反应——急迫买入推高价格后常出现回补机会。本质上赚的是**知情大单定价不足**的钱。

**对手方**：在超大单主动买入中卖出、被价格冲击推高后仍继续成交的流动性提供者与卖方；以及消息扩散后才跟随买入的滞后交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]、[[concepts/信息冲击反应不足与过度|信息冲击反应不足与过度]]。

**失效条件**：

- **大额买入为非知情交易**：指数调仓、被动资金申赎造成的大单不含私有信息，溢价无预测力；
- **信息被瞬时定价**：市场效率高、跟随者反应快时，溢价刚出现即被套利，超额收益消失；
- **算法拆单混淆**：冰山单与拆单使「超大单」样本被选择性识别，溢价方向可能被结构性偏差扭曲。

## 加工公式

```
vwap = ratio(成交额, 成交量)                       # 全市场 VWAP
x    = ratio(超大单买额, 超大单买量) / vwap - 1    # 超大单成交均价相对 VWAP 的溢价
prem = sign(x) * ln(1 + |x|)                       # signed-log 压缩
# 超大单买量或成交量近零置 null
```

## 适用场景

- 作为**大资金紧迫性 / 知情交易强度**的代理，用于微观结构因子与事件研究；
- 与 [[patterns/fields/超大单卖溢价|超大单卖溢价]] 配对：买溢价高 + 卖溢价低（卖方惜售）是典型的看多结构；
- 与撤单溢价、净流入方向组合，区分「真实抢筹」与「虚假挂单」；
- 在**逐笔成交数据完整、规模分档稳定**的市场中构造；日频上可对日内值聚合。

## 可变异维度

- 基准：VWAP → 收盘价/昨收
- 比例：溢价 → 折扣绝对化
