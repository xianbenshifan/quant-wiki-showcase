## 金融解释

**衡量什么**：买侧成交笔数中，被划入大额档（超大单 + 大单）的笔数所占比例。它回答的是「买盘是由大额资金在下单，还是由大量小额资金在下单」——一个**参与结构**问题，而非方向问题。

**为什么有信息量**：买入笔数的规模构成反映买方人群的结构。大单买笔占比高，说明当日的买盘主要由少数大额资金贡献，买盘集中、可能带有明确的建仓意图；占比低则说明买入是大量散户小额挂单的集合行为，分散且情绪化。这一结构本身不指示方向，但它决定了同一段「净流入」的性质：是机构在建仓，还是散户在追涨。因而它常作为**条件变量或权重**，去调节其他方向性字段（净流入、溢价等）的解释力，而不是单独作为多空信号。正因为其经济含义是「分布形态/参与结构」而非方向，本页不标注 `return_source`。

**与相邻字段的区别**：

- [[patterns/fields/大单卖笔占比|大单卖笔占比]]：卖出侧的对应物；两者相除或相减可得「买卖两侧的大单参与是否对称」。
- [[patterns/fields/大单净笔数|大单净笔数]]：给出大单的**方向**；本字段只给大单在买盘中的**份额**，两者正交。
- [[patterns/fields/大单买溢价|大单买溢价]]：在大单参与的前提下再问成交价位；本字段是参与结构的**门槛**信息。
- [[patterns/fields/个人投资者交易比|个人投资者交易比]]：同样刻画参与结构，但用**金额阈值（小额成交额占比）**、针对散户，而非笔数档位的大单口径。
- 小单买笔占比：以剩余法定义的散户买笔份额，与本字段互补（分母口径须一致）。

## 加工公式

```
大单买笔数 = 超大单买笔数 + 大单买笔数
大单买笔占比 = 大单买笔数 / 买笔数
# 分母买笔数为 0 时置 null
```

## 适用场景

- **为大单方向字段提供集中度背景**：同样的净流入，若大单买笔占比高，更可能是机构建仓而非散户噪声，方向信号可信度更高；
- **刻画投资者结构**：在不同机构化程度、不同市值/流动性分层的池子中，该占比的截面分布差异可作为分组或中性化维度；
- **作为条件掩码**：只在大单买笔占比高的样本上交易方向性因子，过滤散户噪声主导的时段。
