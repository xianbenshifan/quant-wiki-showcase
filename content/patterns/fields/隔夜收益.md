## 金融解释

**衡量什么**：今开相对昨收的价格变动 $OvernightRet_{i,t} = Open_{i,t}/Close_{i,t-1} - 1$。它把全日收益中「非交易时段」的那一段单独切出。

**为什么有信息量**：隔夜段的定价机制与日内段**相反**。隔夜没有连续撮合，价格变动来自开盘集合竞价：隔夜积累的公开信息、海外市场映射、消息面情绪，以及投资者在非交易时段的心理锚定，共同决定开盘跳空。传统上隔夜收益呈**弱动量**（信息延续），而日内段呈反转，两者显著负相关，构成 [[concepts/隔夜与日内收益拔河|隔夜与日内收益拔河]] 的经典图景。把隔夜段独立出来，能分别检验「信息在非交易时段的积累与释放」与「连续交易时段的过度反应修正」两套机制。

**为什么与注意力有关**：开盘跳空是**关注度的集中释放**。隔夜的信息、传闻与情绪在开盘瞬间被一次性定价，注意力最集中的标的跳空幅度更大、随后修正也更明显。隔夜收益因而既承载信息动量，也承载注意力 / 情绪的开盘冲击。

**与相邻字段的区别**：

- [[patterns/fields/日内收益|日内收益]]：$Close/Open-1$，与隔夜收益在时间上互补、机制上相反，方向性预测常反号；对数口径下两者之和等于全日收益。
- [[patterns/fields/收益率|收益率]]：全日收益，把两段混在一起，无法区分机制。
- [[data-semantics/量价/价格#开盘价|开盘价]]（data-semantics）：原始语义；隔夜收益是它与昨收的初加工。
- 绝对隔夜跳空幅度：本字段的绝对值版本，只保留幅度、丢弃方向。

## 收益来源

本页归属 [[alpha/隔夜信息反应不足|隔夜信息反应不足]]

**赚什么钱**：其一为**动量**——隔夜信息在开盘被定价后，若未被充分消化，价格会沿跳空方向继续移动，隔夜收益因此带有弱动量属性；其二为**注意力与情绪**——开盘跳空是关注度与情绪的一次性释放，情绪化定价随后修正，为反转或修正类策略提供空间。

**对手方**：隔夜信息反应不足、在开盘后才跟进的交易者（动量来源）；以及在开盘情绪高点追入、随后承受修正的投资者（注意力来源）。

**理论支撑**：[[concepts/隔夜与日内收益拔河|隔夜与日内收益拔河]]、[[concepts/开盘心理锚定|开盘心理锚定]]。

**失效条件**：

- **信息在盘前已充分定价**：若集合竞价与盘前交易把隔夜信息完全消化，动量延续消失；
- **涨跌停封板**：一字板使隔夜收益被制度截断，方向含义失真；
- **机制切换**：交易时段、集合竞价规则调整会改变隔夜段的信息承载方式，历史关系失效。

## 加工公式

```
OvernightRet = Open / Close(前一日) - 1
# 对数口径：ln(Open / Close_{t-1})
```

## 派生形态

- **绝对隔夜跳空幅度**：$|\ln(Open_t/Close_{t-1})|$ 跨日求和 → [[paradigms/隔夜跳空|隔夜跳空]]。
- **隔夜距离（截面）**：$|OvernightRet-\overline{OvernightRet}^{cs}|$ → [[paradigms/修正的隔夜反转|修正的隔夜反转]]。
- **隔夜收益率因子**：保留符号直接作选股因子，周/月可对区间日度求和 → [[paradigms/隔夜收益率|隔夜收益率]]。

## 适用场景

- 需要**隔离隔夜信息冲击**、单独研究非交易时段定价时；
- 构造隔夜动量 / 隔夜反转 / 修正反转因子，或在周 / 月频率上对隔夜收益求和；
- 与 [[patterns/fields/日内收益|日内收益]] 配对做正交分解，研究两段拔河的相对强弱；
- 用绝对跳空幅度度量隔夜风险冲击，配合 [[patterns/mask/跳跃示性掩码|跳跃示性掩码]] 识别事件。

## 可变异维度

- 口径：简单 ↔ 对数
- 强度：带符号 ↔ 绝对值
- 聚合窗：日 → 周/月求和
