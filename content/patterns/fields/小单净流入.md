## 金融解释

**衡量什么**：小单（散户）人群的买量减卖量，再用买卖量之和归一化到 $[-1, 1]$。正值表示散户在净买入，负值表示散户在净卖出。小单量通常用**剩余法**定义：总量减去超大单、大单、中单，再截断非负。

**为什么有信息量**：散户净流入是**大众人群方向**的直接度量。它在财务上恒等于其他所有档位净流入的相反数（各档之和为零），但在行为含义上完全独立：散户的净买入常由**注意力与情绪**驱动——看到涨幅、看到新闻、看到热度才进场，而不是因为估值便宜。因此小单净流入高，通常并不代表该股票被「看好」，反而往往是**情绪已经兑现、后续回落概率上升**的标记。这也是「聪明钱 vs 大众钱」框架里，为什么小单方向常被当作**反向指标**而非同向信号。

**为什么用归一化失衡而非原始净额**：散户净买入的绝对金额随股票大小、当日活跃度剧烈变化，直接影响截面比较；归一化到 $[-1,1]$ 后，度量的是「散户方向的偏向程度」而非「散户投入的资金规模」，跨股可比性更强。

**与相邻字段的区别**：

- [[patterns/fields/大单净流入|大单净流入]]：机构/大额人群的方向；两者之差即 [[patterns/fields/大单小单背离|大单小单背离]]，后者同时使用了两方信息，信息含量更高；
- [[patterns/fields/小单净笔数|小单净笔数]] / [[patterns/fields/小单净额|小单净额]]：同一方向的笔数、金额口径版本，分别对散户下单频率与资金规模敏感；
- [[patterns/fields/个人投资者交易比|个人投资者交易比]]：度量散户参与的**份额**而非**方向**，与本字段正交；
- [[patterns/fields/小单净撤单压力|小单净撤单压力]]：散户的撤单意图，度量未成交的意愿动摇，与本字段互为验证。

## 收益来源

本页归属 [[alpha/量激增注意力|量激增注意力]]

**赚什么钱**：主要赚**注意力**的钱——散户净买入是关注度与情绪驱动的定价痕迹，高关注度买入把价格推离基本面，随注意力衰减价格回归；次要赚**行为偏差**的钱——散户的追涨杀跌、处置效应与过度自信使其系统性买在高点，为反向交易提供对手盘。

**对手方**：在情绪高点追入、随后承受回落的散户自身；以及被散户注意力推高价格后接盘的后来者。

**理论支撑**：[[alpha/大小单博弈|大小单博弈]]（散户资金行为）；[[concepts/行为金融凸显理论|行为金融凸显理论]]（注意力与显著效应）。

**失效条件**：

- **散户结构变化**：机构化程度提升、小单不再等价于散户时，行为学含义消失；
- **散户被信息优势方反向定价**：当散户群体的平均信息质量提升（如使用专业工具），其净流入不再系统性地错误；
- **恒等式约束主导**：各档净流入之和为零这一会计恒等关系，使小单净流入在部分情形下只是其他档位的镜像，而非独立行为信号。

## 加工公式

```
小单买量 = max(买量 − 超大单买量 − 大单买量 − 中单买量, 0)
小单卖量 = max(卖量 − 超大单卖量 − 大单卖量 − 中单卖量, 0)
小单净流入 = 归一化失衡(小单买量, 小单卖量)
           = (小单买量 − 小单卖量) / (小单买量 + 小单卖量)
# 分母近零置 null；剩余法负值截断为 0
```

## 可变异维度

- 口径：量 → 额/笔数
- 规模档：剩余 → 仅小单

## 适用场景

- **作为反向情绪指标**：用于识别散户情绪高点，配合反转类因子使用；
- **与大单方向构成背离因子**：作为 [[patterns/fields/大单小单背离|大单小单背离]] 的减项，是「聪明钱」框架的核心组件；
- **情绪/关注度因子的权重或分组变量**：散户净流入活跃的标的上，情绪类因子区分度更高。
