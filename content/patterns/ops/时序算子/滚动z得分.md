## 金融解释

**做什么**：以每个时点为终点，用过去 window 期样本算均值与标准差，输出

$$z_t=\frac{x_t-\operatorname{mean}_w(x)}{\operatorname{std}_w(x)}.$$

**为什么有信息量**：它把当前值标准化为「相对近期分布的位置」，剔除标的的长期水平与波动差异，是时变标准化与异常检测的常用工具。相比整窗口 z 得分，它用的是**近期**基准，能跟上分布漂移（波动率、活跃度的 regime 变化）。

**与相邻构件的分工**：[[patterns/ops/时序算子/整窗口z得分|整窗口z得分]] 用整段样本，基准稳定但迟钝；本页基准随 t 变化，灵敏但样本少、噪声大。[[patterns/ops/截面算子/截面z得分|截面z得分]] 是同一时点跨股票的标准化，正交维度不同。[[patterns/ops/时序算子/滚动排名|滚动排名]] 是分布无关的位置度量（只保留次序），本页保留幅度信息。三者分别回答「相对长期的自己 / 相对近期的自己 / 相对当下的市场」。

## 算子定义

```
rolling_zscore(x, window)   # (x - 窗口均值) / (窗口标准差 + eps)
```

- 窗口含当前点，因此分母含 $x_t$，存在轻微内生性；
- 窗口不足时按 min_samples 置空；标准差近零 → null。

## 适用场景

- **时变标准化**：多因子合成前按个股近期分布归一；
- **异常检测**：识别相对近期的极端读数；
- **波动调整的动量 / 反转**：把收益除以近期波动；
- **regime 识别**：z 长期偏正或偏负反映水平漂移。

## 边界与陷阱

- **低方差数值不稳**：近常数或清淡窗口标准差趋零，$z$ 被放大成噪声，必须加零方差守卫并置空；
- **内生性**：当前值同时进入分子与分母，短窗口下 $z$ 被压缩、极值被低估；
- **min_samples 语义**：窗口不足时置空还是用现有样本，直接决定暖机长度与可用样本量；
- **对极端值敏感**：均值与标准差都受离群影响，宜先缩尾，或改用中位数—MAD 口径。

## 可变异维度

- 窗口：可调
- min_samples：严格性
- 中心 / 尺度：均值—标准差 → 中位数—MAD
