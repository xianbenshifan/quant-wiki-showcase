## 范式概述

盘口平均深度 $= (\text{BV1}+\text{SV1})/2$，即买一量与卖一量的算术平均，衡量**最优档位的平均挂单厚度**。对每个 5min 盘口快照逐 bar 计算，再取当日全部有效 bar 的算术平均，得到日频流动性因子。深度越大流动性越高，与未来收益负相关。

**为什么「最优档深度」是流动性的核心度量**：流动性的本质是「以多小的代价完成一笔交易」。最优档（买一 / 卖一）是交易者**立刻**能够成交的价位，其挂单厚度直接决定了「一笔小单能否被无损吸收」——挂单厚则冲击小，挂单薄则价格立刻跳动。因此最优档深度是最贴近**即时交易成本**的度量，比买卖价差（度量成本的价格侧）更直接地反映**容量**（能承受多大的量）。

**为什么要把买卖两侧取平均**：单看买一量或卖一量会引入**方向性偏差**——买盘厚卖盘薄意味着买压占优（看多信号），反之亦然。本范式要度量的是**流动性总量**而非方向，因此对两侧取算术平均，把「不平衡」这一维度抹去，只留下「厚度」。这也是它与 [[patterns/fields/净撤单压力|净撤单压力]] 之类方向性失衡指标的分工差异。

**为什么「深度大」对应「未来收益低」**：这属于**流动性溢价的镜像**。研报标注 `factor_sign negative`，与 [[patterns/fields/非流动性|非流动性]] 的定价逻辑一致——流动性差的股票（深度薄）需要更高的预期收益作为补偿，因此深度与未来收益负相关。此外，深度也可以视为一种「交易便利性」的度量：深度充裕的股票更容易被套利与交易，定价更充分，因而更难有超额收益。

## 构造要点

1. **零量防御（关键前置）**：record $\text{zero\_mask} = (\text{BV1}==0) \mid (\text{SV1}==0)$；`replace(0,nan).ffill()` 沿时间正向补缺（NAS book_snapshot 防御默认）。
   这一步不可省略：盘口快照中买一量或卖一量为 0 是常见现象——可能是**涨跌停**（单边挂满、对手方为 0）、**集合竞价**、或数据缺失。若直接把 0 当真实值，深度会被系统性低估。用「先记录掩码、再置 NaN、再前向填充」的顺序，既补上了缺失又能以掩码区分「原本就是 0」与「补出来的」。这是 NAS 盘口数据的通行防御处理。
2. **$\text{avgdepth}_t = (\text{BV1}_t + \text{SV1}_t)/2$**；任一档为 0 则该 bar 深度为 0（零量判定以 **ffill 前**原始值为准）。
   注意括号里的约束：判定「是否为零量 bar」必须用**填充前**的原始值，否则补出来的值会掩盖真实的零量状态。
3. **日内聚合**：当日全部有效 bar 的算术平均（`nanmean`）。
   用 `nanmean` 而非 `mean`：前者自动跳过 NaN（无效 bar），后者会把 NaN 传播为整日 NaN。算术平均等权对待每个 bar——若希望更重视收盘时段，可改加权（见可变异维度）。
4. **落盘**：Datetime 钉 `15:00:00`，日频，`max_lookback=0`。
   钉到 15:00 是因为日频因子的锚点必须统一（收盘时刻），便于与其他日频因子对齐；`max_lookback=0` 表示当日因子只用当日数据、不需历史窗口。

## 可变异维度

- 档位：最优档(1) → 2 / 3 档深度均值（更广的容量视角）
- 聚合：日内算术平均 → 加权 / 仅收盘时段（重视收盘前的流动性状态）
- 输入：买一卖一量 → 更宽档位组合（对应 [[patterns/fields/总深度\|总深度]] 族）
- 频率：5min → 1min / 15min

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]]

**赚什么钱**：主要赚**流动性溢价**的钱——深度薄的股票交易成本高、变现困难，持有者要求更高预期收益作为补偿，因此做多低深度（高非流动性）股票可获得溢价。次要赚**信息不对称**的钱——深度变化也反映做市意愿：深度持续偏低可能意味着流动性提供者因逆向选择风险而撤退，这本身携带信息。

**对手方**：需要即时成交、付出价格冲击成本的交易者（流动性需求方）；以及流动性危机中被迫平仓、无法等待的一方。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（逆向选择成本与做市意愿）；Amihud 型非流动性定价见 [[patterns/fields/非流动性|非流动性]]。

**失效条件**：

- **流动性危机**：机制反转——深度在危机中集体枯竭，且高深度股票更易成为抛售对象，溢价关系被打破；
- **挂单可撤销导致深度失真**：盘口挂单是**意图**而非承诺，高频做市商可在成交瞬间撤单（闪电撤单），名义深度远超真实可成交量；
- **涨跌停与制度性零量**：涨跌停时单边深度为 0，若零量防御处理不当（如误当作真实薄盘），会把制度状态误读为极端非流动性。
