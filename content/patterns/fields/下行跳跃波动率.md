## 金融解释

**衡量什么**：把日内高频（典型 5 分钟）对数收益按符号拆分，取负收益部分的二次变差 $\text{RS}^- = \sum r^2 \cdot \mathbf{1}(r<0)$，减去连续扩散分量的稳健估计的一半，再截断为非负：$\text{RVJN} = \max(\text{RS}^- - \tfrac{1}{2}\widehat{\text{IV}}, 0)$。连续分量估计常用双幂次 / 三幂次变差（见 [[patterns/fields/多幂次变差|多幂次变差]]）。

**为什么有信息量**：下行跳跃是**负向离散信息的指纹**——利空财报、监管处罚、评级下调、流动性事件等，会让价格在一两个 bar 内完成一次性向下重估。它与上行跳跃对称，但在经济含义上更贴近投资者真正在意的东西：**崩盘风险**。投资者对尾部损失的厌恶远强于对等幅收益的偏好，因此下行跳跃被单独定价，通常要求正的风险补偿。减去 $\tfrac{1}{2}\widehat{\text{IV}}$ 的逻辑与上行版本相同——无跳跃时，负收益二次变差只含连续分量的一半，超出部分才是跳跃；截断非负把估计噪声映射为「无下行跳跃」。

**为什么单独成构件**：下行跳跃是构造下行大 / 小跳分解、上下行跳跃不对称（SRVJ）等范式的基础。由于上下行跳跃的定价不对称，把下行分量单独抽出，才能刻画「坏消息冲击」的强度，并支持「恐惧溢价」类研究。

**与相邻字段的区别**：

- [[patterns/fields/上行跳跃波动率|上行跳跃波动率]]：对称的正收益版本；两者相减即上下行跳跃不对称性，本字段捕获的是「坏消息冲击强度」；
- [[patterns/fields/已实现跳跃波动率|已实现跳跃波动率]]：总跳跃（不分方向），是本字段与上行版本的加总根；
- [[patterns/fields/多幂次变差|多幂次变差]]：本字段的连续分量减项；
- [[patterns/fields/日跳跃度|日跳跃度]]：低频代理，不区分方向、不基于二次变差分解；
- [[patterns/fields/更优波动率|更优波动率]]：连续波动水平，不含跳跃分离。

## 收益来源

本页归属 [[alpha/跳跃风险补偿|跳跃风险补偿]]

**赚什么钱**：赚**波动与尾部风险溢价**——下行跳跃是不可分散的崩盘风险，投资者厌恶这种尾部损失，因而对下行跳跃风险高的股票要求更高的预期收益作为补偿。这是波动 / 尾部风险溢价的典型形态：承担别人不愿承担的崩盘暴露，获得风险补偿。

**对手方**：在跳空下跌中被迫割肉、或在恐慌中被动抛售的投资者；以及对尾部风险定价不足、未要求足够溢价的持有者。

**理论支撑**：[[concepts/特异波动异象|特异波动异象]]（跳跃 / 波动风险与截面收益）；[[concepts/信息冲击反应不足与过度|信息冲击反应不足与过度]]（跳跃后的价格修正）。

**失效条件**：

- **跳空被连续化**：涨跌停把一次跳跃拆成多日连续下跌，高频二次变差低估真实下行跳跃；
- **波动风险溢价被套利消除**：卖波动 / 卖尾部风险的供给充裕、交易拥挤时，溢价可能压缩甚至转负；
- **可预期事件造成的跳变**：分红除权、指数调整等确定性事件的价格跳变不含信息，也无补偿。

## 加工公式

```
RS⁻ = Σ r² · I(r < 0)                 # 负收益分钟二次变差
RVJN = max(RS⁻ − ½ · ÎV, 0)           # ÎV 为连续波动率估计（RBV/RTV）
# 截断非负；ÎV 见 多幂次变差
```

## 可变异维度

- 频率：5 分钟 → 1 分钟/10 分钟
- IV̂ 估计：双幂次 ↔ 三幂次 ↔ 其它稳健估计
- 截断：max(·,0) 固定

## 适用场景

- **崩盘风险的横截面度量**：作为尾部风险的直接代理，用于风险分层与暴露控制；
- **上下行跳跃不对称性的分子**：与上行版本配对构造 SRVJ；
- **下行大 / 小跳分解**：在坏消息冲击内部进一步按幅度拆分。
