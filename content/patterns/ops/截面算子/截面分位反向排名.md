## 金融解释

**做什么**：与 截面分位双侧排名 共用同一条分位轴，但左侧改成对 $-x$ 排名——轴左「值越小排名越大」，轴右仍按 $x$ 升序排名。结果是**左反右正**的不对称映射：偏离轴越远（无论哪一侧）排名越高。

**它操作化了什么**：把「相对参照轴的偏离强度」变成单峰的正向信号。双侧排名用符号区分左右（带方向性），反向排名则把两侧都转成同向递增的强度，近似一个**不对称的绝对偏离**度量——左尾越极端、右尾越极端，输出都越大。适用于「无论向哪一侧极端都算异常」的命题，例如两侧尾部都可能对应流动性冲击或波动放大。

## 算子定义

```
rev_rank(x, q):
    a = quantile_cs(x, q)
    left  = rank_asc(-x | x < a)   # 越小于轴，rank 越大
    right = rank_asc( x | x > a)   # 越大于轴，rank 越大
```

## 适用场景

- 只关心「极端化程度」、不关心方向的双侧强度信号；
- 与掩码配合：先切出两尾状态，再在状态内比较强度；
- 需要把「左尾深度」与「右尾高度」折算到同一正向尺度时；
- 作为两尾对称化处理的非参替代（相较 $|x-a|$ 更稳健）。

## 边界与陷阱

- **方向信息被抹掉**：正负两侧同号递增，若下游需要区分「高值极端」与「低值极端」，必须另配 [[patterns/ops/点算子/符号|符号]] 或分状态处理；
- **不对称并非对称**：左反右正的斜率由两侧各自的样本分布决定，输出在轴两侧的尺度并不等价，不能当作对称的 $|x-a|$；
- **$q$ 与样本量**：与双侧排名相同，$q$ 决定轴，两侧样本不足时排名噪声大；
- **与双侧排名的选择**：先想清楚命题是否携带方向——带方向用双侧，只在意极端强度用反向；两者互换会把符号搞反。

## 可变异维度

- q：轴分位
- 左反 / 右反可互换
- 分组口径：全截面 → 行业内
