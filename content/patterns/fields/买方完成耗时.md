## 金融解释

**衡量什么**：对买侧订单，取「平均最早挂出时间」与「平均完结时间」的对数之差，再做保号对数压缩：$\text{buy\_completion\_time} = \operatorname{sign}(d)\cdot\ln(1+|d|)$，其中 $d = \ln(\text{买均完结时间}+1) - \ln(\text{买均挂出时间}+1)$。它度量的是**买侧挂单从挂出到结清的平均存活时长**。

**为什么有信息量**：订单存活时长是流动性提供者**耐心**的直接体现。买单愿意长时间挂在盘口等待成交，说明买方在提供即时流动性、承担库存与逆向选择风险；反之，买单被迅速成交或撤走，说明买盘急切、以主动成交为主。因此买侧完成耗时越长，通常对应买侧流动性供给意愿越强；越短则对应买方急躁、流动性需求主导。把它与卖侧版本对比，可揭示**买卖两侧耐心差异**——例如买侧耐心显著高于卖侧，可能预示需求的持续性更强。

**为什么用对数增量而非原始时间差**：挂单时长分布高度右偏（少数订单存活极久），对数差把时间尺度标准化、压缩长尾，使不同活跃度的股票可比；再套一层保号对数则进一步钝化极值。

**与相邻字段的区别**：

- [[patterns/fields/订单完成耗时|订单完成耗时]]：买卖两侧的**合成**版本，度量总体耐心；本字段是其分方向分解；
- [[patterns/fields/卖方完成耗时|卖方完成耗时]]：对称的卖侧版本，二者之差是买卖耐心差异；
- [[patterns/fields/成交执行率|成交执行率]]：度量「成交 / 挂单」的比例，是**数量**维度的执行效率；本字段是**时间**维度的存活时长；
- [[patterns/fields/成交笔数压力|成交笔数压力]]：笔数失衡的方向，本字段不含方向、只描述存活。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/信息风险补偿|信息风险补偿]]

**赚什么钱**：其一为**流动性溢价**——长时间挂单的买侧参与者是在提供即时流动性、承担被动成交与库存风险，理应获得补偿，买侧耐心是其供给稳定性的代理；其二为**信息不对称**——知情买方倾向快速成交、不愿挂单等待暴露意图，因此短完成耗时可能标记知情买盘，长完成耗时更多是被动流动性提供者。

**对手方**：以主动卖单吃掉耐心买单的急躁交易者；以及为流动性提供者的库存风险付费的一方。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **高撤单环境**：订单存活时间被频繁撤单压缩，完成耗时更多反映撤单策略而非流动性耐心；
- **算法拆单与冰山单**：可见订单的存活时间被算法重塑，与真实流动性供给意愿脱钩；
- **行情剧烈期**：价格快速变动使订单几乎瞬间成交或被撤，截面差异被压缩。

## 加工公式

```
d = ln(买均完结时间 + 1) − ln(买均挂出时间 + 1)      # 对数时间差
买方完成耗时 = sign(d) * ln(1 + |d|)                  # 保号对数压缩
# 时间戳缺失或为 0 时置 null
```

- 口径：挂单存活 → 成交点击
- 频率：可调

## 适用场景

- **买侧流动性供给意愿的度量**：与卖侧版本配对研究两侧耐心差异；
- **执行质量评估**：与成交执行率组合，区分稳健供给与高频挂撤；
- **订单级别数据完整的市场**：只有成交记录、无挂单生命周期时不可构造。
