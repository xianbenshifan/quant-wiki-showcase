## 金融解释

**衡量什么**：先取买一挂单量变化与卖一挂单量变化的**绝对值之和**，除以成交量增量的绝对值，得到「订单簿两侧变动量」相对「成交量」的比例；对该比例做时序缩尾后，再做有符号对数压缩。它度量的是：**单位成交量背后，订单簿被扰动了多少**——比值越高，说明同样的成交规模引发了更大的挂单变动，订单流失衡越剧烈。

**为什么有信息量**：它是对经典 **VPIN（Volume-Synchronized Probability of Informed Trading，成交量同步知情交易概率）** 的低成本代理。VPIN 的核心思想是：知情交易者会不断从一侧吃掉流动性，使买卖不平衡累积，因此「成交量中有多大比例是方向不平衡的」可以作为**订单流毒性**（toxicity）的度量。本字段用「挂单两侧变化量 / 成交量」近似这一不平衡：当知情者持续在单侧成交，对手方挂单被迅速消耗、两侧挂单变化不对称，比值抬升。因此它携带**信息不对称**的信号——高毒性意味着做市方在与知情者交易中承受逆向选择损失，通常会扩大价差、收缩流动性，并对未来价格有指示作用。

**为什么要缩尾与对数压缩**：比值在成交量增量趋零时会剧烈放大，厚尾严重；缩尾与有符号对数把极端值压缩，使截面排序不被少数极端点主导。有符号对数还保留了比值的符号信息（挂单净变化方向）。

**与相邻字段的区别**：

- [[patterns/fields/冲击斜率代理|冲击斜率代理]]：用**价格变化 / 订单流失衡**度量单位订单流的价格冲击，是**价格**视角；本字段用挂单变化 / 成交量，是**毒性/不平衡**视角；
- [[patterns/fields/订单流失衡|订单流失衡]]：度量五档挂单**增量**的加权净方向，是**方向**字段；本字段度量两侧变化的**总量比例**，不含方向（取绝对值）；
- [[patterns/fields/净主动成交量|净主动成交量]]：从主动成交角度度量方向失衡；本字段从**挂单**侧度量不平衡的剧烈程度。

## 收益来源

本页归属 [[alpha/信息风险补偿|信息风险补偿]]

**赚什么钱**：主要赚**信息不对称**的钱——订单流毒性高意味着知情交易者正在积极利用私有信息，价格尚未充分反映这些信息，毒性越高、后续价格调整可能越大。做空/低配毒性高的标的，或在毒性回落时反向介入，是这一逻辑的常见用法。

**对手方**：在知情者持续单向成交中被动提供流动性、承受逆向选择损失的做市方与限价单提供者；以及未能识别毒性、在信息扩散前按旧价格成交的交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（Easley–O'Hara PIN 与订单流毒性）；[[alpha/知情卖出信号|知情卖出信号]]。

**失效条件**：

- **成交量分桶假设被破坏**：VPIN 依赖「按成交量分桶、每桶交易量相等」的构造，若用时间桶近似，毒性与波动的对应关系失真；
- **挂单侧代理不等于成交侧**：真实知情交易体现在**成交**的不平衡上，用挂单变化近似会混入做市报价调整等非知情因素；
- **高频做市主导**：当订单簿变化主要来自做市商库存管理而非知情交易时，比值不再指向信息。

## 加工公式

```
毒性原始值 = (|ΔBV1| + |ΔSV1|) / |成交量增量|
毒性缩尾 = 时序缩尾(毒性原始值, 1%)
毒性代理 = signed_log(毒性缩尾)
# signed_log(x) = sign(x)·ln(1+|x|)；分母成交量为 0 时置 null
```

## 可变异维度

- 档位：1 档 → 多档合并
- 缩尾：1% → 0.5%/5%

## 适用场景

- **订单流毒性的低成本代理**：在无法获得完整逐笔数据的场景，用盘口变化近似 VPIN；
- **流动性风险的横截面识别**：识别交易环境对做市方最不利、价差最可能扩大的标的；
- **与其他知情交易字段联合**：与冲击斜率、订单流失衡同向时毒性信号更可信。
