## 金融解释

**衡量什么**：被撤超大单卖委托的均价 $= \text{超大单卖撤额}/\text{超大单卖撤量}$，相对全市场 VWAP 的偏差，再取 signed-log：$x = \text{委托均价}/\text{VWAP} - 1$。正值表示被撤的大额卖单报价**高于**市场均价，负值表示报价低于市场均价。

**为什么有信息量**：卖侧撤单的报价位置同样暴露意图。被撤大额卖单若挂在**远低于** VWAP 的位置，可能是为了制造抛压恐慌的幌骗挂单（极少真的会以该价格成交）；若挂在略高于 VWAP 的位置被撤，则更像卖方在试盘后调整报价。因此该字段是**大额卖委托报价激进度**的度量，与买侧镜像一起，构成对盘口真伪与订单流毒性的双侧画像。单看卖侧，它回答的是「被撤的大额卖压究竟挂在什么价位」，帮助判断卖盘是虚是实。

**与相邻字段的区别**：

- [[patterns/fields/超大单卖溢价|超大单卖溢价]]：用**实际成交**的超大单卖出均价对 VWAP 取偏差，度量卖方愿意以多低的价格真实抛售（真实供给强度）；本页用**被撤**委托报价，度量虚假或调整中的卖压。一实一虚。
- [[patterns/fields/超大单买撤溢价|超大单买撤溢价]]：买侧镜像；买撤溢价高（远高于 VWAP）与卖撤溢价低（远低于 VWAP）若同时出现，是双边幌骗的典型形态。
- [[patterns/fields/大单卖撤溢价|大单卖撤溢价]]：规模档降到大单，语义同构、参与者更广。
- [[patterns/fields/撤单笔数失衡|撤单笔数失衡]] / [[patterns/fields/撤单失衡|撤单失衡]]：只看撤单数量方向；本字段看撤单报价位置。

## 收益来源

本页归属 [[alpha/超大单冲击回补|超大单冲击回补]]

**赚什么钱**：赚**信息不对称**的钱。被撤大额卖委托的报价位置标记了盘口上虚假供给的痕迹：远端低价幌骗会误导市场高估抛压，识别它就能避免在虚假恐慌中割肉，并可在虚假卖压撤去后捕捉价格反弹。本质上是在交易**订单流毒性 / 盘口真伪**这一信息维度。

**对手方**：被虚假卖压恐吓、以不利价格卖出的交易者；以及无法区分真实与虚假挂单、依据可见深度决策的被动方。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]、[[alpha/大小单博弈|大小单博弈]]。

**失效条件**：

- **撤单为正常改价**：高波动环境下大额卖单频繁调整报价，远端撤单不再标记操纵；
- **分层挂单普遍化**：若市场参与者普遍采用分层挂撤策略，该度量的区分度被稀释；
- **监管收紧**：针对虚假申报的监管使幌骗减少，报价位置的信息含量下降。

## 加工公式

```
vwap = ratio(成交额, 成交量)                          # 全市场 VWAP
x    = ratio(超大单卖撤额, 超大单卖撤量) / vwap - 1    # 委托均价相对 VWAP 的偏差
prem = sign(x) * ln(1 + |x|)                          # signed-log 压缩
# 撤量或成交量近零置 null
```

## 适用场景

- 作为**卖侧盘口真伪**的特征，配合实际成交溢价判断卖盘虚实；
- 研究**幌骗 / 虚假申报**的双边形态：买撤溢价与卖撤溢价同时极端；
- 与不同规模档、买侧镜像共同构成撤单报价位置的完整画像；
- 需要**逐笔委托数据**（含撤单报价与量额）才能构造。
