## 金融解释

**做什么**：按布尔条件在两条表达式之间取值——条件为真取 `then`，否则取 `else`。它把「分段构造 / 状态依赖」显式化：同一条流水线在不同状态下产出不同量。

**为什么单列一页**：很多因子是**状态依赖**的——「仅在放量时刻用收益反转，其余时刻赋中性」「市场下跌段与上涨段用不同口径」。若不做条件派生，就得为每个状态写一条流水线再合并，难以维护且易错。条件派生把「状态 → 取值」收敛为一个算子。它与掩码的分工是：掩码产出**选择**（哪些样本入选），条件派生产出**赋值**（不同样本取不同值）。

## 算子定义

```
conditional(cond, then, else):
    return then  where cond is true
    return else  where cond is false
    # cond 为布尔 / 掩码；then、else 可为列、常数或进一步表达式
```

## 适用场景

- 分段 / 状态依赖因子构造（牛熊、高波动 / 低波动段不同处理）；
- 用掩码把「不符合条件」的样本赋为中性值（如 0）而非置空；
- 缺失值填充策略（按条件选择不同来源）；
- 多分支嵌套的分层逻辑。

## 边界与陷阱

- **then / else 与条件同分布效应**：若 `then` 与 `cond` 相关，输出会同时含「状态差异」与「取值差异」，二者混在一起难以归因，须显式控制；
- **与掩码的混淆**：掩码把未命中样本置为缺失（保留样本量语义），条件派生通常赋固定值；用错会把「未命中」误当成「取值 0」，污染截面统计；
- **多分支嵌套的可读性**：嵌套 when-else 很快变得难以维护，应拆成命名中间列或互斥状态表；
- **条件本身的口径**：`cond` 依赖的阈值 / 分位若跨期漂移，输出会在不同期「切换」形态，须保证条件定义稳定；
- **分支量纲不一致**：`then` 与 `else` 量纲不同会产出无意义的混量，须显式统一。

## 可变异维度

- 条件：布尔 / 掩码
- 分支：任意表达式 / 常数
- 未命中处理：置空 → 赋中性值
