## 金融解释

**衡量什么**：小单人群的撤单**笔数率**净压 = 「小单买撤笔数 / 小单买笔数 − 小单卖撤笔数 / 小单卖笔数」。正值表示散户更倾向于撤回买单（相对其挂出的买单），负值表示更倾向于撤回卖单。

**为什么有信息量**：撤单是「挂出来又收回」的动作，用**笔数**度量动作频率，比用量额更贴近「反复试探」这一行为特征。散户的撤单往往表现为**多次挂、多次撤**——价格一动就改主意，一笔资金可能对应数次挂撤。因此笔数口径的撤单率，是散户情绪反复程度最直接的刻画。当小单买撤笔数率系统性偏高时，散户的买入意愿是脆弱的、名义买盘是虚的，真实承接力弱于盘口显示；反之撤卖笔数率高则说明卖压虚化。笔数口径与量口径给出的信号可能不同：一笔小额撤单在量口径下几乎不可见，但在笔数口径下会显著推高撤单率，因此两者应并置解读。

**与相邻字段的区别**：

- [[patterns/fields/小单净撤单压力|小单净撤单压力]]：同一构想的**量口径**版本，对盘口容量变化敏感；本页对撤单**频率**敏感；
- [[patterns/fields/净撤单笔数压力|净撤单笔数压力]]：全市场口径、且常用有符号对数压缩，分母可为挂单或成交，不区分人群；
- [[patterns/fields/大单净撤单笔数压力|大单净撤单笔数压力]]：大单人群的对应物，二者之差构成笔数维度的撤单背离；
- [[patterns/fields/撤单笔数失衡|撤单笔数失衡]]：只比较买撤与卖撤笔数的净方向，不做「撤单/挂单」的归一化，因而无法跨股比较撤单**强度**。

## 收益来源

本页归属 [[alpha/量激增注意力|量激增注意力]]

**赚什么钱**：主要赚**信息不对称**的钱——散户买撤笔数率异常偏高意味着盘口的名义买盘被系统性虚化，真实需求不足这一信息尚未被定价；次要赚**行为偏差**的钱——散户的「挂了又撤」是情绪与注意力快速转移的直接行为痕迹，这种不稳定的参与本身就是定价偏离的来源。

**对手方**：依据小额挂单判断支撑/阻力、把名义买盘当作真实需求的交易者；以及在高频挂撤中反复付出机会成本与撤单成本的散户自身。

**理论支撑**：[[alpha/大小单博弈|大小单博弈]]（散户情绪性交易）；[[concepts/行为金融凸显理论|行为金融凸显理论]]（注意力驱动的交易不稳定性）。

**失效条件**：

- **散户等价性丧失**：算法拆单使小单混入机构被动成交，笔数口径的人群含义被破坏；
- **撤单成本上升**：撤单费或监管限制会整体压低撤单笔数，人群间差异减小；
- **情绪长期平稳期**：当市场情绪稳定、散户行为模式化时，撤单笔数率缺少横截面差异，信号变弱。

## 加工公式

```
小单买撤笔数 = max(买撤单笔数 − 超大单/大单/中单买撤笔数之和, 0)
小单卖撤笔数 = max(卖撤单笔数 − 超大单/大单/中单卖撤笔数之和, 0)
小单净撤单笔数压力 = 小单买撤笔数 / 小单买笔数 − 小单卖撤笔数 / 小单卖笔数
# 各分母近零置 null；剩余法负值截断为 0
```

## 适用场景

- **捕捉散户情绪的快速波动**：笔数口径对高频挂撤更敏感，适合短周期信号；
- **与量口径互为验证**：两口径同号增强可信度，异号提示单笔大额撤单污染；
- **高换手、散户活跃标的**：这类标的小单撤单笔数足够多，统计更稳。
