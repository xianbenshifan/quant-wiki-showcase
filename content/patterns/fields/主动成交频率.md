## 金融解释

**衡量什么**：主动成交的订单笔数除以同期总成交量：$\text{active\_freq} = (\text{主动买笔数} + \text{主动卖笔数}) / \text{成交量}$。它度量**单位成交量对应多少笔主动成交**，即主动交易的**碎片化程度**。

**为什么有信息量**：同样的成交量，可以由少数大额单完成，也可以由大量碎单拼成。比值高，说明成交由许多小额、可能是散户或算法拆分的单子构成，交易粒度细、参与者分散；比值低，则说明成交集中在少数大单上，更可能是机构行为。它是「参与者结构」与「执行方式」的粗粒度代理，与方向无关。

**为什么是中性构件**：它把主动买、主动卖笔数**相加**，抹掉了方向，只保留总量密度。因此它不能单独预测涨跌，但可与方向字段（净主动笔数、主动买占比）正交组合，刻画「谁在交易、怎么交易」。

**与相邻字段的区别**：

- [[patterns/fields/净主动笔数|净主动笔数]]：同族里**有方向**的版本（买笔数 − 卖笔数），本字段是总量密度；
- [[patterns/fields/每笔成交量|每笔成交量]]：$\text{成交量} / \text{笔数}$ 的整体口径，与本字段近似互为倒数但并不等价（本字段分母为成交量、分子只含主动笔数）；
- [[patterns/fields/主动买占比|主动买占比]]：主动成交的**方向占比**，不含密度；
- [[patterns/fields/换手率|换手率]]：以流通股本为分母度量活跃度，本字段以成交量为分母度量粒度。

> 说明：本字段为**中性活动结构量**——它把成交笔数密度化，不携带买卖方向，本身不内在偏向某类收益来源，故本页不标 `return_source`。

## 加工公式

```
主动成交频率 = ratio(主动买笔数 + 主动卖笔数, 成交量)
# 分母成交量近零置 null（可加小常数钝化）
```

## 可变异维度

- 分母：成交量 → 成交笔数
- 频率：可调

## 适用场景

- **参与者结构代理**：识别成交由碎单还是大单主导的时点；
- **执行质量分析**：配合每笔成交量判断拆单强度；
- **条件分层**：作为方向信号的条件变量，检验信号在高 / 低碎片化环境下的差异。
