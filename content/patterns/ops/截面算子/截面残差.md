## 金融解释

**做什么**：在每个时点的截面上把 $y$ 对 $x$ 做回归，输出残差——即「$y$ 中无法被 $x$ 解释的独立部分」。$x$ 可以是市场因子、行业暴露、风格因子，或 PCA 主成分。

**为什么单列一页**：它是**中性化**的一般形式。剔除共同暴露后剩下的特质成分，通常被假设为更干净、更接近可交易 alpha 的部分；同时残差与 $x$ 当期内正交，使组合对 $x$ 的暴露为零。把截面回归残差单独成页，是为了统一 [[patterns/ops/截面算子/行业中性化|行业中性化]]、[[patterns/ops/截面算子/组内中性化|组内中性化]]、[[patterns/ops/其他算子/主成分分析|主成分分析]] 之后取残差等多条路径。

## 算子定义

```
resi(y, x) = y - (alpha + beta * x)      # 每时点截面 OLS
# 长表按 Datetime 分组，宽表整表；x 截面方差近零 -> null
# 多元形式：y 对 [x1..xk + 常数] 回归
```

## 适用场景

- **构造特质信号**：剔除市场 / 行业 / 风格后的特质收益、特质波动；
- **配对与统计套利**：两只相关标的回归后取价差残差；
- **风险中性化**：让组合暴露对给定因子为零；
- **PCA 的后续步骤**：先用主成分提取共同因子，再回归取残差。

## 边界与陷阱

- **OLS 对离群敏感**：少数极端样本可大幅拉动 $\beta$，污染全部残差；应先缩尾或改用稳健回归；
- **截面样本量要求**：自变量个数（尤其行业哑变量）接近甚至超过截面标的数时回归过拟合、残差近乎全零，须保证有效样本远大于参数个数；
- **自变量近常数 / 共线**：$x$ 截面方差趋零或自变量高度共线时 $\beta$ 不稳，须做守卫（置空）或降维；
- **正交性只在本期成立**：残差与 $x$ 的正交是同期截面性质，不保证下一期，跨期累计仍可能重新暴露；
- **与组内中性化的关系**：当 $x$ 是分类分组键时，对哑变量回归取残差等价于组内去均值（[[patterns/ops/截面算子/组内中性化|组内中性化]]）；当 $x$ 连续或需加入市值等额外控制项时，必须走回归版。

## 可变异维度

- 对象：y / x 任意对
- 自变量：单变量 → 多因子 → 哑变量
- 估计方式：OLS → 稳健回归
