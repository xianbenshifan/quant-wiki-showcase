## 金融解释

**衡量什么**：$pvol = \text{成交量} / \text{成交笔数}$，即单位时段内平均每笔成交的规模。它同时混合了两层信息——成交活跃程度（笔数多）与单笔力度（量大）。

**为什么有信息量**：每笔成交规模是**订单大小的低成本代理**。大额委托往往被拆成多笔，但拆单后单笔规模仍显著高于散户的零碎成交，因此 pvol 上升通常意味着大资金 / 知情交易的参与度提高。大单集中冲击会使价格**过度反应**、随后反转；而单笔规模小、成交温和的时段更多呈现动量延续。这条「过度反应—反转」的链条正是「每笔成交量局部反转」「大单推动涨幅」等范式的机制基础。反过来，它也可仅作为**交易异常活跃程度**的细粒度描述，用于刻画市场微观结构的活跃度。

**额口径变体**：平均单笔成交金额 $= \text{成交额} / \text{成交笔数}$，与量口径同构，只是用成交额替代成交量，天然剔除了股价水平对「单笔规模」的影响，跨股票比较时优于量口径。海通「大单推动涨幅」即用额口径取上尾分钟。同一额口径还可以只在下跌分钟上计算，再除以当日全部分钟的平均单笔金额：源文把下跌时单笔金额偏大读成委买大单在承接，与「上尾分钟涨幅随后回吐」不是同一条用法。

**与相邻字段的区别**：

- [[patterns/fields/成交笔数压力|成交笔数压力]]：从**笔数**维度看买卖失衡；每笔成交量是**规模**维度，两者互补。
- 大单净流入一类字段：直接按规模分档统计资金流；每笔成交量不区分方向，只描述单笔平均大小，是无方向的活动强度刻画。
- 换手率：用成交量 / 流通股本衡量活跃度，带市值归一；每笔成交量衡量的是**单笔**规模，与市值无关，更贴近交易者结构。

## 加工公式

```
每笔成交量   = ratio(成交量, 成交笔数)      # 分钟频率；成交笔数为 0 时置 null
每笔成交金额 = ratio(成交额, 成交笔数)      # 额口径，同构
```

## 派生形态

- **平均单笔成交金额（额口径）**：$Amt/TrdNum$，与量口径同公式结构；用于按上尾分位掩码提取「大单博弈」分钟后再连乘收益（见 [[paradigms/大单推动涨幅|大单推动涨幅]]）。来源：大单推动涨幅因子。
- **平均单笔流出金额占比**：下跌分钟的平均单笔成交额，除以当日全部分钟的平均单笔成交额，再对 $T$ 日平均。源文称与未来收益正相关；把分钟收益指示改成大于 0，即平均单笔流入金额占比。见 [[paradigms/平均单笔流出金额占比|平均单笔流出金额占比]]。来源：平均单笔流出金额占比因子。

## 适用场景

- 作为**订单大小 / 大资金参与度**的快速代理，用于筛出大单主导的分钟，再做反转或推动类构造；
- 按上尾分位取「每笔成交量最大的分钟」作为事件样本（配合 [[patterns/mask/分位掩码|分位掩码]]）；
- 需要**跨股票可比**时优先用额口径，避免股价水平差异；
- 与 [[patterns/fields/成交笔数压力|成交笔数压力]]、[[patterns/fields/净主动成交量|净主动成交量]] 组合，区分「大单方向」与「大单强度」。

## 可变异维度

- 口径：成交量 → 成交额 / 笔数
- 频率：分钟 → 5min / 日
- 归一：原始值 → 滚动分位
