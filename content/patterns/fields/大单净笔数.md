## 金融解释

**衡量什么**：把大额档（超大单 + 大单）的买单笔数与卖单笔数相加合并，取归一化失衡：$(\text{大单买笔数} - \text{大单卖笔数})/(\text{大单买笔数} + \text{大单卖笔数})$。正值表示大额资金以**买入笔数**占优，负值表示以卖出笔数占优。

**为什么有信息量**：笔数与量额度量的是不同东西。量额失衡会被**单笔金额大小**主导——一笔超大单就能把当日方向推向极端，反映的是「一次冲击」；笔数失衡对**下单频率**更敏感，反映的是「持续、反复的进场意图」。当一个资金方在若干分钟内连续下出多笔大单，往往是执行一个既定计划（建仓/派发），这种「重复性」在笔数维度比在量额维度更干净。因此本字段是「聪明钱方向」在**频率维度**的度量，常与量额口径互为稳健性检验。

**与相邻字段的区别**：

- [[patterns/fields/大单净笔数档|大单净笔数档]]：仅取 Large 档（剔除 Mega），剔除事件性极强的个别巨单、更接近大资金**常态化**参与；本页是 Mega+Large 合并档，事件性更强、单日波动更大。
- [[patterns/fields/超大单净笔数|超大单净笔数]]：仅 Mega 档，最接近机构专用行为。
- [[patterns/fields/小单净笔数|小单净笔数]]：散户对应的笔数口径，常作反向情绪指标。
- [[patterns/fields/大单净流入|大单净流入]]：同族但为量口径，受单笔大小影响，与本页可交叉验证。
- [[patterns/fields/成交笔数压力|成交笔数压力]]：不分档的全部主动成交笔数净失衡，度量「全市场平均方向」。

## 收益来源

本页归属 [[alpha/普通大单信息延续|普通大单信息延续]]

**赚什么钱**：主要赚**信息不对称**的钱——大单档的净方向被视为资金/信息优势方的态度：大额资金以买入笔数持续占优，意味着有信息的一方在分批吸筹，而价格尚未反映其信息，未来收益偏正。笔数口径比量额口径更贴近「持续性建仓」，噪声更低。

**对手方**：在相反方向上被动成交、以限价单承接的一方（多为散户与小单）；以及在信息扩散后才追入的滞后交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（知情委托的方向含量）；[[alpha/知情卖出信号|知情卖出信号]]。

**失效条件**：

- **拆单算法普及**：机构把大额订单拆成小单执行时，按单笔金额划分的档位与投资者类型脱钩，笔数口径的大单方向被稀释；
- **流动性需求而非信息**：大额净买入也可能来自被动资金申赎或调仓，不携带个股私有信息；
- **反转占主导的短周期**：极短持有期上，大单冲击后的过度反应回落可能压过信息延续，方向符号翻转。

## 加工公式

```
大单买笔数 = 超大单买笔数 + 大单买笔数
大单卖笔数 = 超大单卖笔数 + 大单卖笔数
大单净笔数 = (大单买笔数 − 大单卖笔数) / (大单买笔数 + 大单卖笔数)
# 分母近零置 null；规模档可换为仅 Large（见大单净笔数档）
```

## 可变异维度

- 口径：笔数 → 量
- 规模档：Mega+Large → 仅 Large

## 适用场景

- **短持有期、拆单普遍的市场**：笔数维度对高频拆单更敏感，适合分钟—日频的短周期信号；
- **与量额口径做交叉验证**：两口径同号时信号更可信；相悖往往说明是单笔巨单在主导量额，应降权；
- **作为「持续性建仓」的代理**：比量额口径更能刻画反复进场的计划性交易；
- **与净笔数档区分使用**：样本含指数调整、大宗交易等一次性巨单时，Large-only 口径更稳。
