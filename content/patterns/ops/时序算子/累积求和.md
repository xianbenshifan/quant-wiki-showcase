## 金融解释

**做什么**：按合约对序列做累积求和，沿时间给出逐点路径 $S_t=\sum_{s\le t} x_s$。

**为什么有信息量**：累积量是「从头至今的总经历」。累计成交量与成交额度量累计活动；对数收益的累积和近似复合收益（净值曲线的对数）；累计净流入刻画资金的累积方向。它把「每一期的流量」积分成「一条路径」，因此天然用于绘制累计曲线、判断累计强度与进度。

**与相邻构件的分工**：滚动求和 是**定长移动窗口**的总量，会「遗忘」窗口外的历史；累积求和**不设窗口**、从头累加，对正流量单调不减、随样本增长。整窗口求和 是整段的一个总量（常量标量）；本页是**路径**（每个 t 一个累计值）。三者最易混淆：移动标量、整段常量、单调路径。

## 算子定义

```
cumsum(x)   # x_t 的逐期累加，按合约分组
```

- 按合约分组；起始点与缺失处理（跳过 / 视 0）会整体位移曲线；
- 对可正可负序列（如净流入），路径可升可降。

## 适用场景

- **累计成交量 / 成交额 / 净流入**；
- **对数收益累积** ≈ 复合收益、净值曲线；
- **累计活动量与进度**；
- **与累积极值配合**（CumMax / CumMin）刻画历史高低路径。

## 边界与陷阱

- **单调增长不可比**：对正流量，曲线随样本增长，跨时间、跨标的不可直接比较，须归一（除以样本数、或差分回到流量）或只看斜率；
- **起点敏感**：起始点选择会整体平移曲线，样本长度不同则终点不可比；
- **缺失累积**：跳过还是视 0 会造成长期漂移；停牌若补 0 会压低累计值；
- **与滚动 / 整窗口求和混淆**：路径、移动总量、整段常量三种语义不同。

## 可变异维度

- 对象：成交量 / 成交额 / 对数收益 / 净流入
- 维度：时序累积 → 截面累积
