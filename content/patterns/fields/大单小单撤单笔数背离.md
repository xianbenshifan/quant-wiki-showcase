## 金融解释

**衡量什么**：分别在**大单**和**小单**两个人群中，用「买撤单笔数 / 买笔数 − 卖撤单笔数 / 卖笔数」算出各自的**撤单笔数率净压**（正值表示该人群更多地撤买单、负值表示更多撤卖单），再取二者之差。正值意味着大单的撤单方向比小单更偏向撤买（相对小单而言大单更急于撤掉买单），负值反之。

**为什么有信息量**：撤单是**不花钱就能改变盘口**的行为，因此撤单的方向与浓度，是观察交易者**真实意图**的窗口——挂出来又撤掉，说明当时的挂单并不代表真实成交意愿。把大单与小单分开看，是因为两者的撤单动机截然不同：大单的撤单可能是有计划的报价调整、幌骗或流动性试探，携带策略性信息；小单的撤单更多是情绪反复、追涨杀跌后的犹豫。**背离**（两者之差）把「知情者与大众人群的行为分歧」从共同的撤单噪声中剥离出来——若两个人群同时撤买，差值可能为零，但这并不代表没有信息，因此背离口径与单人群口径是互补的。

**笔数口径的独特价值**：撤单是「挂单—撤单」的**动作**，用笔数度量频率比用量额更直接——一笔巨撤与十笔小撤在量额上可能等价，意图却不同，笔数口径对「反复撤单」更敏感。

**与相邻字段的区别**：

- [[patterns/fields/大单小单撤单背离|大单小单撤单背离]]：同一构想的**量口径**版本，对单笔大额撤单更敏感；本页是**笔数口径**，对撤单频率更敏感。二者在个股上可能出现方向相反的信号，需并置观察；
- [[patterns/fields/小单净撤单笔数压力|小单净撤单笔数压力]]：只保留小单人群的撤单净压，是背离公式的一个减项；
- [[patterns/fields/大单小单背离|大单小单背离]]：用**成交**而非撤单度量大小资金分歧，刻画的是「已发生的方向分歧」；本页刻画的是「未成交的意图分歧」，二者互补。

## 收益来源

本页归属 [[alpha/大小单博弈|大小单博弈]]

**赚什么钱**：主要赚**信息不对称**的钱——大单撤单方向的异常（相对小单）暴露了策略性交易者的意图，这类意图尚未反映在成交与价格中；次要赚**行为偏差**的钱——小单撤单率的波动是散户情绪反复的痕迹，背离揭示了大资金与散户情绪的错位，错位越大，散户被情绪牵着走的定价偏离越可能被反向利用。

**对手方**：被撤单行为误导、依据盘口名义挂单做决策的普通交易者；以及在散户情绪反复中追涨杀跌、高买低卖的散户自身。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（策略性委托与逆向选择）；[[alpha/大小单博弈|大小单博弈]]（小单人群的情绪性行为）。

**失效条件**：

- **撤单监管与做市约束**：对频繁撤单的监管限制或做市商义务增加，会系统性压低所有人的撤单率，人群间的差异被压缩；
- **拆单使人群边界模糊**：算法把大单拆成小单挂撤后，大单/小单的撤单行为不再对应不同人群，背离失去行为学含义；
- **真实信息不通过撤单表达**：当知情者选择直接以成交（而非挂撤）执行时，撤单背离不携带任何信息，信号为空。

## 加工公式

```
大单撤单笔数净压 = 大单买撤笔数 / 大单买笔数 − 大单卖撤笔数 / 大单卖笔数
小单撤单笔数净压 = 小单买撤笔数 / 小单买笔数 − 小单卖撤笔数 / 小单卖笔数
大单小单撤单笔数背离 = 大单撤单笔数净压 − 小单撤单笔数净压
# 各分母近零置 null；小单可由「总笔数 − 大/中单笔数」剩余法定义并截断非负
```

## 可变异维度

- 口径：笔数 → 量
- 撤单率基准：撤/挂 → 撤/成

## 适用场景

- **高频、撤单数据可得的场景**：5min 及更高频、能区分挂/撤笔数时，该字段区分度最高；
- **与量口径背离做联合验证**：笔数与量两种口径同号时信号更稳，异号时往往说明存在单笔巨型撤单，应降权；
- **情绪反复时段**：散户情绪波动大的阶段，小单撤单噪声上升，背离更能凸显大单的策略性意图。
