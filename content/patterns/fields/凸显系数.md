## 金融解释

**衡量什么**：度量当日个股收益 $r_i$ 相对市场参照收益 $\bar r$（常取全市场收益中位数）的**显眼程度**：$\sigma(r_i,\bar r) = (|r_i|+|\bar r|-r_i-\bar r)/\theta$。分子对偏离市场常态的收益给出更高分数，参数 $\theta$（常取 0.1）钝化接近零的收益噪声，使小幅波动不被误判为凸显。$\sigma$ 越大，该日收益在投资者眼中的「份量」越重。

**为什么有信息量**：这是[[concepts/行为金融凸显理论|行为金融凸显理论]]在个股层面的操作化。投资者注意力有限，会被相对参照点**显著偏离**的收益吸引，并对这些日子赋予过高权重；$\sigma$ 正是「哪一天足够显眼」的排序依据。它本身不直接作因子（真正的信号是与收益配对后的协方差），但它是理解显著效应族的关键中间量：没有它，就无法把客观收益序列转成认知加权的输入。$\theta$ 的作用则是把日常的小幅波动挡在门外，避免「噪声日」产生虚高的凸显分。

**与相邻字段的区别**：

- [[patterns/fields/凸显权重|凸显权重]]：本字段的**下游**——$\sigma$ 只给排序键，$\omega$ 把排名转成跨日衰减权重。
- [[patterns/fields/惊恐度|惊恐度]]：另一套显著/偏离强度口径，用**绝对偏离**、对涨跌一视同仁，更接近「异动程度」；本字段更强调相对参照的显眼度，方向性更强。
- [[patterns/fields/收益率|收益率]]：本字段的输入，本身中性；凸显系数在其上叠加了「相对参照的显眼度」。
- [[patterns/fields/日跳跃度|日跳跃度]]：从价格路径连续性度量跳跃，是路径视角；凸显系数是横截面相对偏离视角。

## 收益来源

本页归属 [[alpha/凸显收益误估|凸显收益误估]]

**赚什么钱**：主要赚**行为偏差**的钱——凸显性驱动投资者对极端收益日的系统性误估（过度外推显眼的好消息、过度恐慌于显眼的坏消息），据此构造的权重—收益协方差可捕捉误估修正；次要赚**注意力**的钱——$\sigma$ 高的日子正是注意力集中的日子，注意力驱动的定价偏离随后衰减。

**对手方**：被显眼收益吸引、在显眼日以偏离基本面的价格追涨或杀跌的投资者；其错误定价的修正构成收益。

**理论支撑**：[[concepts/行为金融凸显理论|行为金融凸显理论]]；[[alpha/量激增注意力|量激增注意力]]。

**失效条件**：

- **机构主导定价**：专业投资者对凸显性不敏感，其占比高时参照点附近的定价偏离被套利消除；
- **显眼源于真实信息**：若极端收益来自基本面重估，则「显眼=误估」的假设不成立，无反向修正；
- **市场普涨普跌**：当全市场偏离度普遍较高（或参照中位数剧烈漂移）时，$\sigma$ 的横截面区分度被压缩。

## 加工公式

```
σ(r_i, r̄) = ( |r_i| + |r̄| − r_i − r̄ ) / θ
# r̄ 可取全市场收益中位数；θ 常取 0.1（钝化零收益噪声）
```

## 可变异维度

- 参照：市场中位数 → 行业中位数 / 等权均值
- $\theta$：0.1 → 其它钝化强度
- 频率：日 → 分钟（慎用，显著效应理论建立在日频记忆上）

## 适用场景

- **显著效应族的排序键**：为凸显权重提供输入，构造凸显权重收益协方差类因子；
- **异动日的横截面筛选**：识别近期收益相对市场最显眼的标的，配合反转研究；
- **注意力强度的分档变量**：与惊恐度、换手率等联合刻画注意力集中的样本。
