## 金融解释

**衡量什么**：把买盘前五档的挂单量 $\\{\text{BV}_i\\}_{i=1..5}$ 与卖盘前五档的挂单量 $\\{\text{SV}_i\\}_{i=1..5}$ 全部相加，得到盘口可见挂单的**总量**，即盘口整体「厚度」。

**为什么有信息量**：总深度度量的是市场**承接能力**的容量侧——一笔订单在不显著推动价格的前提下，最多能消化多大的量。深度越厚，交易成本越低、价格越不易被单笔订单推动，股票越「流动」。与只取最优档的深度相比，五档总量把价格稍远处的挂单也纳入，度量的是**更广义的容量**：大额交易往往需要扫过多档，因此总深度对大资金的可行性更有解释力。它同时携带**流动性溢价**（深度薄的股票需要更高预期收益补偿）与**信息**（深度骤变往往是流动性提供者根据信息调整库存的痕迹）两重含义。总深度是**无方向**的容量度量，与「哪一侧更厚」（失衡类）正交。

**与相邻字段的区别**：

- [[patterns/fields/最优档深度|最优档深度]]：只取 BV1+SV1，度量**即时**交易成本与容量；总深度度量**包括远档在内**的整体容量，两者在不同规模的交易上各有解释力；
- [[patterns/fields/深度冲击|深度冲击]] / [[patterns/fields/深度变化|深度变化]]：把总深度（或最优档深度）做一阶相对变化，度量深度的**动态**；本字段是**水平**；
- [[patterns/fields/近端失衡|近端失衡]] / [[patterns/fields/加权失衡|加权失衡]]：度量厚度的**方向不对称**，本字段只度量总量、抹去方向；
- [[patterns/fields/相对价差|相对价差]]：从**价格侧**度量交易成本（报价宽度），总深度从**数量侧**度量容量，二者是流动性的两个不同维度。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]]

**赚什么钱**：赚**流动性溢价**的钱——盘口薄（总深度低）的股票交易成本高、变现困难，持有者要求更高预期收益以补偿承担的交易成本，因此低深度与高未来收益相关。

**说明**：本字段为**无方向的容量度量**（买卖两侧相加，取值不随多空力量对比变化），信息不对称只在「深度持续收缩反映流动性提供者的逆向选择担忧」这一间接层面起作用，属二级效应，故不把 `info_asymmetry` 列为主来源。

**对手方**：需要即时成交、付出价格冲击成本的交易者（流动性需求方）；以及流动性枯竭时被迫平仓、无法等待的一方。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（逆向选择与做市意愿）；[[patterns/fields/非流动性|非流动性]]（Amihud 型非流动性定价）。

**失效条件**：

- **流动性危机**：危机中深度集体枯竭且高深度股票也可能被抛售，溢价关系反转；
- **挂单可撤销**：深度是意图而非承诺，做市商可闪电撤单，名义深度远超真实可成交量；
- **涨跌停与制度性零量**：单边深度为 0 时若把制度状态误读为极端非流动性，信号失真。

## 加工公式

```
总深度 = Σ(i=1..5) BV_i + Σ(i=1..5) SV_i
# 各档为零量时的处理口径须统一（置 null / 前向填充 / 记 0）
```

## 适用场景

- **大额交易的容量评估**：需要扫多档成交时，总深度比最优档深度更能解释可行性；
- **流动性风险因子**：作为截面流动性的代理，与其他流动性度量互为稳健性检验；
- **深度动态研究的基准**：先算总深度水平，再取变化得到深度变化/深度冲击。
