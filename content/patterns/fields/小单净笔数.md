## 金融解释

**衡量什么**：小单人群的买单笔数减卖单笔数，再以买卖笔数之和归一化。正值表示散户在**笔数**上净买入（下买单的次数多于下卖单的次数），负值反之。

**为什么有信息量**：笔数口径度量的是**下单频率**而非资金规模。散户的行为特征是「小额、多次」，一笔资金往往对应多次下单，因此笔数净方向更贴近散户**参与意愿的人数/次数**，而量额口径更容易被少数大额散户影响。当散户笔数净买入很高时，说明大量的散户账户正在涌入买单——这是**注意力事件的典型指纹**：新闻、涨幅榜、社交媒体热度会先体现在「更多人下买单」上，而不是「更大的金额」。因此笔数口径对小盘、低价的散户股尤其敏感，常作为情绪强度的代理。

**与相邻字段的区别**：

- [[patterns/fields/小单净流入|小单净流入]] / [[patterns/fields/小单净额|小单净额]]：量、额口径的同族版本；笔数口径对「多少人参与」敏感，量额口径对「多少钱参与」敏感，三者可互为稳健性检验；
- [[patterns/fields/大单净笔数|大单净笔数]] / [[patterns/fields/大单净笔数档|大单净笔数档]]：大额人群的笔数净方向，是「聪明钱」框架的另一侧；
- [[patterns/fields/成交笔数压力|成交笔数压力]]：全部主动成交笔数的净失衡，不区分人群，是「全市场平均方向」。

## 收益来源

本页归属 [[alpha/量激增注意力|量激增注意力]]

**赚什么钱**：主要赚**注意力**的钱——散户下单次数激增是关注度驱动的参与痕迹，关注度带来的买入压力推高价格，随后随注意力衰减而回归；次要赚**行为偏差**的钱——散户在情绪高涨时更多次地买入，是过度自信与追涨行为的直接体现，其错误方向构成反向交易的对手盘。

**对手方**：在关注度高点追入、随后承受回落的散户；以及在散户反复下单推高价格后接盘的后来者。

**理论支撑**：[[alpha/大小单博弈|大小单博弈]]；[[concepts/行为金融凸显理论|行为金融凸显理论]]（注意力与显著收益）。

**失效条件**：

- **小单≠散户**：算法拆单或小额机构委托使小单笔数混入非散户行为；
- **机构化提升**：散户直接参与度下降后，笔数净方向的信息含量减弱；
- **参与人数饱和**：当散户参与已达到上限、笔数不再有增量时，该指标的边际信息下降。

## 加工公式

```
小单买笔数 = max(买笔数 − 超大单买笔数 − 大单买笔数 − 中单买笔数, 0)
小单卖笔数 = max(卖笔数 − 超大单卖笔数 − 大单卖笔数 − 中单卖笔数, 0)
小单净笔数 = 归一化失衡(小单买笔数, 小单卖笔数)
# 分母近零置 null；剩余法负值截断为 0
```

## 可变异维度

- 口径：笔数 → 量
- 规模档：小单 → 全部

## 适用场景

- **关注度/情绪事件的细粒度代理**：笔数口径能更早捕捉「更多人进场」，适合事件驱动研究；
- **小盘、低价、散户主导标的**：这类标的散户笔数多，统计更稳，区分度更高；
- **与量额口径交叉验证**：三口径同号时情绪信号更可信。
