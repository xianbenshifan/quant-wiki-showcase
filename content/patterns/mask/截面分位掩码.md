## 金融解释

**做什么**：以**截面 rank 百分位**为切点，对列做布尔状态掩码：某标的在当日横截面中的排序位置落在指定百分位一侧为真、其余为 NaN（不选中）。

**为什么用 rank 而不是分位值**：这里比较的是**截面内的排序位置**（rank / count），而不是数值的分布分位点。rank 口径对分布形状与离群值更稳健——即使截面上有个别极端值把分布拉出厚尾，rank 仍把每只股票放进等宽的百分位格子。这使它适合「取截面最前 / 最后的一批」，而不受少数异常值扭曲。

**与分位掩码的区别**：[[patterns/mask/分位掩码|分位掩码]] 通常是**时序**口径（每股相对自身历史），回答「它相对自己的历史处于什么位置」；截面分位掩码是**横截面**口径，回答「它在当天的市场里排第几」。前者适合单股状态因子，后者适合「横截面分组对比」——如把当日流动性最高的 20% 与最低的 20% 分组对照。

**为什么有信息量**：很多命题本身就是横截面的——「横截面流动性最高的组是否定价更有效」「波动率最大的组是否有更高的风险补偿」。截面分位掩码提供了在**同一时点**上把标的切成可对比组别的工具，天然控制了市场共同因子。

同一截面 rank 机制可参数化为两种**判定方向**（见「掩码条件」），金融语义对称：

- **上尾**（截面 rank 百分位 ≥ $q$）：截面内排名靠前的组，如当日截面流动性前 20%；
- **下尾**（截面 rank 百分位 ≤ $q$）：截面内排名靠后的组，如当日截面流动性后 20%。

## 掩码条件

以截面 rank 百分位 $q$ 为切点，两种判定方向：

```
data: ur → mask: 截面分位掩码(q, direction) → agg: mean
```

| 方向 | 判定 | 语义 |
|------|------|------|
| 上尾 | `cs_rank(x) / count ≥ q` | 截面靠前（`cs_quantile_ge`） |
| 下尾 | `cs_rank(x) / count ≤ q` | 截面靠后（`cs_quantile_le`） |

$q \in (0, 1)$。上尾 / 下尾可组合成「截面两尾」（两端）或「截面中枢」（中间带）。长表按 per-Datetime 分截面，宽表按整表分截面。


## 适用场景

- **横截面分组对比**：流动性 / 波动 / 换手率头尾组对照，是最常见的骨架；
- **截面极值取样**：只保留当日最极端的一批标的做事件研究；
- **配合市场指标列**：先物化市场级指标，再对个股做截面 rank；
- 标的数量充足、截面分布相对均匀的市场（A 股全市场）区分度最好。

## 边界与陷阱

- **截面边界随样本变动（数据层）**：可交易股票集合在期与期之间变化（新股、停牌、ST），rank 的绝对门槛含义会漂移；
- **长表 / 宽表口径（计算层）**：长表须按每个 Datetime 单独分截面，宽表按整表分截面；口径混用会得到完全不同的分组；
- **与分位掩码口径混用（概念层）**：时序分位与截面 rank 回答不同问题，命题是「相对自身」还是「相对市场」必须明确；
- **缺失值参与 rank（数据层）**：停牌 / 无数据若参与排序会占用 rank 位置、扭曲百分位，须先剔除。

## 可变异维度

- 方向：上尾 / 下尾（可组合两尾 / 中枢）
- $q$：0~1
- 截面维度：per-Datetime（长表） / 整表（宽表）
- 口径：截面 rank 百分位（默认） vs 截面分位值比较（见 [[patterns/mask/分位掩码|分位掩码]]）
