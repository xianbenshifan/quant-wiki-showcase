## 金融解释

**衡量什么**：最优买价与最优卖价上挂单量之和 $\text{best\_depth} = BV_1 + SV_1$，即最接近成交价位的挂单厚度。

**为什么有信息量**：最优档是**冲击成本的第一道防线**。任何一笔市价单都要先吃掉最优档的挂单，才能推动价格向下一档移动。因此最优档越厚，同等成交量的瞬时价格冲击越小、成交越容易在接近报价的位置完成；最优档越薄，盘口越脆弱，一笔中等规模的主动单就可能把价格打穿多档。它是刻画**即时流动性缓冲**最直接的存量指标，也是很多流动性、执行成本、脆弱性类因子的基础输入。

**与相邻字段的区别**：

- [[patterns/fields/总深度|总深度]]：把五档买卖量全部加总，衡量的是整段盘口的承接能力；最优档深度只聚焦「成交发生的那一档」，对即时冲击更敏感。二者结合可判断深度是「集中在最优档」还是「分散在深档」。
- [[patterns/fields/相对价差|相对价差]]：度量的是**价格维度**的即时交易成本（买卖价差宽度），最优档深度度量的是**数量维度**的缓冲；一个宽价差配一个厚最优档，与窄价差配薄最优档，执行含义完全不同。
- [[patterns/fields/深度变化|深度变化]] / [[patterns/fields/深度冲击|深度冲击]]：度量最优档（或总）深度的**变化率**，是流量概念；本字段是存量水平。
- [[patterns/fields/凸度差|凸度差]] / [[patterns/fields/斜率失衡|斜率失衡]]：从多档形状出发，本字段只看第一档。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]]

**赚什么钱**：赚**流动性溢价**。最优档深度度量的是「即时流动性供给」的厚度：挂着大量最优档买单 / 卖单的参与者，实际上是在为急于成交的市场提供即时流动性，并承担被逆向选择（被知情者吃掉挂单）和价格冲击的风险。市场必须为这种服务支付补偿——最优档薄、冲击成本高的股票，其预期收益中应包含更高的流动性补偿。

**对手方**：需要立即成交、主动吃掉最优档挂单并承担冲击成本的急躁交易者；以及在流动性紧张时被迫以不利价格变现的持仓者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（价差与深度中的逆向选择成分）。

**失效条件**：

- **隐藏流动性充裕**：冰山单、隐藏单在场外提供承接，可见最优档深度低估真实缓冲，溢价被高估；
- **算法快速补单**：高频做市使最优档被吃掉后瞬间补充，瞬时深度与长期流动性供给脱钩；
- **流动性环境整体宽松**：市场层面流动性充裕时，个股间最优档深度差异被摊薄，溢价收窄。

## 加工公式

```
best_depth = BV_1 + SV_1          # 仅当 BV_1 > 0 且 SV_1 > 0，否则 null
avg_depth  = (BV_1 + SV_1) / 2    # 平均形式，等于 best_depth / 2
```

## 派生形态

- **盘口平均深度**：对最优档深度取平均形式 `avg_depth=(BV1+SV1)/2`，再按日做均值聚合为日频因子（任一档为 0 则该 bar 记 0）→ [[paradigms/盘口平均深度|盘口平均深度范式]]。

## 适用场景

- 作为**即时流动性 / 冲击成本**的存量代理，用于流动性因子、脆弱性因子；
- 与 [[patterns/fields/相对价差|相对价差]] 组成二维流动性画像：价差看成本、深度看容量；
- 与 [[patterns/fields/总深度|总深度]] 对比，判断流动性是集中在最优档还是分布在深档；
- 在**分钟级、报单连续**的标的上更可靠；对报单稀疏、最优档常年为 0 的标的须做缺失处理。

## 可变异维度

- 档位：1 → 2/3 档
- 口径：和 (BV1+SV1) → 平均 (BV1+SV1)/2
