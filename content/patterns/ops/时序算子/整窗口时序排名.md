## 金融解释

**做什么**：对每个合约的整段样本，计算当前值在其中的百分位位置（rank / count），输出 0~1。窗口即该合约的全部可见数据。

**为什么有信息量**：排名是**分布无关**的相对位置度量——不假设分布形状、不受量纲与极端值影响，只回答「当前值在过去所有读数里排第几」。它把「高低」转成可跨标的、跨时间比较的 0~1 刻度，天然适合构造状态（历史高位 / 低位）、阈值与掩码。

**与相邻构件的分工**：[[patterns/ops/时序算子/整窗口分位数|整窗口分位数]] 是它的反函数式搭档——排名回答「当前值排第几」，分位数回答「第几名对应多大的值」。[[patterns/ops/时序算子/滚动排名|滚动排名]] 的基准是近窗口，度量「相对近期的位置」（时变、灵敏）；本页基准是整段，度量「相对长期的位置」（稳定、迟钝）。[[patterns/ops/截面算子/截面排名|截面排名]] 的基准是同一时点跨股票，回答「当天在全市场排第几」。三者基准不同，含义不可互换。

## 算子定义

```
global_rank(x)         # 当前值在整段样本中的 rank / count（0~1）
```

- 当前值参与自身排名；并列值口径（平均名次 / 最小名次）须统一；
- 实现上常以广播形式回填，但输出逐行随当前值变化。

## 适用场景

- **时序状态**：相对自身历史的高位 / 低位划分；
- **可比位置**：把不同量纲、不同分布的序列映射到同一 0~1 尺度；
- **掩码与阈值来源**：如「排名 > 0.8」切出历史高位组；
- **与分位数配对**：一个给位置、一个给数值门槛。

## 边界与陷阱

- **前视风险**：整段含未来行，早期行的排名用到了后续样本，回测会系统性高估区分度；实盘须用滚动或扩张排名；
- **样本量决定分辨率**：整段样本少时排名被离散化成少数档位，跨标的比较变粗；
- **并列值主导**：大量重复值（如零成交）时排名口径会显著改变结果；
- **与截面排名混淆**：自身历史位置与同期横截面位置回答不同问题，切勿混用。

## 可变异维度

- 对象：任意列
- 基准长度：整段 → 扩张 / 滚动
- 维度：时序排名 → 截面排名
