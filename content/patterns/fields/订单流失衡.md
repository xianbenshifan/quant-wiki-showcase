## 金融解释

**衡量什么**：对五档分别计算归一化订单流增量 $\text{ofi}_i = (\Delta BV_i - \Delta SV_i)/(BV_i + SV_i)$（经 1% 时序缩尾），再用距离衰减权重 $(6-i)/15$ 聚合：$\text{mlofi} = \sum_{i=1}^{5}(6-i)\cdot\text{ofi}_i/15$。近档权重最大（5/15），远档权重最小（1/15），是「越靠近成交、越重要」这一微观结构直觉的显式编码。

**为什么有信息量**：OFI 度量的是挂单量的边际净流入，而非存量失衡。买侧挂单净增、卖侧净减，说明买盘正主动向成交价逼近——这是知情交易者建仓的典型痕迹，也是价格在短期内被推动的前兆。OFI 之所以在微观结构文献中地位突出，是因为它把「挂单的更新流」与「价格冲击」联系了起来：价格变动在很大程度上可由 OFI 线性解释，因此 OFI 既是价格压力的度量，也是订单流毒性的度量。加权聚合在近档高信噪比与深档稳健性之间取得折中。

**与相邻字段的区别**：

- [[patterns/fields/浅档订单流失衡|浅档订单流失衡]]：只取 1–2 档、等权，对短时冲击最敏感、噪声最大；本页五档加权，噪声更低、覆盖更全。
- [[patterns/fields/深档订单流失衡|深档订单流失衡]]：只取 3–5 档，反映盘口深处供需，偏中期；本页把近档与深档统一到一条加权曲线。
- [[patterns/fields/近端失衡|近端失衡]]：最优档的**存量水平** $BV_1 - SV_1$，不含差分；OFI 是**增量流量**，二者机制不同且常有领先关系。
- [[patterns/fields/撤单失衡|撤单失衡]]：度量撤单行为的方向；OFI 度量挂单净增量的方向，可区分「新增挂单」与「既有挂单被撤」。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：其一为**信息不对称**——知情者通过主动单与挂单调整在盘口留下 OFI 方向，跟随该方向可在信息扩散前建仓，这是订单流毒性的直接变现；其二为**流动性溢价**——OFI 刻画挂单在地点与时间上的迁移，一侧挂单持续净撤意味着流动性供给收缩，剩余提供者要求更高补偿。

**对手方**：在盘口以被动挂单成交、被知情单吃穿的流动性提供者；以及反应滞后、在 OFI 已推动价格后才跟随的交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **做市算法主导**：高频做市使挂单快速增撤，OFI 更多反映库存管理而非信息意图；
- **拆单 / 冰山单**：真实大单被隐藏，可见 OFI 低估其强度，方向可能滞后或失真；
- **制度性盘口**：涨跌停、集合竞价、临时停牌使盘口结构退化，OFI 失去正常微观含义。

## 加工公式

```
ofi_i = ts_winsorize( ratio(ΔBV_i - ΔSV_i, BV_i + SV_i), 1% )   # i = 1..5
mlofi = sum_{i=1..5} (6 - i) * ofi_i / 15
# 分母近零置 null；Δ 为相对上一期的差分
```

## 适用场景

- 构造**短中期价格压力 / 知情交易**信号：五档加权比单档更稳健，适合分钟到日频；
- 作为**执行算法**的即时状态输入，与浅档、深档版本分层使用；
- 与 [[patterns/fields/近端失衡|近端失衡]] 配对，观察「存量状态 + 增量流向」的共振；
- 与 [[patterns/fields/撤单失衡|撤单失衡]] 组合，区分挂单净增的两种来源。

## 可变异维度

- 卷积核：(6-i)/15 → 等权/对数权重
- 档位：1-5 → 1-10
