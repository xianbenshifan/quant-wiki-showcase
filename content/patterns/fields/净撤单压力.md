## 金融解释

**衡量什么**：先分别计算两侧的**撤单压力**——买撤单量 / 买入成交量、卖撤单量 / 卖出成交量，再取二者之差。正值表示买侧的撤单相对其成交更活跃，即买盘挂单更「靠不住」；负值反之。它与 [[patterns/fields/撤单失衡|撤单失衡]] 的关键差异在分母：撤单失衡只在撤单量内部做比，而本字段把撤单放到**实际成交量**的尺度上衡量。

**为什么有信息量**：撤单是「挂出来又收回」的动作，不产生成交却能改变盘口，因此撤单的方向是判断**名义供需可信度**的窗口。用实际成交量做分母，回答的是「相对于真实发生的交易，挂单被撤回的力度有多强」——这比单纯的撤单量差更能穿透个股活跃度的差异：一笔撤单在成交清淡的股票上是重大信号，在巨量成交的股票上可能微不足道。哪一侧的撤单相对成交更密集，那一侧的名义支撑/阻力就更可能是虚假的；由于撤单发生在成交之前，该字段带有领先性。

**与相邻字段的区别**：

- [[patterns/fields/撤单失衡|撤单失衡]]：分母是撤单总量，衡量撤单量的**内部**方向，不含成交参照；本字段以成交为尺，度量「相对真实的撤单力度」。
- [[patterns/fields/净撤单笔数压力|净撤单笔数压力]]：同一构想的**笔数口径**，对撤单频率敏感；本页是**量口径**，对被抽走的盘口容量敏感，且笔数版常配以有符号对数压缩。
- 大单净撤单压力：把主体限定为大单/超大单，刻画大资金的意图；本页不区分人群，是「全市场」口径。
- [[patterns/fields/撤单强度时序单位比率|撤单强度时序单位比率]]：只度量撤单**总量**占挂单的比例（无方向），与本页正交。

## 收益来源

本页归属 [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：主要赚**信息不对称**的钱——撤单的相对力度与方向暴露了策略性交易者和做市方的报价意图。一侧的挂单被相对其成交大量撤回，意味着该侧的名义供给是「虚」的，这一信息在成交价格中尚未体现，据此可判断真实承接力并提前布局。

**对手方**：依据盘口挂单判断支撑/阻力、把随时可撤的挂单当作真实供需的交易者；他们在撤单发生后才发现名义流动性消失，被动承受价格冲击。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（策略性委托与逆向选择）。

**失效条件**：

- **撤单监管/费用上升**：撤单成本提高会系统性压低两侧撤单量、改变撤单结构，使该差值的含义与量级漂移；
- **算法报价主导**：做市算法的高频报价更新（含改价）使撤单成为常态噪声，方向性不再对应意图；
- **改价计入撤单**：若数据源把改价计为撤单，买侧正常的报价调整会污染净压方向。

## 加工公式

```
买撤单压力 = 买撤单量 / 买入成交量
卖撤单压力 = 卖撤单量 / 卖出成交量
净撤单压力 = 买撤单压力 − 卖撤单压力
# 两侧成交量近零置 null；口径可换为笔数
```

## 可变异维度

- 分母：实际成交量 → 挂单总量
- 口径：量 → 笔数

## 适用场景

- **名义盘口可信度判断**：在挂单量与实际成交明显不匹配时，识别哪一侧的供给是虚的；
- **与撤单失衡配对使用**：失衡给「哪侧撤得多」、本字段给「相对成交撤得多重」，二者同向时信号更稳；
- **活跃度差异大的截面**：以成交为分母使不同活跃度的股票可比，适合宽池横截面。
