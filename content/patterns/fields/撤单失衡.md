## 金融解释

**衡量什么**：买侧撤单量与卖侧撤单量的归一化差：$\text{撤单失衡} = (\text{买撤单量} - \text{卖撤单量})/(\text{买撤单量} + \text{卖撤单量})$。正值表示撤单集中在**买方**（买单退得更快），负值表示撤单集中在**卖方**。

**为什么有信息量**：撤单是「挂出来又收回」的动作，它**不产生成交却能改变盘口**，因此撤单的方向是观察**名义供需可信度**的窗口。哪一侧的挂单被大量撤回，那一侧的名义支撑/阻力就是「虚」的：

- **买侧撤单占优**（正失衡）：原本显示的买盘支撑在退却，说明买方意愿不坚定，名义买盘不足以承接抛压，价格更易走弱；
- **卖侧撤单占优**（负失衡）：名义卖压在收缩，若同时伴随价格企稳，则可能意味着抛售意愿减弱。

它比成交方向更早：因为撤单发生在成交之前。这是它区别于所有「成交类」方向字段的核心——成交是**已发生**的供需，撤单是**意图层面**的供需变化，带有领先性。它也是撤单家族里最基本的一维（只看方向、不分人群、不做归一化强度），其余撤单字段（大小单撤单压力、撤单背离、撤单强度）都是它的细化。

**与相邻字段的区别**：

- [[patterns/fields/撤单笔数失衡|撤单笔数失衡]]：同构的**笔数口径**版本，对撤单频率敏感；本页是**量口径**，对盘口容量被抽走的幅度敏感；
- [[patterns/fields/净撤单压力|净撤单压力]]：分母用**实际成交量**而非撤单总量，且分别对买卖两侧标准化（买撤/买成交 − 卖撤/卖成交），度量的是「相对成交的撤单压力」；本页只用撤单量内部做比，不含成交；
- [[patterns/fields/撤单强度时序单位比率|撤单强度时序单位比率]]：只度量撤单**总量**占挂单的比例，不含方向；本页只度量**方向**，不含强度；
- [[patterns/fields/大单小单撤单背离|大单小单撤单背离]]：在人群间比较撤单方向，本页是全市场不分人群的总方向。

## 收益来源

本页归属 [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：主要赚**信息不对称**的钱——撤单方向的异常暴露了策略性交易者（做市方、大资金）的真实意图：一侧挂单的快速撤离往往是其调整仓位或撤出支持的信号，这一意图在成交发生前即可观察到，构成信息优势。识别出「名义支撑/阻力不可信」的一方，可据此提前布局。

**对手方**：依据盘口挂单判断支撑/阻力、把随时可撤的挂单当作真实供需的交易者；他们在撤单发生后才发现名义流动性消失，被动承受价格冲击。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（策略性委托与逆向选择）；[[alpha/大小单博弈|大小单博弈]]（撤单行为的群体差异）。

**失效条件**：

- **撤单成本上升**：撤单费、频繁撤单监管会整体压低撤单量并改变其结构，字段含义被系统性削弱；
- **算法报价主导**：做市算法的高频报价更新使撤单成为常态噪声，方向性不再对应意图；
- **改价口径混入**：若数据把「改价」计为撤单，撤单失衡会混入正常的报价调整，方向信号被稀释。

## 加工公式

```
撤单失衡 = 归一化失衡(买撤单量, 卖撤单量)
         = (买撤单量 − 卖撤单量) / (买撤单量 + 卖撤单量)
# 分母近零置 null；口径可换为笔数/额
```

## 可变异维度

- 口径：量 → 笔数/额
- 频率：可调

## 适用场景

- **名义支撑/阻力的可信度判断**：盘口有大量挂单却持续撤单时，提示该侧供需是「虚」的；
- **短周期方向信号的前哨**：撤单先于成交，可用于分钟—日频的早期方向识别；
- **与撤单强度联合**：强度高（撤单多）+ 方向明确时信号最强。
