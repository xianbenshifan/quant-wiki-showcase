## 金融解释

**做什么**：在窗口内取指定分位 q 的值，逐点输出。如滚动 90% 分位给出近期的高分位刻度。

**为什么有信息量**：分位数是**相对门槛**，随窗口滚动自动适应分布变化，常用于构造时变的尾部阈值：滚动高分位可作「近期高点 / 卖压线」，低分位作「近期低点 / 支撑线」，滚动中位数（q=0.5）作稳健中枢。相比极值，分位数对单点异常稳健——0.9 分位不会被单个极大值主导，因此比 max/min 更适合做尾部刻度。

**与相邻构件的分工**：[[patterns/ops/时序算子/滚动中位数|滚动中位数]] 是 q=0.5 的特例；[[patterns/ops/时序算子/滚动分位截断|滚动分位截断]] 用分位阈值去做变换，本页只输出阈值本身；[[patterns/ops/时序算子/整窗口分位数|整窗口分位数]] 基准是整段（长期刻度）。[[patterns/ops/时序算子/滚动最大值|滚动最大值]] 与 [[patterns/ops/时序算子/滚动最小值|滚动最小值]] 是极端次序统计量（对应 0 / 1 分位），对离群敏感。高分位与低分位之差还是窗口离散度的稳健度量。

## 算子定义

```
rolling_quantile(x, window, q)   # 窗口内第 q 分位
```

- q ∈ (0,1)；窗口不足按 min_samples 置空；
- 分位插值口径（线性 / 最近邻）须统一。

## 适用场景

- **滚动尾部阈值**：如 90% 分位作近期上界；
- **VaR 式风险线**：低分位作下行阈值；
- **稳健离散度**：分位差替代极差；
- **阈值来源**：配合滚动分位截断、滚动排名。

## 边界与陷阱

- **样本量要求**：极端分位（0.95、0.99）需远多于 $1/(1-q)$ 个样本，短窗口估计极不稳；
- **输出阶梯性**：窗口滑动时次序统计量会离散跳变，阈值不够平滑；
- **min_samples**：窗口不足置空会造成暖机段、减少可用样本；
- **与截面分位混淆**：时序分位与同期横截面分位回答不同问题。

## 可变异维度

- 窗口：可调
- q：0~1
- 基准：滚动 → 整段 / 截面
