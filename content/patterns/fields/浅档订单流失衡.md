## 金融解释

**衡量什么**：订单流不平衡（OFI）度量的是某一档挂单量相对上一期的**净增量**方向：$\text{ofi}_i = \Delta BV_i - \Delta SV_i$，再除以 $BV_i + SV_i$ 归一化。浅档版本只取第 1、2 档并等权平均：$\text{mlofi\_shallow} = (\text{ofi}_1 + \text{ofi}_2)/2$。

**为什么有信息量**：最优档与次优档是成交最先发生、也是知情者下达主动单时最先被吃 / 最先补充的地方。浅档 OFI 因而对**短时价格冲击**最敏感——买侧挂单持续净增、卖侧净减，说明买盘在向成交价逼近，价格上行压力大；反之亦然。与「存量失衡」不同，OFI 看的是**流量的边际变化**，它捕捉的是流动性提供者的即时行为与方向性意图。

**与相邻字段的区别**：

- [[patterns/fields/深档订单流失衡|深档订单流失衡]]：取第 3–5 档，反映盘口深处的挂单变化，更多关联大宗承接与流动性缓冲的慢变量；浅档更快、更贴近短期冲击，深档更慢、更贴近中期供需结构。
- [[patterns/fields/订单流失衡|订单流失衡]]：五档按距离加权聚合（近档权重大），是浅档与深档的折中；浅档版本把权重完全压在最近两档，信噪比更集中但也更易被单档噪声主导。
- [[patterns/fields/近端失衡|近端失衡]]：比较的是最优档的**存量水平** $BV_1 - SV_1$，不含时间维度的增量；OFI 是**Δ 流量**，二者可同时使用且常有领先 / 滞后关系。
- [[patterns/fields/微价格偏离|微价格偏离]]：把最优档挂单量差异映射为价格的加权偏离，是价格版的同源信息。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：其一为**信息不对称**——知情者用主动单在浅档集中执行，浅档 OFI 的方向正是其意图的早期痕迹，跟随它可在信息扩散前建仓；其二为**流动性溢价**——浅档挂单的净增减直接改变即时流动性的松紧，净撤单一侧等于在收回流动性，为继续提供流动性的一侧创造补偿空间。

**对手方**：在浅档以挂单形式被动成交、被知情单吃掉的流动性提供者；以及反应滞后、在价格已被浅档 OFI 推动后才跟随的交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **高频做市主导**：浅档挂单被算法高频补充与撤销，OFI 方向更多反映做市库存管理而非信息，信号被稀释；
- **拆单与冰山单**：真实大单被拆分或隐藏，浅档可见增量低估其强度，方向可能失真；
- **制度性冲击**：涨跌停、集合竞价、盘中临时停牌使浅档结构退化，OFI 失去正常含义。

## 加工公式

```
ofi_i  = ts_winsorize( ratio(ΔBV_i - ΔSV_i, BV_i + SV_i), 1% )   # i = 1, 2
mlofi_shallow = (ofi_1 + ofi_2) / 2
# 分母近零置 null；Δ 为相对上一期的差分
```

## 适用场景

- 构造**短周期**（分钟到日内）价格压力 / 知情交易信号：浅档 OFI 的领先性在短周期最强，随窗口拉长衰减；
- 作为**执行算法**的即时状态输入：判断当前应加速还是等待；
- 与 [[patterns/fields/深档订单流失衡|深档订单流失衡]] 配对，观察「浅档先动、深档跟随」的传导顺序；
- 在**报单连续、tick 数据完整**的活跃标的上更有效；冷门标的浅档常年稀疏，OFI 噪声大。

## 可变异维度

- 档位：1-2 → 1-3 档
- 权重：等权 → 加权
