## 金融解释

**衡量什么**：单位时段内的成交金额除以成交数量，即成交量加权平均价（VWAP）。有两个口径：**全量口径** $\text{成交额}/\text{成交量}$，以及**增量口径**（对日内累计量额先做一阶差分再相除）$\text{成交额增量}/\text{成交量增量}$。

**为什么有信息量**：VWAP 本身是一个**价格水平**，不携带买卖方向，但它是几乎所有「溢价/折价」类字段的**共同基准**。大单买溢价、大单卖溢价、撤单溢价都要回答「某类订单的成交/委托价格相对市场平均是高还是低」，而市场平均就是 VWAP。之所以用 VWAP 而非收盘价作基准，是因为 VWAP 对全时段的成交量加权，不易被尾盘少数几笔大单操纵，更能代表「当日真实成交的平均成本」。它也是执行算法最重要的业绩基准（成交价相对 VWAP 的正负决定交易好坏）。因此它虽中性，却是量价体系里的**坐标原点**。

**两个口径的差异**：全量口径给出的是时段内的整体均价；增量口径给出的是**当前 bar** 的边际成交价。研究单笔/单 bar 层面的价格冲击时须用增量口径——否则前期累计成交会把当前价格稀释。注意高频库中量额常为日内累计值，增量口径必须先差分。

**与相邻字段的区别**：

- [[patterns/fields/中间价|中间价]]：用买卖一价平均，代表**尚未成交**的盘口均衡价；VWAP 用**已成交**加权，两者分别对应「报价基准」与「成交基准」；
- [[patterns/fields/收益率|收益率]]：价格的**变化率**；VWAP 是价格的**水平**，不可互相替代；
- [[patterns/fields/大单买溢价|大单买溢价]] / [[patterns/fields/大单卖溢价|大单卖溢价]]：以 VWAP 为基准的溢价字段，是本字段的直接下游。

## 加工公式

```
VWAP（全量口径） = 成交额 / 成交量
VWAP（增量口径） = 成交额增量 / 成交量增量   # 仅当成交量增量 > 0
# 分母近零置 null；累计口径须先差分还原增量
```

## 可变异维度

- 口径：全量 → 增量
- 频率：5min → 1min

## 适用场景

- **作为溢价/折价字段的基准价**：所有衡量「某类订单成交价高低」的字段都以它为参照；
- **执行质量评估**：把实际成交价与 VWAP 比较，衡量交易是否优于市场均价；
- **量价关系建模**：作为单位时间的平均成交成本，与收益、波动配对研究。
