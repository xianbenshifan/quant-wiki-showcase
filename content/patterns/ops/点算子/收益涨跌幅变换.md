## 金融解释

**做什么**：对**正的水平量**序列（价格、成交额等）计算区间变化率 $\text{pct\_chg} = x_t / x_{t-k} - 1$。它要求两期取值都为正（否则比率会产生无经济含义的伪收益），并可衍生三种形态：$\text{abs}$（绝对值 → 波动强度）、$\text{ex}$（截面去中位 → 相对超额），再配合对数压缩抑制极端。

**为什么单列一页**：把「水平」转成「变化」是收益类因子的第一步。价格的水平本身没有横截面可比性（高价股与低价股不可直接比较），变化率才可比、才与「赚了多少」直接挂钩。正值约束是为了避免负值序列（如净流入、价差）在比率域产生无意义的数值。

**它与收益率变换的分工**：本页是「变换族」的语义约定（含 abs / ex 衍生、log_scale 压缩、正值约束），[[patterns/ops/点算子/收益率变换|收益率变换]] 是更基础的「前值之比减一」实现；二者同源，本页强调衍生形态与正值口径，后者强调逐点实现与滞后 $k$。

## 算子定义

```
pct_chg(x, k) = x_t / x_{t-k} - 1        # 仅当 x_t > 0 且 x_{t-k} > 0，否则 null
abs_form      = |pct_chg|                 # 波动强度
ex_form       = pct_chg - median_cs(pct_chg)    # 相对超额（去截面中枢）
# 可选 log_scale = sign(v) * ln(1 + |v|) 压缩极端
```

## 适用场景

- 价格 → 收益（动量 / 反转）的基础构造；
- 成交额 / 成交量的变化率（活跃度变化）；
- 多期收益（$k=2/5/20$）与相对超额形态；
- 需要强度而非方向时用 $\text{abs}$ 形态。

## 边界与陷阱

- **正值约束的样本代价**：两期任一期非正即置空，负值序列会整段失效，须改口径或改用 [[patterns/ops/时序算子/差分|差分]]；
- **前值不可靠**：停牌、复权、口径变更会让 $x_{t-k}$ 失真，产生伪收益；跨停牌应置空或按可交易日对齐；
- **$k$ 决定含义**：$k=1$ 是相邻期变化，$k=20$ 是月度动量，经济含义完全不同，须与命题匹配；
- **与差分的区别**：差分 $x_t - x_{t-k}$ 保留量纲、可正可负；变化率无量纲、强调相对幅度，跨量级可比；
- **`ex` 形态的口径**：去截面中位会改变符号含义（相对超额），与原始变化率不能混用。

## 可变异维度

- lag：1 → 2 / 5 / 20（多期收益）
- 去均值：截面中位 → 截面均值 / 市场基准
- 应用：收盘价 → 任意正水平量（成交额占比等）
