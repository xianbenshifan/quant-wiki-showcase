## 金融解释

**衡量什么**：分别用**量**口径计算大单与小单的撤单率净压——「买撤量 / 买量 − 卖撤量 / 卖量」，再取两者之差。正值表示大单相对小单更偏撤买（大单在撤回买单这一侧更积极），负值表示大单相对更偏撤卖。

**为什么有信息量**：这是撤单家族里「分歧」思想的量口径实现。它不关心撤单总量，只关心**大资金与小资金的撤单方向是否相反**。当两类人群在同侧撤单（都撤买或都撤卖），差值趋近于零，尽管盘口名义深度可能在快速蒸发，该字段却给出弱信号——这恰恰是它的设计意图：把「共识性的撤单噪声」滤掉，只留下**知情者与散户之间的行为错位**。大资金在撤买单、散户在撤卖单，说明两类人对后市的判断相反，而历史经验上大资金方向更具预测力。

**量口径的独特价值**：撤单的**金额**而非笔数，更能反映「被抽走的盘口容量」。幌骗之所以有效，往往依赖在关键价位堆放**大额**挂单再瞬间撤走，制造虚假的供需；用撤单量度量的背离，对这种「以量压价」的策略更敏感。

**与相邻字段的区别**：

- [[patterns/fields/大单小单撤单笔数背离|大单小单撤单笔数背离]]：同一构想的笔数口径版本，对撤单**频率**敏感；本页对**容量**敏感。二者互补，宜并置而非择一；
- [[patterns/fields/大单小单背离|大单小单背离]]：用**成交量**衡量大小资金方向分歧，度量已成交的分歧；本页用**撤单量**，度量未成交的意图分歧。前者是「做了什么」，后者是「想做什么又收回」；
- [[patterns/fields/撤单失衡|撤单失衡]]：只看全市场买撤与卖撤的净方向，不区分人群，因此无法分离「知情 vs 大众」；
- [[patterns/fields/小单净撤单压力|小单净撤单压力]]：只取小单人群的撤单净压，是背离公式的一个减项。

## 收益来源

本页归属 [[alpha/大小单博弈|大小单博弈]]

**赚什么钱**：主要赚**信息不对称**的钱——大单撤单方向的相对异常是策略性交易者意图的直接暴露；买卖撤单的错位方向预示了盘口支撑/阻力的真实强弱，而这类信息尚未体现在成交价中。次要赚**行为偏差**的钱——小单撤单率是大众人群情绪反复的代理，背离刻画了知情的冷静与大宗的躁动之间的落差，落差越大，情绪定价偏离越可能反转。

**对手方**：依据名义盘口深度与挂单量做判断、却被撤单误导的交易者（以为某价位有坚实支撑/阻力，实则挂单随时可撤）；以及在情绪反复中被动接盘/割肉的散户。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（策略性委托与信息优势）；[[alpha/大小单博弈|大小单博弈]]（小单撤单的情绪性）。

**失效条件**：

- **撤单被算法全面接管**：当大小单的撤单行为都主要来自执行算法的随机化处理时，人群间差异不再对应信息差异；
- **监管抑制幌骗**：对虚假挂单的处罚提高使撤单量整体下降，且策略性撤单与正常撤单更难区分；
- **大宗/协议交易占比高**：盘口撤单（连续竞价）在总成交中占比很低时，字段的截面区分度被摊薄。

## 加工公式

```
大单撤单净压 = 大单买撤量 / 大单买量 − 大单卖撤量 / 大单卖量
小单撤单净压 = 小单买撤量 / 小单买量 − 小单卖撤量 / 小单卖量
大单小单撤单背离 = 大单撤单净压 − 小单撤单净压
# 小单量可由「总量 − 大/中单量」剩余法定义并截断非负；各分母近零置 null
```

## 可变异维度

- 口径：量 → 笔数
- 撤单率：撤/挂 → 撤/成

## 适用场景

- **识别策略性撤单造成的虚假盘口**：在大额挂单频繁出现又消失的价位，该字段可提示哪一侧的供给是「虚」的；
- **与笔数口径联合**：量、笔数背离同号时信号更可信，异号时提示存在单笔巨额撤单或大量小额撤单，需人工判读；
- **短周期横截面选股**：日频以上信号衰减较快，更适合日内—日频的短持有期框架。
