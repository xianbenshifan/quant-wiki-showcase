## 金融解释

**做什么**：两列逐点相除 $a/b$，分母近零或非有限时置空。与 [[patterns/ops/点算子/安全比值|安全比值]] 是同一语义的两种命名——一个强调「比值」的金融含义，一个强调「除法」的运算形式。

**为什么单列一页（以及为什么不重复）**：它为二元除法提供统一的除零守卫，是许多二元构造（失衡、杠杆、强度）的基础运算。由于与安全比值语义一致，本页只补充「运算层」的用法与约定，避免库里出现两套不一致的除零口径。

## 算子定义

```
div(a, b) = a / b
# |b| < eps 或非有限 -> null
```

## 适用场景

- 任意两列的逐点比率合成；
- 作为复合比值的中间步骤（先除后减 / 乘）；
- 分母含零或缺失的字段对。

## 边界与陷阱

- **与安全比值重复**：二者不应产生两套守卫语义；若下游混用，同一构造在不同脚本里口径会不一致，须统一到一处约定；
- **零除与「无意义」要区分**：分子为零、分母正常时结果为零（有意义）；分子非零、分母近零时置空（无意义）——两者不能都置零；
- **量纲随输入变化**：$a/b$ 的量纲取决于分子分母，跨字段复用时要检查结果是否仍是目标经济量；
- **与逐点乘的对称性**：除以 $b$ 与乘 $1/b$ 不等价（后者会先制造 Inf），不要用乘法绕过守卫。

## 可变异维度

- 分子 / 分母：任意语义
- 阈值：可调
