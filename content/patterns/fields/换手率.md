## 金融解释

**衡量什么**：换手率 = 成交量 / 流通股本，即单位流通盘在给定窗口内被交易的比例。它把成交量的**绝对规模**转换为**相对股本的比例**，从而剔除市值与股本大小的差异——一只小盘股成交几百万股可能已是高换手，一只大盘股成交同样股数则微不足道。

**为什么有信息量**：换手率度量的是**交易活跃度**，而活跃度与**信息含量、关注度、投资者情绪**高度相关：

- 高换手意味着当日有大量筹码易手，新的持有人带来了新的预期，信息更容易被吸收进价格——因此高换手股票的价格往往**信息含量更高**，其收益的持续性/反转性也更可靠；
- 换手也是关注度与情绪的代理：散户情绪高涨、新闻热度上升时换手率抬升，这与行为金融的注意力机制一致；
- 在因子构造中，换手率常作为**调节权重**，用于放大「真实参与度」高的样本——例如用换手率加权跳跃收益，把「换手充分、交易真实发生」的股票赋予更高权重，降低低流动性噪声的干扰。

**与相邻字段的区别**：

- [[patterns/fields/成交额占比|成交额占比]]：以**市场**为分母度量相对活跃，换手率以**自身股本**为分母度量绝对参与度，前者是横截面概念、后者是自身状态；
- [[patterns/fields/成交额单位比率|成交额单位比率]]：以自身**当日峰值**为分母度量相对放量，换手率以**股本**为分母，关注的是「筹码换了多少」而非「相对自身放大了多少」；
- [[patterns/fields/振幅|振幅]]：度量价格摆动的**幅度**，换手率度量交易的**规模**，两者常并列作为「热度」的价、量两面。

## 收益来源

本页归属 [[alpha/量激增注意力|量激增注意力]] [[alpha/可知性分流定价|可知性分流定价]]

**赚什么钱**：主要赚**注意力**的钱——换手率抬升是关注度与情绪升温的代理，被关注驱动的交易把价格推离基本面，随后随注意力衰减而回归；次要赚**行为偏差**的钱——高换手常伴随散户追涨、处置效应与过度自信，这些偏差使价格在短期内系统性地偏离。

**对手方**：在情绪高点追入、为高换手买单的投资者；以及在处置效应驱动下过早卖出、错失后续收益的投资者另一面。

**理论支撑**：[[concepts/行为金融凸显理论|行为金融凸显理论]]（注意力与显著效应）；[[alpha/活跃度条件反转|活跃度条件反转]]（活跃度与反转）。

**失效条件**：

- **高换手由制度性事件驱动**：指数调整、解禁、ETF 申赎造成的换手不含注意力含义；
- **机构化提升**：当换手主要由做市与算法交易贡献时，换手率与散户情绪的对应关系削弱；
- **长期持有期**：在长周期上，短期的关注度效应被平滑，换手率的信息含量下降。

## 加工公式

```
换手率 = 成交量(bar/日) / 流通股本(日度)
# 分母取最近可得日度流通股本；分钟级换手率用当日累计量
```

## 可变异维度

- 频率：日 → 分钟（当日累计）
- 分母：流通股本 → 总股本

## 适用场景

- **作为调节权重**：加权跳跃收益、动量/反转因子，放大高参与度样本的信号；
- **情绪/热度代理**：识别关注度升高的标的；
- **流动性分层变量**：区分高、低换手的股票池，控制因子在不同参与度下的表现差异。
