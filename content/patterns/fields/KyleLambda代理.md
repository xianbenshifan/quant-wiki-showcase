## 金融解释

**衡量什么**：把「单位成交量增量推动了多少价格变化」这一比值 $r = \text{收盘收益} / \text{成交量增量}$ 做保号对数压缩：$\operatorname{sign}(r)\cdot\ln(1+|r|)$。分母是逐 bar 还原后的成交量增量（见 [[patterns/fields/成交量增量|成交量增量]]），分子是同期收盘收益，因此它度量的是**价格冲击斜率**——每多成交一单位量，价格被推动多远，量纲上对应 Kyle $\lambda$ 的市场深度视角。

**为什么有信息量**：Kyle（1985）的做市模型把价格冲击系数 $\lambda$ 解释为市场深度的倒数，并在均衡中论证 $\lambda$ 与「知情交易者掌握的信息相对噪声交易规模」成正比。因此高 $\lambda$ 不止意味着流动性差，还意味着**订单流毒性高**：做市方在与知情者交易中承受更大的逆向选择损失，需要更宽的价格让步。这就是本字段的双重含义——它同时是流动性成本与信息不对称的度量，也是它比单纯的成交量归一化更有信息量的原因。

**为什么做保号对数**：比值在成交量增量趋零时爆炸，分布厚尾严重；$\ln(1+|r|)$ 压缩极值、保留符号，使截面排序不被少数冷门时点主导。

**与相邻字段的区别**：

- [[patterns/fields/Amihud代理|Amihud 代理]]：分母是**成交额的相对水平**（单位量比），是 Amihud 型的额口径冲击；本字段分母是**成交量增量**，是 Kyle 型的量口径斜率，二者量纲不同；
- [[patterns/fields/冲击斜率代理|冲击斜率代理]]：分子用中间价收益、分母用**订单流失衡**（挂单增量），度量盘口层面的冲击；本字段只用成交侧的量与价，更接近已实现的成交冲击；
- [[patterns/fields/成交量增量|成交量增量]]：本字段的分母，是中性还原构件；
- [[patterns/fields/非流动性|非流动性]]：Amihud 原始比值，不含差分、不做对数。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/信息风险补偿|信息风险补偿]]

**赚什么钱**：其一为**流动性溢价**——深度差（$\lambda$ 高）的股票，持仓者未来成交需付出更高的价格冲击成本，要求更高的预期收益补偿；其二为**信息不对称**——高 $\lambda$ 意味着订单流毒性高，价格尚未充分反映知情者的私有信息，做空 / 低配毒性高者、或在毒性回落时介入，是常见用法。

**对手方**：被动提供流动性、承受逆向选择损失的做市方与限价单持有者；以及支付即时冲击成本的急躁交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（订单流毒性与逆向选择）；[[alpha/知情卖出信号|知情卖出信号]]。

**失效条件**：

- **拆单与冰山单**：真实大单被隐藏，成交量增量的可见部分低估知情强度，斜率失真；
- **做市算法主导**：挂单快速增撤使成交量增量更多反映库存管理而非信息，$\lambda$ 的知情成分下降；
- **制度性截断**：涨跌停、停牌使价格无法按冲击幅度移动，$\lambda$ 被系统性低估。

## 加工公式

```
r = ratio(收盘收益, 成交量增量)          # 单位成交量增量推动的价格变化
kyle_lambda_proxy = sign(r) * ln(1 + |r|)
# 成交量增量近零置 null；增量为逐 bar 差分还原的非负量
```

## 适用场景

- **市场深度 / 价格冲击的横截面度量**：与 Amihud 型字段互为量、额口径的两条腿；
- **订单流毒性研究**：与成交量不平衡概率代理、订单流失衡联合，区分「毒性水平」与「毒性的价格后果」；
- **分钟级微观结构因子**：需要已实现成交冲击而非报价冲击时更合适。

## 可变异维度

- 分子：收盘收益 → 中间价收益
- 分母：成交量增量 → 成交额增量
