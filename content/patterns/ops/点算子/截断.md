## 金融解释

**做什么**：把取值裁剪到 $[lo, hi]$——低于下界取下界、高于上界取上界、区间内不变。它操作化的是「把极端值拉回可用范围」，是缩尾（winsorize）的硬边界形式（缩尾替换分位外的值，裁剪只做上下限夹取）。

**为什么单列一页**：极端值（错价、涨跌停、数据错误、真实尖峰）会主导均值、标准差、回归与相关。截断是最轻量的抑制手段：只动两端、保留中间与样本量、不改变缺失结构，计算成本极低。它常作为 对数压缩、[[patterns/ops/截面算子/截面z得分|截面z标准化]] 的前置步骤。

## 算子定义

```
clip(x, lo, hi) = min(max(x, lo), hi)
# lo / hi 可为固定值，也可由滚动或全局分位生成
```

## 适用场景

- **因子标准化 / 合成前的离群处理**；
- **已知合理边界的量**：如收益的涨跌停限制、比率的有界范围；
- **与分位阈值配合**：$[q_{0.01}, q_{0.99}]$ 缩尾；
- **高频数据的瞬时错价修正**。

## 边界与陷阱

- **边界应来自分布而非拍脑袋**：固定阈值若与当前分布尺度不匹配，会裁掉太多或太少；稳健做法是用滚动 / 全局分位（见 滚动分位截断）；
- **对真实极端事件一并裁剪**：若命题正是关于极端事件（崩盘、涨停、放量），截断会把信号本身削平，此时应改用掩码隔离而非裁剪；
- **裁剪与缩尾不同**：裁剪在边界处制造大量并列值，可能影响 rank 的平局处理与方差；缩尾把极端值替换为分位值，二者对尾部形状影响不同；
- **改变分布形状**：截断后人为压低峰度 / 偏度，若下游依赖分布矩需注意；
- **上下界对称性**：收益 / 失衡类分布未必对称，上下界应分别按两侧分位设定，硬套对称区间会引入偏置。

## 可变异维度

- 上下界：固定值 / 分位数
- 截断方式：硬夹取 → 缩尾替换
- 窗口：全局 / 滚动
