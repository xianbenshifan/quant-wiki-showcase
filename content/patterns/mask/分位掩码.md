## 金融解释

**做什么**：以**分位**为切点，把某序列的取值位置转成布尔掩码——值落在指定分位区域为真、其余为 NaN（不选中）。它把连续的数值量转换成若干可对比的**状态子集**。

**为什么用分位而不是绝对阈值**：分位切点是**相对**的，它随样本分布自动调整。当波动水平整体抬升或下降时（A 股的特征之一），「波动率 > 2%」这种绝对阈值会挑选出数量迥异的两批样本，导致因子在不同时期不可比；而「波动率处于上尾 20%」始终选出同样比例的样本，跨期可比。这是分位掩码相对于 [[patterns/mask/阈值掩码|阈值掩码]] 的核心优势：**切点不随市场水平漂移**。

**为什么它有用**：很多金融命题本身就是关于「极端 vs 常态」的条件陈述——「高波动时更容易反转」「低流动性时定价更低效」。分位掩码是表达这类条件句的工具：把样本切成状态，再在状态内统计目标量的行为，即可检验该条件是否成立。它因此是 regime 族（如 [[patterns/mask/振幅掩码|振幅掩码]]、[[patterns/mask/趋势掩码|趋势掩码]]）与双状态对比类因子的共同底座。

**四种判定区域及各自含义**：

- **上尾**（值 ≥ 高分段）：识别分布右端的极端高值。如高流动性、高收益、大单推动的活跃时刻——通常是「事件/冲击」发生的样本；
- **下尾**（值 ≤ 低分段）：识别分布左端的极端低值。如低流动性、低收益的清淡时刻——通常是「无人问津/被忽视」的样本；
- **两尾**（值落在 [q_lo, q_hi] 之外）：同时取两端，刻画「非典型状态」，用于剔除常态后观察极端化的整体影响；
- **中枢**（值落在中间分位区间内）：取分布中部的「常态」样本，作为非极端对比的基底，或用于剔除极端值后的稳健统计。

## 掩码条件

以分位 `q` 为切点，四种判定区域：

```
data: rtn → mask: 分位掩码(q, region) → agg: mean
```

| 区域 | 判定 | 语义 |
|------|------|------|
| 上尾 | `x ≥ 分位(1-q)` | 高分段（`quantile_ge`） |
| 下尾 | `x ≤ 分位(q)` | 低分段（`quantile_le`） |
| 两尾 | `x < 分位(q_lo)` 或 `x > 分位(q_hi)` | 分布两端（`quantile_outside`） |
| 中枢 | `分位(q_lo) ≤ x ≤ 分位(q_hi)`，$q_{lo}=\min(q,1-q)$、$q_{hi}=\max(q,1-q)$ | 分布中部（`quantile_between`） |

要求 `0 < q ≤ 0.5`（越接近 0.5 段越宽）。低/高段互斥且非全覆盖（中段不入选），对比用 `双状态掩码差`。


## 适用场景

- **单侧状态因子**：只在上尾（或下尾）子集上统计目标量，构造「极端时刻」因子，如「高波动时的收益反转强度」；
- **双状态对比（pair_gap）**：分别在上尾与下尾子集统计，取两者之差，是最常见的对比骨架——如「高换手 vs 低换手时刻的量价行为差」；
- **中枢作稳健基底**：用中枢样本做「去极端」的统计，降低少数异常值对因子的主导；
- **分位档位扫描**：q 取 10%/20%/30% 观察因子单调性，确认信号不是某个特殊阈值下的巧合。

## 边界与陷阱

- **分位基准的选择会改变结论**：时序分位（每股自己的历史分布）与截面分位（同时点全市场分布）回答的是不同问题——前者问「这只股票相对它自己的历史处于什么位置」，后者问「它在当天的市场横截面里排第几」。选错基准会得到完全不同的状态划分，须与因子命题匹配（截面对比类因子通常用截面分位，见 [[patterns/mask/截面分位掩码|截面分位掩码]]）；
- **样本量不足时切点不稳**：窗口太短或有效样本太少时，分位估计噪声大，边界附近样本的状态会在相邻期频繁翻转。经验上窗口内样本数应远大于 `1/q`；
- **不处理缺失值会改变分位**：未剔除停牌/无成交样本时，分位会被大量零值或缺失值扭曲；
- **边界样本的抖动**：恰好落在切点附近的样本，其状态对估计误差极敏感。若因子结果对 q 的微小扰动（如 0.2 → 0.21）敏感，说明信号主要来自边界噪声而非真实状态差异，应改用平滑权重或扩大状态间距；
- **与阈值掩码混用**：分位不随水平漂移是优点，但也意味着它**无法表达绝对水平**。当命题本身是绝对门槛（如「超过涨跌停」「超过某经济意义上的成本线」）时，应回到 [[patterns/mask/阈值掩码|阈值掩码]]，不要强行用分位近似。

## 可变异维度

- 判定区域：上尾 / 下尾 / 两尾 / 中枢
- qt：0.2 → 0.3 / 0.4（越接近 0.5 段越宽）
- 分位方向：列内时序分位 → 截面分位
- 口径：分位值比较 → rank/排名比较（截面 rank 口径见 [[patterns/mask/截面分位掩码|截面分位掩码]]）
- 应用序列：ur（流动性）/ illiq / rtn（趋势）
