## 金融解释

**衡量什么**：分别对买侧与卖侧的撤单量按规模分档（超大单 / 大单 / 中单）统计占比分布，各算香农熵，再取两侧熵之差。熵刻画的是分布的**分散程度**：熵越高，撤单越均匀地摊在各规模档，说明撤单来自大量参与者、单笔规模各异；熵越低，撤单越集中在少数规模档，说明撤单由少数大额委托主导。

**为什么这个结构差有信息量**：撤单是撤单者主动放弃排队位置的行为，不是随机噪声。买卖两侧「撤单规模结构」的差异，实际反映两侧订单提交者构成的不同——一侧熵明显更低，意味着该侧撤单更可能来自少数大额、策略性参与者（幌骗、流动性抽回、算法批量撤单），另一侧熵更高则更接近散户的自然撤单。因此熵差回答的是「**哪一侧的撤单更集中、更可疑**」，它与撤单绝对量无关，是纯结构维度的度量。

**与相邻字段的区别**：

- [[patterns/fields/撤单失衡|撤单失衡]] 与 [[patterns/fields/撤单笔数失衡|撤单笔数失衡]] 度量「谁撤得多」的方向性总量差；熵差度量「撤单的规模结构是否对称」。两者可以正交：可能一侧撤单总量大但分散、另一侧总量小但集中。
- [[patterns/fields/净撤单压力|净撤单压力]] 用撤单量除以真实成交量，衡量挂单的「虚假程度」；熵差不引入成交基准，只做结构比较。
- 量口径熵与笔数口径熵是两个不同口径，不可混用。

## 加工公式

```
p_i = part_i / sum(parts)         # 各规模档撤单量占比；分母近零置 null
H_buy  = -sum(p_i * ln(p_i))      # 买侧撤单规模分布香农熵，i ∈ {超大单, 大单, 中单}
H_sell = -sum(q_i * ln(q_i))      # 卖侧同理
cancel_entropy_gap = H_buy - H_sell
```

## 适用场景

- 作为**结构性特征**并入更大的微观结构因子或特征集：它描述的是撤单「由谁发起」的画像，本身不预测涨跌，但能为其他信号提供条件分层（例如只在熵差极端时相信撤单方向信号）。
- 用于区分「大额参与者主导的撤单」与「散户散乱撤单」：当研究命题涉及幌骗、流动性抽回、订单流毒性时，熵差比总量口径更贴近机制。
- 在**逐笔数据完整、规模分档口径稳定**的样本上更有意义；日内高频粒度上单 bar 样本过少，宜在日频或多 bar 累积窗口上计算，或对分钟值做时序平滑后再用。

## 可变异维度

- 规模分档：Mega/Large/Medium → 更多档
- 熵口径：量 → 笔数
