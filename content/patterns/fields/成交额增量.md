## 金融解释

**衡量什么**：成交额的相邻 bar 一阶差分。与成交量增量同理，高频库中成交额常为**日内累计**口径，必须先差分才能还原每根 bar 的真实成交金额。对累计值回落（差分为负）的情形采用「取原值」的回退规则，保证增量非负。

**为什么有信息量**：增量是成交额类字段的基础原料，本身不携带方向，但它是许多规格化与事件识别的前置：成交额单位比率（增量 / 当日峰值）、成交额占比的时序构造、峰岭形态中的「放量 bar」判定、对数成交额增量等，都以它为输入。它的价值在于把累计口径还原为**逐 bar 可比**的资金规模，使下游的比值、求和、形态识别具有正确的量纲。换一个角度说，它是把「今天成交了多少钱」翻译成「这一根 bar 成交了多少钱」的桥梁——缺少这一步，所有基于逐 bar 的分析都会把日内累计趋势误当作时点强度。

**与相邻字段的区别**：

- [[patterns/fields/成交量增量|成交量增量]]：量口径的对应物，不含价格因子，反映的是成交**股数**的变化；额增量则同时包含量与价，反映**资金规模**的变化；
- [[patterns/fields/对数成交额增量|对数成交额增量]]：在本字段上取对数、仅保留正增量，用于压缩厚尾；
- [[patterns/fields/成交额单位比率|成交额单位比率]]：把本字段除以当日峰值规格化，是直接下游；
- [[patterns/fields/成交额占比|成交额占比]]：横截面归一，与本字段的绝对量级是两个层级。

## 加工公式

```
原始增量 = 成交额 − 上一 bar 成交额（按合约分组）
增量 = 若原始增量非空且 ≥ 0 则取原始增量，否则取成交额
# 回退规则保证增量非负，用于日内累计口径的还原
```

## 可变异维度

- 防回退：回落原值 → 截断 0
- lag：1 → k

## 适用场景

- **量能规格化的分子**：作为成交额单位比率、超额单位比率等字段的输入；
- **放量 bar 的识别**：峰岭成交比、喷发掩码等形态识别需要逐 bar 增量；
- **资金规模变化研究**：研究日内资金流入节奏时，增量比累计值更有信息。
