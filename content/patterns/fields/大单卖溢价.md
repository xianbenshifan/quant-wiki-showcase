## 金融解释

**衡量什么**：取已成交的大额卖单的均价（大单卖额 / 大单卖量），与当日全市场成交均价 VWAP 比较，做相对偏差并压缩。正值表示大单卖家卖在了**高于**市场均价的位置（卖得好），负值表示卖在了低于均价的位置（为求成交而让价）。

**为什么有信息量**：大单卖家是主动跨价差成交还是挂单被动成交，会体现在成交均价相对 VWAP 的偏位上。**大幅折价成交**说明卖家急于出货——愿意接受明显低于市场均价的价格换取成交速度，这通常与不利信息或流动性压力有关；**溢价成交**则说明大单在整体偏强的环境中顺势派发，或该笔大单本身处于买盘承接较强的时段。这个字段因此把「大单卖出」从单纯的方向信号，升级为携带**紧迫程度与价格让步**的信号。

**与相邻字段的区别**：

- [[patterns/fields/大单买溢价|大单买溢价]]：镜像的买方版本，度量大单买入相对 VWAP 的溢价（抢筹力度）；
- [[patterns/fields/大单卖撤溢价|大单卖撤溢价]]：同公式结构但分子换成**被撤回**的卖委托均价，度量的不是成交让步而是撤单报价位置；
- [[patterns/fields/大单净流入|大单净流入]]：只看大单买卖的**量向**，不关心成交价格相对基准的高低；
- 成交均价：本字段的基准价（VWAP）本身，是中性价格加工，无方向含义。

## 收益来源

本页归属 [[alpha/普通大单信息延续|普通大单信息延续]]

**赚什么钱**：主要赚**信息不对称**的钱。大单卖家愿意以显著低于市场均价的折扣出货，往往意味着其掌握或预期不利信息、急于在信息扩散前减仓；这类「有信息支撑的抛售」在信息尚未被完全定价时，预示后续价格走弱。因此该字段可作为知情卖方紧迫度的横截面代理。

**对手方**：在折价抛售中接盘的买家——他们以「比市场均价便宜」的价格买入，看似占了便宜，实则承担了知情卖方转嫁的下跌风险。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（知情交易与逆向选择）；[[alpha/知情卖出信号|知情卖出信号]]（成交结构中的知情主导）。

**失效条件**：

- **流动性压力主导**：当折价抛售来自赎回、强平、保证金压力等非信息因素时，它不预示个股基本面恶化，方向含义失效；
- **大单竞价机制**：若大单通过集合竞价或大宗交易以固定价格成交，其均价与 VWAP 的偏位由制度安排决定，而非紧迫程度；
- **日内 VWAP 时段偏差**：大单集中在开盘/尾盘等 VWAP 权重不同时的时段成交，会导致相对偏差被时段结构而非交易意图驱动。

## 加工公式

```
大单卖均价 = 大单卖额 / 大单卖量
VWAP = 成交额 / 成交量
大单卖溢价 = signed_log( 大单卖均价 / VWAP − 1 )
# signed_log(x) = sign(x)·ln(1+|x|)；分母近零置 null
```

- 规模档：Large → Mega

## 适用场景

- **度量卖方紧迫度**：在大单净流出已经发出方向信号后，用本字段区分「温和减仓」与「夺门而出」，后者更可能对应持续下跌；
- **与买方溢价配对**：把买、卖溢价并置，观察买卖两侧的让步是否对称，判断是单边施压还是全市场流动性紧张；
- **流动性压力监测**：在赎回高发、市场承压时段，折价指标整体抬升，可用于横截面识别最脆弱的标的。
