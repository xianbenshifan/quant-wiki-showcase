## 金融解释

**做什么**：对窗口内序列输出偏度（样本三阶标准化中心矩），衡量分布的不对称。正值 = 右尾长，少数大涨把分布拉向右侧；负值 = 左尾长，少数暴跌。它不是「波动大小」，而是**波动的方向偏向**。

**为什么有信息量**：投资人对两端的态度并不对称——负偏（暴跌可能性）是投资者厌恶的尾部风险，理论上应获得风险补偿；正偏（彩票型收益）则被过度偏好，可能被高估。因此偏度既是**尾部风险的刻度**，也是**行为偏好的指纹**。把它与波动率配合，可区分「对称的高波动」与「有方向的高波动」——后者才是崩盘风险的直接刻画。

**零方差守卫的含义**：偏度分母含 $\sigma^3$，窗口内取值恒定时 $\sigma=0$ 会除零。约定 $n\ge 3$ 且方差为 0 时输出 0，语义是「无不对称信息」，而不是把该点当作有效观测。

## 聚合方式

```
skew(x, window, mask=None)
# 零方差且 n>=3 -> 0
```

语义：窗口内样本偏度；可选掩码先切状态子集再计算。

## 适用场景

- **崩盘风险 / 彩票偏好**：横截面上按滚动偏度排序，负偏股与正偏股的风险补偿结构不同；
- **尾部形状刻画**：与波动率、峰度组成「波动—不对称—尾部厚度」的三维画像；
- **状态内的分布变化**：在掩码子集里算偏度，观察某状态下分布是否变得更偏；
- **作为独立因子或调节量**：偏度本身可作因子（特质偏度、波动率偏度），也可用于风险调整。

## 边界与陷阱

- **高阶矩对极端值极敏感**：偏度按偏差的三次方加权，单根极端 bar 可主导整个窗口的符号。这与中位数的稳健性形成鲜明对照；
- **样本量要求高**：偏度是渐近估计，窗口太短（经验上少于 20–30 根）时估计噪声极大，符号会在相邻期频繁翻转；
- **近零方差仍会爆炸**：守卫只覆盖严格 $\sigma=0$，$\sigma\to 0$ 时比值仍不稳定。对低波动序列应加下限或改用秩口径；
- **跨 regime 混合**：长窗口若跨越波动状态切换，得到的是两段分布的混合偏度，含义不清；
- **口径未统一**：是否做小样本修正、是否 fisher 调整，数值会不同，跨库比较须先对齐定义。

## 可变异维度

- 窗口：可调
- 口径：样本偏度 / fisher 调整 / 稳健（分位偏度）
