## 金融解释

**做什么**：两列逐点相减 $a-b$，衡量差量或相对偏离。

**为什么单列一页**：差值是金融构造里最直接的「相对」操作——个股减市场（超额）、买价减卖价（价差）、当前减基准（偏离）、买量减卖量（失衡）。它度量的是**绝对差**（有量纲），与 [[patterns/ops/点算子/归一化失衡|归一化失衡]] 的相对份额形式互补：要「差多少」用减法，要「偏向哪边」用失衡。

## 算子定义

```
sub(a, b) = a - b        # 任一为非有限 -> null
```

## 适用场景

- **超额 / 相对量**：个股 − 基准、当前 − 历史中枢；
- **价差类**：买价 − 卖价、中间价 − 成交价；
- **失衡的绝对形式**（买量 − 卖量），需要无量纲时再归一化；
- **与截面中位数组合**成去中枢（见 [[patterns/ops/截面算子/截面中位数|截面中位数]]）。

## 边界与陷阱

- **有量纲、跨标不可比**：$a-b$ 的量级依赖标的规模（大盘股成交量差天然大于小盘股），横截面比较前通常需再标准化，或改用归一化失衡；
- **符号与方向约定**：$a-b$ 与 $b-a$ 只差符号，配下游因子时方向务必一致；
- **与逐点加的分工**：减法表达「差异 / 背离」，加法表达「叠加 / 合并」；组合同向信号用加，比较两者用减；
- **缺失传播**：任一非有限即置空，双列缺失的样本损失可能很大；
- **与时序差分的混淆**：逐点减是同一期两列的差，[[patterns/ops/时序算子/差分|差分]] 是同一列跨期的差，维度与语义都不同。

## 可变异维度

- 对象：任意语义 / 字段对
- 是否再归一化
