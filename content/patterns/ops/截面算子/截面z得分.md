## 金融解释

**做什么**：在同一时点的截面上，把每个取值减去截面均值、再除以截面标准差，得到「相对截面中枢偏离了多少个标准差」$z_i = (x_i - \bar{x}) / s_x$。它把任意量纲的横截面映射到均值 0、单位标准差的公共尺度上。

**为什么单列一页**：多因子合成、回归与中性化的前置步骤都需要先让不同因子「可比」。绝对量纲（成交额、价差、收益率）彼此不可加，z 得分用当期横截面自身的矩做标准化，使同一时点的股票之间相对位置可直接比较，无需外部基准。

**它度量什么**：z 得分保留**等距差异**——$z=2$ 与 $z=1$ 的差距和 $z=1$ 与 $z=0$ 一样。这与 [[patterns/ops/截面算子/截面排名|截面排名]] 只保留「序」不同：z 保留了「差多少」，因此当信号强度本身携带信息、且分布近似对称时更有效。

## 算子定义

```
z(x) = (x - mean_cs(x)) / (std_cs(x) + eps)
# 逐截面计算；截面标准差为零或非有限 -> null
```

## 适用场景

- **多因子线性合成前统一尺度**：避免量纲大的因子主导权重；
- **回归型构造中标准化自变量**：使系数之间可比；
- **分布近似对称、离群不主导的因子**：如收益、波动率；
- **需要区分「偏离中枢的幅度」的场景**：与只保序的 rank 形成分工。

## 边界与陷阱

- **对极端值不稳健**：均值与标准差都被离群值主导，一根错价或一个涨跌停样本即可压低其余股票的 $|z|$；应先做 [[patterns/ops/点算子/截断|截断]] 或分位缩尾，或改用 [[patterns/ops/截面算子/截面排名|截面排名]]；
- **厚尾分布仍然厚尾**：标准化只改一阶矩与二阶矩，不改变尾部形状，$z$ 仍可能极端，不能替代缩尾；
- **小截面样本不足**：标的数太少时均值/标准差估计噪声大，z 跨期不稳；
- **分母趋零**：当截面几乎同值（如全部接近涨跌停）时标准差趋零，比值被放大成噪声，必须置空而非硬除；
- **与 rank 的取舍**：z 保留距离但不抗离群，rank 抗离群但丢距离；若尾部收益差更大，z 更贴合真实差异，但也更易被单点污染。

## 可变异维度

- 对象：任意列
- 分组口径：全截面 → 行业内 / 市值桶内截面
