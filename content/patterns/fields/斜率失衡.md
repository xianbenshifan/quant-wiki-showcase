## 金融解释

**衡量什么**：把某一侧的盘口看成「价格—累计深度」曲线，其斜率刻画为跨越若干档价格需要消耗多少挂单量。本字段用价格跨度除以该侧总深度来近似这一斜率：$\text{bid\_slope} = \dfrac{BP_1 - BP_5}{\sum \text{BV}}$，$\text{ask\_slope} = \dfrac{SP_5 - SP_1}{\sum \text{SV}}$，再取 $\text{slope\_imb} = \text{bid\_slope} - \text{ask\_slope}$。数值越大表示该侧**每单位深度所能支撑的价格跨度越大**，即盘口越「稀薄 / 陡峭」。

**为什么有信息量**：最优档失衡（[[patterns/fields/近端失衡|近端失衡]]）只回答「买一卖一谁厚」，而斜率失衡回答「**整段盘口的价格支撑结构偏向哪一侧**」。即使买卖一档量相等，若买侧五档的价格跨度远大于卖侧，说明买盘只是浅浅堆在第一档、越往外越空，稍大的卖压就能把价格连续打穿；反之亦然。它是价格冲击成本的**形状维度**度量，直接关系到「同等主动成交量会把价格推多远」。

**与相邻字段的区别**：

- [[patterns/fields/近端失衡|近端失衡]]：只看最优档的买卖量差，是「一档」的纵深；斜率失衡是「多档梯度」的纵深，更关注价格—深度曲线的整体倾斜。
- [[patterns/fields/凸度差|凸度差]]：看的是价格—深度曲线的**曲率**（中凹还是中凸），描述形状的弯折；斜率失衡看的是整体**倾斜**，两者可同时存在。
- [[patterns/fields/加权失衡|加权失衡]]：对各档买卖量差做距离加权求和，是量的失衡；斜率失衡除的是价格跨度，是价的梯度。
- [[patterns/fields/订单流失衡|订单流失衡]]：度量挂单的**增量**方向（变化量）；斜率失衡度量的是**存量**结构。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/信息风险补偿|信息风险补偿]]

**赚什么钱**：主要服务两类逻辑。其一是**流动性溢价**——斜率失衡刻画哪一侧的盘口更稀薄，稀薄侧的即时冲击成本更高；为这一侧的成交提供流动性、承担被连续打穿风险的参与者应获得补偿。其二是**信息不对称**——知情者倾向于在深度较薄的一侧发起攻击以放大价格效应，斜率失衡同时是订单流毒性的形状代理。

**对手方**：在稀薄一侧被迫以连续不利价格成交的急躁交易者；以及被盘口形状误导、以为有深度支撑而接盘的交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **盘口被瞬时刷新**：高频做市使挂单快速补充，存量斜率对未来冲击的指示被增量刷新抵消；
- **冰山单 / 隐藏单主导**：可见深度不代表真实承接力，斜率失衡可能系统性高估稀薄侧的脆弱性；
- **制度性价格限制**：接近涨跌停时盘口结构退化为单边，斜率不再反映真实的流动性供给意愿。

## 加工公式

```
bid_slope = ratio(BP_1 - BP_5, sum(BV_i, i=1..5))     # 买侧价格跨度 / 买侧总深度
ask_slope = ratio(SP_5 - SP_1, sum(SV_i, i=1..5))     # 卖侧同理
slope_imb = bid_slope - ask_slope                     # 分母近零置 null
```

## 适用场景

- 需要刻画**多档盘口的整体脆弱性**时，比单档失衡更稳健：单一档位的量易受挂撤单噪声影响，五档梯度更能反映真实承接结构；
- 与 [[patterns/fields/近端失衡|近端失衡]] 配合：近端看方向、斜率看形状，二者同向时可放大对短期冲击的判断；
- 在**深度数据完整、档位稳定的标的**上有效；小盘股或报单稀疏的标的三、五档可能长期为空，斜率不稳。

## 可变异维度

- 端点：1-5 档 → 1-3 档
- 深度分母：总量 → 最优档
