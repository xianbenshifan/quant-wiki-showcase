## 金融解释

**衡量什么**：**微价格** = $(\text{SP1}\cdot\text{BV1} + \text{BP1}\cdot\text{SV1})/(\text{BV1}+\text{SV1})$，即用对手方挂单量作为权重，把买一价与卖一价加权平均——买盘越厚，权重越偏向卖一；卖盘越厚，权重越偏向买一。再取微价格相对中间价（$\text{mid}=(\text{BP1}+\text{SP1})/2$）的相对偏离，即为本字段。

**为什么有信息量**：中间价把买卖两侧视为等权，忽略了两侧**数量**的不对称；而微价格把「哪一侧挂单更厚」编码进价格。直观上，若买盘远厚于卖盘，卖方要大量卖出需不断向下打，价格更容易走低，因此微价格向卖一侧偏；反之向买一侧偏。微价格因此被视作比中间价更接近**均衡价**的估计。它的偏离方向，是对**短期价格漂移**的直接预测——偏离指向哪一侧，价格往往在更短窗口内朝该方向移动（随后可能反转）。这是订单簿不平衡在**价格空间**里的表达，与在**数量空间**里的失衡字段（近端失衡、加权失衡）互为对偶。

**与相邻字段的区别**：

- [[patterns/fields/中间价|中间价]]：本字段的基准，单纯取买卖一价均值，不含挂单量信息；
- [[patterns/fields/近端失衡|近端失衡]]：直接从 $(\text{BV1}-\text{SV1})/(\text{BV1}+\text{SV1})$ 度量最优档挂单的**数量**失衡，不做价格加权；本字段把同样的信息映射到价格偏离上，二者高度相关但量纲不同；
- [[patterns/fields/相对价差|相对价差]]：度量买卖价差的**宽度**（交易成本），不含方向；
- [[patterns/fields/加权失衡|加权失衡]]：把失衡扩展到五档，本字段默认只用最优档。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/信息风险补偿|信息风险补偿]]

**赚什么钱**：主要赚**流动性溢价**的钱——微价格偏离反映了盘口承接能力的不对称：一侧越厚，越能以小成本吸收冲击，价格越可能朝另一侧移动，做市/流动性提供者通过承担并利用这种不对称获取补偿；次要赚**信息不对称**的钱——知情者会在某一侧堆积挂单或撤单，微价格偏离是其订单簿痕迹，暗示短期真实供需。

**对手方**：需要即时成交、跨越价差的主动方（他们为消耗较薄一侧的流动性付出冲击成本）；以及未能识别盘口不对称而被动成交的一方。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（订单簿中的逆向选择）；[[alpha/活跃度条件反转|活跃度条件反转]]（短时冲击后的价格修正）。

**失效条件**：

- **挂单可瞬时撤销**：微价格依赖的挂单量是意图而非承诺，做市商可在成交前撤单，使价格偏离失去指示意义；
- **知情者隐藏订单**：冰山单、隐藏单使可见挂单量不能代表真实供需，微价格的「厚侧」判断被扭曲；
- **极端失衡状态**：一侧挂单趋零（涨跌停、单边行情）时，微价格趋于该侧报价，但价格无法实际移动，偏离成为制度性假信号。

## 加工公式

```
微价格 = (SP1·BV1 + BP1·SV1) / (BV1 + SV1)
微价格偏离 = 微价格 / 中间价 − 1
# 中间价 = (BP1 + SP1)/2；BV1+SV1 近零置 null
```

## 可变异维度

- 口径：价格偏离 → 笔数加权偏离
- 边界：分母加小常数防零 → 分母近零置 null

## 适用场景

- **短周期价格漂移预测**：在分钟—日内频率上，微价格偏离是订单流不平衡的高频代理；
- **改善成交基准**：作为比中间价更优的「公平价」估计，用于执行算法的参考价；
- **与数量失衡联合**：数量失衡给方向、微价格偏离给价格空间的幅度，二者同向时信号更强。
