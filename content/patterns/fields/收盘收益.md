## 金融解释

**衡量什么**：相邻两期收盘价的收益率，经 signed-log 变换，是日 / bar 频「收益」的标准落盘形态。它是 [[patterns/fields/收益率|收益率]] 在日频与收盘锚点上的具体口径。

**为什么有信息量**：与所有纯收益变换一样，它**不携带内在方向**——同一列在不同窗口下既能充当动量、也能充当反转的输入。它的复用价值在于：几乎每一个因子评估环节（相关性、分位分组、regime 划分、收益预测）都需要一列「当期的市场结果」作为右侧变量，而收盘价是最稳定、覆盖最全、争议最小的收益锚点。把它显式登记为一个 field，是为了在下游构造时明确「右侧收益用的是收盘口径、signed-log 变换、lag=1」这一组约定。

**与相邻字段的区别**：

- [[patterns/fields/收益率|收益率]]：同公式同语义，历史命名不同；两者是别名关系，不应同时作为独立特征入模。
- [[patterns/fields/绝对收盘收益|绝对收盘收益]]：去掉符号只留幅度，服务于波动 / 非流动性类分子。
- [[patterns/fields/中间价收益|中间价收益]]：用中间价而非收盘价，剔除了收盘瞬时买卖价差跳动的影响，更适合微观结构研究；收盘收益更贴近可实现的收盘成交损益。
- [[patterns/fields/超额收益|超额收益]]：本字段再减去同期截面中位数，剥除市场共同方向。

## 加工公式

```
r = close_t / close_{t-1} - 1          # 仅当两期价格均 > 0，否则 null
close_rtn = sign(r) * ln(1 + |r|)       # signed-log 变换
```

## 适用场景

- **右侧收益基准**：因子 IC / 分组 / 多空组合的收益变量，优先用收盘收益，覆盖面与可比性最好；
- **动量或反转序列源**：更换 lag 与聚合窗口即可切换两种逻辑；
- **regime 划分与条件掩码**：用过去 k 期收盘收益定义涨跌状态；
- 需要**贴近可实现收盘损益**时用收盘口径，而非中间价口径。

## 可变异维度

- lag：1 → 2/5/20
- transform：可选原始收益
