## 金融解释

**衡量什么**：把日内高频（典型 5 分钟）对数收益按符号拆分，取正收益部分的二次变差 $\text{RS}^+ = \sum r^2 \cdot \mathbf{1}(r>0)$，减去连续扩散分量的稳健估计的一半，再截断为非负：$\text{RVJP} = \max(\text{RS}^+ - \tfrac{1}{2}\widehat{\text{IV}}, 0)$。连续分量估计常用三幂次变差（见 [[patterns/fields/多幂次变差|多幂次变差]]）。

**为什么有信息量**：总跳跃波动率只回答「有多少跳跃」，不区分方向，而信息冲击的方向往往才是定价关键。**上行跳跃是正向离散信息的指纹**——超预期财报、政策放松、大额订单、并购传闻等，会让价格在一两个 bar 内完成一次性向上重估，而非连续漂移。之所以减去 $\tfrac{1}{2}\widehat{\text{IV}}$，是因为在无跳跃的原假设下，正、负收益各自的二次变差都约等于连续分量的一半；只有超出这一基准的部分才是可归因于跳跃的强度。截断非负则把有限样本下的估计噪声（无跳跃时差值可能为负）映射为「无上行跳跃」。

**为什么单独成构件**：上下行跳跃的定价并不对称。投资者对崩盘的恐惧使下行跳跃承担正的风险补偿；而上行跳跃——尤其幅度异常大的「好得难以置信」的跳跃——短期常伴随过度反应后的修正，其风险溢价可能为负。把上行跳跃从总跳跃中拆出来，是构造上下行跳跃不对称（SRVJ）、大 / 小跳分解等范式的前提。

**与相邻字段的区别**：

- [[patterns/fields/下行跳跃波动率|下行跳跃波动率]]：对称的负收益版本；两者相减即上下行跳跃不对称性，单用本字段捕获的是「好消息冲击强度」；
- [[patterns/fields/已实现跳跃波动率|已实现跳跃波动率]]：总跳跃（不分方向），是本字段与下行版本的加总根，不可与本字段互相替代；
- [[patterns/fields/多幂次变差|多幂次变差]]：本字段的连续分量减项，本身是稳健波动率；
- [[patterns/fields/日跳跃度|日跳跃度]]：用单复利差的泰勒残差做低频代理，不分解方向，也不基于二次变差；
- [[patterns/fields/更优波动率|更优波动率]]：连续波动的水平估计，不含跳跃分离。

## 收益来源

本页归属 [[alpha/跳跃风险补偿|跳跃风险补偿]] [[alpha/正跳跃追逐|正跳跃追逐]]

**赚什么钱**：主要赚**波动与尾部风险溢价**——上行跳跃是不可分散的尾部风险与信息冲击的载体，投资者对这种无法预判的剧烈变动要求补偿；同时，正向大跳后的过度反应修正也为反向交易提供收益来源（这一层更偏反转，但就构件本身的定价属性而言，主成分仍是波动与尾部风险）。

**对手方**：在跳空后被迫追高、或未能及时调整仓位的投资者；以及对尾部风险定价不足的持有者。

**理论支撑**：[[concepts/特异波动异象|特异波动异象]]（跳跃 / 波动风险与截面收益）；[[concepts/信息冲击反应不足与过度|信息冲击反应不足与过度]]（跳跃后的价格修正）。

**失效条件**：

- **跳空被连续化**：涨跌停制度把一次跳跃拆成多日连续变动，高频二次变差低估真实上行跳跃；
- **低频化后溢价消失**：长持有期下跳跃风险被平滑，其定价能力减弱甚至反向；
- **微观结构噪声主导**：高频买卖价差跳动被误判为跳跃，抬高 RVJP 并与流动性混淆。

## 加工公式

```
RS⁺ = Σ r² · I(r > 0)                 # 正收益分钟二次变差
RVJP = max(RS⁺ − ½ · ÎV, 0)           # ÎV 为连续波动率估计（常用三幂次）
# 截断非负；ÎV 见 多幂次变差
```

## 可变异维度

- 频率：5 分钟 → 1 分钟/10 分钟
- IV̂ 估计：双幂次 ↔ 三幂次 ↔ 其它稳健估计
- 截断：max(·,0) 固定

## 适用场景

- **上下行跳跃不对称性的分子**：与下行版本配对构造 SRVJ 信号；
- **正向信息冲击强度度量**：识别近期被利好信息反复击中的标的，配合事件研究；
- **大 / 小跳分解**：先算总跳跃，再按方向与幅度拆分。
