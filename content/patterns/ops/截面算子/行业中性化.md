## 金融解释

**做什么**：把因子暴露对行业哑变量回归，取残差，剔除行业间中枢差异。它在每个截面内把因子变成「相对所属行业均值的偏离」，但以回归形式表达，便于加入其它控制项。

**为什么单列一页**：A 股行业轮动强，估值、动量、波动等因子都带有显著行业属性；不中性化时，因子组合可能只是在押注某几个行业。行业中性化让因子在行业间可比，把「选行业」与「选个股」分离，是估值 / 动量类因子常见的预处理步骤。

## 算子定义

```
resid = x - predict(x ~ industry_dummies)
# 每时点截面：x 对行业哑变量（+ 可选市场项 / 市值项）回归取残差
# 含截距时须剔除一列哑变量以避免共线
```

## 适用场景

- 因子暴露与行业高度相关（估值、盈利、动量）；
- 组合需行业暴露中性、避免行业押注；
- 作为多因子合成的预处理，使因子在行业间可比；
- 与市值中性化组合（行业 × 市值）以同时控制两类结构。

## 边界与陷阱

- **只控行业、不控风格**：行业中性化后因子仍可能暴露于市值、波动等风格；若需全风格中性，应把风格暴露一并放入回归（[[patterns/ops/截面算子/截面残差|截面残差]] 的多因子形式）；
- **行业分类口径**：申万 / 中信 / GICS 以及分类的历史调整会改变残差，跨期使用须固定口径并对齐历史成分；
- **小行业样本不足**：细分行业内标的很少时回归系数不稳，残差噪声大；
- **哑变量共线**：含截距时必须去掉一列基准行业，否则设计矩阵奇异；加入「行业 × 市值」交互时自由度消耗更快；
- **与组内中性化等价性**：仅用行业哑变量、含截距的回归残差与组内去均值等价，不要误以为回归版一定「更强」，差别只在能否加入连续控制项。

## 可变异维度

- 中性化维度：行业 → 市值 / 行业 × 市值
- 是否含市场项：是 / 否
- 行业分类口径：申万 / 中信 / GICS
