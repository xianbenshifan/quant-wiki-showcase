## 金融解释

**衡量什么**：在窗口内（如过去一个月）按 [[patterns/fields/凸显系数|凸显系数]] $\sigma$ 对各日收益排序，得到排名 $k$（最凸显记 1）；再用认知参数 $\delta\in(0,1]$ 与客观概率 $\pi$（常取窗口长度倒数 $1/N$）合成归一化权重 $\omega_{i,s} = \delta^{k_{i,s}} / \sum_{s'}(\delta^{k_{i,s'}}\pi_{s'})$。

**为什么有信息量**：这是[[concepts/行为金融凸显理论|行为金融凸显理论]]中「概率权重扭曲」的操作化。理论认为，投资者并非按客观概率加权各期收益，而是对**心理上显眼**的收益赋予过高权重；$\delta<1$ 的几何衰减正是这一扭曲的工程表达——$\delta$ 越小，注意力越集中在最显眼的少数几天，权重分布越尖。因此 $\omega$ 不是统计意义上的加权方案（如时间衰减），而是**认知偏差的刻度**：它把「客观收益序列」翻译成「投资者主观上会放大哪些日子」。它本身是权重而非信号，通常与收益配对，在 [[paradigms/凸显权重收益协方差|凸显权重收益协方差]] 中取 $\operatorname{cov}(\omega, r)$ 得到方向明确的行为扭曲度量。

**与相邻字段的区别**：

- [[patterns/fields/凸显系数|凸显系数]]：本字段的**排序键**，度量单日收益有多显眼；本字段把单日凸显性转换成跨日的衰减权重。
- [[patterns/fields/惊恐度|惊恐度]]：另一套显著强度口径（绝对偏离），可直接作收益的乘数权重；凸显权重基于**序数排名**而非连续强度，对极端值更稳健。
- [[patterns/fields/个人投资者交易比|个人投资者交易比]]：散户参与份额，是另一维度的注意力/主体权重，常与显著效应族联合使用。

## 收益来源

本页归属 [[alpha/凸显收益误估|凸显收益误估]]

**赚什么钱**：主要赚**行为偏差**的钱——凸显权重把注意力错配编码进权重，使 $\omega$ 与收益的协方差成为过度乐观/悲观的度量，做多低协方差、做空高协方差即可捕捉误估的修正；次要赚**注意力**的钱——权重本身的集中程度（$\delta$）刻画注意力分配，注意力越集中，扭曲越强。

**对手方**：对显眼收益过度外推、在显眼日以偏离基本面的价格交易的投资者；其错误定价的修正构成收益。

**理论支撑**：[[concepts/行为金融凸显理论|行为金融凸显理论]]（Bordalo–Gennaioli–Shleifer 显著效应）。

**失效条件**：

- **机构主导定价**：专业投资者较少受凸显性影响，其占比高时权重扭曲被套利抹平；
- **显眼源于真实信息**：若显眼日的收益是持续基本面改善的真实信号，则不存在反向修正；
- **注意力参数失稳**：$\delta$ 由研究者设定而非估计，其取值变化会系统性改变权重集中度与因子符号。

## 加工公式

```
k(i,s) = 窗口内按凸显系数 σ 降序的排名（最凸显 = 1）
ω(i,s) = δ^{k(i,s)} / Σ_{s'} ( δ^{k(i,s')} × π_{s'} )
# δ 常取 0.7，π 常取窗口长度倒数；排名并列须先定去重规则
```

## 可变异维度

- $\delta$：0.7 → (0,1]
- $\pi$：均匀 $1/N$ → 其它客观概率
- 窗口：自然月 → 滚动 $N$ 日

## 适用场景

- **凸显权重收益协方差（STR）类因子的权重**：与收益配对求协方差，构造行为扭曲度量；
- **注意力加权的其他变体**：与个人投资者交易比、波动率加剧等权重维度组合；
- **日频行为因子**：凸显理论基于日频记忆，不适宜直接搬到分钟频率。
