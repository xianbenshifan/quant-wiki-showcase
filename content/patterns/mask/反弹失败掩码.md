## 金融解释

**做什么**：从「日内价格相对当日极值的位置」构造两类形态掩码——**反弹强度** $\text{bounce\_up} = \text{close}/\text{low} - 1$（低开后向上收复的力度）与**失败强度** $\text{fail\_down} = \text{high}/\text{close} - 1$（高开后回落的力度），各自取市场截面 pct 排名的高分位为真。

**为什么这两个比值能刻画情绪摆动**：它们把「收盘价在当日高低区间中的位置」转成了连续强度。$\text{bounce\_up}$ 大，说明收盘价远高于当日最低——多头在盘中完成强势收复；$\text{fail\_down}$ 大，说明收盘价远低于当日最高——多方推升失败、卖方占优。两者都是**单日内多空力量对比的结果**，强度越极端，当日情绪摆动越剧烈。

**为什么有信息量**：低开高走（收复）与高开低走（失败）是典型的**日内反转 / 情绪形态**。极端形态往往对应恐慌后的错杀修复，或亢奋后的回落——它们标记的是情绪主导、可能被后续修正的样本。注意它与趋势掩码不同：这是**日内形态**（单日 $\text{low}\to\text{close}$ / $\text{high}\to\text{close}$），趋势是跨日方向。

## 掩码条件

判定规则（语义级）：

- 反弹强度 $\text{bounce\_up} = \text{close}/\text{low} - 1$（低开高走强度）；
- 失败强度 $\text{fail\_down} = \text{high}/\text{close} - 1$（高开低走强度）；
- 两条强度序列各自取**市场截面 pct 排名**，排名 $\ge$ 阈值 $q$ 者掩码为真（$q$ 通常取 0.8）；
- 输出两张布尔掩码：反弹掩码（高 $\text{bounce\_up}$）、失败掩码（高 $\text{fail\_down}$）。

加工链路：价格语义 → 反弹 / 失败强度序列 → 掩码 → 聚合。

- 与趋势掩码不同：反弹 / 失败是**日内形态**，趋势是跨日方向；
- 与 up_trend 叠加可构成「低开高走且市场强势」的复合掩码。

## 收益来源

本页归属 [[alpha/极端时刻过度反应|极端时刻过度反应]]

**它服务于哪些赚钱逻辑**：主要服务于**反转**——低开高走的极端样本常是恐慌错杀后的修复，高开低走的极端样本是亢奋后的回落，两者都对应情绪冲击后的价格修正。次要服务于**行为偏差**——日内极端摆动是凸显效应、处置效应与羊群的集中体现（恐慌卖出压低最低价、亢奋追入推高最高价），形态掩码把这些偏差发生的样本切出来。

**对手方**：在低开时恐慌割肉、错失修复的投资者；在高开时亢奋追入、承受回落的投资者。

**理论支撑**：[[alpha/极端时刻过度反应|极端时刻过度反应]]、[[concepts/行为金融凸显理论|行为金融凸显理论]]。

**失效条件**：
- **低开高走由真实利好驱动**：价格收复是信息重估而非情绪错杀，后续不会反转而是延续；
- **形态在不同市场制度下含义改变**：如涨跌幅限制、T+1 会改变高低开后的可交易性，情绪修复机制被约束；
- **极端形态由流动性事件造成**：如指数调仓、大额赎回，与情绪无关。

## 适用场景

- **日内反转形态因子**：在反弹 / 失败掩码选中的交易日上统计后续收益；
- **情绪摆动切片**：把高摆动日与平稳日分组对比；
- **与趋势掩码组合**：构造「弱势市场中的低开高走」等条件形态；
- 在**波动较大、散户参与度高**的池子里区分度更好。

## 边界与陷阱

- **高低价含集合竞价（数据层）**：当日最高 / 最低若来自开盘或收盘集合竞价，$\text{bounce}/\text{fail}$ 强度会被人为抬高，须明确极值口径；
- **强度与截面排名的双重极端（计算层）**：既要当日形态极端、又要截面排名靠前，样本可能很稀疏，须检查命中数量；
- **与趋势掩码混淆（概念层）**：反弹 / 失败是**日内**形态，不能替代跨日趋势；两者叠加时须明确主次；
- **分子分母口径（计算层）**：用 $\text{close}/\text{low}$ 与 $\text{open}/\text{close}$ 等不同基准会得到不同形态定义，须与命题一致。

## 可变异维度

- 强度口径：$\text{close}/\text{low}$ → 收盘相对开盘
- 阈值：0.8 → 0.9
- 形态组合：bounce + up_trend 可叠加
- 基准：市场截面排名 → 自身时序分位
