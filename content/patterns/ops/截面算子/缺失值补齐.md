## 金融解释

**做什么**：对因子值有缺失的股票，按情况补其因子值为**行业均值**或 **0**，使截面保持完整、所有股票都能进入排序与回归。

**为什么需要它**：财务因子在两类股票上天然缺失——新上市（无足够历史报告）、亏损或停牌（某些比率无定义，如净利润为负时部分增速失效）。若不补齐而直接删除，会导致：一是**样本损失**，某些行业或市值段的股票被系统性剔除，因子组合向「有完整财务数据」的成熟公司倾斜；二是**样本不可比**，不同因子的缺失集合不同，多因子合成的样本不一致，加权结果失真。补齐的价值在于**把缺失本身中性化**——让缺值股票以「行业中位水平」参与截面，而不是被排除在定价之外。

**为什么用行业均值或 0**：缺值往往与行业、公司类型相关（如金融股无毛利率、ST 股无正盈利），用**行业均值**补齐保留行业结构、避免跨行业偏置；用 **0** 补齐等价于「相对截面中枢无信息」，在标准化后的因子上即取中位位置。两种口径是对缺失原因的两种假设——「应有但没披露」用行业均值，「无意义或不可比」用 0。

**与相邻构件的分工**：[[patterns/ops/点算子/条件派生|条件派生]] 提供 when-else 三支的通用形式（条件 → 取值 A / 取值 B），本页是它在「缺失 → 补齐」这一特定条件上的具名实例；[[patterns/ops/截面算子/组内中性化|组内中性化]]/[[patterns/ops/截面算子/行业中性化|行业中性化]] 会以行业为组去均值，与「按行业均值补缺」同源，但目的是剥离行业影响而非补值。

## 算子定义

```
if is_missing(f):
    f_filled = industry_mean(f)      # 或：0 / 全截面均值 / 中位数
else:
    f_filled = f
# 逐截面、按行业分组计算均值；行业中位数亦可替代均值以抗离群
```

## 适用场景

- **多因子合成的预处理**：统一各因子的样本集合，避免不同因子样本不一致导致的加权偏误；
- **财务因子的截面**：新上市、亏损、停牌导致的缺值，用行业均值或 0 中性化；
- **基本面因子在成长/周期行业间缺失模式不同**时，优先用行业口径补齐以保留结构。

## 边界与陷阱

- **补齐掩盖真实缺值信息**：缺值本身可能携带信息（如「无正盈利」意味质量差），一律用 0 补齐会抹平这一信号，必要时改为**掩码标记**而非补值；
- **行业均值口径依赖分类标准**：申万/中信/GICS 不同分类会改变均值，跨期须固定口径；
- **小行业均值不稳**：细分行业内样本很少时行业均值噪声大，可退化为全截面中位数；
- **与去极值顺序**：应在 [[patterns/ops/截面算子/MAD去极值|MAD去极值]] **之前**补齐，否则补齐值可能又被去极值压缩，或缺失导致 MAD 估计偏差；
- **前视风险**：用全样本或未来样本的行业均值补历史截面即前视，须用当期或滚动窗口均值。
