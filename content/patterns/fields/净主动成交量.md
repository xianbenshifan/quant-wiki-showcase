## 金融解释

**衡量什么**：主动买量与主动卖量的归一化失衡 $\text{net\_active\_vol} = (\text{主动买量} - \text{主动卖量}) / (\text{主动买量} + \text{主动卖量})$，取值 $[-1,1]$，正值表示主动买盘占优，负值表示主动卖盘占优。它是订单流方向的**最基础字段**。

**为什么有信息量**：主动成交（taker）是付出价差、要求即时成交的一方，其净方向直接反映「谁在急、谁的信息更可能占优」。归一化使不同流动性水平的股票与时段可比，并天然抑制了成交量规模的机械影响。它是几乎所有订单流类范式的原始方向输入。

**为什么归一化而非直接用净额**：净额（买量 − 卖量）受个股规模、时段活跃度影响，不可跨股票比较；除以买卖总量后得到相对失衡，量纲统一、便于截面排序，也避免了成交量水平与方向混淆。

**与相邻字段的区别**：

- [[patterns/fields/净主动成交额|净主动成交额]]：**额**口径，同构但量纲不同；额口径对价格冲击的刻画更直接，量口径对股数结构更纯；
- [[patterns/fields/净主动笔数|净主动笔数]]：**笔数**口径，反映交易频率方向的偏移，对碎单结构更敏感；
- [[patterns/fields/主动买占比|主动买占比]]：同一信息的**占比**形式（$= (\text{净失衡}+1)/2$），二者单调对应，不可同时入模；
- [[patterns/fields/主动被动成交差|主动被动成交差]]：条件在各自侧总量上的**主动性结构**，与净失衡维度不同；
- [[patterns/fields/成交量不平衡概率代理|成交量不平衡概率代理]]：度量毒性**强度**（取绝对值、不含方向），本字段度量方向。

## 收益来源

本页归属 [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：赚**信息不对称**的钱——主动买入净额为正意味着知情者或信息优势方在积极吸筹，价格尚未充分反映其信息，跟随该方向可获取信息扩散前的收益；反向（净主动卖出）则用于识别派发与下行压力。

**对手方**：被动挂在对手侧、被主动单吃穿的流动性提供者；以及在净主动方向已明确后仍按旧价格成交的滞后者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]；[[alpha/知情卖出信号|知情卖出信号]]。

**失效条件**：

- **拆单与算法单主导**：主动方向可能只是执行算法的工作方式，不指向信息；
- **做市库存管理**：做市方被动跨价成交使净失衡混入非信息成分；
- **信息被瞬时定价**：主动流方向被市场即时吸收时，跟随无超额收益。

## 加工公式

```
净主动成交量 = ratio(主动买量 − 主动卖量, 主动买量 + 主动卖量)
# 分母为 0 置 null；主动买卖量来自逐笔成交的主动方向标注
```

## 可变异维度

- 口径：量 → 额/笔数
- 频率：5min → 1min

## 适用场景

- **订单流方向的基础输入**：所有主动成交类因子的原始方向；
- **短周期多空信号**：分钟级聚合后用于日内反转 / 动量研究；
- **与其他维度正交组合**：与规模档（大 / 小单）、笔数维度联合刻画资金结构。
