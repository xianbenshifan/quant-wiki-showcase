## 金融解释

**做什么**：把指定列除以它 $k$ 期前的值再减一，$v_t / v_{t-k} - 1$，按标的（合约）分组计算；前值非正或非有限时置空。得到的是价格或数量的**变化率**。

**为什么单列一页**：它是最基础的「水平 → 收益」变换，几乎所有动量、反转、波动率因子都从它出发。相比 [[patterns/ops/点算子/收益涨跌幅变换|收益涨跌幅变换]]（含 abs / ex 衍生与压缩的变换族），本页聚焦逐点实现本身：分组、滞后与守卫。把守卫单独写明，是因为前值非正时比率在数学上仍可算、在经济上却无意义（零值 / 负值序列会产生伪收益）。

## 算子定义

```
pct_change(x, k=1) = v_t / v_{t-k} - 1
# 按 Contract 分组；v_{t-k} <= 0 或非有限 -> null
```

## 适用场景

- 价格收益（动量 / 反转）；
- 量、额等水平量的变化率；
- 多期收益与累计变化；
- 作为波动率、相关性等二阶统计的输入。

## 边界与陷阱

- **前值非正即置空**：负值 / 零值序列会整段失效，这是有意的口径选择而非缺陷，但须让下游明确这些样本是缺失而非 0；
- **停牌与复权**：跨停牌日的 $v_{t-k}$ 与实际可比价不一致，须用复权价或按交易日对齐，否则产生伪跳跃；
- **$k$ 与频率匹配**：$k$ 倍 bar 周期的物理时长决定经济含义，分钟级 $k=1$ 与日频 $k=1$ 不可比；
- **与收益涨跌幅变换的重复风险**：二者同源，实现口径须一致（同为正值约束、同样滞后口径），不要在同一库里并存两套不同守卫；
- **对前值极小值敏感**：比率在前值接近 0 时极易被放大，应置空而非靠 eps 硬除。

## 可变异维度

- 滞后 k：1 → 2 / 5
- 对象：价格 / 量 / 额
