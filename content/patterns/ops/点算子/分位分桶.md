## 金融解释

**做什么**：按截面分位数把连续取值切成 $n$ 个样本（近似）均衡的桶，输出桶号 0..n-1。它把连续暴露离散化为有序分组。

**为什么单列一页**：分位分桶是**非参分层**的入口。需要「把暴露当分类变量」时（分组中性化、分组统计、分组回归），用分位桶比用绝对阈值更能保证各组样本均衡、跨期可比——切点随分布自适应，不随市场整体水平漂移。它也是 [[patterns/ops/截面算子/组内中性化|组内中性化]] 最常用的分组键来源之一，并可直接用于构造分位组合。

## 算子定义

```
bucket(x, n_bins) = floor(percentile_rank(x) * n_bins)    # 0..n_bins-1
# 逐截面；分位口径（截面 / 时序）须明确
```

## 适用场景

- **分组中性化 / 分组回归的分组键**；
- **分层组合构造**：按暴露分位分桶做多空；
- **非参控制**：不想假设暴露与收益线性关系时，用桶号做哑变量；
- **截面样本充足、需要稳健分层时**。

## 边界与陷阱

- **桶内信息被抹掉**：同一桶内可能仍有单调关系，分桶后只剩「档位」，若信号连续变化会损失精度；此时用 [[patterns/ops/截面算子/截面排名|截面排名]] 或 z 更合适；
- **$n$ 的两难**：桶太少分层太粗、组间差异被平均；桶太多每组样本不足、估计噪声大，且桶边界抖动。经验上取 5 / 10，并检查结果对 $n$ 的敏感性；
- **分位口径混淆**：截面分位（同日全市场）与时序分位（个股自身历史）切出的桶含义不同，前者用于横截面比较、后者用于个股状态，两者不可互换；
- **桶大小不均**：截面标的数不能被 $n$ 整除、或存在大量并列值时，各桶样本不等，组均值估计精度不一致；
- **输出是序数**：桶号是类别标签，不能当连续值做加减乘除或线性回归（除哑变量化）。

## 可变异维度

- n_bins：4 / 8 / 16
- 分位口径：截面 → 时序
- 分组键组合：行业 × 桶
