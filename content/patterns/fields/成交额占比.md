## 金融解释

**衡量什么**：$\text{AMTPercent}_{i,t} = \text{AMT}_{i,t} / \sum_j \text{AMT}_{j,t}$，即个股在某一时点的成交额占**全市场同期**成交额的份额。它把个股成交放到市场截面上归一，回答「这只股票当下吸引了全市场多少比例的成交」。

**为什么有信息量**：绝对成交额高的股票可能只是因为它市值大、股本多，未必「异动」；除以全市场同期成交额后，得到的是**相对市场的成交集中度**。当某只股票的份额明显高于其常态时，说明资金在当下集中涌入，这通常与**注意力事件**（新闻、涨幅榜、社交热度）或信息扩散相关。把分母固定为「全市场同期」，还能剔除市场整体的量能涨落——牛市普涨时所有股票成交额都高，但份额不一定变，因此该字段刻画的是**相对异动**而非绝对活跃。

**为什么用同时点占比**：成交额有明显的日内节律（开盘、尾盘高），若用全日总额或不同时间窗做分母，会混入节律差异。按「同一时点」归一，等于把每只股票、每个时点都放在同一市场基准下比较，剔除了日历与时段效应。

**t−1 领先版本**：在极端收益分钟的构造中，常取**前一期**（$t-1$）的成交占比作为信号——强调的是「价变之前」的成交领先，而非与价格同步的成交。这样得到的字段度量的是**价格变动之前**的成交异动，可用于刻画「先有量、后有价」的传导。

**与相邻字段的区别**：

- [[patterns/fields/成交额单位比率|成交额单位比率]]：除以**自身当日峰值**（时序归一），本字段除以**全市场同期**（横截面归一）；前者度量「相对自身有多放量」，后者度量「相对市场有多集中」；
- [[patterns/fields/成交额增量|成交额增量]]：绝对增量，不含归一；
- [[patterns/fields/成交量不平衡概率代理|成交量不平衡概率代理]]：度量订单流毒性，与本字段的「活跃份额」维度不同。

## 收益来源

本页归属 [[alpha/量激增注意力|量激增注意力]]

**赚什么钱**：主要赚**注意力**的钱——成交份额的异常抬升是关注度与信息扩散的直接代理，注意力驱动的集中买入把价格推离基本面，随后随关注度衰减而回归；领先版本进一步刻画了「量在价先」的传导，可用于事件驱动型信号。

**对手方**：在成交异动中被吸引追入、承接了注意力定价偏离的投资者。

**理论支撑**：[[concepts/行为金融凸显理论|行为金融凸显理论]]（注意力与显著效应）；[[alpha/活跃度条件反转|活跃度条件反转]]。

**失效条件**：

- **全市场普涨/普跌**：极端行情下分母剧烈波动，个股份额被系统性稀释或放大，截面差异失真；
- **指数与 ETF 交易**：被动资金造成的成交份额变化不含注意力含义；
- **停牌/无成交**：份额为 0 或缺失的标的需与「低关注」区分处理。

## 加工公式

```
成交额占比(i,t) = 成交额(i,t) / Σ_j 成交额(j,t)
# 全市场分母；停牌/无成交个股不计入或占比记为 0（口径须统一）
```

## 可变异维度

- 分母：全市场 → 同行业 / 同指数成分
- 频率：1 分钟 → 5 分钟
- 滞后：当期 → t−1（领先）

## 适用场景

- **注意力/异动事件的识别**：捕捉相对市场的成交集中；
- **领先版本用于量在价先研究**：以 $t-1$ 占比预测当期价格变动；
- **作为量价因子的成分**：与收益共振类字段配合，构成价量共振信号。
