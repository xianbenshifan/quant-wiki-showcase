## 金融解释

**衡量什么**：最高价与最低价之间的相对摆动幅度。常用两种口径：**比率口径** $\text{High}/\text{Low} - 1$（以最低价为基准），以及**昨收口径** $(\text{High} - \text{Low})/\text{Close}_{t-1}$（以昨日收盘为基准，衡量相对前收的日内波动）。两者都度量「当日价格走过的范围」，但基准不同，量纲与分布略有差别。

**为什么有信息量**：振幅是**波动环境**的直接度量，也是低波异象与若干「切割/修正」振幅因子的共同输入。它的信息含量不止于「波动大小」：

- 振幅高说明当日的价格发现过程剧烈、多空分歧大，这类股票往往更受**博彩偏好**资金的青睐（彩票型股票的特征之一就是高振幅），并伴随更高的尾部风险；
- 高价区与低价区的振幅分布可以不同——同样幅度的摆动，发生在高位（已上涨后）与低位（已下跌后）所对应的行为含义不同，这也是「理想振幅切割」按收盘价分位分组的原因；
- 结合 [[patterns/fields/日跳跃度|日跳跃度]] 可以判断振幅是否由**跳跃**（消息冲击）贡献，从而区分「已吸引博彩资金的消息型波动」与「平稳的常态波动」。

因此振幅是一个看似简单的字段，却处在低波异象、博彩偏好、波动风险定价三条逻辑的交汇处。

**与相邻字段的区别**：

- [[patterns/fields/已实现跳跃波动率|已实现跳跃波动率]]：从高频收益分解出跳跃分量，是**路径**视角；振幅只用最高/最低价，是**极值**视角（对单笔极端成交更敏感）；
- [[patterns/fields/收益波动比|收益波动比]]：把收益除以波动估计，度量单位波动的收益实现，本字段只给波动的**幅度**；
- [[patterns/fields/换手率|换手率]]：度量交易**活跃度**（量/股本），与振幅常被并列作为「情绪/热度」的二维刻画。

## 收益来源

本页归属 [[alpha/连续波动补偿|连续波动补偿]] [[alpha/可知性分流定价|可知性分流定价]]

**赚什么钱**：主要赚**波动与尾部风险溢价**的钱——高振幅股票承担更大的日内价格风险与崩盘尾部风险，厌恶风险的投资者要求更高预期收益；同时低振幅股票在「低波异象」下表现出风险调整后更优的收益，是这一溢价在截面上的另一面。

**对手方**：愿意为博彩型、高振幅收益付出溢价的投资者（他们买入波动、承担尾部风险，为波动卖方支付保险费）；以及在高波动中被动承受损失的一方。

**理论支撑**：[[concepts/特异波动异象|特异波动异象]]（波动率与截面收益的反向关系）；[[concepts/行为金融凸显理论|行为金融凸显理论]]（大幅摆动吸引注意力）。

**失效条件**：

- **低波异象反转**：在特定市场状态（如流动性危机、极端行情）下，高波动的风险补偿关系可能反转；
- **振幅被单笔异常价污染**：最高/最低价可能由一笔异常成交造成，此时振幅不代表真实波动环境；
- **涨跌停约束**：涨跌停会截断当日的价格范围，使振幅被系统性低估。

## 加工公式

```
振幅(比率口径) = 最高价 / 最低价 − 1
振幅(昨收口径) = (最高价 − 最低价) / 前收盘价
# 最低价/前收盘价近零或非正时置 null
```

## 派生形态

- **理想振幅切割**：按收盘价分位日分别均值再作差 → [[paradigms/理想振幅|理想振幅]]。
- **日内振幅切割（涨跌幅键）**：按分钟涨跌幅高低 λ 切割振幅，再 Vmean/Vstd 等权 → 日内振幅切割因子。
- **翻转/修正振幅**：低跳跃度日振幅取反 → [[paradigms/修正的振幅|修正的振幅]]。

## 可变异维度

- 口径：High/Low−1 ↔ (High−Low)/昨收
- 频率：日 → 5min

## 适用场景

- **低波/高波异常的横截面因子**：作为波动风险的基础度量；
- **博彩偏好的代理**：与换手率、价格水平联合识别彩票型股票；
- **分组与切割条件**：按振幅分位或按涨跌幅切割，构造条件因子（理想振幅、日内振幅切割）。
