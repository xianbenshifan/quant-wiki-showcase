## 金融解释

**衡量什么**：最优买价与最优卖价上挂单量的归一化失衡：$\text{prox\_imb} = \dfrac{BV_1 - SV_1}{BV_1 + SV_1}$，取值理论上落在 $[-1,1]$；落在边界的 $\pm 1$ 或 $0$（单边挂单退化为 dominance 状态）视为不可信，置 null。正值表示买一挂单占优。

**为什么有信息量**：最优档是成交发生的唯一位置，也是买卖双方力量对比最直接的交锋点。买一挂单远厚于卖一，说明买方愿意在最优价位承接、卖压相对不足，短期价格更可能向上；反之亦然。它是**订单流方向最直接、最原始的代理**，几乎不需要任何假设，因此成为盘口类因子的基准构件。与 OFI 等增量指标相比，近端失衡是**存量快照**，反映的是当前状态而非变化速率。

**与相邻字段的区别**：

- [[patterns/fields/订单流失衡|订单流失衡]] / [[patterns/fields/浅档订单流失衡|浅档订单流失衡]]：度量挂单量的**增量**方向（Δ 流量）；近端失衡是**存量**水平，二者机制不同，常呈领先 / 滞后关系（OFI 先动、失衡随后）。
- [[patterns/fields/加权失衡|加权失衡]]：把各档买卖量差做距离加权求和，覆盖多档；近端失衡只看第一档，噪声更大但更即时。
- [[patterns/fields/微价格偏离|微价格偏离]]：把最优档挂单量差异映射为**价格**的加权偏离，是同一信息的价版表达；近端失衡是量版。
- [[patterns/fields/最优档深度|最优档深度]]：只看最优档的**总厚度**、不带买卖方向；近端失衡看两侧的相对比例，方向是核心。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：其一为**信息不对称**——最优档的买卖失衡是知情者下单意图的最早可见痕迹，跟随失衡方向可在信息扩散前建仓；其二为**流动性溢价**——一侧挂单显著偏薄意味着该侧流动性供给不足，为补足这一侧提供流动性者可获得补偿，失衡也刻画了即时流动性压力的方向。

**对手方**：在偏薄一侧被主动单吃穿挂单的流动性提供者；以及依据可见失衡方向追单、却被反向信息打击的跟随者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **挂单可自由撤销**：最优档失衡只是可撤回的承诺，幌骗挂单会制造虚假失衡；
- **做市算法快速均衡**：高频做市使失衡在毫秒级被抹平，快照中的失衡不含持久信息；
- **制度性单边**：涨跌停封板时最优档退化为单边，失衡失去比较意义。

## 加工公式

```
prox_imb = ratio(BV_1 - SV_1, BV_1 + SV_1)
# 边界值（归一化后 ∈ {-1, 0, 1}）置 null；分母近零置 null
```

## 适用场景

- 作为**订单流方向**的基准度量，用于短周期价格压力信号；
- 与 [[patterns/fields/加权失衡|加权失衡]]、[[patterns/fields/微价格偏离|微价格偏离]] 交叉验证；
- 与 OFI 类增量指标组合，构建「存量 + 流量」的共振信号；
- 在**报单连续、tick 数据完整**的活跃标的上最可靠；冷门股最优档常年单边，需谨慎。

## 可变异维度

- 口径：绝对失衡 → 归一化失衡
- 边界处理：置 null → 保留 ±1
