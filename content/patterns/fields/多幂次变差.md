## 金融解释

**衡量什么**：取相邻的 $k$ 个分钟对数收益，把它们的**绝对值**按幂次 $m_1,\dots,m_k$ 相乘，再对整个交易日求和并按正态矩常数 $\mu_q$ 归一：$V_{m_1,\dots,m_k} = \sum_i |r_i|^{m_1}\cdots|r_{i-k+1}|^{m_k}$。常用的双幂次（$k=2$，$m$ 各取 1）与三幂次（$k=3$，$m$ 各取 $2/3$）分别对应 RBV 与 RTV。它估计的是波动中的**连续分量**（积分波动率），而不是包含跳跃的总波动。

**为什么有信息量**：价格变动可分解为连续扩散与（有限活跃的）跳跃两部分。已实现二次变差 $\sum r_i^2$ 同时包含两者，会被少数极端跳跃主导；而多幂次变差用**相邻收益的乘积**代替平方，单个极端收益只与相邻的（通常很小的）收益相乘，因此其对跳跃的敏感性被大幅削弱，成为连续分量的稳健估计 $\widehat{IV}$。这一点有双重价值：一是作为**独立的高频波动因子**，刻画剔除了跳跃的「基础波动」；二是作为 [[patterns/fields/已实现跳跃波动率|已实现跳跃波动率]] 的减项，$\max(\text{RV}-\widehat{IV},0)$ 才能把跳跃分离出来。没有它，跳跃分解无从谈起。

**与相邻字段的区别**：

- [[patterns/fields/已实现跳跃波动率|已实现跳跃波动率]]：以本字段为连续分量估计，度量**跳跃**强度；本字段度量的是**连续**波动，二者的差即跳跃。
- [[paradigms/已实现波动率|已实现波动率]]：二次变差，是总波动（连续 + 跳跃）；本字段是其连续分量的稳健估计。
- [[patterns/fields/更优波动率|更优波动率]]：用 5 分钟内开高低收 4 价、分钟级局部窗口估计；本字段用全日相邻收益幂积，尺度更长、对跳跃更稳健。
- [[patterns/fields/日跳跃度|日跳跃度]]：用单复利差残差近似跳跃，是低频代理；本字段是高频二次变差族口径。

## 收益来源

本页归属 [[alpha/连续波动补偿|连续波动补偿]]

**赚什么钱**：主要赚**波动与尾部风险溢价**的钱——连续波动是不可分散的基础风险，厌恶波动的投资者要求更高预期收益补偿；在与跳跃分量分解后，连续波动与跳跃风险可分别定价，本字段提供的是其中**连续成分**的风险暴露。

**对手方**：不愿承担波动风险、以较低预期收益持有低波资产（或卖出波动）的投资者；他们为波动风险的承担者支付溢价。

**理论支撑**：[[concepts/特异波动异象|特异波动异象]]（波动率与截面收益的关系）。

**失效条件**：

- **跳跃被连续化**：涨跌停、交易机制或数据频率把本应一次完成的跳跃拆成多根小步收益，多幂次变差会高估连续分量；
- **波动溢价信息被套利消除**：当低波异象/波动卖方拥挤时，波动风险的定价关系可能压缩甚至反转；
- **连续波动中混入微观结构噪声**：买卖价差跳动被算作小收益，会系统性抬高估计并使其与流动性混淆。

## 加工公式

```
# 一般形式
V_{m1,...,mk} = Σ_i |r_i|^{m1} |r_{i-1}|^{m2} … |r_{i-k+1}|^{mk}
μ_q = E(|Z|^q) = 2^{q/2} Γ((q+1)/2) / Γ(1/2)

# 双幂次变差（k=2，各幂次取 1）
RBV = μ_1^{-2} · Σ_i |r_i| · |r_{i-1}|

# 三幂次变差（k=3，各幂次取 2/3）
RTV = μ_{2/3}^{-3} · V_{2/3,2/3,2/3}
# 相邻收益缺失时该乘积项跳过，不置 0
```

## 派生形态

- **已实现双幂次变差 RBV**：$k=2$，相邻绝对值积 → 已实现双幂次变差因子
- **已实现三幂次变差 RTV**：$k=3$，三分之二次幂积 → 已实现三幂次变差因子

## 可变异维度

- $k$：2（双幂）↔ 3（三幂）↔ 更高阶
- 幂次：等比均分（如各 $2/k$）或其它 $m$ 组合
- 频率：5 分钟（$n\approx48$）↔ 1/10 分钟

## 适用场景

- **跳跃分解的连续分量估计**：作为 RVJ 的减项，把跳跃从总波动中分离；
- **独立的连续波动因子**：研究「剔除跳跃后的基础波动」与截面收益的关系；
- **波动状态识别**：作为已实现波动率的稳健替代，用于波动状态切换与条件分层；
- **采样频率适中**：5 分钟是噪声与精度的折中，过密会引入微观结构噪声。
