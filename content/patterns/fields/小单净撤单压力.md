## 金融解释

**衡量什么**：小单（散户）人群的撤单率净压 = 「小单买撤量 / 小单买量 − 小单卖撤量 / 小单卖量」。正值表示小单相对更倾向于**撤掉买单**（买盘退缩），负值表示更倾向于撤掉卖单（卖盘退缩）。

**为什么有信息量**：撤单是**不产生成交就能撤回意愿**的行为，因此撤单率是观察人群真实态度的镜子——挂单代表意图，撤单代表意图的动摇。小单的撤单行为尤其值得单看，因为散户的下单与撤单更受情绪支配：他们常常在上涨时挂出买单、随后因价格波动或情绪转变而撤掉，或在下跌时挂出卖单再撤回。**小单买撤率系统性偏高**（净压为正）说明散户的买盘支撑是「虚的」——看似有买盘，实则随时会撤，这类名义支撑不足以承接抛压，价格更容易向下；反之若散户集中撤卖，说明卖压是虚的。

**为什么要把小单单独抽出来**：散户与机构的撤单动机不同。机构的撤单更可能是策略性报价调整，携带信息；散户的撤单更多是情绪的反复。把两者混在一个「总撤单失衡」里，等同于把两种性质相反的行为平均掉。单独看小单撤单，得到的是**大众人群情绪稳定度**的干净度量。

**与相邻字段的区别**：

- [[patterns/fields/小单净撤单笔数压力|小单净撤单笔数压力]]：同一构想的**笔数口径**版本，对撤单频率敏感；本页是**量口径**，对被抽走的盘口容量敏感；
- [[patterns/fields/净撤单压力|净撤单压力]]：不区分人群，分母用**实际成交量**而非挂单量，是「全市场」的撤单压力；本页限定小单且分母用挂单量；
- [[patterns/fields/大单净撤单压力|大单净撤单压力]]：大单人群的对应物，二者之差即撤单背离；
- [[patterns/fields/撤单强度时序单位比率|撤单强度时序单位比率]]：只度量撤单**总量**强度，不分人群与方向。

## 收益来源

本页归属 [[alpha/量激增注意力|量激增注意力]]

**赚什么钱**：主要赚**信息不对称**的钱——小单撤买率偏高时，名义买盘虚化，真实承接力弱于盘口显示，这一信息尚未反映在价格中，价格更易下行；次要赚**行为偏差**的钱——散户撤单率是情绪反复的代理，其系统性模式（涨时虚挂买单、跌时虚挂卖单）本身是可被反向利用的行为偏差。

**对手方**：依据盘口挂单判断支撑/阻力的交易者——他们把散户随时可撤的挂单当作真实需求，从而误判供需；以及追涨杀跌、反复挂撤而付出交易成本的散户自身。

**理论支撑**：[[alpha/大小单博弈|大小单博弈]]（散户情绪与资金行为）；[[concepts/信息不对称与PIN|信息不对称与PIN]]（盘口名义流动性中的策略性成分）。

**失效条件**：

- **散户占比下降**：市场机构化后小单不再等价于散户，该字段的行为学含义削弱；
- **撤单监管与做市约束**：撤单成本上升（如撤单费、监管限制）会系统性降低小单撤单率，截面差异被压缩；
- **真实流动性与意图背离被抹平**：当所有参与者都使用同类算法撤单时，人群差异不再携带信息。

## 加工公式

```
小单买撤量 = max(买撤单量 − 超大单/大单/中单买撤量之和, 0)
小单卖撤量 = max(卖撤单量 − 超大单/大单/中单卖撤量之和, 0)
小单净撤单压力 = 小单买撤量 / 小单买量 − 小单卖撤量 / 小单卖量
# 各分母近零置 null；剩余法负值截断为 0
```

## 适用场景

- **识别虚化买盘/卖盘**：在盘口有大量小额挂单但价格迟迟不动时，撤单净压可提示这些挂单是否可信；
- **与笔数口径联合**：量、笔数两口径同号时更稳；异号提示存在单笔大额撤单或大量小额撤单；
- **散户主导的标的与时段**：小市值、高换手标的中，小单撤单信号更强。
