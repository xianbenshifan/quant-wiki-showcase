## 金融解释

**衡量什么**：相对价差的一阶差分 $\Delta\text{rel\_spread} = \text{rel\_spread}_t - \text{rel\_spread}_{t-1}$，即报价宽度相对上一期的**瞬时变化**。正值表示价差走阔（交易成本瞬升），负值表示价差收窄。

**为什么有信息量**：相对价差是**水平**（流动性成本有多高），价差冲击是**变化**（成本在瞬间怎样跳变）。价差的突然走阔通常意味着流动性提供者在一瞬间撤出、或提高了逆向选择补偿——这往往发生在信息事件、深度被抽走或波动骤升的时刻，是市场微观结构恶化的领先信号；价差骤降则可能对应流动性回归或波动平息。因此它是**流动性状态突变**的探测器，而不只是一个成本水平。

**为什么用相对价差做差分**：绝对价差不可跨股票比较，相对价差已按中间价标准化；对其做差分既保留「走阔 / 收窄」的方向，又使不同价位股票的变化可比。

**与相邻字段的区别**：

- [[patterns/fields/相对价差|相对价差]]：水平量（存量），本字段是其变化（流量 / 事件）；
- [[patterns/fields/深度冲击|深度冲击]]：从**数量**维度刻画最优档承接力被抽走；本字段从**价格**维度刻画报价宽度突变，二者互补，常同向出现；
- [[patterns/fields/深度变化|深度变化]]：总深度的变化，与本字段分别对应盘口的价、量两维；
- [[patterns/fields/微价格偏离|微价格偏离]]：盘口内部的方向性偏离，本字段不含方向。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]]

**赚什么钱**：赚**流动性溢价**——价差走阔意味着提供即时流动性所需的补偿上升，在被冲击、宽度突变的时点，剩余流动性提供者承担了更高的库存与逆向选择风险，理应获得更高的预期补偿；价差冲击刻画这一风险变化的速度。

**对手方**：在价差骤升时仍需跨越价差成交的急躁交易者；以及在流动性收缩中被迫变现的持仓者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（价差中的逆向选择成分）。

**失效条件**：

- **最小报价单位约束**：低价股价差被报价单位主导，变化更多是制度噪声而非流动性信号；
- **隐藏流动性替代**：真实成交在价差内通过隐藏单完成，报价价差变化与实际成本脱钩；
- **高频做市快速修复**：价差冲击在毫秒级被回补，仅是撮合噪声，不含真实流动性事件。

## 加工公式

```
价差冲击 = 相对价差_t − 相对价差_{t−1}
# 首期置 null（或按约定回退为当期相对价差）
```

## 可变异维度

- 差分：一阶 → 多阶
- 基准：相对价差 → 绝对价差

## 适用场景

- **流动性状态突变的探测器**：识别价差骤变的时点，研究其后的价格冲击；
- **与深度冲击配对**：价差走阔叠加深度骤降是典型的脆弱状态；
- **交易成本建模**：刻画执行成本的时变。
