## 金融解释

**衡量什么**：超大单卖出的成交均价 $= \text{超大单卖额}/\text{超大单卖量}$，相对全市场 VWAP 的偏差，再取 signed-log：$x = \text{超大单成交均价}/\text{VWAP} - 1$。**负值表示超大卖家愿意以低于市场均价的价格抛售**，绝对值越大越急迫。

**为什么有信息量**：它度量的是超大卖家的**抛售激进度**。掌握负面信息或急于减仓的大资金，会不断向下打卖盘、把成交价压到 VWAP 之下，以换取成交速度；愿意接受的价格折扣越大，说明抛售意愿越强、信息或流动性压力越大。与买侧溢价对称，它是大资金真实供给强度的直接痕迹，常领先于价格的短期下行，并在过度抛售后留下反转空间。

**与相邻字段的区别**：

- [[patterns/fields/超大单卖撤溢价|超大单卖撤溢价]]：用**被撤**委托报价衡量（虚假或调整中的卖压）；本页用**实际成交**衡量（真实供给强度）。一虚一实。
- [[patterns/fields/超大单买溢价|超大单买溢价]]：买侧镜像；买溢价高（抢筹）与卖溢价深负（抛售）同时出现，说明大资金在激烈换手、分歧巨大。
- [[patterns/fields/大单卖溢价|大单卖溢价]]：规模档降到大单，语义同构、样本更多。
- [[patterns/fields/净主动成交量|净主动成交量]]：度量超大单的**方向性净额**；本字段度量**成交价格位置**，是强度而非方向的补充。

## 收益来源

本页归属 [[alpha/超大单冲击回补|超大单冲击回补]]

**赚什么钱**：赚**信息不对称**的钱。超大单愿意以低于 VWAP 的价格抛售，反映其对标的有负面信息优势或强烈的减仓压力。若这一信息尚未被充分定价，跟随卖出 / 回避该股票可规避信息扩散带来的下跌；深度负溢价也标记了短期过度抛售，为随后的反弹提供机会。本质上赚的是**知情大单定价不足**的钱。

**对手方**：在超大单主动卖出中接盘的流动性提供者与买方，他们在信息劣势下成为对手；以及消息扩散后才跟风卖出的滞后交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]、[[concepts/信息冲击反应不足与过度|信息冲击反应不足与过度]]。

**失效条件**：

- **大额卖出为非知情交易**：指数调仓、赎回、被动减仓造成的大单不含私有信息，溢价无预测力；
- **信息被瞬时定价**：市场效率高时，负溢价刚出现即被套利，超额收益消失；
- **流动性冲击主导**：若抛售源于流动性需求而非信息，价格影响会较快恢复，方向信号失效。

## 加工公式

```
vwap = ratio(成交额, 成交量)                        # 全市场 VWAP
x    = ratio(超大单卖额, 超大单卖量) / vwap - 1     # 超大单成交均价相对 VWAP 的偏差
prem = sign(x) * ln(1 + |x|)                        # signed-log 压缩
# 超大单卖量或成交量近零置 null
```

## 适用场景

- 作为**大资金抛售压力 / 知情交易强度**的代理，用于微观结构因子与事件研究；
- 与 [[patterns/fields/超大单买溢价|超大单买溢价]] 配对：买溢价低 + 卖溢价深负 = 强空头结构；
- 与撤单溢价、净流入方向组合，区分「真实抛售」与「虚假挂单恐吓」；
- 在**逐笔成交数据完整、规模分档稳定**的市场中构造；日频上可对日内值聚合。
