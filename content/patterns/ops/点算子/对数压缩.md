## 金融解释

**做什么**：对列做 $\log(1+x)$，压缩正偏分布的右尾，使大值不再压倒性主导下游统计。

**为什么单列一页**：成交额、成交量、市值、持仓等水平量近似**对数正态**，原始尺度下方差几乎完全由少数大值决定，均值、回归、相关都会被它们主导。对数变换把**乘法性差异**转成**加法性差异**——「10 倍」与「100 倍」的差距在对数域只差一个固定步长，更符合「相对规模」的经济直觉，也让线性模型与相关系数更稳健。

## 算子定义

```
log(x) = ln(1 + x)        # 仅对 x >= 0 有意义；x < 0 -> null
```

## 适用场景

- **正偏水平量**：成交额、成交量、换手、市值；
- **需要跨规模可比、弱化大值主导的合成 / 回归**；
- **与比值结合**：先压缩再标准化，降低尾部影响；
- **量级跨度大的字段**：原始值数量级跨越多个十位时尤其必要。

## 边界与陷阱

- **定义域**：$x < 0$ 无定义（须置空或改用 [[patterns/ops/点算子/带符号对数|带符号对数]]）；$x = -1$ 会发散，须守卫；
- **接近零时压缩过强**：$\log(1+x)$ 在 $x\approx 0$ 附近近似线性尚可，但对含大量零的稀疏量会放大零附近差异，未必符合预期；
- **不是稳健化**：对数只压右尾，若离群出现在负方向则无帮助；
- **不可逆的口径变化**：取对数后「均值」不再等于原始均值、「总和」也不再可加，跨口径对账须还原；
- **与带符号对数的选择**：只有非负量用本算子，可正可负用带符号版本，混用会静默丢样本。

## 可变异维度

- 对象：正偏量（成交额 / 量）
- 平移常数：$\log(1+x)$ 的 1 → 其他
