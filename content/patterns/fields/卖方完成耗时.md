## 金融解释

**衡量什么**：对卖侧订单，取「平均完结时间」与「平均挂出时间」各自的对数，相减得到存活时长的对数增量，再做有符号对数压缩：$\text{sign}(d)\cdot\ln(1+|d|)$，其中 $d = \ln(\text{卖单平均完结时间}+1) - \ln(\text{卖单平均挂出时间}+1)$。数值越大，表示卖单从挂出到结清等待得越久。

**为什么有信息量**：订单存活时长是流动性提供者**耐心**的直接体现。愿意长时间挂着卖单等待成交的参与者，实际上是在提供即时流动性、承担库存与逆向选择风险；卖单被迅速成交或撤走，则说明卖方急躁、耐心低。因此卖方完成耗时是**卖侧流动性供给意愿**的代理：耗时越长，卖侧供给越稳、微观结构越厚；耗时越短，卖压越急躁、由流动性需求主导。把它单独抽出来，是因为买卖两侧的耐心可以显著不同——买侧耐心远高于卖侧，可能预示需求更持久，反之则供给更迫切。

**与相邻字段的区别**：

- [[patterns/fields/买方完成耗时|买方完成耗时]]：镜像的买侧版本，二者之差揭示两侧耐心结构。
- [[patterns/fields/订单完成耗时|订单完成耗时]]：综合买卖两侧的总口径，是两侧的加权合成，与本字段同时入模会信息重复。
- [[patterns/fields/成交执行率|成交执行率]]：度量「实际成交 / 挂单量」的**比例**；完成耗时度量「挂了多久才结清」的**时间**，二者互补。
- 撤单类字段：撤单是挂单「未完结」的另一种结局，与完成耗时共同刻画挂单的命运结构。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/信息风险补偿|信息风险补偿]]

**赚什么钱**：其一为**流动性溢价**——卖单存活时间长意味着有人持续提供卖侧流动性、承担被动成交风险，理应获得补偿，完成耗时是这一供给耐心的代理；其二为**信息不对称**——知情者希望快速完成以隐藏意图，卖侧完成耗时异常短可能标记知情抛售，而耗时长更多是被动流动性提供者。

**对手方**：需要即时成交、以主动单吃掉耐心挂单的急躁交易者；以及为流动性提供者的库存风险买单的一方。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **高撤单率环境**：订单整体存活时间被频繁撤单压缩，完成耗时更多反映撤单策略而非耐心；
- **算法拆单与冰山单**：可见订单的存活时间被算法重塑，与实际供给意愿脱钩；
- **行情剧烈期**：价格快速变动使卖单几乎瞬间成交或被撤，截面差异被压缩。

## 加工公式

```
d = ln(卖单平均完结时间 + 1) − ln(卖单平均挂出时间 + 1)   # 对数时间差
卖方完成耗时 = sign(d) × ln(1 + |d|)                      # 有符号对数压缩
# 时间戳缺失或为 0 时置 null
```

## 可变异维度

- 口径：挂单存活 → 成交点击
- 频率：可调

## 适用场景

- **卖侧流动性供给意愿度量**：用于流动性状态因子、执行质量评估；
- **与买方完成耗时配对**：研究买卖两侧耐心差异与后续价格方向的关系；
- **与成交执行率组合**：高执行率 + 长耗时 = 稳健的流动性供给，低执行率 + 短耗时 = 高频撤单；
- **订单级数据完整**（含挂出与完结时间戳）的市场中可用。
