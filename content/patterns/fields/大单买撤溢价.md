## 金融解释

**衡量什么**：先求被撤回的大额买单的**委托均价**（大单买撤额 / 大单买撤量），再与当日全市场成交均价 VWAP（成交额 / 成交量）比较，取相对偏差并做有符号对数压缩。正值表示被撤的大额买单原本挂在**高于**市场均价的位置。

**为什么有信息量**：撤单本身携带意图，而「被撤订单报价在什么位置」进一步区分了撤单的性质。一笔报价显著高于 VWAP 的大额买单被撤掉，往往并非真心求成交——它挂在偏离市场的位置，可能是为制造买盘汹涌的假象（幌骗式分层挂单），也可能是大额资金测试市场深度后迅速收手；反之，报价接近或低于 VWAP 的撤单更像真实的报价调整或抢先挂单后的放弃。因此本字段度量的是**大额买委托的报价激进度**，是订单流毒性 / 操纵痕迹的一个切面，与「成交了什么价」是两个不同维度。

**与相邻字段的区别**：

- [[patterns/fields/大单买溢价|大单买溢价]]：同公式结构，但分子是**已成交**大额买单的均价，度量真实需求的紧迫度（愿付多高价成交）；本页是**被撤**委托的报价，度量意图真伪。一实一虚，常配合使用。
- [[patterns/fields/超大单买撤溢价|超大单买撤溢价]]：规模档从大单升级到超大单，语义同构；超大单更偏机构/大资金，操纵与意图信号通常更强。
- [[patterns/fields/大单卖撤溢价|大单卖撤溢价]]：卖侧镜像，度量被撤大额卖委托的报价位置；买卖两侧同时极端可能指向双边幌骗。
- [[patterns/fields/撤单失衡|撤单失衡]]：只看撤单的**量向**，不看报价位置，是粗粒度的方向度量。

## 收益来源

本页归属 [[alpha/普通大单信息延续|普通大单信息延续]]

**赚什么钱**：主要赚**信息不对称**的钱——被撤大额买委托的报价位置暴露了订单流的意图结构：异常偏高的远端撤单更像幌骗，会对跟随者形成误导性的深度信号；识别「盘口上哪些买盘是虚的」，等于获得了一般投资者不具备的订单流视角，可在虚假支撑撤去后捕捉价格回落，或避免被虚假需求诱导。

**对手方**：被幌骗挂单误导、以为存在强买盘而追入的交易者；以及无法区分真实与虚假挂单、按可见深度决策的被动方。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（策略性委托与逆向选择）。

**失效条件**：

- **撤单为正常报价调整**：市场波动大时大额委托频繁改价，远端撤单不再标记操纵，溢价失去信息；
- **分层挂单普遍化**：若所有参与者都使用分层/幌骗式挂单，该度量失去截面区分度；
- **监管结构变化**：针对虚假申报的处罚收紧会减少幌骗行为，溢价的信息含量下降。

## 加工公式

```
vwap = 成交额 / 成交量                                  # 全市场 VWAP
x    = (大单买撤额 / 大单买撤量) / vwap − 1             # 委托均价相对 VWAP 的溢价
大单买撤溢价 = sign(x) × ln(1 + |x|)                    # 有符号对数压缩
# 撤单量或市场成交量近零置 null
```

## 适用场景

- **识别虚假买盘**：在挂单频繁出现又消失的价位，用报价位置区分「虚挂」与「真实调整」；
- **与成交溢价配对**：先用大单买溢价判断真实抢筹力度，再用本字段判断盘口买盘真伪；
- **订单流毒性研究**：5 分钟以下频率、逐笔委托数据完整时区分度最高；
- **与不同规模档、卖侧镜像共同构成撤单报价位置的完整画像**。
