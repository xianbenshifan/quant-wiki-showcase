## 金融解释

**衡量什么**：把股票按**代码顺序**排序，取某只股票相邻的 $n$ 只（通常 $n=10$）代码邻居，对其过去 $T$ 日（通常 5–20 日）的日均涨跌幅做等权平均，得到 $\text{NBR\_ret}_i$。

**为什么有信息量**：行情软件、交易终端普遍按代码顺序展示股票列表，投资者的注意力在浏览列表时会**溢出到焦点股票的代码邻居**。当某只股票因事件成为焦点、投资者在列表中查看它时，会顺带看到相邻代码的股票；若焦点股的强势表现引发乐观情绪，这种情绪可能外溢到邻居，推高其价格——这就是**注意力溢出（协同 / 溢出通道）**。邻码股票收益正是这一通道上「邻居表现」的代理变量：邻居涨得好，说明溢出源活跃或溢出方向偏乐观，可用于预测焦点股自身的后续表现或构造溢出类因子。

**与相邻字段的区别**：

- [[patterns/fields/收益率|收益率]]：本字段的原料是邻居的收益率，但合成逻辑建立在**代码相邻**这一非基本面关系上，语义指向注意力通道而非自身收益。
- 行业 / 同概念收益：按基本面相关性（行业、概念板块）分组合成；邻码分组是**展示顺序**驱动的、与基本面无关的外生分组，二者可正交使用。
- [[patterns/fields/超额收益|超额收益]]：个股相对市场的强弱；邻码收益是「邻居」群体的表现，是个股之外的信息。

## 收益来源

本页归属 [[alpha/邻码注意力溢出|邻码注意力溢出]]

**赚什么钱**：赚**注意力与情绪**的钱。注意力溢出使焦点股的情绪向代码邻居扩散，被溢出的邻居价格会暂时偏离其基本面，且在情绪衰减后回归；利用邻居收益的领先性，可在溢出发生早期布局、在回归前退出。这属于关注度 / 情绪驱动的定价，而非基本面定价。

**对手方**：受注意力溢出影响、因「顺带看到」而追买邻居股票的情绪交易者；以及过度外推邻居表现、忽视基本面差异的投资者。

**理论支撑**：[[alpha/邻码注意力溢出|邻码注意力溢出]]。

**失效条件**：

- **展示方式改变**：若终端改为按涨跌幅 / 行业 / 搜索热度排序，代码相邻不再对应注意力相邻，溢出通道断裂；
- **算法与机构主导**：专业投资者按基本面而非列表顺序选股，溢出强度随机构占比上升而减弱；
- **信息快速定价**：市场效率提高使溢出效应在日内即被套利，日频信号的预测力下降。

## 加工公式

```
NBR_ret_i = mean( 日均涨跌幅_j , j ∈ 按代码排序的相邻 n 只 )
# n 常取 10；T 常取 5–20 日
```

## 可变异维度

- 邻居数 n：10 → 5/20
- 窗口 T：5–20
- 聚合：等权 → 距离衰减加权

## 适用场景

- 构造**注意力溢出 / 协同类因子**：用邻居收益预测焦点股的短期表现；
- 作为**情绪状态的横截面代理**，与个股自身收益正交后使用；
- 与 [[paradigms/自信溢出|自信溢出]] 等范式配合，研究溢出方向与强度；
- 在**散户占比高、行情软件使用频繁**的市场中区分度更高；机构主导的市场溢出更弱。
