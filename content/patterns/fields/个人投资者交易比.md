## 金融解释

**衡量什么**：把「小额个人买入金额」与「小额个人卖出金额」取均值（小额阈值常取单笔成交额 < 4 万元），再除以个股当日总成交额：$\text{retail\_ratio} = \text{mean}(\text{小额个人买额}, \text{小额个人卖额}) / \text{总成交额}$。它度量的是**散户在个股成交中的参与份额**，而不是散户的买卖方向。

**为什么有信息量**：散户占比高的股票，定价更容易被情绪与注意力驱动。散户资金分散、信息处理能力弱、交易动机常来自显著收益与新闻曝光，因此当一只股票的成交主要由小额个人单构成时，它对情绪冲击更敏感、更容易出现过度反应。经验上小市值股票的该占比系统性更高，这正是「小市值更易受显著效应影响」这一说法的微观基础。它因此常被用作**情绪 / 显著类因子的权重**——把注意力或凸显信号按散户参与强度放大，在散户主导的样本里信号更强。

**为什么用买卖均值而非净额**：本字段要的是**参与强度**而非方向。买入与卖出都代表散户在参与，取均值（或合计）可避免方向性污染，使它成为纯「主体构成」度量，与方向性的 [[patterns/fields/小单净流入|小单净流入]] 等字段互补而非重复。

**与相邻字段的区别**：

- [[patterns/fields/小单净流入|小单净流入]] / [[patterns/fields/小单净笔数|小单净笔数]]：前者度量散户的**方向**（净买 / 净卖），本字段度量散户的**份额**，维度不同；
- [[patterns/fields/成交额占比|成交额占比]]：个股占全市场成交的份额，是横截面集中度；本字段是散户在个股内部成交中的占比；
- [[patterns/fields/每笔成交量|每笔成交量]]：单笔平均规模，是本字段的「镜像」——单笔越小越可能是散户，但每笔成交量不含主体标签；
- [[patterns/fields/惊恐度|惊恐度]]：注意力强度度量，与本字段同为惊恐范式的权重维度，常配对使用。

## 收益来源

本页归属 [[alpha/量激增注意力|量激增注意力]]

**赚什么钱**：主要赚**注意力与情绪**的钱——散户参与度高的股票，价格中混入更多关注度驱动的过度反应，随后随情绪衰减而回归；次要赚**行为偏差**的钱——散户的系统性追涨杀跌、对显著信息的误估，为反向交易者提供了对手盘。

**对手方**：被新闻 / 涨幅榜吸引而追入、或恐慌割肉的散户；以及在散户主导的过度反应中提供流动性的理性交易者。

**理论支撑**：[[concepts/行为金融凸显理论|行为金融凸显理论]]；[[alpha/大小单博弈|大小单博弈]]。

**失效条件**：

- **拆单模糊主体边界**：机构算法把大单拆成小额单，使「小额单」不再等于散户，主体标签失真；
- **散户行为机构化**：散户通过 ETF、量化产品间接入市，小额单与情绪驱动的对应关系减弱；
- **信息被快速定价**：当散户参与确实反映基本面信息且被迅速定价时，情绪反转逻辑不成立。

## 加工公式

```
个人投资者交易比 = ratio(mean(小额个人买入金额, 小额个人卖出金额), 个股总成交额)
# 小额阈值常取单笔成交额 < 4 万元；分母总成交额近零置 null
```

## 可变异维度

- 金额阈值：4 万 → 2 万 / 5 万
- 分子：买卖均值 → 仅买 / 仅卖 / 买卖合计
- 分母：总成交额 → 流通市值（换手口径）

## 适用场景

- **情绪 / 显著因子的权重**：与惊恐度、凸显权重等相乘，把注意力信号限定在散户主导样本；
- **横截面分层**：按散户占比分组，检验同一信号在高 / 低散户组中的差异；
- **小市值研究**：解释小市值股票对情绪冲击更敏感的原因。
