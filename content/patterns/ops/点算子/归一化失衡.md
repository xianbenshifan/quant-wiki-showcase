## 金融解释

**做什么**：对两个非负分量 $a,b$ 计算 $(a-b)/(a+b)$，把绝对差转成 $[-1,1]$ 的**相对失衡**：正值偏向 $a$、负值偏向 $b$，0 表示两侧均衡。

**为什么单列一页**：买卖量、挂单量、主动 / 被动成交等「两分量」场景里，绝对差 $a-b$ 依赖总量规模，跨股票不可比；归一化失衡把它变成无量纲的方向性压力指标，天然落在 $[-1,1]$ 且对大总量不敏感。它操作化的是「订单流方向压力 / 买卖失衡」，是订单流因子的常见底座（见 [[patterns/fields/订单流失衡|订单流失衡]]）。

**与安全比值的区别**：安全比值是 $a/b$，衡量相对倍数、对分母量级敏感且无界；归一化失衡是 $(a-b)/(a+b)$，衡量两分量的相对份额、有界且对称。要「几倍」用前者，要「偏向哪边、偏向多少」用后者。

## 算子定义

```
norm(a, b) = (a - b) / (a + b),   a, b 非负
# |a + b| < eps -> null；输出范围 [-1, 1]
```

## 适用场景

- 买卖量 / 额失衡、主被动成交失衡、挂单深度失衡；
- 需要横截面可比的有界方向压力指标；
- 与分位掩码配合切出「强买压 / 强卖压」状态。

## 边界与陷阱

- **要求非负分量**：$a,b$ 有负值时公式失去「份额」含义（分母可能趋零且符号混乱），须改用其他失衡形式；
- **总量信息丢失**：失衡为 1 时，$a=100,b=0$ 与 $a=10^8,b=0$ 输出相同；若大额失衡比小额失衡更有信息，须与总量并列；
- **分母趋零**：$a+b$ 近零（清淡时刻）时不可靠，置空会系统性剔除清淡样本；
- **极端饱和**：一侧为零时输出 $\pm 1$，大量样本落在端点会使分布堆叠、区分度下降；
- **与逐点减的关系**：$a-b$ 是绝对差（有量纲、依赖规模），归一化失衡是它的无量纲版本，不可混用。

## 可变异维度

- 分量：a / b → 任意语义对
- 分母：$a+b$ → $\max(a,b)$ 等变体
- 方向：可反转
