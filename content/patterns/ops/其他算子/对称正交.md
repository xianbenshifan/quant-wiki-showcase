## 金融解释

**做什么**：在同一截面上，对 $N$ 只股票 × $K$ 个因子的矩阵 $F_{N \times K}$ 做线性变换，得到一组**两两正交**（相关性为零）的新因子 $\tilde{F}_{N \times K} = F_{N \times K} S_{K \times K}$，其中过渡矩阵 $S$ 为对称矩阵。变换后因子的线性组合解释力与原因子集相同（只是旋转），但消除了因子间的共线性。

**为什么需要正交化**：多因子线性合成 $F = \sum_k v^k f^k$ 隐含假设因子之间相关性低。实际中同族因子高度相关（源报告指出单季度净利润增速与单季度营收增速的秩相关系数达 0.42），直接加权会让组合在某些风格上**过度暴露**：两个高度相关的成长因子被同时赋予权重，等价于把成长风格押注加倍，组合长期稳健性下降。正交化把「重复计数」的共同成分拆开，权重才能各自有意义。

**为什么用对称正交而不是施密特（Gram-Schmidt）正交**：施密特正交**依赖因子的排列顺序**，排在前面的因子几乎不被修改，后面的因子被大幅调整——因子的经济意义按顺序被不对称地破坏。对称正交的三个性质正是针对此：

1. **无顺序偏好**：不需要提供正交次序，对每个因子平等看待；
2. **修改最小**：在所有正交过渡矩阵中，对称正交后的矩阵与原矩阵距离（Frobenius 范数）最小，因此正交后因子与原因子的**对应关系最清晰、经济意义保持能力最好**；
3. **只用截面数据**：计算只需当期截面因子值，不依赖时序估计，效率高。

**与相邻构件的分工**：[[patterns/ops/其他算子/主成分分析|主成分分析]] 也产出正交因子，但主成分是**无标签的统计方向**（最大化解释方差、符号与尺度不唯一），无法对应到某个具名因子；对称正交则保留「每个新因子对应一个原因子」的对应关系，经济可解释性强。[[patterns/ops/截面算子/截面残差|截面残差]] 是**有监督**的剥离（对一个已知暴露回归取残差），对称正交是**无监督**的整体旋转。

## 算子定义

```
# 输入：截面标准化后的因子矩阵 F (N×K)，列向量已 Z-Score 标准化（均值 0、范数 1）
M = F' F                       # K×K
M = U D U'                     # 特征分解：D 特征根对角阵，U 特征向量阵（列）
S = U D^(-1/2) U'              # 对称过渡矩阵（因 S 对称而得名）
F_tilde = F S                  # 正交化后因子矩阵：任意两列内积为 0
# 输出：两两正交的新因子，与原因子一一对应、且 Frobenius 范数下相似性最高
```

## 适用场景

- **多因子线性复合前的共线性处理**：因子相关性高、直接加权会导致风格过度暴露时；
- **同族因子并列入模**：如成长族（净利润增速、营收增速）、质量族（ROE、ROA）内部高度相关；
- **需要保留经济可解释性**：正交后因子仍能对应到原因子含义（与 PCA 的取舍）；
- **横截面处理**：只依赖当期截面数据，计算成本低，适合高频滚动使用。

## 边界与陷阱

- **本质是旋转、不产生新信息**：正交化不增加 alpha，只重分配权重；若原因子集本身无区分度，正交后同样无区分度；
- **线性无关假设**：要求输入因子列线性无关，若存在完全共线（如两个因子成比例）则 $M$ 奇异，$D^{-1/2}$ 不可算，须先剔除冗余因子；
- **标准化前提**：推导假设每个因子已 Z-Score 标准化（$\bar{f^k}=0,\ \|f^k\|=1$），未标准化时过渡矩阵的对称性与「最小修改」性质不成立；
- **符号与尺度不唯一**：特征向量符号可整体翻转，跨期使用须固定符号对齐，否则因子方向跳变；
- **小截面不稳**：$N$ 不足或有效样本少时协方差结构噪声大，正交结果跨期不稳定；
- **与 PCA 混用**：两者都产出正交基但目标不同（保留对应关系 vs 最大化方差），不可互相替代。
