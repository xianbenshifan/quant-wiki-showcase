## 金融解释

**做什么**：在窗口内对两列配对序列 $x,y$ 求样本协方差 $\operatorname{cov}(x,y)=\mathbb{E}[(x-\bar x)(y-\bar y)]$。它是有符号的：正 = 同向共变，负 = 反向；且保留量纲——数值大小同时反映共变方向与两列各自的波动幅度。

**为什么有信息量**：很多金融命题本身就是「两列一起动」：「资金流是否推动价格」（$\operatorname{cov}(\text{净流入},\text{收益})$）、「凸显权重是否放大定价扭曲」（[[paradigms/凸显权重收益协方差|凸显权重收益协方差]] 用权重序列与收益序列的协方差刻画）、「资产对市场组合的暴露」（beta 的分子）。协方差把这些命题操作化为一个标量。

**与相关系数的分工**：协方差是**带规模的共变**，相关系数是**标准化后的联动**。当「规模」本身有含义（如大额资金同步流入）时要用协方差；当只需「联动强弱、跨股可比」时应改用 [[patterns/agg/双列相关聚合|双列相关聚合]]。

## 聚合方式

```
cov(x, y, window) = 窗口内样本协方差
# 可选：稳健协方差 / Spearman 秩协方差（见可变异维度）
```

语义：两列须**成对对齐**，按窗口缩减为每合约一个标量。

## 适用场景

- **绝对共变规模有意义**：资金流推动强度、权重—收益扭曲强度；
- **beta / 暴露的分子**：与市场组合作协方差，再除以市场方差；
- **上下行分解的前置**：把协方差拆成上行 / 下行半协方差，考察不对称共变；
- **量纲需要保留**：当「多少钱一起动」比「一起动的程度」更重要时。

## 边界与陷阱

- **跨股不可比**：数值随两列量纲与波动水平变化，直接横向排序无意义。要比较须先除标准差（即转成相关）或统一标准化；
- **成对样本对齐**：两列若一方在某 bar 缺失，协方差的有效样本被改变。删除法、填零法会得到不同结果，须与因子命题一致；
- **极端配对主导**：协方差是两个偏差的乘积，一个极端配对样本即可显著抬高或压低数值；
- **与相关混用**：把协方差当「联动强度」解读，会把波动水平差异误读为相关差异；
- **尺度口径**：总体 vs 样本（除以 $n$ 还是 $n-1$）会影响数值。

## 可变异维度

- 估计：样本协方差 → 稳健协方差 / Spearman 秩协方差
- 窗口：自然月 → 滚动 N
- 标准化：协方差 → 相关系数（除以两列标准差）
- 方向分解：全样本 → 上行 / 下行半协方差
