## 金融解释

**做什么**：求合约整段样本的总和并广播——整段累计总量。

**为什么有信息量**：金融数据里大量量本身就是「流量」。窗口求和对应经济学上的**总量**——成交额求和是区间成交金额，成交量求和是区间换手规模，净流入求和是区间净资金流，二次变差（$\sum r^2$）是区间已实现波动。总量让「某区间累计规模 / 强度」成为可度量对象；对对数收益求和还近似区间复合收益，是低频化的常用手段。

**与相邻构件的分工**：三者粒度不同，最易混淆。本页是**整段一个总量**（合约级常量、广播）；[[patterns/ops/时序算子/滚动求和|滚动求和]] 是**定长移动总量**（每个时点一个窗口和，随 t 变化）；[[patterns/ops/时序算子/累积求和|累积求和]] 是**从头至今的路径**（每个 t 一个累计值，对正流量单调不降）。前两者是标量或移动标量、随窗口长度变化，后者是路径、随样本增长。与 [[patterns/agg/均值聚合|均值聚合]] 只差一个窗口长度因子，但分别保留规模与强度。

## 算子定义

```
global_sum(x)          # 整段求和，广播到每一行
```

- 按合约整段有效样本求和；NaN 跳过或视 0 须显式约定；
- 对象可为量、额、净流入、平方收益等流量 / 强度序列。

## 适用场景

- **区间流量总量**：总成交额、总成交量、净资金流；
- **低频化**：日度值在周 / 月区间求和；
- **已实现波动**：$r^2$ 的求和（二次变差）；
- **规模控制变量**：与均值配对，同时得到规模与强度。

## 边界与陷阱

- **样本长度不可比**：整段长度不同则总量不可比，须归一（除以样本数即回到均值）或统一区间长度；
- **输出近常量**：单独作为因子在时序上不变，须与当前值配合；
- **量纲巨大**：成交额等量纲远大于收益率，与其它列组合前须做尺度对齐；
- **前视风险**：整段含未来行，回填历史即前视；与累积求和的粒度混淆也是常见误用（一个是标量、一个是路径）。

## 可变异维度

- 对象：成交额 / 成交量 / 净流入 / 平方收益
- 基准长度：整段 → 扩张 / 滚动
- 归一化：原始和 → 均值（除以样本数）
