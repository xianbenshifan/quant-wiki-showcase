## 金融解释

**做什么**：在窗口内取 $q_{hi}$ 分位与 $q_{lo}$ 分位之差（常用 P70−P30），输出一个标量。它与 [[patterns/agg/标准聚合|标准聚合]]、[[patterns/agg/极差聚合|极差聚合]] 同属**离散度**家族，但取的是分布内部区间。

**为什么有信息量**：标准差用全部样本且平方加权，尾部单点即可抬高；极差只看两端，完全由最值决定。分位差取「中间大部分样本」的展开宽度，对两端离群样本不敏感，因而更能刻画**典型波动**。在厚尾数据（收益、成交量、价差）上，分位差比标准差更接近「平常的波动有多大」。

**量纲特征**：分位差与原始变量同量纲、不含平方，解释直观；跨股比较时不会像方差那样被量纲放大。

## 聚合方式

```
quantile_diff(x, q_lo, q_hi, window, mask=None)
# q_hi - q_lo，要求 0 <= q_lo < q_hi <= 1
```

语义：窗口内先排序，取两个分位点相减；可选掩码限定状态子集。

## 适用场景

- **稳健波动代理**：收益、成交、价差的典型波动幅度，尤其在厚尾样本上替代标准差；
- **尾部贡献诊断**：与极差并排看，$\text{极差}-\text{分位差}$ 近似尾部对整体宽度的贡献；
- **跨股 / 跨期比较**：同量纲、不受极端值主导，排序更稳；
- **分布内部形状**：两个分布可有相同的分位差却形状迥异，因此常与偏度、峰度配合而非单独使用。

## 边界与陷阱

- **分位估计收敛慢**：分位点由排序位置决定，比均值更依赖样本量。窗口太短时 P70/P30 会在相邻取值间跳；
- **q 的选择会改变结论幅度**：P90−P10 与 P70−P30 数值差异大。若因子排序对 q 敏感，说明信号主要来自某一端的尾部样本；
- **丢失内部形状**：分位差只给一个宽度，无法区分「单峰窄」与「双峰宽」；
- **与极差混用**：极差由 2 个样本决定，极不稳；不要把极差当成「更简单的分位差」；
- **样本不足与缺失**：未剔除停牌 / 无成交样本时，分位点被零值或缺失扭曲。

## 可变异维度

- q_lo / q_hi：0~1（常用 0.3/0.7、0.25/0.75、0.1/0.9）
- 窗口：可调
