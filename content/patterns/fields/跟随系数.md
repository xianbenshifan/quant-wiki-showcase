## 金融解释

**衡量什么**：在某个被识别为「优势」（知情 / 大单主导）的活跃时刻 $t_{\text{adv}}$ 之后，普通投资者在短窗口内追加成交的力度：

$$
\text{follow\_coef}(t_{\text{adv}}) = \frac{\sum_{t \in (t_{\text{adv}},\, t_{\text{adv}}+\Delta]} \text{VolBar}_t}{\text{VolBar}_{t_{\text{adv}}}}
$$

分子是跟随窗口内的 bar 成交量增量之和，分母是优势时刻本身的成交量增量。比值越高，说明优势时刻引发的跟随成交越密集。

**为什么有信息量**：它刻画的是「冲击—跟随」这一微观结构链条。大资金或知情者的集中成交首先制造一个异常活跃的时刻，随后散户与动量交易者观察到价格 / 量能异动并**跟风涌入**。跟随强度越高，说明该异动越成功地吸引了注意力与羊群资金，价格越可能在短期内被推至过度反应的位置，从而为随后的回归埋下伏笔。反之，跟随清淡说明异动未被市场消化，信息可能仍在扩散途中。因此该字段既标记了**行为层面的羊群**，也标记了**过度反应**的强度。

**与相邻字段的区别**：

- [[patterns/mask/TopK排序掩码|TopK排序掩码]]：负责识别「优势时刻」$t_{\text{adv}}$（如成交量 TopK 且相邻去重），是本字段的前置事件定义；跟随系数是事件之后的强度度量。
- [[patterns/fields/每笔成交量|每笔成交量]]：描述单笔平均规模，是无事件结构的大小刻画；跟随系数建立在「事件 + 后续窗口」的时间结构上。
- [[patterns/fields/成交量增量|成交量增量]]：本字段的原料，刻画单 bar 量能变化；跟随系数把它组织成事件相对量。
- [[patterns/fields/超大单买溢价|超大单买溢价]]：度量优势时刻本身的价格激进度；跟随系数度量其后的跟随响应，两者可组合成「冲击强度 + 跟随强度」。

## 收益来源

本页归属 [[alpha/跟随大单过度反应|跟随大单过度反应]]

**赚什么钱**：主要服务两类逻辑。其一为**反转**——跟随成交越密集，价格越可能被羊群推离基本面、形成过度反应，随后回归，做反向交易可获得修正收益；其二为**行为偏差**——跟随本身是羊群与注意力驱动的系统性认知偏差，识别高跟随时刻等于定位情绪最亢奋、定价最易偏离的样本。

**对手方**：在优势时刻之后跟风追入、最终承受价格回归损失的散户与动量交易者；以及在高跟随时刻为羊群提供对手盘的理性方。

**理论支撑**：[[concepts/跟随交易与价格过度反应|跟随交易与价格过度反应]]、[[alpha/大小单博弈|大小单博弈]]。

**失效条件**：

- **跟随由基本面确认驱动**：若跟随成交来自真实信息的持续扩散，价格延续而非反转，反向逻辑失效；
- **算法拆单稀释跟随**：程序化交易使「跟随」越来越多是算法行为而非情绪羊群，行为偏差成分下降；
- **事件定义失真**：优势时刻识别规则变化（TopK 的 K、去重方式）会改变跟随样本，机制链条不稳。

## 加工公式

```
follow_coef(t_adv) = ratio(sum(VolBar_t, t in (t_adv, t_adv+Δ]), VolBar_{t_adv})
# 分母为 0 时置缺失，不参与日聚合
```

- **VolBar**：bar 成交量增量（由 [[patterns/fields/成交量增量|成交量增量]] 得到）
- **优势时刻** $t_{\text{adv}}$：经 TopK 与相邻去重后的海量时刻
- **跟随窗口** $\Delta$：常见 5 分钟（1 个 5min bar 或 5 个 1min bar）

日跟随系数为当日所有有效 follow_coef 的算术均值。

## 可变异维度

- 跟随窗口：5min → 1min / 10min
- 聚合：算术均值 → 加权均值 / 中位数
- 优势时刻定义：TopK+去重 → 其他事件识别规则

## 适用场景

- 作为**羊群 / 过度反应强度**的特征，用于反转、情绪类因子的条件分层；
- 与 [[patterns/mask/TopK排序掩码|TopK排序掩码]] 配合做事件研究：先定位优势时刻，再按其后的跟随强度分组；
- 在**散户占比高、情绪驱动明显**的标的上区分度更高；
- 用日聚合值作为低频信号，或保留逐事件值做高频事件研究。
