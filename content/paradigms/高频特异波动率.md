## 范式概述

高频特异波动率在**显式多因子框架**下度量「个股相对市场的偏离强度与高频波动的乘积」：先用 Fama 三因子加流动性与反转因子对过去 21 天日收益回归，取**特异率 $= 1-R^2$**；再取同期日内分钟收益标准差为**高频基础波动率**；二者以 $\sqrt{\text{特异率}} \times \text{高频基础波动率}$ 相乘。非线性变体先对 std 做截面 min-max 归一化、再指数变换，以加强头部波动区分。相对 [[paradigms/特质隔夜收益波动率|特质隔夜收益波动率]]（PCA 隐式因子残差 std）：本范式用**显式因子**剥离共同风险，并用**高频波动**细化个股波动腿。

**特异率为什么用 $1-R^2$**：回归的 $R^2$ 是日收益方差中被共同因子解释的比例，$1-R^2$ 即**个股特有**部分的比例。它是 $[0,1]$ 的「相对偏离强度」，与波动相乘时天然充当**杠杆系数**——同样幅度的个股波动，若更多来自个股特有信息（高低特异率），则被放大得更多。相比之下，残差 std 会把「偏离强度」与「波动幅度」混为一谈（对照隐式路径）。

**为什么要开根号**：$1-R^2$ 是**方差**比例，而基础波动是**标准差**量纲。取 $\sqrt{1-R^2}$ 使杠杆系数与标准差同量纲；同时开根会把 $[0,1]$ 区间拉开，放大中间区间的个股差异，避免高 $R^2$ 股票被过度压缩。

**为什么用显式因子、且要加流动性与反转**：Fama 三因子（MKT / SMB / HML）剥离市场、规模、价值三类共同风险；再加入流动性（LIQ）与反转（RET）因子，是因为这两类与波动相关性较高——若不剥离，它们的共同波动会漏进特异项，使 $1-R^2$ 把「共同风险」误当成「个股特有」。加这两项的目标是得到更纯的「价格相对市场偏离」。

**为什么用高频分钟波动而非日收益波动**：21 天日收益只有 21 个观测，std 估计极不稳定；同期日内分钟收益提供成百上千个观测，估计更精细，也更能刻画个股真实的波动强度。频率宜 $\le 30$ 分钟：太细（如 1 分钟）会被买卖价差跳动等微观结构噪声污染，太粗则样本又回落到日收益的量级、失去高频的意义。

**非线性变体为什么用 min-max + 指数**：std 的截面分布右偏、少数股票波动极高。min-max 把 std 压到 $[0,1]$ 后再取 $e^{\text{norm}}$，指数函数**放大头部、压缩尾部**，使最波动的一批股票区分度更强（源页表述为「加强头部波动区分」）。

## 构造要点

1. **过去 21 天日收益对 MKT / SMB / HML / RET / LIQ 做时序回归，特异率 $= 1-R^2$**。
   用时序回归（每只股票各自一条时间序列）而非截面回归，是因为目标是「该股自身收益里无法被共同因子解释的份额」。21 天窗口是估计 $R^2$ 的最小可行样本长度与时效之间的折中。
2. **同期取日内分钟收益（频率宜 $\le 30$ 分钟）标准差 → 高频基础波动率 $\text{std}$**。
   时间窗与回归一致（同为过去 21 天），保证「偏离强度」与「波动幅度」刻画的是同一段行情，两个腿才对得上。
3. **线性：$\sqrt{\text{特异率}} \times \text{std}$；非线性：先 $\text{norm}=(\text{std}-\min)/(\max-\min)$，再 $e^{\text{norm}}$，再与 $\sqrt{\text{特异率}}$ 相乘**。
   线性版等权对待所有波动水平；非线性版用指数重塑分布、突出重点（见范式概述）。两版共享同一杠杆腿，只改波动腿的形状。
4. **流动性与反转因子与波动类相关较高，有助于更纯粹剥离价格相对市场偏离**。
   这一步是回归因子集的设计理由，而非额外计算——它决定了「特异率」是否真的特异。

## 派生形态

- **高频特异波动率（线性）**：$\sqrt{\text{特异率}} \times$ 分钟 std → 高频特异波动率因子。
- **非线性高频波动率**：对 std 截面 min-max 归一化后取 $e^{\text{norm}}$，再 $\times \sqrt{\text{特异率}}$；加强头部波动区分、淡化尾部 → 非线性高频波动率因子。

## 可变异维度

- 因子集：FF3 + RET + LIQ ↔ 更少 / 更多显式因子。因子集越全，特异率越纯，但回归噪声与共线性风险越高。
- 窗口：21 → 20 / 60。越长 $R^2$ 越稳但越滞后，越短越贴近当下但越噪。
- 分钟频率：$\le 30$ 分钟内可调。在微观结构噪声与样本量之间取舍。
- 波动腿：线性 std ↔ min-max + exp 非线性。前者保序、后者强调头部。
- 输出：$\sqrt{\text{特异率}} \times \text{vol}$ ↔ 仅特异率 / 仅残差 std（对齐隐式族）。拆开可检验两个腿各自的贡献。

## 收益来源

本页归属 [[alpha/彩票型波动高估|彩票型波动高估]]

**赚什么钱**：主要赚**波动风险溢价**的钱——特异波动是剥离共同风险后仍无法分散的个股风险，承担它理应要求补偿；$\sqrt{\text{特异率}} \times$ 高频波动把「相对市场的偏离强度」与「波动幅度」相乘，放大对个股异质风险的暴露。次要赚**行为偏差**的钱——经典「特异波动异象」表明，高特异波动股票（尤其小盘、高换手、彩票型）因投资者分散不足与对小概率高收益的偏好而被定价过高，未来收益偏低；本范式用更有效的高频波动与更纯的显式残差把这一异象暴露做得更极端。

**对手方**：过度追逐高波动、彩票型股票的散户投资者；分散不足、为可分散风险支付了过高价格的一方；以及在个股异质风险上定价错误的交易者。

**理论支撑**：[[concepts/特异波动异象|特异波动异象]]（特异率与波动的正向杠杆加强异常信息）；[[concepts/隐式因子框架|隐式因子框架]]（对照路径）。

**失效条件**：

- **异象被套利消除**：当特异波动异象被广泛认知与交易，高特异波动股票的价格已充分反映风险，异常收益消失；
- **行为偏差减弱**：若投资者结构转向机构主导、分散化程度提高，彩票偏好与分散不足带来的定价偏差收缩，异象来源变弱；
- **特异波动退化为系统性风险**：当个股异质波动与系统性风险高度联动（如危机中相关性骤升），「剥离共同因子后即为可分散风险」的核心假设被破坏，杠杆放大的不再是纯个股信息。
