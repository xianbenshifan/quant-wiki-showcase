## 金融解释

**衡量什么**：把中间价收益除以订单流失衡的绝对值，得到「单位订单流不平衡推动了多少价格」，再做时序缩尾与保号对数压缩：$\text{impact} = \operatorname{sign}(\cdot)\cdot\ln\big(1+|\text{winsorize}(\text{中间价收益}/|\text{订单流失衡}|)|\big)$。它度量的是**订单流驱动的瞬时价格冲击斜率**，量纲上对应 Kyle $\lambda$ 的订单簿版本。

**为什么有信息量**：它把两个微观结构核心量联系起来——价格变化（中间价收益）与盘口供需的边际变化（订单流失衡）。斜率越大，说明单位挂单失衡就能推动价格走远，市场深度越浅；同时，由于分子是中间价而非成交价，它捕捉的是**报价层面对订单流的即时反应**，比成交层面的冲击更早。因此它既是流动性的度量，也是订单流毒性的价格后果。

**为什么取绝对值与缩尾**：斜率的方向由订单流失衡的符号决定，取绝对值聚焦「幅度」；比值在订单流失衡趋零时爆炸，缩尾与对数压缩把极端值压回可用范围。

**与相邻字段的区别**：

- [[patterns/fields/KyleLambda代理|Kyle Lambda 代理]]：分母是**成交量增量**（成交侧），本字段分母是**订单流失衡**（盘口挂单侧），一个已实现、一个更前瞻；
- [[patterns/fields/订单流失衡|订单流失衡]]：本字段的分母，度量方向与强度；本字段把它转换为价格冲击；
- [[patterns/fields/成交量不平衡概率代理|成交量不平衡概率代理]]：度量订单流毒性的**水平**，本字段度量毒性的**价格后果**；
- [[patterns/fields/非流动性|非流动性]]：Amihud 型的额口径冲击，不依赖盘口数据。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/信息风险补偿|信息风险补偿]]

**赚什么钱**：其一为**流动性溢价**——斜率高的股票深度浅，持仓者未来成交需付出更高冲击成本，要求更高预期收益；其二为**信息不对称**——订单流冲击斜率大意味着知情者的成交能把价格推得更远，毒性更难被吸收，价格对订单流更敏感，跟随订单流方向可获益。

**对手方**：被动挂单、被订单流吃穿并承受价格不利变动的流动性提供者；以及支付即时冲击成本的急躁交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **挂单快速增撤**：订单流失衡更多反映做市报价调整而非信息，斜率的知情成分下降；
- **隐藏订单**：冰山单使可见订单流失衡低估真实压力，斜率被系统性低估；
- **制度性盘口**：涨跌停、集合竞价使盘口结构退化，斜率失去正常微观含义。

## 加工公式

```
冲击原始值 = ratio(中间价收益, |订单流失衡|)      # 分母近零置 null
冲击缩尾   = 时序缩尾(冲击原始值, 1%)
冲击斜率代理 = sign(冲击缩尾) * ln(1 + |冲击缩尾|)
```

## 可变异维度

- 分子：中间价收益 → 收盘收益
- 分母：订单流失衡 → 浅档订单流失衡
