## 金融解释

**衡量什么**：把某一侧的盘口看成「价格档位—挂单量」曲线，用相邻档位量差之差近似其**曲率**（二阶差分）：买盘凸度取 $(BV_1-BV_2)-(BV_3-BV_4)$，卖盘凸度取同构的档位组合，两者之差即凸度差。正值表示买盘深度曲线相对更「中凸」或卖盘更「中凹」，即两侧深度的弯折方向不对称。

**为什么有信息量**：盘口形态有三类信息——**方向**（哪侧厚）、**倾斜**（哪侧越往外越稀薄）、**曲率**（深度沿价格怎么弯折）。凸度差捕捉的是第三类。它回答的是：即使两侧总深度相当，深度是集中在近档（中凸，形如厚墙）还是分散在中远档（中凹，形如浅滩）？近档集中的一侧，小单即可被吸收、稍大的主动单才会触及远端，价格冲击是「先钝后锐」；深度分散的一侧，冲击成本沿价格平滑上升。因此凸度差刻画的是**冲击成本随成交量的非线性形状**，是盘口脆弱性的一个独立维度，无法由方向或倾斜字段推出。

**与相邻字段的区别**：

- [[patterns/fields/斜率失衡|斜率失衡]]：度量价格—深度曲线的**整体倾斜**（一阶结构），回答「哪侧越往外越空」；凸度差度量**弯曲**（二阶结构），回答「深度怎么分布」。
- [[patterns/fields/加权失衡|加权失衡]]：对各档买卖量差做距离加权求和，是**量**的失衡；凸度差是**形状**的失衡，两者可同时存在。
- [[patterns/fields/近端失衡|近端失衡]]：只看最优档的方向，是单点信息；凸度差是多档形状信息。
- [[patterns/fields/总深度|总深度]]：只给厚薄总量，不带方向也不带形状。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/信息风险补偿|信息风险补偿]]

**赚什么钱**：其一为**流动性溢价**——凸度差刻画两侧冲击成本曲线的形状不对称，一侧若深度集中于近档、远端稀薄，则该侧的大额成交将遭遇陡增的冲击成本，为这种「形状风险」提供流动性者应获得补偿；其二为**信息不对称**——知情者偏好攻击深度形状最脆弱的一侧以放大价格效应，凸度差因此也是订单流毒性的形状代理。

**对手方**：在形状脆弱一侧被迫以递增冲击成本连续成交的急躁交易者；以及被盘口近档厚墙误导、以为深度充足的接盘者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **冰山单/隐藏单主导**：可见深度不代表真实承接力，形状脆弱性可能被系统性高估或低估；
- **做市算法瞬时补单**：挂单在毫秒级被补充，存量曲线的形状对未来冲击的指示被增量刷新抵消；
- **制度性单边盘口**：接近涨跌停时一侧档位退化，二阶差分失去比较意义。

## 加工公式

```
买盘凸度 = (买一量 − 买二量) − (买三量 − 买四量)
卖盘凸度 = (卖一量 − 卖二量) − (卖四量 − 卖三量)
凸度差 = 买盘凸度 − 卖盘凸度
# 档位缺失或退化为 0 时置 null；档位组合与口径可替换
```

## 可变异维度

- 端点：1/2/3/4 档组合 → 其他档
- 口径：价差 → 深度加权

## 适用场景

- **冲击成本非线性研究**：需要区分「近档厚墙」与「浅滩分散」两种盘口时；
- **与斜率失衡、近端失衡联合**：近端给方向、斜率给倾斜、凸度给形状，三者组合是对盘口最完整的刻画；
- **深度数据完整、档位稳定的标的**：小盘股或报单稀疏标的的中远档常为空，二阶差分不可靠。
