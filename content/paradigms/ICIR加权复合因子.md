## 范式概述

把多个单因子合成为一个综合打分因子，流程是：**标准化 → 正交去共线性 → 以滚动 ICIR 加权线性复合**。源报告据此为指数增强组合的收益预测模型打分：$F = \sum_k v^k f^k$，权重 $v^k$ 取自各因子滚动 12 期 ICIR 的归一化。

**为什么要复合而不是单因子**：单因子只捕捉一个维度（估值、成长、质量…），在不同市场状态下有效性各异；把多维度信号合成，等于做**信号分散**，降低对单一维度的依赖，综合 IC 与稳定性都更高（源报告复合因子 IC 均值 0.137、年化 ICIR 7.15，远高于任一单因子）。

**为什么先正交再加权**：线性加权隐含假设因子间相关性低，但同族因子高度相关（净利润增速与营收增速秩相关 0.42）。按 ICIR 直接加权会把同一份信息重复计入，使组合在成长等风格上**过度暴露**，长期稳健性下降。因此先用[[patterns/ops/其他算子/对称正交\|对称正交]]得到两两正交的新因子——对每个因子平等看待、对原矩阵修改最小、保留经济意义——再分配权重。

**为什么权重用 ICIR 而不是 IC 或等权**：IC 只度量预测能力的均值，ICIR $= \operatorname{mean}(\text{IC})/\operatorname{std}(\text{IC})$ 把**稳定性**纳入——IC 高但波动剧烈（ICIR 低）的因子在不同时期效果时好时坏，应当降权。ICIR 加权因此给「持续有效」的因子更高权重。相比等权，它利用了「哪些因子近期更管用」的动态信息；相比固定权重，它随窗口滚动、适应因子有效性漂移。

**为什么权重必须滚动**：因子有效性会衰减与轮动；用全样本 IC 定权重既隐含「有效性稳定」的假设，又会**前视**（用未来样本的 IC 决定当期权重）。滚动窗口只用历史数据，防前视且跟踪时变。

## 构造要点

1. **因子池与标准化**：从规模、估值、技术、成长、盈利、一致预期、流动性、波动、分红九类中筛选显著因子（源报告因子库见表 9），每个因子先做缺失值补齐 → [[patterns/ops/截面算子/MAD去极值\|MAD去极值]] → [[patterns/ops/截面算子/截面z得分\|截面z得分]] → 市值与行业中性化。
   **为什么先标准化**：不同因子量纲不同（比率、增速、对数市值），不标准化则加权被量纲主导。
2. **估 IC**：逐期计算每个因子与**下期收益**的截面 IC（源报告考察未来 20 个交易日收益）。IC 是权重的原始输入，其对齐口径须在窗口内一致。
3. **正交化**：对标准化后的因子矩阵做[[patterns/ops/其他算子/对称正交\|对称正交]]，得到两两正交的新因子。**为什么在估权重之前**：正交保证一份信息只拿一份权重，权重才有「互不重复」的解释。
4. **计算 ICIR 与权重**：窗口内 $\text{ICIR}_k = \operatorname{mean}(\text{IC}_k)/\operatorname{std}(\text{IC}_k)$，归一化为 $v_k$。源报告用**滚动 12 期**窗口。
   **为什么是 12 期**：窗口过短则 ICIR 的分母（IC 标准差）噪声大、权重跳变；过长则丧失时变性。12 期是稳定性与时变性的折中。
5. **线性复合**：$F_t = \sum_k v_k(t) f^k_t$，得到每期一个复合因子值（综合打分），作为组合优化的预期收益输入 $r$。
6. **与组合优化衔接**：复合因子分作为个股预期收益，进入线性规划——最大化 $r^T w$，约束风格/行业相对基准暴露、个股偏离、成分股权重占比、换手率等（见下表）。

- **预期收益的语义**：组合优化目标函数 $r^T w$ 中的 $r$ 即本范式产出的复合因子打分；$w$ 为待求权重向量。约束条件包括风格偏离度、行业偏离度、个股偏离度、成分股权重占比、个股权重上限、换手率约束（第七个约束 $\sum|w-w_0| \le to_h$）；目标函数与上述约束均可化为线性约束，用线性规划求解。
- **回测设定（源报告）**：基准中证 500；回测 2010-01 至 2019-04；交易成本买 0.1%/卖 0.2%；月频调仓价格为自然月第一个交易日 VWAP，日频为 T 日收盘生成持仓、T+1 日 VWAP 交易；股票池剔除上市半年内新股、ST、ST 摘帽不满 3 个月、退市前 1 个月，调仓时非停牌非涨跌停。

## 可变异维度

- **权重来源**：滚动 ICIR（12 期）→ 等权 / IC 加权 / 半衰 IC 加权 / 最大化 ICIR 优化；
- **正交方式**：对称正交 → 施密特正交 / 回归取残差 / 不正交；
- **窗口长度**：12 期 → 6/24 期（稳定性与时变性的取舍）；
- **IC 口径**：截面 IC → 秩 IC；未来收益窗口：20 日 → 5/10 日；
- **因子池**：九类维度可增删；
- **组合优化约束**：风格/行业偏离上下限、个股权重上限、成分股权重占比、换手率上下限可调。

## 候选收益来源（初判，待主 agent §4.6 裁决）

**候选归属**：[[alpha/风格因子归因收益|风格因子归因收益]]（本页未写 `return_source`，由主 agent 决定）

**赚什么钱**：本范式本身是**复合/组合方法**，其收益来自因子池中各 alpha 的综合，而权重分配（ICIR 加权）与共线性处理（正交）决定了组合最终暴露在哪些因子上。就「权重」这一层而言，它赚的是**因子预测能力的时变性**的钱——ICIR 加权重仓近期预测力强且稳定的因子，等同于对因子有效性做动态择时。次要地，它通过正交避免了对单一风格（如成长）的重复暴露，从而获得更接近**风格中性的截面选股**收益。

**对手方**：在本范式选中的高复合因子股票上做对手盘的交易者——通常是把资金集中押注单一风格、忽略因子有效性漂移、或在信息时效上滞后的参与者。

**理论支撑**：[[concepts/风格因子风险模型|风格因子风险模型]]（因子暴露与因子收益的分解是本范式权重与归因的基础）。

**失效条件**：

- **因子有效性集体失效**：若因子池整体进入衰减期（风格极端切换、拥挤度过高），加权方式无论多优都无法补偿，复合因子退化；
- **权重估计被噪声主导**：IC 标准差估计不稳或窗口过短时，ICIR 权重剧烈跳变，复合因子跨期不一致，稳定性优势消失；
- **正交破坏经济含义**：对称正交虽保留对应关系，但旋转后因子的金融解释变弱；若下游依赖因子语义（如约束某风格暴露）则需额外对齐。

## 关于收益来源（方法论范式）

**本页不标注 `return_source`**：本范式是**多因子复合方法**（标准化 → 对称正交 → ICIR 加权复合），其收益来源**由因子池中各因子的构造决定**，无法先验指定单一枚举值。就「权重」这一层而言，它赚的是「因子预测能力时变性」的钱（重仓近期强且稳的因子）；就「正交」这一层而言，它赚的是「避免对单一风格重复暴露」的钱。同一次复合方法用于不同因子池，会得到完全不同性质的因子。

因此本页在收益来源的计数与统计中豁免（与 `pipeline: unclassified` 的元范式同一处理口径）。

## 因子表现基准

复合因子 IC 均值 0.131（定期更新）→ 0.133（实时更新财报）→ 0.137（实时更新所有报告），年化 ICIR 6.31 → 6.50 → 7.15，IC 胜率均为 96.4%。
