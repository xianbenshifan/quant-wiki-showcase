## 金融解释

**衡量什么**：取已成交的大额买单的**成交均价**（大单买额 / 大单买量），与当日全市场成交均价 VWAP 比较，做相对偏差并压缩。正值表示大单买家成交在**高于**市场均价的位置，负值表示在低于均价处被动承接。

**为什么有信息量**：溢价度量的是大单买家的**价格激进度**。愿意连续吃卖盘、把成交价推高到 VWAP 之上的买家，通常是为了避免挂单等待而暴露意图或错失机会——这是真实需求紧急性与（可能的）信息优势的直接痕迹。相反，成交在 VWAP 之下说明该买家更有耐心、在低位被动承接，或只是被动的挂单成交。因此本字段把「大单在买」这一方向信号，升级为携带**紧迫程度与价格让步**的信号。它与 [[patterns/fields/大单买撤溢价|大单买撤溢价]] 构成一实一虚：一个说「愿意花多少钱成交」，一个说「挂出来又收回的报在哪」。

**与相邻字段的区别**：

- [[patterns/fields/大单买撤溢价|大单买撤溢价]]：分子换成被撤回的买委托均价，度量未成交的报价位置；本页用**已成交**口径，度量真实需求的紧迫度。
- [[patterns/fields/超大单买溢价|超大单买溢价]]：规模档升级到超大单，更偏机构/大资金、冲击力更强；本页是普通大单口径。
- [[patterns/fields/大单卖溢价|大单卖溢价]]：卖侧镜像，度量大单卖家的抛压与折价力度；买卖溢价同时高企说明大资金在激烈换手。
- [[patterns/fields/大单净流入|大单净流入]]：只看大单买卖的**量向**，不关心成交价相对基准的高低；本字段是强度维度的补充。
- 成交均价：本字段的基准价 VWAP 本身，是中性价格加工。

## 收益来源

本页归属 [[alpha/普通大单信息延续|普通大单信息延续]]

**赚什么钱**：主要赚**信息不对称**的钱——大单愿意支付高于 VWAP 的溢价，反映其对标的有信息优势或强烈看多，且不惜以价格冲击换取建仓速度；若这一信息尚未被充分定价，跟随该信号可在信息扩散前获得收益。本质上赚的是**知情大单定价不足**的钱，溢价本身也标记了短期价格冲击与随之而来的过度反应机会。

**对手方**：在大单主动买入中卖出、被价格冲击推高后仍继续成交的流动性提供者与卖方；以及消息扩散后才跟随买入的滞后交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]；[[concepts/信息冲击反应不足与过度|信息冲击反应不足与过度]]。

**失效条件**：

- **大额买入为非知情交易**：指数调仓、被动资金申赎造成的大单不含私有信息，溢价无预测力；
- **信息被瞬时定价**：市场效率高、跟随者反应快时，溢价刚出现即被套利；
- **算法拆单混淆**：冰山单与拆单使「大单」样本被选择性识别，溢价方向可能被结构性偏差扭曲。

## 加工公式

```
vwap = 成交额 / 成交量                              # 全市场 VWAP
x    = (大单买额 / 大单买量) / vwap − 1             # 大单成交均价相对 VWAP 的溢价
大单买溢价 = sign(x) × ln(1 + |x|)                  # 有符号对数压缩
# 大单买量或市场成交量近零置 null
```

## 可变异维度

- 基准：VWAP → 收盘价
- 规模档：Large → Mega+Large

## 适用场景

- **大资金紧迫性/知情强度代理**：用于微观结构因子与事件研究；
- **与卖方溢价配对**：买溢价高 + 卖溢价低（卖方惜售）是典型看多结构；
- **与净流入、撤单溢价组合**：区分「真实抢筹」与「虚假挂单」；
- **逐笔成交数据完整、规模分档稳定的市场**；日频上可对日内值聚合。
