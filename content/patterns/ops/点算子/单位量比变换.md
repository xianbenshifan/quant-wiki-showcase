## 金融解释

**做什么**：把日内的**累计**成交额 / 成交量（日内累计投影）转换成「单位量」——先差分还原每根 bar 的增量，再除以当日累计峰值（$\text{ur}$）或当日总量（$\text{mktr}$）：

$$\text{ur} = \frac{\Delta}{\max_{\text{当日}}\Delta},\qquad \text{mktr} = \frac{\Delta}{\sum_{\text{当日}}\Delta}$$

输出是当日进程中的相对量能强度与占比。

**为什么需要这一步**：原始成交额高度依赖市值、股价与流通盘，跨股票、跨日直接比较会混入规模效应与水平差异。除以当日自身的峰值或总量后，量纲被剥离，得到 0~1 的「相对量能」——同一口径下不同股票、不同日期可比，适合做横截面比较与分位掩码（如 high_liq 用 ur 分位）。

**它操作化了什么**：单位交易量的边际强度与市场占比。$\text{ur}$ 刻画「当前 bar 相对当日最活跃时刻的强度」，$\text{mktr}$ 刻画「当前 bar 占当日成交的份额」，二者是活跃度 / 流动性状态的标准化底座。

## 算子定义

```
step1  diff = 累计量的 bar 增量；负增量回落为原值（累计量不应回退）
step2  ur   = diff / max(当日 diff)
       mktr = diff / sum(当日 diff)
step3  可选：ur - 截面中位（去中枢，得到相对超额）
# 分母近零或非有限 -> null
```

## 适用场景

- 日内（分钟级）数据、需要跨股票比较量能强度时；
- 刻画流动性 / 活跃度状态，供阈值掩码、分位掩码使用；
- 构造「单位量突增」事件样本；
- 与 [[patterns/ops/点算子/收益涨跌幅变换|收益涨跌幅变换]] 配合：一个归一量能、一个算变化率。

## 边界与陷阱

- **时段未完成导致分母失真**：开盘初期当日峰值 / 总量尚未形成，$\text{ur}$ 的分母偏小、易被放大；应按已过时段归一，或改用同时钟历史的参照（见 [[patterns/mask/喷发成交量掩码|喷发成交量掩码]]）;
- **累计量回退**：数据修正或口径变化会让累计量非单调，若不把负增量回落为原值，会出现伪负增量；
- **分母趋零**：无成交或极清淡 bar 的分母近零，必须置空而非硬除；
- **与绝对量的取舍**：归一后丢失绝对规模信息（大票小票的 $\text{ur}$ 可比，但「当天到底做了多少」不可见），需要规模信息时应与原始量并列保留；
- **去均值口径**：`ur − 截面中位` 的 `ex` 形态会改变符号含义，配因子时须与下游保持一致。

## 可变异维度

- 归一分母：当日 max → 当日 sum（mktr）
- 负增量处理：回落原值 → 截断为 0
- 去均值：截面中位 → 截面均值
