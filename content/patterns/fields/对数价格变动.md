## 金融解释

**衡量什么**：对逐笔成交序列，取每笔成交价的对数与上一笔成交价的对数之差，即 $\Delta \ln \text{P}_i = \ln(\text{P}_i) - \ln(\text{P}_{i-1})$。它把离散的逐笔成交拼成一条连续的价格冲击路径，是对「单笔成交推动了多大幅度价格变化」的逐笔度量。

**为什么有信息量**：bar 级收益率只保留一个时段内的净变化，把中间的来回震荡全部折叠掉；而逐笔 $\Delta \ln \text{P}_i$ 保留了**每一笔主动成交**把价格推到哪里的信息。这在两类研究里不可替代：一是**订单级价格冲击**——把成交额或成交量增量与对应的 $\Delta \ln \text{P}$ 配对，就能估计 Kyle 型冲击斜率；二是**大单冲击的逐笔分解**——单笔大单究竟把价格推动了几个最小变动单位，只有逐笔层面才能看到。因此它是许多微观结构字段（冲击斜率、非流动性代理）的原始建材，本身不预设方向，方向由后续的聚合与配对逻辑决定。

**与相邻字段的区别**：

- [[patterns/fields/收益率|收益率]]：bar 级（5min/日）价格收益，粒度更粗、频率更低，适合常规因子；本字段是逐笔粒度，只有高频逐笔数据可得时才成立；
- [[patterns/fields/绝对收益|绝对收益]]：收益率的绝对值形态，度量幅度不度量方向，仍是 bar 级；
- [[patterns/fields/成交均价|成交均价]]：给出的是时段内价格的水平（VWAP），而非相邻价格的变动量，两者一个刻画水平、一个刻画路径。

## 加工公式

```
ΔlnP_i = ln(成交价_i) − ln(成交价_{i−1})
# 单笔成交的对数价格变动；第一笔或前价缺失、价格非正时为 null
```

## 可变异维度

- 层：普通大单 → 全部成交 / 仅超大单
- 方向：主动买成交 → 主动卖成交的分侧口径

## 适用场景

- **订单级价格冲击估计**：作为因变量与单位成交量增量配对，估计 Kyle lambda 型斜率；
- **剔除超大单后的大单冲击研究**：在逐笔层面剔除超大单后，对普通大单的 $\Delta \ln \text{P}$ 求和，可得到更纯净的「跟随交易」冲击度量；
- **高频微观结构因子**：需要区分「价格被推进的路径」而非仅净变化的场景。
