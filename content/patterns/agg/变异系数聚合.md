## 金融解释

**做什么**：对窗口内序列输出 $\text{CV}=\sigma/\mu$，即标准差除以均值。它把「绝对波动」转成「相对于均值的波动」，得到无量纲的比值。

**为什么有信息量**：对成交额、盘口深度、换手这类**正量纲的规模变量**，标准差天然随水平增长——大票的成交额标准差本就比小票大，直接比较 std 等于在比较规模而非稳定性。CV 除以均值后去掉了规模，回答的是「这只标的的活跃度有多不稳定」。它是「风险 ÷ 水平」这一风险调整思想的雏形，在水平差异大的横截面上比 std 更可比。

**与标准聚合的分工**：std 给绝对波动，CV 给相对波动。当被聚合的变量均值稳定且远离零、且命题关心「相对不稳定」时，用 CV；否则用 std 或 [[patterns/agg/分位差聚合|分位差聚合]]。

## 聚合方式

```
cv(x, window, mask=None)
# std / (mean + eps)
```

语义：窗口内先求均值与标准差，再相除；`eps` 仅用于避免除零。可选掩码限定状态子集。

## 适用场景

- **正量纲规模变量**：成交额、成交量、盘口深度、换手率——CV 让不同规模的标的可比；
- **横截面量级差异大**：当 std 与均值强相关（大票波动大），需要去规模的稳定性度量时；
- **相对风险的粗代理**：与均值配合，识别「同等活跃度下波动更剧烈」的标的；
- **状态内的相对波动**：在掩码子集内算 CV，观察某状态下波动相对水平是否抬升。

## 边界与陷阱

- **均值近零时爆炸 / 变号**：这是 CV 最大的陷阱。$\mu\to 0$ 时比值发散，$\mu<0$ 时 CV 的符号与大小都失去「相对波动」的含义。**均值接近零或可正可负的序列（尤其收益率）不应使用 CV**，`eps` 只能防严格除零，不能修复近零不稳；
- **对均值的微小噪声极敏感**：均值本身是被估计量，其误差会被放大到比值上，窗口越短越严重；
- **异号序列无金融意义**：带符号的量（如净流入、价差变化）的 CV 无法解释为「相对波动」；
- **口径依赖**：除以均值还是除以绝对值均值、用总体还是样本标准差，都会改变数值与排序，跨库比较须对齐；
- **与 std 的关系**：CV 单调性在 std 固定时与 1/mean 一致，可能把「水平低」误读为「相对波动高」。

## 可变异维度

- 窗口：可调
- 分母口径：均值 → 绝对值均值 / 中位数（更稳健的 CV 变体）
