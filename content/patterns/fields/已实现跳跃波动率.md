## 金融解释

**衡量什么**：用全日高频（典型 5 分钟）对数收益构造**已实现二次变差** $\text{RV} = \sum r^2$，再减去连续分量的稳健估计（多幂次变差，常用三幂次 $\text{RTV}$）得到跳跃分量的总强度，最后截断为非负：$\text{RVJ} = \max(\text{RV} - \widehat{\text{IV}}, 0)$。

**为什么有信息量**：价格变动在理论上可分解为**连续扩散**（无时无刻的小幅随机波动）与**跳跃**（短时、非连续、由信息冲击驱动的剧烈变动）两部分。二次变差同时包含两者，而多幂次变差（相邻收益乘积和）在存在有限活跃跳跃时仍稳健地逼近连续分量。两者相减，就把「跳跃」从总波动中**分离**出来。跳跃是**信息事件**的直接指纹——财报、政策、突发新闻造成的价格重估都表现为跳跃。因此 RVJ 度量的是「这段时间里有多少波动来自不可预期的信息冲击」，与单纯的波动率水平是不同的风险维度。

**为什么要截断非负**：有限样本下 $\text{RV} - \widehat{\text{IV}}$ 可能因估计误差为负（没有跳跃时，两者都应逼近同一连续分量，噪声可使差为负）。截断到 0 是把「无跳跃」这一真实状态映射为 0，而非让负的估计噪声污染截面排序。

**与相邻字段的区别**：

- [[patterns/fields/多幂次变差|多幂次变差]]：本字段的连续分量估计（减项），本身是稳健波动率；
- [[patterns/fields/上行跳跃波动率|上行跳跃波动率]] / [[patterns/fields/下行跳跃波动率|下行跳跃波动率]]：把本字段按跳跃方向做符号分解，是更细的「方向性跳跃」；
- [[patterns/fields/振幅|振幅]]：只用最高/最低价刻画日内摆动幅度，不区分连续与跳跃成分；
- [[patterns/fields/日跳跃度|日跳跃度]]：用单复利差的泰勒残差近似跳跃，是低频代理，与本字段的高频二次变差口径不同。

## 收益来源

本页归属 [[alpha/跳跃风险补偿|跳跃风险补偿]]

**赚什么钱**：主要赚**波动与尾部风险溢价**的钱——跳跃代表无法被连续扩散模型刻画的信息冲击风险，投资者厌恶这种不可分散的尾部风险，因而对高跳跃风险的股票要求更高预期收益作为补偿。

**对手方**：在信息冲击中被动持有、承受跳跃损失的一方；以及不愿承担跳跃风险而卖出（为获得风险补偿付费）的投资者。

**理论支撑**：[[concepts/特异波动异象|特异波动异象]]（波动/跳跃风险与截面收益的关系）；[[concepts/信息冲击反应不足与过度|信息冲击反应不足与过度]]（跳跃后的价格修正）。

**失效条件**：

- **跳空被连续化**：涨跌停制度或交易机制会把本应一次完成的跳跃拆成多日连续变动，使高频二次变差低估真实跳跃；
- **低频化后溢价消失**：在长持有期或低频聚合下，跳跃风险被平滑，其定价能力减弱甚至反向（低波异象）；
- **微观结构噪声主导**：高频数据中的买卖价差跳动（非真实价格跳跃）会被误判为跳跃，抬高 RVJ 并与流动性混淆。

## 加工公式

```
RV = Σ r²                                    # 日内高频对数收益平方和
ÎV = 多幂次变差（常用三幂次 RTV）              # 连续分量稳健估计
RVJ = max(RV − ÎV, 0)                        # 截断非负，度量总跳跃强度
```

## 适用场景

- **跳跃风险的横截面定价**：作为独立风险因子，或与其他波动因子正交化后使用；
- **信息事件强度度量**：识别哪些标的在近期经历了更多信息冲击，配合事件研究；
- **波动分解的基础**：作为上行/下行跳跃波动率的加总根，先算总量再分解方向。
