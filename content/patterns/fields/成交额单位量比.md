## 金融解释

**衡量什么**：与 [[patterns/fields/成交额单位比率|成交额单位比率]] 同构——把成交额增量除以当日（或滚动窗口）的成交额峰值水平，得到相对量能强度——但它是**盘口（LOB）侧**的实现路径，即在使用盘口快照构造的因子体系中，对该相对量能另起的口径列名。它同样落在 $[0,1]$ 量纲上，接近 1 表示量能接近峰值。

**为什么单独成页（而不是并入单位比率）**：两者**加工公式同构、金融含义一致**，按知识库的去重纪律本应归并；之所以以「派生形态/别名口径」的方式保留独立说明，是因为它在下游被赋予了**不同的角色**——它主要作为 [[patterns/fields/非流动性|非流动性]] 等 Amihud 型字段的**分母**。理解「它除以的是自身峰值」这一点，对正确解读非流动性至关重要：Amihud 非流动性 = 绝对收益 / 单位量比，分母若换用绝对成交额或滚动均值，数值量纲与排序都会改变。因此本页的独立价值在于**明确它与额口径单位比率的对应关系**，避免同一体系内混用两套分母。

**与相邻字段的区别**：

- [[patterns/fields/成交额单位比率|成交额单位比率]]：同一构想的通用/额口径实现，两者公式结构相同，量纲一致，但由不同视图（LOB 快照 vs 成交聚合）计算，数值不可直接混用；
- [[patterns/fields/成交额增量|成交额增量]]：本字段的分子（增量），绝对量级；
- [[patterns/fields/成交额占比|成交额占比]]：横截面归一（除以全市场），与本字段的时序归一不同；
- [[patterns/fields/非流动性|非流动性]]：以本字段为分母的下游字段，度量单位成交额推动的价格变动。

> 说明：本字段为**中性规格化构件**——它把量能映射到「相对自身当日峰值」的刻度，本身不携带方向；其收益含义取决于所参与的具体因子（如作为 [[patterns/fields/非流动性|非流动性]] 的分母时服务于流动性溢价度量），故本页不标 `return_source`。

## 加工公式

```
成交额单位量比 = 成交额增量 / 当日成交额峰值
# 成交额增量为逐 bar 差分还原；当日峰值按合约与交易日求 max；分母近零置 null
```

## 可变异维度

- 分母：当日峰值 → 滚动均值
- 口径：额 → 量

## 适用场景

- **Amihud 型非流动性的分母**：为单位价格冲击的度量提供相对量能基准；
- **LOB 体系内的量能规格化**：盘口因子中需要相对量能刻度时；
- **跨股量能形态比较**：自归一化后可在截面内比较。
