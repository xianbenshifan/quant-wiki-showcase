## 金融解释

**衡量什么**：合并大额档（超大单 + 大单）的撤单笔数与成交笔数，求两侧撤单笔数率之差：大单买撤笔数 / 大单买笔数 − 大单卖撤笔数 / 大单卖笔数。正值表示大单相对更频繁地**撤回买单**，负值表示更频繁地撤回卖单。

**为什么有信息量**：笔数口径度量的是**下单与撤单的动作频率**，而非被抽走的容量。大资金的执行往往表现为「多笔、连续」的挂撤试探（如分批测试深度、逐步调整报价），这种重复性在笔数维度比在量额维度更干净：一笔巨额撤单会主导量口径，却在笔数口径下只是一个计数。因此本字段刻画的是大资金撤单行为的**节奏**——哪一侧的报价被更频繁地收回。它比量口径更早反映策略变化，但也更容易被正常的报价维护动作污染，两者应并置解读。

**与相邻字段的区别**：

- [[patterns/fields/大单净撤单压力|大单净撤单压力]]：同一构想的**量口径**版本，对盘口容量被抽走的幅度敏感；本页对撤单**频率**敏感。
- [[patterns/fields/小单净撤单笔数压力|小单净撤单笔数压力]]：散户对应物，主体为小单；二者之差构成笔数维度的撤单背离。
- [[patterns/fields/净撤单笔数压力|净撤单笔数压力]]：全市场口径、不区分人群，且常配有符号对数压缩；本页限定大额档、用原始差。
- [[patterns/fields/撤单笔数失衡|撤单笔数失衡]]：只比较买撤与卖撤笔数的净方向，不做「撤/成交」归一化，无法比较强度。

## 收益来源

本页归属 [[alpha/普通大单信息延续|普通大单信息延续]]

**赚什么钱**：主要赚**信息不对称**的钱——大额挂单撤单频率的方向暴露了策略性报价的节奏：一侧的撤单笔数率异常偏高，说明该侧的名义供给被系统性虚化，真实承接力弱于盘口显示，而这一信息尚未被价格反映。

**对手方**：依据盘口挂单笔数密度判断供需、把大额挂撤当作真实意愿的交易者；以及被大额虚挂误导而追入的跟随者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（策略性委托与盘口真伪）。

**失效条件**：

- **改价计入撤单**：改价被计为撤单会系统性抬高两侧笔数率，且抬高幅度取决于报价策略，净方向可能被扭曲；
- **算法报价全面接管**：当高频报价更新成为常态，大额笔数维度的撤单不再区分真实意图；
- **规模档失效**：拆单使「大额档」不再等价于大资金，主体含义被稀释。

## 加工公式

```
大单买撤笔数 = 超大单买撤笔数 + 大单买撤笔数
大单卖撤笔数 = 超大单卖撤笔数 + 大单卖撤笔数
大单买笔数   = 超大单买笔数 + 大单买笔数
大单卖笔数   = 超大单卖笔数 + 大单卖笔数
大单净撤单笔数压力 = 大单买撤笔数 / 大单买笔数 − 大单卖撤笔数 / 大单卖笔数
# 各分母近零置 null；规模档可调
```

## 可变异维度

- 口径：笔数 → 量
- 规模档：可调

## 适用场景

- **捕捉大资金报价节奏的快速变化**：笔数口径对高频挂撤更敏感，适合短周期信号；
- **与量口径互为验证**：两口径同号增强可信度，异号提示存在单笔巨额撤单或大量小额撤单；
- **大额成交活跃的标的**：大单笔数样本充足时比值更稳。
