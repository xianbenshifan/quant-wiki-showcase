## 金融解释

**衡量什么**：对 $t-4$ 到 $t$ 共 5 根分钟 bar 的开、高、低、收（20 个价格）求标准差，除以这 20 个价格的均值，再取平方：$V_t = \left[\dfrac{\operatorname{std}(P)}{\operatorname{mean}(P)}\right]^2$。

**为什么有信息量**：单分钟收益给出的波动估计极不稳定——只用到两个价位，任何一笔噪声成交都会污染它。更优波动率改用相邻 5 分钟的**全路径价格**（20 个点）平滑波动，样本点更多、估计更稳，且同时刻画了分钟内振幅（高 / 低）与分钟间漂移（开 / 收），比「只用收盘—收盘」更能反映真实的即时风险状态。它本身不预测方向，而是为 [[patterns/fields/收益波动比|收益波动比]] 一类「波动调整后收益」提供分母，也是灾后重建、勇攀高峰类范式的核心中间量。

**为什么除以均值再平方**：直接对价格求标准差会随价格水平线性缩放，高价股天然数值大，无法跨股票比较。除以均价把量纲化为**相对波动**（类似变异系数），平方则把它还原回与收益方差同阶的量纲，便于与收益做比值。这也带来一个代价：均值近零（低价股、除权后）时除法失稳，必须保护。

**与相邻字段的区别**：

- [[patterns/fields/收益率|收益率]]：本字段是**风险**度量，收益是**回报**度量，二者在收益波动比中组合；
- 已实现波动率：通常用固定窗口的平方收益求和，只用收盘价；更优波动率用 4 价放大样本，对日内路径更敏感，但窗口更短、更偏局部；
- 日内收益波动率：在收益序列上做时序波动估计，刻画的是更长尺度的波动水平；更优波动率是**单个分钟**的局部瞬时估计。

## 加工公式

```
V_t = [ std({Open, High, Low, Close}_{t-4..t}) / mean({Open, High, Low, Close}_{t-4..t}) ]^2
# 均值近零时置 null 或用大数替代
```

## 适用场景

- 作为**局部波动分母**：构造收益波动比、波动调整收益等需要「当下波动状态」的合成量；
- 用作**波动状态切换**的即时探测器：相比长窗已实现波动率，它更快反映波动由静转动的拐点；
- 在**分钟级、流动性充足**的标的上更可靠：5 分钟窗口需要连续 20 个有效价位；
- 与 [[patterns/fields/日跳跃度|日跳跃度]] 配合，分离连续波动与非连续跳跃成分。

## 可变异维度

- 窗口：5 分钟 × 4 价 → 更大窗口
- 口径：std/mean 平方 → 其它波动估计
- 除法保护：均值近零 → null / 大数替代
