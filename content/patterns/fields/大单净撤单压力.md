## 金融解释

**衡量什么**：先合并大额档（超大单 + 大单）的买卖撤单量与买卖量，再求两侧撤单率之差：大单买撤量 / 大单买量 − 大单卖撤量 / 大单卖量。正值表示大单相对更倾向**撤掉买单**（大资金买盘退缩），负值表示更倾向撤掉卖单。

**为什么有信息量**：撤单是「挂出来又收回」的动作，不产生成交却能改变盘口，因此撤单率是观察人群真实态度的镜子。大单的撤单尤其值得单看：大资金的挂单通常金额大、对盘口显示影响显著，其撤回也更可能来自**策略性意图**（试探深度、掩护方向、撤出支持）而非情绪波动。**大单买撤率系统性偏高**（净压为正）说明大资金的买盘支撑是「虚的」——看似有大量买单，实则随时会撤，这类名义支撑不足以承接抛压，价格更易向下；反之集中撤卖则说明大额卖压虚化。把大单单独抽出来，是为了与散户撤单（[[patterns/fields/小单净撤单压力|小单净撤单压力]]）区分：机构撤单偏策略，散户撤单偏情绪，混在一起会互相抵消。

**与相邻字段的区别**：

- [[patterns/fields/小单净撤单压力|小单净撤单压力]]：散户对应物，分母用挂单量、主体为小单；本页是大资金口径，二者之差即撤单背离的主体项。
- [[patterns/fields/大单净撤单笔数压力|大单净撤单笔数压力]]：同一构想的**笔数口径**，对撤单频率敏感；本页是**量口径**，对被抽走的盘口容量敏感。
- [[patterns/fields/净撤单压力|净撤单压力]]：不区分人群、分母为实际成交量，是「全市场」口径；本页限定大额档且分母为挂单量。
- [[patterns/fields/撤单失衡|撤单失衡]]：只比较买卖撤单量的净方向，不做「撤/挂」归一化，无法跨股比较强度。

## 收益来源

本页归属 [[alpha/普通大单信息延续|普通大单信息延续]]

**赚什么钱**：主要赚**信息不对称**的钱——大单撤买率偏高时，大资金的名义买盘被虚化，真实承接力弱于盘口显示，这一信息尚未反映在价格中，价格更易下行；识别「大额挂单哪些是虚的」即是订单流层面的信息优势。

**对手方**：依据盘口挂单判断支撑/阻力、把大单挂单当作真实需求的交易者；以及被大额虚挂误导而追入的跟随者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（策略性委托与逆向选择）。

**失效条件**：

- **撤单被执行算法接管**：当大单撤单主要来自算法随机化处理时，方向不再对应意图；
- **监管抑制幌骗**：对虚假申报的处罚提高使大额撤单整体下降，策略性与正常撤单更难区分；
- **大单定义失效**：拆单算法普及使「大额档」不再等价于大资金，主体含义被稀释。

## 加工公式

```
大单买撤量 = 超大单买撤量 + 大单买撤量
大单卖撤量 = 超大单卖撤量 + 大单卖撤量
大单买量   = 超大单买量 + 大单买量
大单卖量   = 超大单卖量 + 大单卖量
大单净撤单压力 = 大单买撤量 / 大单买量 − 大单卖撤量 / 大单卖量
# 各分母近零置 null；规模档可改为仅 Large
```

## 可变异维度

- 规模档：Mega+Large → 仅 Large
- 分母：挂单 → 成交

## 适用场景

- **识别大资金造成的虚假盘口**：大额挂单频繁出现又消失时，提示哪一侧的供给是「虚」的；
- **与笔数口径联合**：量、笔数净压同号时信号更可信，异号提示存在单笔巨额撤单或大量小额撤单；
- **短周期横截面选股**：日频以上信号衰减较快，更适合日内—日频的短持有期框架；
- **与净流入方向交叉验证**：大单净流入为正但净撤单压力也为正（买盘虚挂），是典型的可疑结构。
