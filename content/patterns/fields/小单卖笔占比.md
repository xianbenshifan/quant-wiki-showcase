## 金融解释

**衡量什么**：卖出侧成交笔数中，被划入小额档（通常由「卖笔数减去超大单/大单/中单」的剩余法定义）的笔数所占比例。它度量卖出活动的**人群结构**：卖盘是散户小额挂单的集合，还是机构大额委托的成果。

**为什么有信息量**：小单卖笔占比是**散户参与卖出强度**的代理。散户卖出的行为特征与买入对称——金额小、笔数多、易受情绪与处置效应驱动（亏损时不愿卖、稍有回本就急于卖）。当该占比高时，说明卖压主要来自分散的散户群体：这类卖出通常缺乏信息、集中度低，价格往往能在需求恢复时较快企稳；占比低则说明卖出由大额资金主导，更可能有明确的减仓逻辑，价格承压更持续。因此它本身不含方向，但能**校正**对「净流出」性质的判断——同样是净卖出，散户主导与机构主导的后续含义截然不同。

**与相邻字段的区别**：

- [[patterns/fields/小单买笔占比|小单买笔占比]]：买入侧对应物，两者之差可刻画散户在买卖两侧参与的不对称；
- [[patterns/fields/大单卖笔占比|大单卖笔占比]]：直接度量卖出侧大额档的笔数占比，与本字段互补；
- [[patterns/fields/个人投资者交易比|个人投资者交易比]]：用**成交金额**而非笔数度量散户参与，且不分买卖侧；
- [[patterns/fields/小单净流入|小单净流入]]：给出小单的**方向**，本字段只给出卖出侧**份额**，是正交维度。

## 加工公式

```
小单卖笔数 = max(卖笔数 − 超大单卖笔数 − 大单卖笔数 − 中单卖笔数, 0)
小单卖笔占比 = 小单卖笔数 / 卖笔数
# 分母卖笔数为 0 时置 null；剩余法负值截断为 0
```

## 可变异维度

- 规模档：剩余 → 仅中小单
- 口径：笔数 → 量

## 适用场景

- **判断卖压性质**：与方向性净流出字段搭配，区分「散户恐慌抛售」与「机构系统性派发」；
- **散户情绪因子的分组变量**：在散户卖笔占比高的股票上，处置效应、反转类因子的区分度更强；
- **与买方占比联合**：买卖两侧小单占比的对称性可刻画散户是单边出逃还是双向活跃。
