## 金融解释

**衡量什么**：分别计算买侧与卖侧「主动成交占该侧总量的比例」，再相减：$\text{gap} = \text{主动买量}/\text{买量} - \text{主动卖量}/\text{卖量}$。正值表示买方成交更偏主动进攻（taker），卖方更偏被动挂单；负值反之。

**为什么有信息量**：净主动成交量告诉你「净方向上买方还是卖方占优」，但它不区分这一净额是由「买侧更主动」还是「卖侧总量收缩」造成的。本字段把两侧各自**条件在自身总量**上标准化，刻画的是**主动性的结构差异**：即使买卖总量相等，也可以一侧全靠主动单、另一侧全靠被动单，这种结构差异携带不同的交易意图信息。它因此是净失衡字段的正交补充。

**为什么用占比之差而非净额**：占比之差天然剔除了买卖总量规模的影响，使不同流动性水平的股票可比，也避免了单侧总量波动对结果的机械干扰。

**与相邻字段的区别**：

- [[patterns/fields/主动买占比|主动买占比]]：只看买侧主动额占主动总额的比例，不条件在买侧总量上，也不含卖侧对比；
- [[patterns/fields/净主动成交量|净主动成交量]]：买卖主动量的净失衡，是「量」维度；本字段是「结构」维度；
- [[patterns/fields/主动成交频率|主动成交频率]]：总量密度，无方向；
- [[patterns/fields/订单流失衡|订单流失衡]]：从**挂单增量**度量方向，本字段从**成交主动性**度量方向。

## 收益来源

本页归属 [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：赚**信息不对称**的钱——主动性强的一方是付出价差、要求即时成交的一方，更可能是掌握信息的知情者或急于调仓的大资金；当买侧主动占比系统性高于卖侧时，价格的上行动力与信息含量更高，跟随该结构可获取信息扩散前的收益。

**对手方**：被动挂单、被主动单吃穿的流动性提供者；以及在主动性结构失衡后仍按旧价格成交的滞后者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **算法执行主导**：主动 / 被动角色由执行算法决定（如 TWAP 偏被动、VWAP 偏主动），结构差异不指向信息；
- **做市库存管理**：做市方为平衡库存主动跨越价差，使两侧主动性差异含非信息成分；
- **信息被快速定价**：主动性差异在极短时间内被吸收，跟随无超额收益。

## 加工公式

```
主动买占比 = ratio(主动买量, 买量)          # 买侧主动比例
主动卖占比 = ratio(主动卖量, 卖量)          # 卖侧主动比例
主动被动成交差 = 主动买占比 − 主动卖占比
# 分母近零置 null；口径可换为笔数
```
