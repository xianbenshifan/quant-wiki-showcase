## 金融解释

**做什么**：两列逐点相加 $a+b$，是因子组合中最基本的**合成**算子。

**为什么单列一页**：多信号叠加是构造复合因子的默认动作——把多个子信号等权或加权求和。它操作化的是「多个证据的合并」；与 [[patterns/ops/点算子/逐点乘|逐点乘]] 的区别是：加法假设各分量**贡献可加**、彼此独立叠加，乘法假设分量间存在**交互 / 调制**关系。

## 算子定义

```
add(a, b) = a + b        # 任一为非有限 -> null
```

## 适用场景

- **多因子等权 / 加权合成**（配合权重列先乘后加）；
- **组合多个同向子信号**以提升稳定性；
- **构造总分 / 合计暴露**；
- **与基准相加**以还原水平（如相对量 + 基准）。

## 边界与陷阱

- **量纲必须一致**：不同量纲直接相加无意义，合成前须先各自标准化（[[patterns/ops/截面算子/截面z得分|z]] 或 [[patterns/ops/截面算子/截面排名|rank]]）；
- **共线性 / 重复计数**：高度相关的子信号相加会变相加权同一暴露，需先做相关性检查或正交化；
- **缺失传播**：任一非有限即置空，双列缺失会整片丢样本；有时期望「缺失视为 0 求和」而非置空，须显式约定；
- **与求和聚合的分工**：逐点加是同一行两列相加（跨字段），[[patterns/agg/求和聚合|求和聚合]] 是同一列多行相加（跨时间窗口），两者不可互换；
- **权重尺度**：加权合成时权重之和决定整体量级；若后续还要标准化，权重绝对水平不影响结果但影响可解释性，须固定约定。

## 可变异维度

- 对象：任意语义 / 字段对
- 等权 → 加权（先乘后加）
