## 金融解释

**做什么**：在每个截面内按分组键（行业、市值桶等）把 $y$ 减去所在组的均值，使每组内部的均值为零，组间水平差被剔除。

**为什么单列一页**：它是最轻量、最稳健的分组中性化——无需解回归、无需指定哑变量，只要有一个分组键即可消除「组间中枢」的影响。典型场景是行业估值中枢差异：某行业内所有股票估值都系统性偏高时，直接比较估值会混入行业效应，组内去均值后剩下的才是「相对同行的贵贱」。

**它操作化了什么**：「相对同组中枢的偏离」。当分组键由暴露自身的分位桶生成时（见 分位分桶），它等价于按分位分层做非参中性化。

## 算子定义

```
group_neut(y, group) = y - mean(y | Datetime, group)
# 在每个截面内按 group 求组均值并广播相减
```

## 适用场景

- 已知分组键且组间水平差异明显（行业、板块、市值桶、交易所）；
- 需要稳健、非参的分组标准化（不假设线性关系）；
- 行业内相对比较、分组内再排名或再 z 化的前置；
- 分组数较多但每组样本仍充足时。

## 边界与陷阱

- **只去水平、不去斜率**：若因子与目标的关系在组间斜率不同，仅去组均值不足以中性化，需改用 [[patterns/ops/截面算子/截面残差|截面残差]]（回归版）；
- **小组样本噪声**：分组过细时组均值估计不稳，甚至把信号本身减没，应保证每组有效样本足够；
- **与行业中性化的关系**：分组键为行业时，组内去均值与「对行业哑变量回归取残差」等价；差别在于行业中性化还可加入市值等连续控制项，而组内中性化只处理单一分类键；
- **分组键缺失**：缺失分组键的样本无法归属，须明确剔除或单列一组，否则会污染全局均值口径；
- **去均值后仍相关**：组内中性化不改变组内方差结构，也不消除与组间变量的相关，不能当作完整的风险中性化。

## 可变异维度

- 分组键：分桶号 / 行业码 / 市值桶
- 去均值 → 同时去中位（稳健版）
