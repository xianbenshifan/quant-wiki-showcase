## 金融解释

**做什么**：求合约整段样本的标准差并广播——该合约的**无条件波动水平**（长期波动量级）。

**为什么有信息量**：波动是风险的核心度量。整段标准差给出一只标的「一贯有多颠簸」，是横截面风险分组、标准化分母、波动率基线的基础。对收益序列，整段标准差就是最简单的已实现波动率估计；对成交量、价差等序列，它刻画活跃度或成本的稳定性。

**整窗口与滚动的根本区别**：本页用整段样本，输出一个常量（广播），是**无条件 / 长期波动**；[[patterns/ops/时序算子/滚动标准差|滚动标准差]] 用每个时点前的固定窗口，输出逐点变化，是**条件 / 局部波动**。前者适合横向比较「谁天生更颠簸」，后者适合识别「此刻波动是否放大」。两者组合（滚动波动 ÷ 整段波动）可刻画波动状态。

## 算子定义

```
global_std(x)          # 整段标准差，广播到每一行
```

- 按合约整段有效样本计算；样本 / 总体口径（ddof）须统一；
- 近常数序列标准差趋零，作为分母时须加护栏。

## 适用场景

- **长期波动率基线**：横截面风险分层与分组；
- **标准化分母**：与整窗口均值配对构成 [[patterns/ops/时序算子/整窗口z得分|整窗口z得分]]；
- **波动状态对照**：与滚动波动之比度量波动相对自身长期水平的变化；
- **风险调整**：把收益类因子除以波动得到风险调整强度。

## 边界与陷阱

- **对极端值高度敏感**：方差对尾部平方放大，一根异常 bar 即可抬高整段标准差，使用前宜先缩尾或做分位截断；
- **样本长度不可比**：整段长度不同的标的，波动估计的稳定性与口径不同，跨标的比较须谨慎；
- **前视风险**：整段统计含未来行，回填历史即前视；
- **输出近常量**：单独作为因子无时序变化，须与当前值或滚动统计配合。

## 可变异维度

- 对象：收益 / 成交 / 价差
- 基准长度：整段 → 扩张 / 滚动
- 稳健化：原值 → 缩尾后 / 绝对偏差（MAD）
