## 金融解释

**衡量什么**：成交量的相邻 bar 一阶差分。由于高频库中的成交量常为**日内累计**口径（自开盘逐 bar 累加），差分还原出每根 bar 的**真实增量**。对落差为负的情形（累计量回落）采用「取原值」的回退规则，得到非负的增量。

**为什么有信息量**：增量本身不携带买卖方向，但它是几乎所有**量价微观结构估计**的必需分母或自变量。最典型的是 Kyle 型价格冲击：把价格变化除以成交量增量，得到「单位成交量推动多少价格」，这是度量市场深度与流动性的核心量。此外，买卖量的单位比率、量能事件识别、峰岭形态判定都建立在增量之上。因此它是一个**基础加工字段**：价值在于把累计口径还原为可比的逐 bar 量，为下游提供正确的量纲，而非自身携带 alpha。

**为什么需要「回落取原值」的回退**：日内累计口径在跨日或数据异常时可能出现不单调（累计值回落）的情形。若直接取负的差分会得到无意义的负成交量；回退规则（负增量时取原值）在语义上等价于「把这一天视为新的起点」，保证增量非负、可用于后续比值。这是口径防御，而非金融信号。

**与相邻字段的区别**：

- [[patterns/fields/成交额增量|成交额增量]]：额口径的对应物，多乘了价格因子；量增量对成交量本身变化更纯，额增量对资金规模更敏感；
- 对数成交额增量：在本字段的额口径版本上再做对数压缩，处理厚尾；
- [[patterns/fields/成交额单位比率|成交额单位比率]]：把增量除以当日峰值做规格化，是增量的下游；
- [[patterns/fields/成交量不平衡概率代理|成交量不平衡概率代理]]：以本字段为分母构造的毒性代理，方向含义由该字段赋予。

## 派生形态

### LOB 侧 vol_diff

- **含义**：LOB 因子中作为 Kyle lambda 分母的成交量增量，取成交量的**单位比率**序列再做差分（而非对原始成交量差分）。
- **与本体**：与「成交量增量」同构，仅实现侧从原始量差分改为单位比率差分。**非独立字段**，实现变体归档于此（原同名变体页已归并，勿再建重复页）。
- **用途**：作为 Kyle lambda 的分母，度量的仍是「单位成交对应的价格冲击」。

## 加工公式

```
原始增量 = 成交量 − 上一 bar 成交量（按合约分组）
增量 = 若原始增量非空且 ≥ 0 则取原始增量，否则取成交量
# 回退规则保证增量非负，用于日内累计口径的还原
```

## 可变异维度

- 防回退：回落原值 → 截断 0
- lag：1 → k
- 口径：原始量差分 → 单位比率(成交量) 的差分（见派生形态）

## 适用场景

- **Kyle lambda 等冲击估计的分母**：任何「价格变化 / 成交量」的微观结构估计都需要正确的逐 bar 增量；
- **量能事件的逐 bar 刻画**：放量/缩量事件识别需要增量而非累计值；
- **量价关系的时序建模**：作为成交活跃度变化的直接度量。
