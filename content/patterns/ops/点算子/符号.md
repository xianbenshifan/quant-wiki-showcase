## 金融解释

**做什么**：取 $x$ 的符号（$-1/0/1$），保留方向、丢弃幅度。

**为什么单列一页**：把连续量降成纯方向哑变量，是最彻底的非参化——只关心「涨 / 跌 / 不变」，不关心多少。它操作化的是「方向状态」，常用于方向一致性统计（同向天数）、符号型信号合成，以及在对幅度信息不信任（噪声大）时只保留方向。

**与绝对值的分工**：符号与绝对值是一对分解——$\operatorname{sign}(x)$ 给方向，$|x|$ 给强度，两者相乘可还原 $x$。不少构造会把方向与强度分开处理（方向用符号，强度用绝对值或对数压缩后另行合成）。

## 算子定义

```
sign(x) = -1 if x < 0;  0 if x == 0;  1 if x > 0
```

## 适用场景

- 方向一致性 / 胜率类统计；
- 噪声大、幅度不可信时只保留方向；
- 与其他强度量相乘，构成「方向 × 强度」合成；
- 作为条件派生 / 掩码的布尔源。

## 边界与陷阱

- **零点的归属**：$x=0$ 归 0（第三类）还是并入某一侧，会改变分布与胜率口径，须统一；对含大量零的稀疏量尤其重要；
- **幅度信息被彻底丢弃**：$+0.001$ 与 $+10\%$ 同为 1，若两者后续行为差异大则损失信息；
- **与绝对值相乘的可逆性**：$\operatorname{sign}(x)\cdot|x|$ 只在原始值上可还原，若中间经过任何压缩（如对数）再乘会改变量级；
- **噪声导致频繁翻转**：接近 0 的量在微小扰动下符号跳变，方向一致性统计会被噪声主导，必要时加死区（deadband）。

## 可变异维度

- 对象：收益 / 失衡类
- 零点归属：0 → 并入某侧
- 是否加死区
