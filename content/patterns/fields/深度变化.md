## 金融解释

**衡量什么**：五档买卖挂单总量（[[patterns/fields/总深度|总深度]]）相对上一期的一阶相对变化：$\text{depth\_change} = \dfrac{\text{total\_depth}_t}{\text{total\_depth}_{t-1}} - 1$，再做 1% 时序缩尾。正值表示盘口变厚（承接力增加），负值表示变薄。

**为什么有信息量**：深度变化刻画的是**流动性供给的扩张与收缩速率**。与只看最优档的 [[patterns/fields/深度冲击|深度冲击]] 相比，它覆盖五档、是对整段盘口承接能力的综合度量：变厚可能来自流动性提供者加码挂单、也可能来自大量被动挂单涌入；变薄则意味着流动性在撤离。流动性供给的收缩本身是一个风险状态——它预示未来冲击成本抬升、变现变难，因此在截面与时间序列上都有定价含义。由于变化率可正可负，它的符号携带方向信息，而幅度衡量收缩 / 扩张的剧烈程度。

**与相邻字段的区别**：

- [[patterns/fields/深度冲击|深度冲击]]：只看最优档且翻符号，专指「承接力被抽走」的负向冲击；深度变化覆盖五档、保留双向符号，是更中性的流动性动态度量。
- [[patterns/fields/总深度|总深度]]：存量水平；深度变化是它的变化率，二者一为状态、一为变化。
- [[patterns/fields/浅档订单流失衡|浅档订单流失衡]]：OFI 关注买卖两侧的**净增量方向**（Δ买−Δ卖），深度变化关注两侧**合计厚度**的变化，不带买卖方向。
- 涨跌幅 / 成交量增量：价格与量能的增量还原，与盘口厚度无关。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]]

**赚什么钱**：赚**流动性溢价**。深度变化度量流动性供给的收缩 / 扩张：当盘口持续变薄，市场整体承担了更高的即时冲击风险，继续提供流动性的参与者要求更高补偿，因而流动性收缩状态与更高的预期收益相关。它是一种流动性风险的动态暴露，而非静态非流动性水平。

**对手方**：在盘口变薄、冲击成本上升时仍需成交的急躁方；以及在流动性收缩期被动变现、承受更大价格不利的持仓者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **撤单后瞬时回补**：算法撤单造成深度短暂下降后立即重建，变化率不含真实流动性收缩；
- **结构性挂单行为**：指数成分调整、大宗过户等制度性事件造成深度突变，方向含义被制度因素覆盖；
- **流动性充裕环境**：整体宽松时深度变化被快速吸收，溢价不显著。

## 加工公式

```
depth_change = ratio(total_depth_t - total_depth_{t-1}, total_depth_{t-1})
depth_change = ts_winsorize(depth_change, 1%)
# 前值近零置 null
```

## 适用场景

- 作为**流动性动态**度量：识别盘口厚度的扩张 / 收缩趋势，用于流动性风险择时或截面分组；
- 与 [[patterns/fields/深度冲击|深度冲击]] 互补：一个看最优档压力事件、一个看整段盘口的趋势变化；
- 与 [[patterns/fields/总深度|总深度]] 组合，判断「深度变化是均值回归还是趋势」；
- 在**日频**上常与成交量、价差一同构成流动性状态因子；分钟级则更多用于事件研究。

## 可变异维度

- 缩尾：1% → 0.5%/5%
- 窗口：单 bar → 滚动
