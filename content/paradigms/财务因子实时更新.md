## 范式概述

财务因子通常基于公司定期披露的财务报告，而财报披露高度集中在每年 3、4、7、8、10 月（一季报/中报/三季报/年报的法定截止日分别为 4/30、8/31、10/31、次年 4/30），其他时间财务因子几乎不变。本范式主张：**在因子更新中，财务数据的时效性比截面可比性更重要**——站在任一时点都用每家公司**最新可得**的财务数据更新因子，并进一步把发布时间早于财报的**业绩预告、业绩快报**也纳入更新，使财务信息第一时间进入因子与组合。

源报告给出三档更新方式：

| 更新方式 | 做法 | 侧重 |
| --- | --- | --- |
| 定期更新财报 | 4/8/10 月底等某季度财报全部发布后统一更新 | 截面**可比性**（口径统一、不受季节影响） |
| 实时更新财报 | 任一时点用各公司最新可得财报 | 数据**时效性** |
| 实时更新所有报告 | 在上一档基础上纳入业绩预告、业绩快报 | 时效性**最大化** |

**为什么实时更新更有效**：市场定价的是公司**最新的经营状态**。定期更新有两处代价——数据使用效率低（4/30 更新一季报时年报信息完全没用上）与时效性差（10/31 的三季报数据要沿用到次年 4 月底，长达半年无新增财务信息）。实时更新让因子始终反映最新经营变化，因而选股能力更强。纳入预告/快报则进一步压缩了信息真空期：在 2018 年 1 月底，仅用财报时 2017 年年报覆盖度近乎为 0，纳入预告与快报后 2017 年年报覆盖度超过 70%；2018 年 7 月底中报覆盖度从约 5% 提升到超过 60%。

**机制链条**：财务信息分批披露（快报/预告 → 正式财报，且各公司时点不同）→ 因子若等到统一时点更新，则长期停留在旧状态 → 组合错过信息刚释放、定价尚未完成的窗口 → 用最新可得数据（含预告/快报）实时更新，等于把「信息到达」与「因子反映」之间的时差压到最小，吃到信息逐步定价的那一段。

**为什么实时更新的「截面不可比」不是问题**：实时更新在 3 月底会拿 A 公司四季度 ROE 与 B 公司三季度 ROE 相比，看似不可比。但对三类公司（经营均衡型、周期波动型、季节性型）这一比较均有依据：① 经营均衡型（如恒瑞医药，单季度 ROE 长期稳定在 5%–7%）的投资者预期一致，新数据一旦偏离即打破预期、推动股价；② 周期波动型（如鞍钢股份）的投资者按**盈利动量**决策，最新财报正是动量的载体；③ 季节性型（如万科 A，四季度利润常超全年 50%）存在**季节性盈利异象**——单季度利润最高/最低的财报发布前后，股票相对市场有显著正/负超额收益。三类情形都指向「用最新财报预测未来收益是合理的」。

## 构造要点

1. **取数防前视（最关键）**：部分公司会**修正**历史已发布财报的财务数据（源报告举例：兰花科创 2015 年三季报净利润被 2015 年年报、2016 年三季报两次修正）。站在不同时点实际可获取的数据不同，数据库中保留修正记录。回测中必须取**回测点可见的最新版本**——只用到该时点之前已发布的数值，不能直接用修正后的终值，否则引入未来信息、结果虚高。
2. **界定「最新可得」的优先级**：同一报告期若同时存在正式财报、业绩快报、业绩预告，按信息含量与实际值精度排序取「最新且最实」。预告是**区间值**，快报是**未经审计的点值**，财报是**经审计的确定值**；随着披露推进，用更高精度的数据替换。
3. **预告净利润的取用规则**：业绩预告多以区间形式给出净利润预测，也有公司只给单边（如「预计扭亏」「利润不低于 3000 万」）。源报告的处理是**只选用同时预告利润上限和下限的样本**，并取**上下限均值**作为其净利润估计——单边预测无法确定中枢，区间均值是对称分布下的合理点估计，剔除单边样本则避免系统性偏误。
4. **把「更新时点」本身纳入因子计算**：财务因子在每个交易日按该日各公司最新可得数据重算，因此因子值在财报季会随披露逐步「跳变」，而非在固定时点整体切换。日频调仓时，因子的日度更新与组合的日度再平衡同步，信息进入组合的时滞最小。
5. **因子标准化流程（截面）**：源报告对每个因子做统一预处理——
   - **缺失值处理**：因子值缺失的股票，视情况补为**行业均值或 0**（见 [[patterns/ops/截面算子/缺失值补齐|缺失值补齐]]）；
   - **去极值**：用 MAD（绝对中位数法）去极值，把极值部分按排序均匀插值到 3–3.5 倍绝对中位数范围内（见 [[patterns/ops/截面算子/MAD去极值|MAD去极值]]），比 3σ 更稳健；
   - **标准化**：Z-Score 使因子均值 0、标准差 1，统一量纲（见 [[patterns/ops/截面算子/截面z得分|截面z得分]]）；
   - **市值与行业中性化**：因子对**对数总市值**与**行业哑变量**回归取残差，残差再去极值、标准化（见 [[patterns/ops/截面算子/行业中性化|行业中性化]]、[[patterns/ops/截面算子/截面残差|截面残差]]）。
   **为什么这个顺序**：先去极值再标准化，避免均值/标准差被离群值主导；先补缺值再去极值，避免缺失改变估计；中性化放最后，因为它以标准化后的因子为被解释变量。
6. **复合前的共线性处理**：同族财务因子高度相关（单季度净利润增速与单季度营收增速的秩相关系数 0.42），直接加权会放大成长风格暴露。源报告用**对称正交**（见 [[patterns/ops/其他算子/对称正交|对称正交]]）旋转得到两两正交的新因子——无次序偏好、对原矩阵修改最小、经济意义保持最好——再进入复合。
7. **与调仓频率的配合**：因子既然可日度实时更新，就应把信息第一时间引入组合。源报告对比了月频与日频调仓：日频调仓（每日换手上限 5%）将月频的实时更新组合年化超额从 22.83% 提升到 30.29%，相对最大回撤从 3.51% 降到 2.58%，信息比从 4.28 升到 5.65。**为什么日频更优**：财务信息的释放是连续、分散的（各公司披露时点不同），固定月频调仓只能在月末统一吸收，中间的信息窗口被浪费。
8. **换手率约束的敏感性**：日频调仓对换手率更敏感，源报告测算了不同日换手上限——年化超额与信息比随换手率上升呈「先快速上升后平稳」：换手升到 4% 后再增加，收益与信息比基本不变。**理由**：增量收益与相应增加的交易成本相互抵消。

## 可变异维度

- **更新方式的粒度**：三档（定期财报 / 实时财报 / 实时所有报告）→ 更细的按报告类型优先级合并（预告 → 快报 → 财报逐级替换）；
- **单季度口径**：单季度归母净利润 × 2 /（期初 + 期末）→ TTM 口径 / 期末口径；
- **标准化流程**：缺失值补齐（行业均值 / 0）、去极值（MAD / 3σ / 分位）、中性化（市值 / 行业 / 市值 × 行业）各轴可替换；
- **正交方式**：对称正交 → 施密特正交 / 回归取残差；
- **复合权重**：滚动 ICIR 加权 → 等权 / IC 加权 / 半衰 IC 加权；
- **调仓频率**：月频 → 日频；换手率约束：无约束 → 日换手上限 2%–10%；
- **因子池**：源报告因子库含规模、估值、技术、成长、盈利、一致预期、流动性、波动、分红九类，各域可增删。

## 候选收益来源（初判，待主 agent §4.6 裁决）

**候选归属**：[[alpha/信息冲击消化滞后|信息冲击消化滞后]]（本页未写 `return_source`，由主 agent 决定）

**赚什么钱**：主要赚**信息时效**的钱——财务信息分批到达市场，价格对其消化需要时间（投资者先观望、分批定价，机构调仓与分析师预测修正滞后）。实时更新（含预告/快报）让因子在信息刚释放、价格尚未充分反映时就捕捉到，吃到信息逐步定价的那一段；定期更新则因信息滞后，在这一窗口之外才反应。次要赚**盈利动量/预期打破**的钱——最新财务数据若明显偏离投资者一致预期（经营均衡型公司），会打破预期并推动股价朝新数据方向变动。

**对手方**：仍按**旧财务数据**交易的参与者——他们等到统一更新时点才调整仓位，在信息已部分定价后才跟入，为先行者提供价格；以及在定期的、口径可比的历史财务比较框架下做决策、忽略最新经营变化的资金。季节性型标的的对手方还包括对可预期的季节性高低盈利反应不足的投资者。

**理论支撑**：[[concepts/季节性盈利异象|季节性盈利异象]]（单季度利润最高/最低的财报前后有显著超额收益，解释了实时口径下季节性标的可预测性来源）。

**失效条件**：

- **信息被瞬时定价**：若披露与定价之间的时滞消失（算法即时消化、披露制度使数据同步到达），实时相对定期的优势消失；
- **披露频率与质量下降**：若预告/快报的强制性与覆盖度下降，实时更新可用的早期信息减少，时效性红利收窄；
- **因子有效性源于可比性本身**：若某类财务因子的收益主要来自跨公司截面口径可比（如季节性行业的同业比较），实时口径引入的不可比反而损害信号；
- **拥挤与交易成本**：当日频实时更新被广泛使用，信息窗口的收益被交易成本吞噬（源报告实测换手超过 4% 后增量收益与成本相抵）。

## 因子表现基准

- **因子层面**（2008–2018，全市场分 10 组、未来 20 日超额）：单季度 ROE 的 IC 均值 0.044（定期）→ 0.048（实时财报）→ 0.056（实时所有报告），年化 ICIR 1.83 → 2.05 → 2.45；单季度净利润同比增速 IC 均值 0.035 → 0.040 → 0.047，年化 ICIR 2.08 → 2.46 → 3.08。常见财务因子（单季度 EP、EPTTM、BP、单季度 ROE/ROA、SUE、SUR、单季度 SP、SPTTM 等）在实时更新所有报告下几乎全面提升。
- **复合因子**：IC 均值 0.131（定期）→ 0.133（实时财报）→ 0.137（实时所有报告），年化 ICIR 6.31 → 6.50 → 7.15。
- **中证 500 指数增强**（2010-01 至 2019-04，交易成本买 0.1%/卖 0.2%，行业与风格相对基准暴露为 0）：月频定期更新年化超额 20.66%、相对最大回撤 5.20%、信息比 3.78、月度胜率 83.04%；月频实时更新 22.83%/3.51%/4.28/91.07%；日频实时更新（日换手上限 5%）30.29%/2.58%/5.65/95.54%。

## 关于收益来源（方法论范式）

**本页不标注 `return_source`**：本范式是**因子取用与标准化流程**（更新时点的选择 + 缺失/去极值/标准化/中性化），不是一条具体的因子构造，没有单一「赚什么钱」——它产出的因子池覆盖估值、盈利、成长等多类机制。判定具体因子的收益来源应回到**该因子自身的构造**（如单季度 ROE → 质量类、单季度净利润增速 → 成长类），各自在其范式或 fields 页标注。

因此本页在收益来源的计数与统计中豁免（与 `pipeline: unclassified` 的元范式同一处理口径）。
