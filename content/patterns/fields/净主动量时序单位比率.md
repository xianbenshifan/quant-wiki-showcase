## 金融解释

**衡量什么**：分三步。先把主动买量、主动卖量分别规格化为**时序单位比率**（当根 bar 增量 / 当日该侧峰值，使不同规模、不同活跃度的股票可比）；再对两侧单位比率各取相邻 bar 一阶差分，得到「买侧量能变化的加速度」与「卖侧量能变化的加速度」；最后取两者的归一化净差：$(\Delta\text{买} - \Delta\text{卖})/(\Delta\text{买} + \Delta\text{卖})$。正值表示买侧的相对量能加速快于卖侧。

**为什么有信息量**：原始的 [[patterns/fields/净主动成交量|净主动成交量]] 度量的是**水平**上的买卖净方向，会被「今天整体成交了多少」污染——放量日两边都大，净差反而可能被噪声主导。本字段把方向搬到**变化率**空间：不问「买多还是卖多」，而问「哪一侧的量能正在更快地起来」。资金流的净方向在加速时最容易被观察——知情者建仓需要连续主动吃单，其买侧量能会出现相对自身峰值的加速抬升，而卖侧不同步；这种「一侧加速、一侧不动」的形态比静态净额更早，且受规模水平影响更小。

**与相邻字段的区别**：

- [[patterns/fields/买卖量时序变换差|买卖量时序变换差]]：同属「时序变化」族，但用**环比增速**、未做峰值归一化，量纲随股票规模与当日水位漂移；本字段先归一化到 $[0,1]$ 再差分，跨股可比性更强。
- [[patterns/fields/净主动成交量|净主动成交量]]：绝对水平差；本字段是归一化后的**变化率净差**，一个刻画「状态」、一个刻画「加速度」。
- [[patterns/fields/成交额单位比率|成交额单位比率]]：同样基于单位比率，但**不含方向**（只看总量能强度）；本字段把买卖两侧分开做比，方向是核心。
- [[patterns/fields/撤单强度时序单位比率|撤单强度时序单位比率]]：名字同为「时序单位比率」，但度量的是撤单/挂单的比例（意图可信度），不含主动量方向。

## 收益来源

本页归属 [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：主要赚**信息不对称**的钱——主动买卖量能的相对加速是知情者建仓节奏的可见痕迹：连续主动买入会系统性推高买侧单位比率的差分，而这一「节奏信息」在价格尚未充分反映基本面时即可观察，据此可提前于信息扩散布局。

**对手方**：在知情者加速吸筹/派发时被动成交的另一方（挂单等待成交的流动性提供者）；以及在信息扩散后才跟随的交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（主动委托的方向与节奏携带信息）；[[alpha/知情卖出信号|知情卖出信号]]。

**失效条件**：

- **算法拆单抹平加速度**：大额订单被拆成均匀小单执行时，买侧量能不再出现相对峰值的加速抬升，方向信息退化为纯噪声；
- **主动方向判定失真**：当「主动买/主动卖」依赖报价方向分类、且分类错误率上升时，两侧量能差分不再对应真实意图；
- **高频微观噪声主导**：单位比率的一阶差分对单 bar 噪声极其敏感，在稀疏标的或低流动性时段可能完全由价差跳动决定。

## 加工公式

```
单位比率(主动买量) = 主动买量增量 / 当日主动买量峰值
单位比率(主动卖量) = 主动卖量增量 / 当日主动卖量峰值
Δ买 = 单位比率(主动买量) − 上一 bar 单位比率(主动买量)
Δ卖 = 单位比率(主动卖量) − 上一 bar 单位比率(主动卖量)
净主动量时序单位比率 = (Δ买 − Δ卖) / (Δ买 + Δ卖)
# 峰值按合约与交易日求 max；各分母近零置 null
```

## 可变异维度

- 基准：单位比率差分 → 原始量差分
- 窗口：可调

## 适用场景

- **资金流节奏的短周期跟踪**：在分钟—小时级窗口内识别「一侧量能正在加速」，先于价格完成反应；
- **与静态净额互补**：静态净流入给方向、本字段给节奏，二者同向时信号更强；
- **对规模不敏感的截面比较**：单位比率差分已剥离当日水位，适合跨市值池比较资金流加速度。
