## 金融解释

**衡量什么**：对买盘、卖盘各档挂单量按**距离衰减权重**（最浅档权重最高，常取 5,4,3,2,1）加权求和，再做归一化失衡：$\text{加权失衡} = (\sum w_i BV_i - \sum w_i SV_i)/(\sum w_i BV_i + \sum w_i SV_i)$。正值表示按「近期可成交性」折算后买盘更强。权重逐档递减，是因为越远的档位越难在短期被触及，对实际价格压力的贡献越小。

**为什么有信息量**：它把 [[patterns/fields/近端失衡|近端失衡]] 从单档扩展到多档，在保留方向的同时降低单档噪声——最优档的量极易被单笔挂撤扰动，而五档加权是一个更稳的**整体承接结构**度量。它与近端失衡回答同一问题（哪侧更强）但视角不同：近端失衡是「瞬时的交锋点」，加权失衡是「整段盘口的重心」。权重设计使它天然偏向近档信息，兼顾敏感性与稳健性。

**与相邻字段的区别**：

- [[patterns/fields/近端失衡|近端失衡]]：只取最优档，噪声更大但更即时；加权失衡覆盖多档、更稳健但更滞后。
- [[patterns/fields/斜率失衡|斜率失衡]]：从**价格跨度 / 深度**出发度量倾斜（价格梯度），不带量的加权；加权失衡是纯**量**的加权失衡。
- [[patterns/fields/凸度差|凸度差]]：度量深度曲线的**曲率**（形状），加权失衡度量重心的**方向**。
- [[patterns/fields/微价格偏离|微价格偏离]]：把最优档量失衡映射到**价格空间**，是同一信息的价版表达；加权失衡则扩展到了多档。
- [[patterns/fields/订单流失衡|订单流失衡]]：度量挂单量的**增量**方向；加权失衡是**存量**结构。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/信息风险补偿|信息风险补偿]]

**赚什么钱**：其一为**流动性溢价**——加权失衡刻画盘口整体承接能力的不对称，偏薄一侧的即时冲击成本更高，为该侧补足流动性者可获补偿；其二为**信息不对称**——知情者倾向于在承接薄弱的一侧发起攻击，加权失衡是其订单簿痕迹。

**对手方**：在偏薄一侧被主动单吃穿挂单的流动性提供者；以及依据可见盘口失衡追单、却被真实供需反向打击的跟随者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **挂单可自由撤销**：盘口不平衡只是可撤回的承诺，幌骗挂单可制造虚假失衡；
- **冰山单隐藏真实深度**：可见五档不代表真实承接力，多档加权也可能系统性偏薄；
- **做市算法快速均衡**：高频补单使失衡在毫秒级被抹平，日频聚合后的存量失衡不含持久信息。

## 加工公式

```
权重 = [5, 4, 3, 2, 1]            # 最浅档权重最高，逐档衰减
加权买 = Σ_i 权重_i × 买盘量_i
加权卖 = Σ_i 权重_i × 卖盘量_i
加权失衡 = (加权买 − 加权卖) / (加权买 + 加权卖)
# 分母近零置 null；权重方案与档位深度可替换
```

## 可变异维度

- 权重：线性 5..1 → 等权 / 平方
- 档位深度：5 → 10

## 适用场景

- **多档盘口方向信号**：需要比最优档更稳健、又比斜率/凸度更直接的「哪侧强」判断时；
- **与近端失衡交叉验证**：两者同向时方向可信度更高，异号提示最优档被单笔挂撤扰动；
- **存量 + 流量组合**：与 OFI 类增量字段配对，构建共振信号；
- **报单连续、五档完整的活跃标的**：冷门股中远档常年为空，加权退化为近端。
