## 金融解释

**衡量什么**：收益率减去同一时点全市场（或指定池）的截面中位数：$\text{ex\_pct\_chg} = r - \text{median}_{cs}(r)$。它是**去市场共同方向**后的个股相对收益。

**为什么有信息量**：它本身是中性的相对强弱变换，不携带内在方向——价值的核心在于把「市场 β」从个股收益中剥离，留下纯粹的截面相对表现。因子研究绝大多数关心的是「相对强弱」而非绝对涨跌：市场普涨时的绝对收益无法区分选股能力，只有超额部分才是选股信号。用中位数而非均值去中心，是为了降低极端值对基准的拉动，使基准更接近「典型股票」的表现。截面超额也是后续排名、分组、多空组合构造的自然输入。

**与相邻字段的区别**：

- [[patterns/fields/收益率|收益率]]：未去市场成分的原始收益；超额收益是其截面去中心版本。
- [[patterns/fields/时段残差差|时段残差差]]：按上午 / 下午分段回归取残差之差，剔除的是「市场 × 时段」的联合成分；本页只做一次性截面去中位数，不区分时段也不做回归。
- [[patterns/fields/超额成交额单位比率|超额成交额单位比率]]：量端的镜像操作（量比减截面中位数）；两者一价一量，常配对。
- [[patterns/ops/截面算子/截面残差|截面残差]]：通用的回归取残差算子，可剔除多因子暴露；本页只是单变量中位数去中心，是最简单的一种去市场成分。

## 加工公式

```
ex_pct_chg = r - median_{cs}(r)          # 同一时点全市场合约截面中位数
# r 为（signed-log 或原始的）期间收益率
```

## 适用场景

- 作为**相对强弱**的基础输入：截面排名、分组、多空组合构造；
- 与 [[patterns/fields/超额成交额单位比率|超额成交额单位比率]] 配对构造量价相对强弱信号；
- 作为**简单的市场中性化**：当不需要精确 β 控制、只想快速剥除市场方向时；
- 在**宽截面、股票数充足**的池子里中位数估计更稳，去中心效果更好。

## 可变异维度

- 基准：中位数 → 均值/指数
- 口径：收益 → 量比
