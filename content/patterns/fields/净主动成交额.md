## 金融解释

**衡量什么**：主动买额与主动卖额的归一化失衡 $(\text{主动买额} - \text{主动卖额}) / (\text{主动买额} + \text{主动卖额})$，取值 $[-1,1]$。与 [[patterns/fields/净主动成交量|净主动成交量]] 同构，只是把口径从**成交量**换成**成交额**。

**为什么用额口径**：价格冲击与资金规模直接相关，而成交量口径把「贵股的一手」与「便宜股的一手」等同看待，会低估高价股的资金压力。用成交额后，字段度量的是**资金层面**的主动方向，对价格冲击与资金流更敏感，也天然剔除了股价水平对量口径的影响，跨股票比较更直接。

**为什么归一化**：与净主动成交量同理——去除个股规模与活跃度的机械影响，使失衡可比、便于截面排序。

**与相邻字段的区别**：

- [[patterns/fields/净主动成交量|净主动成交量]]：**量**口径，反映股数结构的净方向；额口径反映资金规模；
- [[patterns/fields/净主动笔数|净主动笔数]]：**笔数**口径，刻画交易频率方向；
- [[patterns/fields/主动买占比|主动买占比]]：占比形式，与净额单调对应；
- [[patterns/fields/大单净流入|大单净流入]]：同为额口径的归一化失衡，但**限定在大单档**，含机构主体含义；本字段覆盖全部主动成交、无规模分层。

## 收益来源

本页归属 [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：赚**信息不对称**的钱——主动买入金额净流入意味着大额资金在积极吸筹，其信息与资金持续性使其方向更具预测力，跟随可在信息扩散前建仓；净流出则提示派发压力。

**对手方**：被动提供流动性、被主动资金吃穿的做市方与限价单持有者；以及反应滞后的跟随者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **算法拆单**：大额主动买入被拆成多笔小额，额口径的净流入仍可见，但主体含义减弱；
- **做市库存管理**：主动成交方向混入库存调整；
- **信息被快速定价**：净流入被瞬时吸收，跟随无超额收益。

## 加工公式

```
净主动成交额 = ratio(主动买额 − 主动卖额, 主动买额 + 主动卖额)
# 分母为 0 置 null；口径可换为量或笔数
```

## 可变异维度

- 口径：额 → 量/笔数
- 频率：可调

## 适用场景

- **资金层面的方向信号**：需要强调资金规模而非股数时；
- **与量口径配对**：量、额口径的差异本身携带「高价股 vs 低价股」的结构信息；
- **短周期横截面选股**：归一化后可直接排序。
