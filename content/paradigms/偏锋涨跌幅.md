## 范式概述

偏锋涨跌幅刻画「**动量脉冲**」分钟里离群偏离的强度：先算同向动量偏离度，再以**截面偏度大于 0** 识别动量时刻，将该时刻对数偏离度加总为日度因子，月末取 20 日标准差。偏度大于 0 意味着离群超涨或少跌更多，高偏离股票日后预期收益更低。

**为什么用「截面偏度」识别动量时刻**：这是本范式最巧妙的一步。截面偏度衡量的是**同一时点全市场收益分布的不对称性**——偏度大于 0 表示分布右侧尾部更长，即有少数股票涨幅明显超出常态。这种「少数股票跑赢、大多数平淡」的状态，正是**动量脉冲**的特征：资金集中流向少数标的，形成局部强势。反之偏度为负时是普跌、少数领跌。因此截面偏度是一个**市场层面的状态开关**，而不涉及个股自身信息——它回答的是「此刻是不是一个动量正在发力的时刻」。

**为什么看「相对同向基准的偏离」**：单看个股收益无法区分「它自己涨」与「整个市场同方向都在涨」。同向动量偏离度减去同向基准（上涨股取涨幅均值、下跌股取跌幅均值），得到的是**个股相对同类股票的额外强度**。这一步剔除了市场共同方向，使信号具有截面可比性——高偏离意味着这只股票在其自身方向上明显跑赢同类。

**为什么高偏离对应未来收益低**：个体在动量时刻的过度强势往往不可持续。偏离度越高，说明该分钟的上涨（或抗跌）越可能由短期资金集中推动而非基本面，这类「脉冲式领先」在随后容易回吐。月末取 20 日标准差而非均值，是为了度量**偏离的波动性/不稳定性**——偶尔一次极端偏离与持续偏离在 std 口径下都会放大，反映的是「这只股票的偏离行为有多不稳定」。

## 构造要点

1. **计算正/负向动量基准**：每分钟算上涨股票收益均值作正向基准、下跌股票收益均值作负向基准。
   分别在上涨组与下跌组内取均值，是为了得到「同方向同类」的参照点。若混在一起取全市场均值，上涨股的正收益会被下跌股抵消，偏离度失去意义。
2. **计算 [[patterns/fields/同向动量偏离度|同向动量偏离度]]** = 个股分钟收益 − 同向基准。
   这一差值即「相对同类强度的度量」，是后续所有步骤的输入。
3. **识别动量时刻并加总**：截面偏度大于 0 的分钟为动量时刻（[[patterns/agg/偏度聚合|偏度聚合]] 计算截面偏度）；对该时刻**对数偏离度**加总得日度因子。
   对偏离度取对数再累加，是为了**压缩极端值**——偏离度可能因个别极端分钟而极大，取对数使分布更接近对称、避免少数观测主导因子；加总则是把当日所有动量时刻的信息累积。
4. **月末低频化**：过去 20 日日度因子的标准差 = 日内偏锋涨跌幅（[[patterns/agg/标准聚合|标准聚合]]）。
   用标准差而非均值：均值会被日度偏离的方向抵消，而标准差度量的是「偏离行为的强度/不稳定性」，更贴合「偏锋」这一语义。

## 可变异维度

- 动量时刻阈值：偏度 > 0 → 其它分位（如 > 0.5 分位）
- 低频化：20 日标准差 → 均值 / 其它窗
- 偏离变换：对数 → 原始
- 基准：同向均值 → 同向中位数（更抗极端值）

## 收益来源

本页归属 [[alpha/凸显收益误估|凸显收益误估]]

**赚什么钱**：主要赚**行为偏差**的钱——动量时刻中的离群强势股承载了过度的资金关注与情绪外推，投资者把短期脉冲误认为持续趋势（代表性偏差），其随后回吐即收益来源。次要成分与**动量**相关：偏度 > 0 的时刻本质是动量正在发力的状态，因此该因子与动量暴露存在重叠，高偏离股短期可能仍有惯性，与回吐机制方向相反，净效应须以实证确定。

**对手方**：在动量脉冲中追逐强势股、把短期偏离外推为持续趋势的交易者；以及在偏离高位接盘的后期资金。

**理论支撑**：[[alpha/极端时刻过度反应|极端时刻过度反应]]（脉冲与反转的关系）；[[concepts/行为金融凸显理论|行为金融凸显理论]]。

**失效条件**：

- **真实趋势启动**：若该时刻的偏离源于基本面改善且资金持续流入，强势会延续，回吐假设不成立；
- **市场宽度极端**：当全市场普遍上涨或下跌时，截面偏度小且不稳定，「动量时刻」的识别失去区分度，掩码选中样本意义不大；
- **流动性冲击造成的假偏离**：单笔大单可在低流动性股上制造极端偏离，此时偏离反映冲击而非情绪，其方向与成因不一致。
