## 金融解释

**做什么**：先在截面上取某个分位值作为「轴」（参照点），再对轴左、轴右两侧**分别**做归一化排名。轴值处取 0，左侧为负、右侧为正：两侧各自在侧内按取值升序映射到 $[0,1]$ 的强度，并叠加方向符号。

**为什么不用整体排名**：[[patterns/ops/截面算子/截面排名|截面排名]] 给整条截面一个单调的 0~1 序，把一切「相对位置」压进同一尺度；当研究者关心的是「相对某个临界水平的强弱」而非「全市场第几名」时，整体排名会把轴两侧的信息混在一起。双侧排名把轴固定住，让左右各自展开，适合**左右不对称**的命题——例如低值档与高值档内部的区分度本就不同。

## 算子定义

```
dual_rank(x, q):
    a = quantile_cs(x, q)                 # 轴
    left  = rank_asc(x | x < a)  → [-1, 0]
    right = rank_asc(x | x > a)  → [ 0, 1]
    # 轴附近（|x - a| 极小）→ 0
```

## 适用场景

- 信号在参照轴两侧需要不同展开尺度的构造；
- 「突破临界后强度」类信号：以某分位为门槛，门槛以上的相对强弱单独刻画；
- 需要保证两侧都有足够样本时（$q=0.5$ 即中位轴，两侧样本均衡）；
- 与分组键组合，构造行业内双侧排名（剔除行业间水平差）。

## 边界与陷阱

- **引入人为参照点、破坏单调性**：整体排名对 $x$ 单调，双侧排名在轴处「重新起跳」，可能把原本单调的因子折成 V 形；若命题是单调因子，应直接用 [[patterns/ops/截面算子/截面排名|截面排名]]；
- **$q$ 的选择决定轴位置**：$q$ 偏向一侧会让该侧样本过少、侧内排名不稳，经验上两侧样本数都应远大于排名所需的分辨率；
- **两侧尺度不可直接比较**：左右各自归一化后，「左 $-0.8$」与「右 $+0.8$」并不代表等量的经济偏离，跨侧比较须谨慎；
- **轴附近抖动被放大**：恰好落在轴两侧的样本得到相反符号，微小估计误差即可翻转方向；若结果对 $q$ 的微小扰动敏感，说明信号主要来自边界噪声。

## 可变异维度

- q：轴分位（0.5 对称 → 其他）
- 是否保留左右符号
- 分组口径：全截面 → 行业内
