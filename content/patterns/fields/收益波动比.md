## 金融解释

**衡量什么**：$t$ 分钟的收益 $r_t$ 除以该分钟的更优波动率 $V_t$，即单位波动所实现的收益。它是一个**波动调整后的收益**：把收益放到当下的波动背景里重新标定。

**为什么有信息量**：同样 1% 的分钟收益，在平静时段是异常大的实现值（比值高），在剧烈波动时段则平平无奇（比值低）。范式关心的从来不是这个比值的绝对水平，而是它的**横截面离散与协方差结构**——波动加剧初期，投资者对波动状态的变化反应不足，个股的收益 / 波动比会系统性偏离，从而在截面上留下可预测的共同变动（见 [[paradigms/收益波动比协方差|收益波动比协方差]]、[[paradigms/日内收益波动比|日内收益波动比]]）。因此该字段的价值在于它是「波动状态」与「收益实现」之间的桥，而不是一个方向性 alpha。

**与相邻字段的区别**：

- [[patterns/fields/收益率|收益率]]：只看收益本身；收益波动比额外除以波动，剔除「高波动股票天然大收益」的水平效应；
- [[patterns/fields/更优波动率|更优波动率]]：本页的分母，纯风险度量；本页是它与收益的合成；
- 长窗 z-score 式标准化：用历史均值方差标准化收益，反映的是「相对历史是否异常」；收益波动比用局部 5 分钟全路径波动，反映的是「相对当下波动状态是否异常」，对波动突变更敏感。

## 加工公式

```
ratio_t = r_t / V_t
# r_t 分钟收益；V_t 为更优波动率（见 更优波动率）；V_t 近零置 null
```

## 适用场景

- 需要**剥离波动水平差异**、比较不同波动状态个股收益实现强度时；
- 构造「波动调整后收益」的横截面离散 / 协方差类因子（如灾后重建、勇攀高峰一类范式）；
- 波动状态切换（由静转动）的事件研究窗口中，比值能放大状态切换期的异常实现；
- 与 [[patterns/mask/异常高波动掩码|异常高波动掩码]] 等配合，先切出波动事件、再看收益 / 波动比的截面表现。

## 可变异维度

- 收益口径：分钟简单收益 → 对数收益
- 分母：更优波动率 → 其它波动估计
