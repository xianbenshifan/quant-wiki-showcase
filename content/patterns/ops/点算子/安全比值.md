## 金融解释

**做什么**：逐点计算 $\text{num}/\text{den}$，并在分母绝对值小于阈值或非有限时把结果置空。它是所有「占比、单位量、压力」类字段的通用比值算子，把「除以一个可能为零或缺失的数」这件危险操作标准化。

**为什么单列一页**：金融数据里大量构造成对比值——单位量（量 / 时间）、压力（失衡 / 总量）、规模标准化（额 / 市值）。分母趋零（无成交、无挂单、停牌）会产生 Inf / NaN 并沿流水线扩散，污染整个截面。安全比值把「除零守卫」固化为一处约定，使不同实现得到一致口径。

## 算子定义

```
ratio(num, den) = num / den
# |den| < eps 或非有限 -> null
```

## 适用场景

- 任何需要「相对量」的构造：占比、单位量、比率、强度；
- 分母可能为零或缺失的流数据（分时、逐笔）；
- 作为 [[patterns/ops/点算子/归一化失衡|归一化失衡]] 等更具体比值的底层步骤。

## 边界与陷阱

- **阈值 eps 的尺度问题**：绝对阈值对不同量纲的分母不通用（成交额的「近零」与价差的「近零」数量级相差很远），必要时应相对化或改用分位阈值；
- **置空带来样本损失与选择偏差**：分母近零的样本往往正是清淡 / 极端时刻，统一置空等于系统性剔除这些状态；若命题关心清淡时刻，须另作处理；
- **与安全除的关系**：二者语义相同（安全除是同义实现），不应并存两套守卫口径，差异只在命名与调用形式；
- **分子分母口径不匹配**：量 / 额、主动 / 被动等口径混搭会得到无经济含义的比值，须显式对齐语义；
- **非有限传播**：若只在最后守卫而中间步骤已产生 Inf，仍会污染结果，守卫应在每次除法处执行。

## 可变异维度

- 分子 / 分母：任意语义
- 阈值 eps：固定 → 相对 / 分位
