## 金融解释

**衡量什么**：$\text{撤单强度} = (\text{买撤单量} + \text{卖撤单量}) / (\text{买量} + \text{卖量})$，即挂出的委托中最终被撤回的比例。它度量的是**撤单的总强度**，不含方向——比值越高，说明越多挂单被「挂而不成、随即撤回」。

**为什么有信息量**：这是**虚假委托概率**的主成分。挂单不需要成交就能影响盘口的显示供需，因此「撤了多少」直接决定名义盘口里有多少是真实意愿、有多少是虚张声势。撤单强度高，意味着盘口的挂单大量是**意图不坚定的**，名义深度与实际可成交量之间落差大：

- 从**流动性可信度**看：高撤单强度下，依据盘口深度判断承接能力会系统性高估真实流动性；
- 从**信息**看：策略性撤单（幌骗、试探、掩护）会在特定时点推高撤单强度，其变化本身携带交易者意图的信息；
- 从**市场情绪**看：恐慌或亢奋时参与者更易反复挂撤，撤单强度上升，因此它也可作为市场焦虑度的时序度量。

它是**无方向**的总量比率，与撤单失衡（有方向、无量级）正交；两者联合使用才能同时刻画「撤得多不多」与「撤在哪一侧」。

**与相邻字段的区别**：

- [[patterns/fields/成交执行率|成交执行率]]：成交/挂单，是本字段（撤单/挂单）的**互补口径**，两者之和约为 1（忽略部分成交等复杂情形）；
- [[patterns/fields/撤单失衡|撤单失衡]]：度量撤单的**方向**，本字段度量**强度**，二者互补；
- [[patterns/fields/净撤单压力|净撤单压力]]：分母为实际成交量并区分买卖侧，是「相对成交」的方向压力；
- 撤单熵差：度量撤单规模的**分布集中度**，与强度不同。

## 收益来源

本页归属 [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：主要赚**信息不对称**的钱——撤单强度高说明盘口存在大量策略性、不可成交的挂单，做市方或大资金正在用名义供需影响他人判断；能够识别「名义流动性不可信」并据此调整成交预期或反向布局，即是信息优势。同时，撤单强度的变化与流动性可信度关联，间接服务于流动性风险定价。

**对手方**：依据盘口挂单做决策、被虚单误导的投资者；以及在低可信度流动性环境中付出超额冲击成本的流动性需求方。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（策略性委托与逆向选择）。

**失效条件**：

- **撤单普遍化**：当高频做市与算法报价使撤单成为所有标的的常态时，横截面差异被压缩；
- **监管与撤单费**：对频繁撤单的限制会整体压低强度，且改变其结构；
- **改价口径**：若改价被计为撤单，强度会系统性偏高，含义偏移。

## 加工公式

```
撤单强度 = (买撤单量 + 卖撤单量) / (买量 + 卖量)
# 分母挂单总量近零置 null；口径可换为笔数
```

## 可变异维度

- 口径：量 → 笔数
- 分母：挂单量 → 成交

## 适用场景

- **虚拟流动性/市场质量监测**：识别名义盘口可信度低的标的与时段；
- **与撤单失衡配对**：强度定「多少」、失衡定「哪侧」，联合刻画撤单行为；
- **作为流动性因子的条件变量**：撤单强度高时，盘口深度类因子的信号须降权。
