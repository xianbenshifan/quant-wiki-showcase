## 金融解释

**衡量什么**：超大单（Mega，最大规模档）买入笔数与卖出笔数的归一化失衡：$\text{mega\_net\_num} = \dfrac{\text{MegaBuyNum} - \text{MegaSellNum}}{\text{MegaBuyNum} + \text{MegaSellNum}}$，取值落在 $[-1,1]$。正值表示超大单以买入笔数为主。

**为什么有信息量**：它度量**最大规模资金在笔数维度上的净方向**。选笔数而非金额有两重意义：一是金额口径会被少数巨额单笔主导，笔数口径更能反映大资金的**下单频次与参与广度**；二是超大单本身已把规模门槛提到最高，单笔金额差异相对被压缩，笔数失衡因而更接近「大资金是持续净买还是净卖」的意图度量。超大单是信息优势最可能栖身的规模档，其净方向因此是知情交易与机构行为的直接线索。

**与相邻字段的区别**：

- [[patterns/fields/大单净笔数|大单净笔数]]：规模档降到大单，参与者更广、更偏中大型资金；超大单更稀、更偏机构，信号更集中但样本更少。
- 大单 / 小单净流入：金额口径的资金流，会被极端大单主导；本页是笔数口径，刻画参与方向而非资金体量。
- [[patterns/fields/净主动笔数|净主动笔数]]：不区分规模，度量全部主动成交的方向；本页只看最大规模档，是「大资金方向」的切片。
- [[patterns/fields/超大单买溢价|超大单买溢价]]：度量超大单的**成交价格位置**（激进度），本页度量**笔数净方向**，一价一量。

## 收益来源

本页归属 [[alpha/超大单冲击回补|超大单冲击回补]]

**赚什么钱**：赚**信息不对称**的钱。超大单的买卖笔数净方向反映最大规模资金的意图：持续净买通常意味着机构 / 知情者在建仓，其信息优势会在随后的价格中逐步体现，跟随该方向可获得信息扩散的收益。笔数口径强调持续性（多笔净买）而非单笔脉冲，因而更接近真实的仓位意图。

**对手方**：在超大单净买入中充当卖方、被信息优势方定价的对手；以及反应滞后的跟随者，他们在信息扩散后才交易。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]、[[alpha/知情卖出信号|知情卖出信号]]。

**失效条件**：

- **大单非知情**：指数调仓、被动资金、程序化大单不含私有信息，净方向无预测力；
- **拆单普遍化**：大额委托被拆成中小单，可识别的「超大单」样本减少且偏向特定策略，信号失真；
- **信息快速定价**：市场效率高时，超大单方向刚形成即被套利，超额收益消失。

## 加工公式

```
mega_net_num = ratio(MegaBuyNum - MegaSellNum, MegaBuyNum + MegaSellNum)
# 分母近零置 null
```

## 适用场景

- 作为**大资金方向**的笔数口径度量，与金额口径资金流交叉验证；
- 在高频 / 分钟级捕捉**机构建仓痕迹**：笔数失衡的持续性好于单笔金额；
- 与 [[patterns/fields/超大单买溢价|超大单买溢价]] 组合：净买笔数多且买溢价高 = 强意图；
- 与 [[patterns/fields/大单净笔数|大单净笔数]] 对比，观察大资金规模档的迁移（超大单减少、大单增多）。

## 可变异维度

- 口径：笔数 → 量/额
- 规模档：Mega → Mega+Large
