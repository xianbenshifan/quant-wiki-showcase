## 金融解释

**做什么**：在时点截面上做线性 min-max 映射，把原始值压到 $[0,1]$：最小值对应 0、最大值对应 1、中间线性内插。它同时保留**序**与**等距差**，且输出有界。

**为什么单列一页**：很多场景需要的不是排序因子，而是一个 $[0,1]$ 的**乘数 / 权重**——用它去调制另一个因子（信噪比权重、置信度、质量权重）。这类权重要求非负有界且单调，min-max 恰好满足；而 [[patterns/ops/截面算子/截面z得分|z 得分]] 无界、可为负，不能直接当权重。

## 算子定义

```
minmax(x) = (x - min_cs(x)) / (max_cs(x) - min_cs(x))
# 逐截面；max = min（截面同值）时整列置空或置 0.5（需全库统一）
```

## 适用场景

- **作为乘法权重调制另一因子**：$f_{\text{new}} = f \times w$，其中 $w \in [0,1]$；
- **需要保留相对距离的有界归一化**：输入有明确上下界含义时；
- **稳健化候选**：先分位截断再 min-max，抑制端点被单点主导；
- **组合权重构造**：把打分转成非负权重后按权重加权合成。

## 边界与陷阱

- **完全被两个端点决定**：最小 / 最大各由一个样本决定，一只错价或极端股即可压缩其余所有股票，稳健性远差于 [[patterns/ops/截面算子/截面排名|rank]]；实务上应先缩尾或分位截断再归一；
- **退化解**：截面 max = min（几乎全部同值）时分母为零，须约定置空或中性值，且跨期口径一致；
- **跨期不可比**：输出是当期相对量，今天的 1 与昨天的 1 代表不同绝对水平，不能直接跨期比较或做时序统计；
- **与 z、rank 的分工**：min-max 有界、保距、不抗离群；z 无界、保距、不抗离群；rank 有界、抗离群、丢距离。按「权重是否需要非负有界」「离群是否可信」在三者中选择。

## 可变异维度

- 稳健化：min / max → 分位截断后再 min / max
- 区间：[0,1] → [-1,1] 对称映射
- 对象：任意列
