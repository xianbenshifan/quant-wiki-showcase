## 金融解释

**做什么**：取 $|x|$，把带方向的量转成非负的**强度**。

**为什么单列一页**：很多金融命题关心的是「多大」而非「哪边」——波动、冲击、偏离、失衡的强度。绝对值把方向维折叠掉，产出强度信号，是波动率族（$|\text{收益}|$、已实现波动）、冲击强度、失衡程度的基础。它与 [[patterns/ops/点算子/符号|符号]] 配对构成「方向 / 强度」分解。

## 算子定义

```
abs(x) = |x|
```

## 适用场景

- 收益 → 波动强度（$|\text{rtn}|$）；
- 失衡 / 偏离 → 绝对偏离强度；
- 需要在同侧比较极端程度时；
- 作为方向—强度分解中的强度支。

## 边界与陷阱

- **折叠方向带来的混同**：$+5\%$ 与 $-5\%$ 都变成 $5\%$，若两者后续行为不对称（下跌冲击更持久），直接取绝对值会掩盖不对称性，此时应分方向或配符号；
- **非负性影响下游统计**：取绝对值后分布右偏、均值非零，原本对称的标准化（z）与相关口径都会改变；
- **零附近无信息**：与符号类似，$x\approx 0$ 的样本被压到很小，稀疏数据中大量零会堆叠在 0；
- **与平方的关系**：绝对值是一阶幅度，平方更放大极端；波动率估计用哪个取决于对尾部的假设（$|\cdot|$ 更稳健）。

## 可变异维度

- 对象：收益 / 失衡类
- 平方化（square）替代
