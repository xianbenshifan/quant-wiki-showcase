## 金融解释

**衡量什么**：先对成交额做相邻 bar 的一阶差分得到增量，再对增量取对数，且只在增量大于 0 时有效（增量非正时置缺失）。它把成交额增量的**原始量级**转换到**对数刻度**上。

**为什么有信息量**：成交额及其增量是典型的右偏厚尾变量——少数时点的增量可以比常态大一到两个数量级。在线性刻度上，这种厚尾会让极端放量时点主导任何相关性估计（如成交额-收益相关、量价弹性）；取对数后，量的相对变化而非绝对变化被度量，极端值被压缩，相关性估计更稳健。这不是金融机制上的创新，而是一个**统计刻度变换**：它让后续在「量—价」关系上做的回归/相关更接近正态假设。因此本字段的价值在于**作为中间加工步骤**，其信息含量取决于下游如何使用它，而非自身携带方向。

**为什么只对增量 > 0 取对数**：增量为负意味着成交额相对上一 bar 回落，其绝对值可能很大但取对数无定义；同时「放量」（正增量）与「缩量」（负增量）在机制上是不同的状态，混在一起取对数会引入不可解释的填补规则。截断到正增量，等于只保留「量能扩张」这一支，下游若需要缩量信息，应另建负向字段（如对绝对值取对数并标号）而非在同一个字段里混合。

**与相邻字段的区别**：

- [[patterns/fields/成交额增量|成交额增量]]：本字段的输入，线性刻度；本字段是它的对数形态；
- [[patterns/fields/成交量增量|成交量增量]]：量口径的同族字段，与额口径的区别在于是否包含价格成分；
- [[patterns/fields/撤单熵差|撤单熵差]] 等熵类字段：同属非线性压缩，但压缩的是分布集中度而非量级。

## 加工公式

```
成交额增量 = 成交额 − 上一 bar 成交额（回落时取原值，见成交额增量）
对数成交额增量 = ln(成交额增量)   # 仅当增量 > 0，否则 null
```

## 可变异维度

- 底数：自然对数 → 10 为底
- 分支：增量 > 0 → 所有非空

## 适用场景

- **量价相关性建模**：在成交额与收益的回归/相关分析中作为量的对数形态，缓解厚尾对系数的影响；
- **量能扩张事件的幅度刻画**：需要区分「放量幅度」相对倍数而非绝对金额时；
- **跨股可比**：不同市值股票的成交额绝对水平差异巨大，对数形态后再做截面比较更公平。
