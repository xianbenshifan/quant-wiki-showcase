## 金融解释

**衡量什么**：把「单位成交额推动了多少价格」这一比值 $r = \text{绝对收益} / \text{成交额单位量比}$ 再做保号对数压缩：$\operatorname{sign}(r)\cdot\ln(1+|r|)$。分子取绝对收益（不看涨跌方向），分母取当日成交额的相对水平（见 [[patterns/fields/成交额单位量比|成交额单位量比]]），因此它度量的是**价格冲击的价格**——同样的成交额能撬动多大的价格变动。它与 [[patterns/fields/非流动性|非流动性]] 同源，区别只在最后一步做了对数压缩。

**为什么做保号对数**：原始比值的分布高度右偏——绝大多数时点冲击很小，少数冷门时点因分母极小而爆出极端值。直接排序会被这几个极端点主导；$\ln(1+|r|)$ 把长尾压平，同时用符号保留「当期绝对收益的方向」这一层信息。代价是变换后的数值不再等于真实冲击，**只能用于排序与比较，不能用于精确损益测算**。

**为什么有信息量**：价格冲击成本是流动性的核心定价对象。比值高说明市场深度薄，少量资金即可推动价格，这类股票在需要变现时要付出更高的冲击成本，理性投资者会要求更高的预期收益作为补偿。与用价差或深度描述盘口不同，本字段是**事后（realized）**度量——记录的是「已经发生的成交把价格推了多远」，因此更接近真实交易成本，而非报价意图。

**与相邻字段的区别**：

- [[patterns/fields/非流动性|非流动性]]：同公式但**不做对数压缩**，数值接近原始比值、解释更直观，但极端值更主导排序；两者同族，不可在同一因子中混用；
- [[patterns/fields/KyleLambda代理|Kyle Lambda 代理]]：分母是**成交量增量**而非成交额的相对水平，是 Kyle 型「单位成交量冲击」视角；本字段是 Amihud 型「单位成交额冲击」视角；
- [[patterns/fields/冲击斜率代理|冲击斜率代理]]：分母是**订单流失衡**（挂单增量），刻画盘口层面的即时冲击，与本字段的成交口径不同；
- [[patterns/fields/成交额单位量比|成交额单位量比]]：本字段的分母，是中性规格化构件。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]]

**赚什么钱**：赚**流动性溢价**——承担流动性差、价格冲击成本高的股票，获得预期收益补偿。机制链条：非流动性股票的持有者未来卖出时要么等待、要么承受显著的价格折让，这种变现风险与成本要求超额回报；本字段用保号对数把这一成本标准化，便于横截面比较与极值控制。

**对手方**：需要即时成交、主动付出价格冲击成本的急躁交易者；以及在流动性紧张时被迫平仓、无法等待的持仓者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（价差与冲击中的逆向选择成分）。

**失效条件**：

- **流动性危机**：机制反转——冲击成本高的股票在踩踏中跌幅更深，指标方向由正转负；
- **流动性整体宽松**：市场层面流动性充裕时非流动性差异被摊薄，溢价收窄；
- **大市值样本内部**：流动性普遍充裕，比值趋于同质，截面区分度低。

## 加工公式

```
r = ratio(绝对收益, 成交额单位量比)          # 单位成交额推动的价格变动
amihud_proxy = sign(r) * ln(1 + |r|)         # 保号对数压缩
# 分母近零置 null；仅当成交额单位量比 > 0 时有效
```

## 适用场景

- **流动性溢价的横截面暴露**：作为非流动性的可控极值版本，排序更稳健；
- **事件 / 短窗口研究**：对数压缩后短窗口噪声不易主导结果；
- **与其他冲击类字段联合**：与 Kyle Lambda 代理、冲击斜率代理同向时信号更可信。

## 可变异维度

- 对数：signed-log → 原始比值
- 分子：绝对收益 → 收盘收益
