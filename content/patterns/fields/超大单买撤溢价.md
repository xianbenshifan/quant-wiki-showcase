## 金融解释

**衡量什么**：先算被撤超大单买单的委托均价 $= \text{超大单买撤额}/\text{超大单买撤量}$，再与全市场 VWAP（$\text{成交额}/\text{成交量}$）比较，取相对溢价并做 signed-log：$\text{sgn}(x)\cdot\ln(1+|x|)$，其中 $x = \text{委托均价}/\text{VWAP} - 1$。正值表示被撤的大额买单报价**高于**市场均价。

**为什么有信息量**：撤单本身携带意图，而「被撤订单报价在什么位置」进一步区分了撤单的性质。一笔报价显著高于 VWAP 的超大买单被撤掉，往往意味着该委托并非真心求成交——它挂在偏离市场的位置，可能是为了制造买盘汹涌的假象（幌骗 / 分层挂单），也可能是大额资金在测试市场深度后迅速收手。反之，报价接近或低于 VWAP 的撤单更像是真实的报价调整。因此这个溢价度量的是**大额买委托的报价激进度**，是订单流毒性 / 操纵痕迹的一个切面。

**与相邻字段的区别**：

- [[patterns/fields/超大单买溢价|超大单买溢价]]：用**实际成交**的超大单买入均价对 VWAP 取溢价，度量的是「愿意为成交付多高的价」（真实需求强度）；本页用**被撤**委托的报价，度量的是「挂在什么位置又收回」（意图真伪）。二者一实一虚，常配合使用。
- [[patterns/fields/超大单卖撤溢价|超大单卖撤溢价]]：卖侧的镜像字段，衡量被撤大额卖委托的报价位置；买卖两侧同时极端，可能指向双边幌骗。
- [[patterns/fields/大单买撤溢价|大单买撤溢价]]：规模档从超大单降到大单，语义同构；超大单更偏机构 / 大资金，大单更偏中大型资金。
- [[patterns/fields/撤单失衡|撤单失衡]]：只看撤单**数量**方向；本字段看撤单**报价位置**，是价格维度的补充。

## 收益来源

本页归属 [[alpha/超大单冲击回补|超大单冲击回补]]

**赚什么钱**：赚**信息不对称**的钱。被撤大额买委托的报价位置暴露了订单流的意图结构：异常高频的远端撤单更像幌骗，会对跟随者形成误导性深度信号。识别这类痕迹，等于识别「盘口上哪些买盘是虚的」，从而避免被虚假需求诱导、并可在虚假支撑撤去后捕捉价格回落。本质上是在交易**订单流毒性 / 盘口真伪**这一信息维度。

**对手方**：被幌骗挂单误导、以为存在强买盘而追入的交易者；以及无法区分真实与虚假挂单、按可见深度决策的被动方。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]、[[alpha/大小单博弈|大小单博弈]]。

**失效条件**：

- **撤单为正常报价调整**：市场波动大时大额委托频繁改价，远端撤单不再标记操纵，溢价失去信息；
- **算法分层挂单普遍化**：若所有参与者都使用分层 / 幌骗式挂单，该度量失去区分度；
- **监管结构变化**：针对虚假申报的监管收紧会使幌骗行为减少，溢价的信息含量下降。

## 加工公式

```
vwap = ratio(成交额, 成交量)                        # 全市场 VWAP
x    = ratio(超大单买撤额, 超大单买撤量) / vwap - 1  # 委托均价相对 VWAP 的溢价
prem = sign(x) * ln(1 + |x|)                        # signed-log 压缩
# 撤量或成交量近零置 null
```

## 适用场景

- 作为**盘口真伪 / 订单流毒性**的特征，配合实际成交溢价判断买盘虚实；
- 用于研究**幌骗与虚假申报**的痕迹，或在微观结构因子里作为操纵代理；
- 与卖侧镜像、不同规模档（大单 / 超大单）共同构成撤单报价位置的完整画像；
- 需要**逐笔委托数据**（含撤单报价与量额）才能构造；仅有成交数据时不可用。
