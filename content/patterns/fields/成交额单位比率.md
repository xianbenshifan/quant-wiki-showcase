## 金融解释

**衡量什么**：把成交额**增量**（逐 bar 还原后的真实增量）除以**当日成交额的最大值**，得到一个 $[0,1]$ 区间内的相对量能。它回答的是「当前 bar 的量能达到了当日最强时点的百分之几」，而不是「成交了多少钱」。

**为什么有信息量**：绝对成交额在不同股票、不同日期之间不可直接比较——大盘股天然成交额高，活跃日天然胜过清淡日。除以**当日峰值**是一种**自归一化**：它把每只股票每天的成交额都映射到「相对自身当日最强水平」的刻度上，从而剥离了规模与日历效应，只保留**量能的时序形态**。当单位比率接近 1 时，说明当前时点的量能接近当日峰值，是**放量事件**；接近 0 则是缩量。由于投资者注意力与成交量高度相关（「量是注意力的影子」），放量事件往往对应关注度集中、信息扩散与情绪升温，因此本字段可作为**注意力/事件**的时序代理。它也是许多量价因子的标准做比（如非流动性、超额量比）的分母。

**与相邻字段的区别**：

- [[patterns/fields/成交额增量|成交额增量]]：本字段的分子，绝对量级；单位比率把它除以当日峰值，得到相对强度；
- [[patterns/fields/成交额单位量比|成交额单位量比]]：同一构想的 LOB 侧实现，差异仅在分母与实现路径，数值口径不可直接互换；
- [[patterns/fields/成交额占比|成交额占比]]：除以**全市场同期成交额**（横截面归一），本字段除以**自身当日峰值**（时序归一），分别对应「相对市场」与「相对自身」两种强度；
- [[patterns/fields/超额成交额单位比率|超额成交额单位比率]]：在本字段基础上再做截面超额，去掉市场共同量能。

> 说明：本字段为**中性规格化构件**——它把量能映射到「相对自身当日峰值」的刻度，本身不携带方向；注意力量级的收益含义取决于它所参与的具体因子（见 [[concepts/行为金融凸显理论|行为金融凸显理论]]、[[alpha/活跃度条件反转|活跃度条件反转]]），故本页不标 `return_source`。

## 加工公式

```
单位比率 = 成交额增量 / 当日成交额峰值
# 成交额增量为逐 bar 差分还原；当日峰值按合约与交易日求 max；分母近零置 null
```

## 可变异维度

- 分母：当日峰值 → 滚动均值
- 口径：额 → 量
- 命名来源：不同来源对该字段的别名一律记入 aliases，不另立页

## 适用场景

- **放量事件的时序识别**：作为量能相对强度的标准化刻度，触发量价事件研究；
- **作为量价因子的做比分母**：非流动性、超额量比等字段的规格化分母；
- **跨股可比的活跃度度量**：自归一化后可在截面内比较不同规模股票的量能形态。
