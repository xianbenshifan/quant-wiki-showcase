## 金融解释

**做什么**：以**市场振幅**为切点切分状态。振幅定义为 $\text{ampl} = \text{high}/\text{low} - 1$，先在每个时点取全市场振幅的**中位数**，再对其时间序列做 pct 排名；排名靠前为高振幅日、靠后为低振幅日。

**为什么用振幅而不是已实现波动率**：振幅只用当日最高价与最低价，是**单日极差**口径，计算简单、对日内路径不敏感，天然捕捉「日内的摆动幅度」。已实现波动率需要日内高频收益，刻画的是**波动强度**；两者相关但不等价——振幅反映「价格被推动的范围」，波动率反映「价格变动的密集程度」。振幅掩码因此常作为「分歧 / 情绪摆动」的粗粒度代理。

**为什么有信息量**：振幅放大意味着多空分歧加剧、情绪摆动剧烈——日内既有强推升又有强打压。高振幅环境通常是**风险定价最剧烈、注意力最集中**的状态；低振幅则是缩量整理、分歧收敛的状态。把两个环境分开，才能判断因子的表现是否依赖波动环境。

## 掩码条件

```
data: 价格语义 → fields: 振幅序列 → mask: 振幅掩码 → aggregate
```

- 振幅是**截面排名**（当日市场振幅分位），不是合约内；
- 计算链路：$\text{ampl} = \text{high}/\text{low} - 1$ → 市场截面中位数 → 滚动 pct 排名 → 按高 / 低分位判定（默认 0.8 / 0.2）；
- 广播到全矩阵后按非空振幅掩码，得到 high_ampl / low_ampl；
- high_ampl 与 up_trend 可叠加（高波动 + 上涨）。

## 收益来源

本页归属 [[alpha/连续波动补偿|连续波动补偿]] [[alpha/可知性分流定价|可知性分流定价]]

**它服务于哪些赚钱逻辑**：主要服务于**波动与尾部风险溢价**——高振幅状态对应风险与不确定性抬升，是风险补偿最集中的样本；同时振幅是尾部风险（日内大幅摆动）的直接刻画。次要服务于**行为偏差**——高振幅往往伴随情绪分歧与过度反应，是凸显效应、羊群与恐慌 / 亢奋最活跃的环境，价格偏离随后可能被修正。

**对手方**：在高振幅情绪摆动中追涨杀跌的交易者；为剧烈波动被动提供流动性的一方。

**理论支撑**：[[concepts/特异波动异象|特异波动异象]]、[[concepts/行为金融凸显理论|行为金融凸显理论]]。

**失效条件**：
- **高振幅由单一确定事件驱动**：如财报公布，摆动是信息重估而非情绪，风险溢价假设减弱；
- **振幅与风险补偿关系反转**：在流动性危机中高振幅对应被迫抛售，补偿机制失效；
- **制度性涨跌停压缩振幅**：涨跌停制度会人为限制 $\text{high}/\text{low}$ 之差，使振幅掩码在极端行情下失真。

## 适用场景

- **波动环境对比**：把因子在高 / 低振幅日分组评估，判断波动环境依赖性；
- **风险状态切片**：高振幅日作为「风险事件窗口」；
- **情绪代理**：高振幅作为市场情绪摆动的粗代理；
- 与 [[patterns/mask/趋势掩码|趋势掩码]] 叠加可同时控制「方向 × 波动」两个环境维度。

## 边界与陷阱

- **振幅只用最高 / 最低价（计算层）**：它不含日内路径信息，两个日内路径完全不同的交易日可能有相同振幅；需要路径信息时应改用已实现波动率；
- **最高 / 最低价的撮合噪声（数据层）**：极值价可能来自单笔异常成交或集合竞价，会把振幅人为抬高，稳健做法是用分位化极值或剔除首末 bar；
- **市场基准的选择（概念层）**：用等权中位数还是指数，会改变高 / 低振幅日的划分；
- **与趋势掩码混淆（概念层）**：振幅刻画**分歧幅度**、不指方向；高振幅日既可能大涨也可能大跌。

## 可变异维度

- 阈值：0.8 / 0.2 → 0.9 / 0.1
- 振幅口径：$\text{high}/\text{low}$ → $(\text{high}-\text{low})/\text{preclose}$
- 聚合：市场 median → 等权 mean
- 窗口：单日 → 多日滚动
