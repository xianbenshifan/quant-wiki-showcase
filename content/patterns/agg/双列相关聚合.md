## 金融解释

**做什么**：在窗口内对两列序列 $x,y$ 求相关系数——把它看作协方差的标准化版本，剔除两列各自的波动幅度，只留下**线性联动的方向与强弱**。取值在 $[-1,1]$ 内，无量纲，因此可以跨股比较。

**为什么有信息量**：量价配合、资金流与收益的同步、两个资产是否同涨同跌，都可以归结为「两列是否同步」。相关系数把这些命题压缩成一个可直接排序的数。秩相关（Spearman）度量的是**单调联动**，不要求线性，且对极端值稳健，是厚尾数据（资金流、高频收益）上的常用变体。

**与协方差的分工**：相关看「一起动的程度」，协方差看「一起动的规模」。要跨股比较用相关；要保留金额 / 暴露的绝对规模用 [[patterns/agg/协方差聚合|协方差聚合]]。

## 聚合方式

```
corr(x, y, window, mask=None)
# 可取 Pearson；秩相关为 RankCorr / Spearman
```

语义：窗口内两列配对样本的相关系数，缩减为每合约一个标量；可选掩码限定状态子集。

## 适用场景

- **跨股 / 跨期比较**：需要无量纲的联动强弱排序时；
- **量价配合**：成交量 / 成交额与收益的相关，刻画放量是推动还是承接；
- **资金流同步**：资金流与收益、资金流与价格的联动（见 [[paradigms/资金流秩相关|资金流秩相关]]）；
- **秩相关场景**：厚尾、含极端值、或关系单调但非线性的数据，用 Spearman 而非 Pearson。

## 边界与陷阱

- **Pearson 只测线性**：真实关系若是单调但非线性（如 U 形、饱和形），Pearson 会低估甚至给零，应改用秩相关；
- **极端值主导**：Pearson 对离群配对样本敏感，少数样本即可拉偏相关；
- **短窗口相关极不稳**：相关系数的估计方差随窗口缩短迅速上升，短窗口下的高低波动多属噪声；
- **跨 regime 混合**：滚动窗口跨越市场状态切换时，得到的是两段关系的平均，含义不清；
- **相关不等于因果 / 领先滞后**：同步相关不区分谁驱动谁，也不含时滞信息；需要方向时须用领先—滞后相关或回归；
- **常量序列未定义**：任一列方差为 0 时相关系数无定义，须置空处理。

## 可变异维度

- 窗口：可调
- 对象：任意数值对
- 相关类型：Pearson ↔ Spearman / RankCorr
- 形态：窗口标量相关 ↔ 滚动相关（逐点版）
