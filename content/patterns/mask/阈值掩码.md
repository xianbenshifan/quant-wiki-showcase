## 金融解释

**做什么**：以**绝对数值阈值**为切点，对序列做布尔状态掩码——值落在阈值一侧为真、其余为 NaN（不选中）。

**为什么需要绝对阈值（而不是分位）**：分位掩码的切点随分布漂移，优点是跨期可比，但它**无法表达绝对水平**。有些命题本身就带经济意义上的绝对门槛：波动率是否超过某水平、成交量是否低于「无法支撑交易成本」的门槛。此时若用分位近似，会随市场整体水平漂移而失真。阈值掩码正是为此存在——它表达「是否跨过某个客观门槛」。

**为什么有信息量**：阈值切出的状态常对应明确的制度或经济含义——高波动（风险 / 尾部）、低流动性（交易成本上升、定价低效）、极端成交（注意力事件）。把这些状态切出来单独统计，是 risk / regime 类因子的基础。

同一阈值机制可参数化为两种**判定方向**（见「掩码条件」），金融语义对称：

- **上界**（值 > 阈值）：识别高于门槛的状态，如异常高波动、高活跃；
- **下界**（值 < 阈值）：识别低于门槛的状态，如清淡、低流动。

## 掩码条件

以阈值 `value` 为切点，两种判定方向：

```
data: rtn → mask: 阈值掩码(value, direction) → agg: mean
```

| 方向 | 判定 | 语义 |
|------|------|------|
| 上界 | `x > value`（可含 `≥`） | 高于门槛（`gt` / `ge`） |
| 下界 | `x < value`（可含 `≤`） | 低于门槛（`lt` / `le`） |

阈值可由固定值或滚动参照给出（如过去 $n$ 日均值、均值 $\pm k$ 倍标准差），方向与阈值组合覆盖单侧数值掩码。


## 适用场景

- **绝对门槛命题**：涨跌停附近、成交额低于某水平、波动率超过年化某阈值；
- **制度 / 约束刻画**：需要表达客观制度门槛（如 ST 判定、指数纳入的流动性门槛）时；
- **滚动参照门槛**：阈值取「过去 $n$ 日均值 $\pm k\sigma$」时，兼具阈值与经济基准（见 [[patterns/mask/异常高波动掩码|异常高波动掩码]]）；
- 跨期较短、水平相对稳定的池子更适合固定阈值。

## 边界与陷阱

- **阈值随股价 / 市值漂移（数据层）**：绝对金额阈值（如成交额 > 1 亿）对不同规模股票含义不同，跨股票不可比；应优先用相对口径（占当日总成交额比例）；
- **与分位掩码的选择（概念层）**：阈值表达绝对水平、分位表达相对位置；市场水平漂移剧烈时固定阈值会失真，须与命题匹配；
- **边界样本抖动（计算层）**：恰好落在阈值附近的样本状态对噪声敏感，若结果对阈值微小扰动敏感，说明信号来自边界噪声；
- **停牌 / 缺失（数据层）**：缺失值若被当作低于 / 高于阈值参与判定，会系统性偏移样本，须先显式剔除。

## 可变异维度

- 方向：gt / ge / lt / le
- 阈值：value → 可调（固定值 / 滚动均值 / 均值 $\pm k\cdot$std）
- 应用序列：波动率 / 成交量 / 收益 / 流动性
