## 金融解释

**衡量什么**：$IntradayRet_{i,t} = Close_{i,t}/Open_{i,t} - 1$，只保留开盘到收盘的路径，把隔夜跳空完全剔除。

**为什么有信息量**：日内与隔夜是两段定价机制相反的时段。隔夜段由被动信息积累、开盘集合竞价与情绪锚定主导，传统上呈**弱动量**；日内段由连续交易与做市流动性驱动，传统上呈**反转**——早盘的过度反应在午后被修正，且与隔夜收益显著负相关。把日内收益单独抽出，等于把「连续交易时段的价格发现」与「隔夜信息冲击」解耦，从而能分别检验两套机制（见 [[concepts/隔夜与日内收益拔河|隔夜与日内收益拔河]]）。

**为什么与关注度有关**：日内反转的强度随投资者注意力与情绪而变。高关注、高情绪标的中，日内追涨杀跌更剧烈，过度反应更明显，反转空间更大；注意力分散时反转减弱。因此日内收益既是反转来源，也是注意力/情绪状态的载体。

**与相邻字段的区别**：

- [[patterns/fields/隔夜收益|隔夜收益]]：$Open_t/Close_{t-1}-1$，两段在时间上互补、机制上相反，方向性预测往往反号；
- [[patterns/fields/收益率|收益率]]：全日收益 = 隔夜 × 日内（对数下可加），是把两段混在一起的复合口径；
- 中间价收益：锚点换成中间价，剔除收盘瞬时价差跳动。

## 收益来源

本页归属 [[alpha/日内路径反转|日内路径反转]]

**赚什么钱**：其一为**反转**——日内早盘情绪化交易把价格推离基本面，午后修正，日内收益的横截面外推因此带有反转属性；其二为**注意力与情绪**——日内路径本身就是关注度驱动的追涨杀跌的产物，情绪越极端、注意力越集中，日内定价偏离与随后的回归越明显。

**对手方**：日内被情绪吸引、在偏离高点追入 / 低点割肉的交易者；以及为这些非理性成交提供对手盘的理性方。

**理论支撑**：[[concepts/隔夜与日内收益拔河|隔夜与日内收益拔河]]、[[concepts/开盘心理锚定|开盘心理锚定]]、[[alpha/量激增注意力|量激增注意力]]。

**失效条件**：

- **日内呈现动量而非反转**：在趋势强、信息持续扩散的市场状态下，日内收益可能延续而非回归，反转逻辑失效；
- **注意力机制被抑制**：低关注、低换手标的中情绪交易稀少，日内收益接近噪声；
- **开盘价失真**：开盘集合竞价受大额委托或制度因素影响时，日内收益的起点锚不可靠，机制链条断裂。

## 加工公式

```
IntradayRet = Close / Open - 1
# 对数口径：ln(Close / Open)
```

## 派生形态

- **日内收益率因子**：日度日内收益直接作因子，周/月可区间求和 → [[paradigms/日内收益率|日内收益率]]。
- **可知性修正**：低波动时翻转符号 → [[paradigms/修正的日内反转|修正的日内反转]]。

## 适用场景

- 需要**剔除隔夜信息、单独研究连续交易时段定价**时；
- 构造日内反转 / 修正反转因子，或在周 / 月频率上对日内收益做区间求和以放大信号；
- 与 [[patterns/fields/隔夜收益|隔夜收益]] 配对做正交分解，研究两段定价的相对强弱；
- 在高换手、高关注、散户占比高的标的上区分度更高。

## 可变异维度

- 口径：简单 ↔ 对数
- 锚点：开盘价 ↔ 早盘某时刻（黄金分割）
- 聚合窗：日 → 周/月求和
