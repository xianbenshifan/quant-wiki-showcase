## 金融解释

**衡量什么**：对第 3、4、5 档分别计算归一化订单流增量 $\text{ofi}_i = \Delta BV_i - \Delta SV_i$（除以 $BV_i + SV_i$，经 1% 时序缩尾），再等权平均：$\text{mlofi\_deep} = (\text{ofi}_3 + \text{ofi}_4 + \text{ofi}_5)/3$。

**为什么有信息量**：深档挂单不参与即时撮合，却是**大宗承接与流动性缓冲**的主要来源。深档 OFI 度量的是盘口深处供需结构的边际变化：买侧深档净增说明有耐心的资金在下移价位布防 / 承接，卖侧深档净增则相反。与浅档相比，深档变化更慢、更少受单笔成交与做市噪声干扰，因而是**中期供需结构**的更稳信号。它也与流动性缓冲的厚薄直接相关：深档被抽空时，一旦最优档被击穿，价格将缺少缓冲而快速滑落。

**与相邻字段的区别**：

- [[patterns/fields/浅档订单流失衡|浅档订单流失衡]]：取 1–2 档，对短时冲击敏感、变化快、噪声大；深档取 3–5 档，变化慢、偏中期，二者常呈「浅档先动、深档跟随」的传导关系。
- [[patterns/fields/订单流失衡|订单流失衡]]：五档按距离加权（近档权重大），是浅档与深档的加权折中；深档版本刻意关掉近档影响，突出盘口深处。
- [[patterns/fields/总深度|总深度]]：存量水平；深档 OFI 是分布在中深处的增量方向，一个看厚度、一个看流向。
- [[patterns/fields/斜率失衡|斜率失衡]]：从价格—深度梯度刻画形状，深档 OFI 从挂单增量的方向刻画流向。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：其一为**流动性溢价**——深档是承接大额卖压 / 买压的缓冲，深档被抽空意味着未来冲击成本上升，为剩余流动性提供者创造补偿；其二为**信息不对称**——有耐心的知情或大额资金常在深档布防以隐藏意图，深档 OFI 的方向是其建仓 / 减仓的早期痕迹。

**对手方**：在深档以挂单被动成交、被大额主动单吃穿的流动性提供者；以及忽视深档结构、在缓冲被抽空后仍按浅档信号交易的滞后参与者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **深档信号过慢**：信息若在浅档已被快速定价，深档 OFI 的滞后确认不再提供增量收益；
- **隐藏单与场外流动性**：深档可见挂单不代表真实缓冲，冰山单使深档 OFI 系统性低估真实供需；
- **制度性挂单**：大宗交易、指数调仓等在深档留下与信息无关的大额挂撤痕迹，方向含义被污染。

## 加工公式

```
ofi_i = ts_winsorize( ratio(ΔBV_i - ΔSV_i, BV_i + SV_i), 1% )   # i = 3, 4, 5
mlofi_deep = (ofi_3 + ofi_4 + ofi_5) / 3
# 分母近零置 null；Δ 为相对上一期的差分
```

## 适用场景

- 需要**中期、稳健**的挂单流向信号时：深档噪声低，适合日频或较长聚合窗口；
- 用于**大宗承接能力**研究：深档净增 / 净减与随后的大额成交、价格滑点相关；
- 与 [[patterns/fields/浅档订单流失衡|浅档订单流失衡]] 配对，构建「浅档—深档」传导与背离信号；
- 在**流动性分层明显**的标的上（大盘股深档厚、小盘股深档稀）区分度更高。

## 可变异维度

- 档位：3-5 → 4-10 档
- 权重：等权 → 深度加权
