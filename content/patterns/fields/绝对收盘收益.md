## 金融解释

**衡量什么**：收盘口径收益率的绝对值 $\text{abs\_close\_rtn} = |\text{close\_rtn}|$，即收盘价相对上期的绝对变动强度。

**为什么有信息量**：它是 [[patterns/fields/绝对收益|绝对收益]] 在**收盘锚点**上的具体口径，专门服务于需要「当日价格变动幅度」的场景。最典型的用途是作为 Amihud 型非流动性指标的分子：单位成交额能推动多大的收盘价格变动，比值越大说明流动性越差。用收盘收益而非全天最高最低，是因为收盘价是当日最具代表性、可执行性最强的价格锚点；用绝对值则是因为流动性冲击的成本与方向无关——涨出来和跌出来的价格变动同样消耗流动性。

**与相邻字段的区别**：

- [[patterns/fields/绝对收益|绝对收益]]：更一般、可锚定任意时段 / 价格的幅度构件；本页固定用收盘口径，语义更窄但也更明确。
- [[patterns/fields/收盘收益|收盘收益]]：保留方向，用于动量 / 反转；绝对收盘收益丢弃方向，只用于波动 / 冲击 / 非流动性。
- [[patterns/fields/非流动性|非流动性]]：把本字段作为分子、单位成交额作为分母后的比值；本页是它的组成原料，不含量纲归一。
- 振幅：用最高最低价之差衡量日内波动，包含路径信息；绝对收盘收益只看端点，更干净但也更粗。

## 加工公式

```
close_rtn     = signed_log(close_t / close_{t-1} - 1)   # 两期价格均 > 0
abs_close_rtn = |close_rtn|
```

## 适用场景

- 作为 Amihud / 非流动性类因子的**分子**，与成交额单位量比或成交额配合；
- 作为**波动强度的逐期原料**，再经聚合构造已实现波动；
- 作为**收盘口径的事件幅度**，筛出收盘有大变动的样本；
- 需要方向时改用 [[patterns/fields/收盘收益|收盘收益]]，不要用绝对值代替。

## 可变异维度

- 口径：收盘 → 中间价/全部
- transform：可去对数
