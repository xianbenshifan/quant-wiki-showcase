## 金融解释

**做什么**：$\operatorname{sign}(x)\cdot\log(1+|x|)$——先取符号，对幅度做对数压缩，再把符号乘回。结果是**保符号、压量级**的非线性变换。

**为什么单列一页**：失衡、溢价、超额、偏离等字段可正可负，直接用 [[patterns/ops/点算子/对数压缩|对数压缩]] 会丢定义域（负值无效）。带符号对数在保留方向信息的同时压缩幅度，使正负两侧的大值都不会主导下游统计，是这类「有方向的强度量」的标准压缩。

## 算子定义

```
log_signed(x) = sign(x) * ln(1 + |x|)
```

## 适用场景

- 可正可负的失衡 / 溢价 / 偏离类字段；
- 需要保留方向、同时抑制极端幅度的合成 / 回归；
- 与 [[patterns/ops/点算子/符号|符号]]、[[patterns/ops/点算子/绝对值|绝对值]] 配套，做方向—强度分解后再压缩。

## 边界与陷阱

- **在零点不可导**：$\operatorname{sign}$ 在 0 处跳变，$x\approx 0$ 的样本对微小扰动敏感，可能造成伪符号翻转；
- **间距被改变**：变换虽仍单调，但压缩量随幅度递增——大值之间的间距被压得远小于小值，若命题关心绝对幅度排序，间距变化会影响线性合成；
- **与绝对值的分工**：绝对值给出强度并丢弃方向，带符号对数既保方向又压幅度；只有下游需要方向时才用后者；
- **零附近尺度**：当 $|x|<1$ 时 $|\log(1+|x|)| < |x|$，会缩小小值差异；若信号主要集中在小值区，压缩可能损失分辨率。

## 可变异维度

- 对象：可正可负字段
- 压缩函数：$\operatorname{sign}(x)\log(1+|x|)$ → $\tanh$ 等有界函数
