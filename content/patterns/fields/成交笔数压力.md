## 金融解释

**衡量什么**：主动买入的成交笔数减去主动卖出的成交笔数，再以两者之和归一化，得到 $[-1,1]$ 区间内的方向指标。正值表示以**笔数**计的主动成交中买方占优，负值表示卖方占优。

**为什么有信息量**：它用**成交笔数**而非成交量或成交额度量「交易方向的净压力」，刻画的是**下单次数**层面的进攻方向。笔数口径的独特之处在于它近似**参与次数**：一笔大额成交与一笔小额成交在量额上差距悬殊，但在笔数上各计一次。因此笔数压力更接近「有多少次交易是以主动买完成的」，对「多数交易者的方向」更敏感，而量额压力更容易被少数大单主导。在散户参与度高的标的上，笔数压力往往比量额压力更早反映方向的转变；在机构主导的标的上，则可能因拆单而失真。它本身是一个**方向性**字段，但方向的经济含义（延续还是反转）依赖下游如何聚合与使用。

**与相邻字段的区别**：

- [[patterns/fields/净主动成交量|净主动成交量]] / [[patterns/fields/净主动成交额|净主动成交额]]：量、额口径的主动方向失衡，与本字段同构但量纲不同；
- [[patterns/fields/大单净笔数|大单净笔数]] 族：只看大额档的笔数方向，本字段覆盖全部主动成交笔数、不分档；
- [[patterns/fields/成交量增量|成交量增量]]：度量量的**时序变化**，不含买卖方向，维度不同；
- [[patterns/fields/成交执行率|成交执行率]]：度量成交占挂单的比例，是**质量**维度而非方向。

## 加工公式

```
成交笔数压力 = 归一化失衡(主动买笔数, 主动卖笔数)
             = (主动买笔数 − 主动卖笔数) / (主动买笔数 + 主动卖笔数)
# 分母近零置 null
```

## 可变异维度

- 口径：笔数 → 量
- 来源：成交 → 挂单

## 适用场景

- **短周期方向度量**：在分钟—日频上，笔数口径对高频交易者的方向更敏感；
- **散户主导标的**：这类标的笔数压力更能代表多数参与者的方向；
- **与量额口径交叉验证**：三口径同号时方向信号更稳，异号提示大单与散户口径分歧。
