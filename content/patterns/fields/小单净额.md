## 金融解释

**衡量什么**：以**成交额**度量小单人群的净方向，并归一化到 $[-1,1]$。一种常见实现是先算小单买额在小单买+卖额中的占比，再作 $2s-1$ 的去中心化映射，使 0 表示买卖均衡、+1 表示全部为买。它回答的是「散户投入的**资金**在买还是卖」。

**为什么有信息量**：金额口径与量、笔数口径的关键区别在于**权重**：它让小资金中的大额散户获得更高权重。散户群体内部也有分层，大额散户（如几十万级的活跃账户）的行为更接近准专业资金，而真正的「大众」是小额账户。因此小单净额既反映散户情绪，也部分混入高净值散户的方向判断，其信息含量介于「纯情绪」与「机构方向」之间。在建模时，若研究目标是纯粹的大众情绪，量或笔数口径更纯；若关注散户资金流入的规模效应，额口径更直接。

**与相邻字段的区别**：

- [[patterns/fields/小单净流入|小单净流入]]：量口径，对小额账户与高频下单更敏感；
- [[patterns/fields/小单净笔数|小单净笔数]]：笔数口径，度量「多少人参与」；
- [[patterns/fields/大单净流入|大单净流入]]：大额人群的额/量方向，与两者之差构成背离；
- [[patterns/fields/成交额占比|成交额占比]]：个股成交额的市场份额，度量绝对活跃度而非方向，维度不同。

## 收益来源

本页归属 [[alpha/量激增注意力|量激增注意力]]

**赚什么钱**：主要赚**注意力**的钱——散户资金净流入是关注度驱动的买入痕迹，其规模效应把价格推离基本面，随注意力衰减回归；次要赚**行为偏差**的钱——散户资金追涨杀跌、在情绪高点集中投入，为反向交易提供对手盘。

**对手方**：在情绪高点投入资金的散户；以及被散户资金推高价格后接盘的后来者。

**理论支撑**：[[alpha/大小单博弈|大小单博弈]]；[[concepts/行为金融凸显理论|行为金融凸显理论]]。

**失效条件**：

- **小单口径被机构污染**：小额算法委托会改变额口径的散户含义；
- **散户结构机构化**：直接参与度下降后，散户资金流向的信息含量下降；
- **系统性资金流冲击**：全市场性申购/赎回会同时改变所有股票的小单净额，截面区分度被摊薄。

## 加工公式

```
小单买额 = max(主动买额 − 超大单/大单/中单买额之和, 0)
小单卖额 = max(主动卖额 − 超大单/大单/中单卖额之和, 0)
小单买额占比 = 小单买额 / (小单买额 + 小单卖额)
小单净额 = 小单买额占比 × 2 − 1            # 去中心化到 [−1, 1]
# 分母近零置 null；剩余法负值截断为 0
```

## 可变异维度

- 口径：额 → 量
- 归一化：占比·2−1 → 直接失衡

## 适用场景

- **关注散户资金规模效应**：在需要衡量「散户投入了多少钱」的场景，额口径比笔数更直接；
- **作为情绪因子的权重**：散户资金净流入活跃的标的上，情绪与反转因子区分度更高；
- **与量、笔数口径做三角验证**：三者同号时信号最稳。
