## 金融解释

**衡量什么**：买入侧成交笔数中，被划入小额档（通常用「总量减去超大单/大单/中单」的**剩余法**定义）的那些笔数所占的比例。它回答「买单是由大量小额委托构成，还是由少数大额委托构成」。

**为什么有信息量**：小单买笔占比是**散户参与买入强度**的一个直接代理。散户下单的特征是金额小、笔数多，因此当该占比高时，说明买入侧的主体是大量分散的小额资金——这通常对应情绪性、关注度驱动的买入；占比低则说明买入集中在机构/大额账户，是更有组织的行为。它本身不含买卖净方向（只统计买单侧），但作为**人群结构的度量**，能帮助判断其他方向性因子作用的「土壤」：在散户占比高的股票上，情绪类、反转类因子的区分度通常更强，而信息类因子的信噪比可能更低。

**与相邻字段的区别**：

- [[patterns/fields/大单买笔占比|大单买笔占比]]：直接度量买入侧大额档的笔数占比，与本字段互补（小单占比 ≈ 1 − 大/中单占比，但取决于剩余法口径）；
- [[patterns/fields/小单卖笔占比|小单卖笔占比]]：卖出侧对应物，两者之差可粗略反映散户在买卖两侧的参与不对称；
- [[patterns/fields/个人投资者交易比|个人投资者交易比]]：同样代理散户参与，但用**成交金额阈值**（小额金额占比）而非笔数档位，二者衡量的是散户活动的不同侧面；
- [[patterns/fields/小单净流入|小单净流入]]：给出小单的**方向**，本字段只给**份额**，是正交维度。

## 加工公式

```
小单买笔数 = max(买笔数 − 超大单买笔数 − 大单买笔数 − 中单买笔数, 0)
小单买笔占比 = 小单买笔数 / 买笔数
# 分母买笔数为 0 时置 null；剩余法负值截断为 0
```

## 可变异维度

- 规模档：剩余 → 仅中小单
- 口径：笔数 → 量

## 适用场景

- **散户情绪因子的分组/加权**：在散户买笔占比高的股票上赋予情绪类、反转类因子更高权重；
- **投资者结构描述**：作为股票池分层的维度，区分机构主导与散户主导的标的；
- **与卖方占比联合**：买卖两侧小单占比的对称/不对称，可刻画散户是单边涌入还是双向活跃。
