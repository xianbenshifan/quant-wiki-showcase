## 金融解释

**衡量什么**：对每个分钟分别计算单利收益与对数收益之差（泰勒展开的残差项），再减去两倍对数收益平方，得到分钟跳跃度，最后对当日分钟取均值、剔除开收盘。核心思想是：**平稳、连续的价格变动不会产生大的单复利差**，只有价格在极短时间内发生大幅跳跃，单利与连续复利之间的二阶差才会显著放大。因此它是「价格路径中不连续成分」的低成本代理。

**为什么有信息量**：跳跃是**不可分散的尾部风险**的现实载体，也是消息冲击的直接痕迹。一天内频繁出现跳跃，意味着该股票当日被突发信息反复击中，其未来收益分布包含更厚的尾部——持有它需要更高的风险补偿。同时跳跃常伴随过度反应：突然跳涨 / 跳跌后往往出现补涨或补跌，因此它也是修正类范式（如修正振幅）中判断「是否已吸引博彩 / 情绪资金」的条件变量。

**与相邻字段的区别**：

- [[patterns/fields/更优波动率|更优波动率]]：度量的是连续波动的**水平**，是二阶矩；日跳跃度剥离连续成分、聚焦跳跃这一非连续成分，二者相关但机制不同。
- 已实现波动率 / 振幅：把涨跌幅一律计入，无法区分「慢慢走出来的大涨幅」与「一步跳上去的涨幅」；日跳跃度正是为了区分这两者而设计。
- [[patterns/fields/收益率|收益率]]：本字段是收益的二阶残差构造，不带方向（跳涨与跳跌同样计入）。

## 收益来源

本页归属 [[alpha/跳跃风险补偿|跳跃风险补偿]]

**赚什么钱**：服务于**波动与尾部风险溢价**——跳跃是不可分散的尾部风险，厌恶尾部损失的投资者愿意支付溢价来规避，承担跳跃风险的持有者因此获得补偿。跳跃密集的股票在平静期要求更高预期收益，是典型的风险溢价来源。

**对手方**：在跳空后被迫追高买入或恐慌割肉的投资者；以及对尾部风险定价不足、未要求足够溢价的持有者。

**理论支撑**：[[concepts/信息冲击反应不足与过度|信息冲击反应不足与过度]]、[[concepts/特异波动异象|特异波动异象]]。

**失效条件**：

- **跳跃源于已充分定价的确定性事件**：如分红除权、指数调整等可预期事件造成的价格跳变不含信息，亦无补偿；
- **涨跌停截断**：制度性涨跌停把本应连续的极端变动截成多日小步，跳跃度的测量被系统性低估、机制链条失真；
- **波动风险溢价被套利消除**：当卖波动 / 卖尾部风险的供给充裕、拥挤交易盛行时，溢价可能压缩甚至转负。

## 加工公式

```
r_simple = P_t / P_{t-1} - 1
r_log    = ln(P_t / P_{t-1})
diff     = r_simple - r_log                 # 单复利差（泰勒残差）
jump_min = diff^2 - 2 * r_log^2             # 分钟跳跃度
jump_day = mean(jump_min)                   # 剔除开收盘后对当日分钟取均值
```

## 适用场景

- 作为**尾部风险暴露**的日频代理，用于风险补偿类因子的暴露控制或分组；
- 作为**过度反应 / 博彩情绪**的条件变量：在振幅修正、情绪反转类范式中，先用跳跃度识别「已被消息击中」的样本；
- 与 [[patterns/mask/跳跃示性掩码|跳跃示性掩码]] 配合，把跳跃强度离散为事件掩码；
- 低频化时按范式对日度序列取均值 / 标准差（见 [[paradigms/日内跳跃度|日内跳跃度]]）。

## 可变异维度

- 频率：分钟均值 ↔ 日间跳跃度
- 低频化：日度 ↔ 20 日均值/标准差等权（见范式）
