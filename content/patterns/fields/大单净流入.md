## 金融解释

**衡量什么**：把大额档（超大单 + 大单）的买量与卖量相加合并，取归一化失衡：$(\text{大单买量} - \text{大单卖量})/(\text{大单买量} + \text{大单卖量})$，落在 $[-1,1]$。正值表示大额资金在**量**上净买入，负值表示净卖出。

**为什么有信息量**：大单方向被普遍视为**资金/信息优势方**的态度——能下大额订单的通常是机构或有信息、有资金优势的参与者。因此大单净流入是「聪明钱」框架里最核心、最直接的方向字段：它不预测价格，而是记录「有优势的一方在往哪个方向下注」。用**归一化失衡**而非原始净额，是因为净额的绝对大小随股票规模与当日活跃度剧烈变化，归一化后度量的是「方向偏向程度」，跨股可比性更强——这是它与原始「大单买量 − 大单卖量」的关键区别。

**与相邻字段的区别**：

- [[patterns/fields/小单净流入|小单净流入]]：散户/小单人群的方向，常被当作反向情绪指标；两者之差即 [[patterns/fields/大单小单背离|大单小单背离]]，后者同时使用两方信息、含量更高。
- [[patterns/fields/大单净笔数|大单净笔数]]：同一方向的**笔数口径**，对下单频率敏感；本页为量口径，受单笔金额大小主导。
- [[patterns/fields/超大单净笔数|超大单净笔数]] / [[patterns/fields/大单净笔数档|大单净笔数档]]：规模档细分（仅 Mega / 仅 Large），主体含义更极端或更常态化。
- [[patterns/fields/大单买溢价|大单买溢价]]：在方向之外再问成交价位（紧迫度）；本字段只给方向与相对规模。
- [[patterns/fields/个人投资者交易比|个人投资者交易比]]：度量散户参与**份额**而非方向，与本字段正交。

## 收益来源

本页归属 [[alpha/普通大单信息延续|普通大单信息延续]]

**赚什么钱**：主要赚**信息不对称**的钱——大额资金持续净买入意味着有信息的一方在吸筹，而价格尚未反映其信息，因此未来收益偏正；净卖出反之。它赚的是**知情交易者信息优势**在扩散过程中带来的价格修正。

**对手方**：在相反方向被动成交、以限价单承接的一方（多为小单与散户）；以及在信息扩散后才跟随的交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（知情委托的方向含量）；[[alpha/知情卖出信号|知情卖出信号]]（成交结构中的知情主导度）。

**失效条件**：

- **拆单算法普及**：机构把大额订单拆成小单执行，按单笔金额划分的档位与投资者类型脱钩，大单净流入的方向信息被稀释；
- **流动性需求而非信息**：大额净买入也可能来自 ETF 申赎、被动跟踪资金或调仓，这类交易不携带个股私有信息；
- **反转占主导的短周期**：极短持有期上，大单冲击后的过度反应回落可能压过信息延续，方向符号翻转。

## 加工公式

```
大单买量 = 超大单买量 + 大单买量
大单卖量 = 超大单卖量 + 大单卖量
大单净流入 = (大单买量 − 大单卖量) / (大单买量 + 大单卖量)
# 分母近零置 null；口径可换为额/笔数
```

## 可变异维度

- 规模档：Mega+Large → 仅 Large
- 口径：量 → 额

## 适用场景

- **聪明钱方向的基准度量**：作为「大单 vs 小单」框架的核心组件，或反转/动量类因子的条件变量；
- **与笔数、额口径交叉验证**：多口径同号时方向更可信，异号说明是单笔巨单主导；
- **与溢价字段组合**：净流入给方向、溢价给紧迫度，构成「是否真买、多急」的二维刻画；
- **中高频横截面**：日频以上信号衰减较快，更适合日内—日频的短持有期。
