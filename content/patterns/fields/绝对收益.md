## 金融解释

**衡量什么**：收益率取绝对值 $\text{abs\_pct\_chg} = |r|$，即价格变动的**幅度**，丢弃方向。

**为什么有信息量**：它本身不是选股信号，而是**波动强度**的统一载体。很多经济量需要「价格变了多少」而不在乎涨跌方向：Amihud 非流动性用绝对收益除以成交额度量价格冲击；跳跃、振幅、波动率类构造用幅度衡量风险暴露；事件研究用绝对收益筛出「有大动作」的样本。把这些场景统一到一个字段上，可以确保「幅度」的口径（用哪段收益、是否 signed-log）在下游保持显式一致。它的信息价值来自**与什么组合**，而非自身——单独看它，涨与跌被混同，不携带方向性 alpha。

**与相邻字段的区别**：

- [[patterns/fields/收益率|收益率]]：保留方向，服务于动量 / 反转；绝对收益只保留幅度，服务于波动 / 冲击 / 非流动性。
- [[patterns/fields/绝对收盘收益|绝对收盘收益]]：同思想、锚定收盘口径的具体实现；本页是更一般的幅度构件。
- 已实现波动率：对绝对收益（或平方收益）做时序求和 / 聚合后的风险度量；绝对收益是它的逐期原料。
- 换手率 / 成交量：度量交易活跃度而非价格变动幅度，二者不可替代。

## 加工公式

```
abs_pct_chg = |r|      # r 为（signed-log 或原始的）期间收益率
```

## 适用场景

- 作为**波动 / 冲击类构造的分子**：Amihud 非流动性、价格冲击代理、绝对收益动量（|r| 的时序均值）；
- 作为**事件筛选条件**：切出「当日有大动作」的样本，再研究其后续行为；
- 作为**风险暴露**：配合 [[patterns/agg/基础统计聚合|基础统计聚合]] 取均值 / 标准差构造已实现波动；
- 需要方向信息时改用 [[patterns/fields/收益率|收益率]]，不要把绝对值当方向信号使用。

## 可变异维度

- 口径：收益 → 价格变化
- transform：可去对数
