## 金融解释

**做什么**：把一大组彼此相关的序列（截面上的多只股票，或一只股票的多个历史期）线性变换为少数互不相关的「主成分」，前几个主成分通常解释大部分共同方差。它是对**共同因子**的数据驱动估计：不需要事先指定市场、行业、风格等风险暴露结构，直接从收益协方差里提取出「大家在一起动的部分」。

**为什么单列一页**：显式多因子模型要先定义因子集合与暴露矩阵，一旦遗漏关键因子、或暴露估计有偏，残差里就会残留共同波动，使「特质」信号被系统性风险污染。PCA 用「最大化解释方差」这一纯统计准则自动找出共同波动的方向，代价是主成分没有经济学标签、符号与尺度都不唯一。它因此是 [[concepts/隐式因子框架|隐式因子框架]] 的实现载体。

**为什么有信息量**：真正可交易的部分往往藏在「剔除共同波动之后」的独立成分里——如特质隔夜收益、特质动量。PCA 提供了一条不依赖因子清单的去共同因子路径，与 [[patterns/ops/截面算子/截面残差|截面残差]]（把已知暴露回归掉）互为「隐式 / 显式」两种做法。

## 算子定义

```
PCA(T × N 收益矩阵) → 前 k 个主成分 F1..Fk
# 对协方差矩阵做特征分解，按解释方差降序取前 k 个
# 输出与彼此正交的因子序列，可作回归自变量或风险因子
# k 由解释力度阈值（累计解释方差）或碎石图决定
```

## 适用场景

- **构造特质信号**：先用 PCA 提取共同因子，再回归取残差（特质收益 / 特质波动），是隔夜特质波动率一类的通用路径；
- **风险模型降维**：把成百上千个相关协变量压缩为少数正交因子，降低估计维度；
- **噪声过滤**：在协方差近乎奇异时提供稳定基底；
- **频率与池子**：需要足够宽的截面（覆盖全市场、标的数 $N$ 远大于主成分数 $k$）与足够长的估计窗口；截面范围越全，提取出的共同因子越有代表性。

## 边界与陷阱

- **主成分方向不唯一（计算层）**：特征向量符号可整体翻转，相邻两期可能反号，直接跨期使用会引入伪跳变；须固定符号，或按与基准因子的相关性做对齐；
- **估计窗口与 regime（数据层）**：窗口太短则协方差噪声大、主成分抖动；太长则跨越风格切换，提取出的「共同因子」含义漂移；
- **截面太窄时秩亏**：$N$ 不足或有效样本太少时协方差矩阵退化，主成分不可靠，应改用结构化因子或收缩估计；
- **与显式因子模型混淆**：主成分是纯统计方向，可能与行业/风格混在一起，不能直接当成可解释的风格暴露；需要标签时应配合 [[patterns/ops/截面算子/截面残差|截面残差]] 做定向回归；
- **$k$ 的选择敏感**：$k$ 偏小残留共同波动，$k$ 偏大会把噪声当因子；结论随 $k$ 大幅波动即说明信号不稳健。

## 可变异维度

- 主成分数：F1 → 前 2 个（解释力阈值驱动）
- 分解对象：截面收益矩阵 → 时序收益矩阵
- 输入：原始收益 → 标准化收益
