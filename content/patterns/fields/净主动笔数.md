## 金融解释

**衡量什么**：主动买笔数与主动卖笔数的归一化失衡 $(\text{主动买笔数} - \text{主动卖笔数}) / (\text{主动买笔数} + \text{主动卖笔数})$，取值 $[-1,1]$。把 [[patterns/fields/净主动成交量|净主动成交量]] 的口径从**数量**换成**笔数**。

**为什么用笔数口径**：笔数度量的是**交易频次**，而非成交量或金额。同样的资金净流入，可以由少数大单完成，也可以由大量碎单完成——前者更像机构建仓，后者更像散户或算法参与。笔数净失衡因此刻画的是**交易频率方向的偏移**，对「有多少笔交易站在买方 / 卖方」更敏感，是挂单与成交活跃度的方向性信号，与量、额口径形成互补。

**为什么归一化**：去除成交活跃度的机械影响，使不同股票的笔数失衡可比。

**与相邻字段的区别**：

- [[patterns/fields/净主动成交量|净主动成交量]] / [[patterns/fields/净主动成交额|净主动成交额]]：量、额口径的同一信息，对规模与资金更敏感；笔数口径对频次更敏感；
- [[patterns/fields/主动成交频率|主动成交频率]]：**总量**笔数密度，不含方向；本字段是其有方向的版本；
- [[patterns/fields/每笔成交量|每笔成交量]]：单笔平均规模，与笔数口径互为镜像；
- [[patterns/fields/主动买占比|主动买占比]]：占比形式，单调对应。

## 收益来源

本页归属 [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：赚**信息不对称**的钱——主动买单的笔数占优意味着买方参与者的**广度**提升，通常伴随信息扩散与买盘跟进，方向具有一定的领先性；笔数口径对碎单与散户参与更敏感，因此也部分携带注意力与情绪成分，但主成分仍是主动交易的方向信息。

**对手方**：被动挂单、被主动笔数吃穿的流动性提供者；以及方向明确后仍滞后的跟随者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]；[[alpha/大小单博弈|大小单博弈]]（笔数口径对散户参与的敏感性）。

**失效条件**：

- **算法拆单主导**：机构把大单拆成大量小额主动单，笔数失衡被系统性放大，主体含义反转；
- **做市高频报价**：做市算法产生大量双向小额成交，稀释笔数净方向；
- **信息被瞬时定价**：参与广度提升已被市场即时吸收，跟随无超额收益。

## 加工公式

```
净主动笔数 = ratio(主动买笔数 − 主动卖笔数, 主动买笔数 + 主动卖笔数)
# 分母为 0 置 null；主动买卖笔数来自逐笔成交的主动方向标注
```

## 可变异维度

- 口径：笔数 → 量/额
- 频率：可调

## 适用场景

- **交易频次方向信号**：强调参与广度而非资金规模时；
- **与量 / 额口径配对**：三者差异揭示大小单结构；
- **短周期横截面选股**：归一化后可直接排序。
