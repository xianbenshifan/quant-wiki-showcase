## 金融解释

**衡量什么**：分别计算买量与卖量的**环比增速**（本 bar 相对上一 bar 的比值），再相减：$\text{gap} = \text{ratio}(\text{买量}_t, \text{买量}_{t-1}) - \text{ratio}(\text{卖量}_t, \text{卖量}_{t-1})$。正值表示买量相对自身在加速、卖量相对自身在减速，即买卖量的**加速度分化**。

**为什么有信息量**：净主动成交量刻画的是**水平**上的买卖失衡，本字段刻画的是**变化率**上的分化。同样的净买入水平，若来自「买量猛增、卖量不变」与「买卖都增但买增得更多」，含义不同——前者更像突发的需求冲击，后者更像整体活跃度上升。把两侧各自相对自身基期标准化后再比较，剔除了单侧规模与水平的影响，只保留节奏差异。

**为什么是中性构件**：它是对买卖量做的**时序比率变换之差**，本质属「增量 / 比率」类加工，方向含义被增速与自归一稀释，需与水平类失衡字段联合才有明确的多空含义。它与 [[patterns/fields/净主动量时序单位比率|净主动量时序单位比率]] 同族（后者是单位比率的差分口径），按同族一致原则不标 `return_source`。

**与相邻字段的区别**：

- [[patterns/fields/净主动成交量|净主动成交量]]：买卖量的**水平**净失衡，方向明确；本字段是**增速**差，方向更弱、更依赖条件；
- [[patterns/fields/净主动量时序单位比率|净主动量时序单位比率]]：同族的单位比率差分版本，实现路径不同，数值不可互换；
- [[patterns/fields/成交量增量|成交量增量]]：单侧绝对增量，不含买卖对比；
- [[patterns/fields/主动被动成交差|主动被动成交差]]：主动性**结构**差异，本字段是量的**时序节奏**差异。

## 收益来源

本页归属 [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：主要赚**信息不对称**的钱——买量与卖量的环比加速度分化，度量的是**哪一侧的成交意愿在增强**。若买量加速而卖量减速，说明主动的买入需求在相对增强；这类分化往往先于价格反映知情者或大资金的进场节奏，其方向性信息可用于预测短期价格压力。

**对手方**：在买卖加速分化中被动成交、未识别出资金方向转换的交易者；以及把单边放量误读为对称活跃的投资者。

**失效条件**：

- **买卖对称放量**：若两侧同时加速（如大盘整体活跃），差值趋零但成交结构已变，此时分化失去方向含义；
- **单侧基数效应**：上一 bar 的基数极小会让环比增速异常放大，制造虚假分化（低流动性股尤甚）；
- **算法拆单抹平节奏**：主动买卖被拆单分散后，单 bar 的加速度差异不再对应真实的意愿变化。

> 说明：本字段为**中性时序加工**——它把买卖量各自自归一后作差，本身不内在偏向某类收益来源（属知识库「增量还原 / 归一化 / 比率」类），故本页不标 `return_source`。

## 加工公式

```
买量增速 = ratio(买量_t, 买量_{t−1})          # 前值近零置 null
卖量增速 = ratio(卖量_t, 卖量_{t−1})
买卖量时序变换差 = 买量增速 − 卖量增速
```

## 可变异维度

- 窗口：1 bar → 滚动
- 口径：增速 → 单位比率

## 适用场景

- **量能节奏分化研究**：识别买卖量加速不一致的时点；
- **作为方向信号的增强项**：与净主动成交量同向时提高信心；
- **微观结构建模**：需要刻画量能变化率而非水平时。
