## 范式概述

修正的日内反转用「可知性」代理（低波动或低换手变化）识别**更可能发生动量的股票**，对其当月日内收益均值**取相反数**，使反转因子在动量区自动翻转，从而提纯反转、抑制动量污染。理论锚点见 [[concepts/球队硬币与可知性|球队硬币与可知性]]。

**核心问题：反转因子为什么会被动量污染**：反转因子假设「过去跌得多 → 未来涨」，但这个假设只在**过度反应**的情形下成立。而在**信息不确定**的股票上，价格变动更多是**噪声**而非过度反应——这类股票的历史涨跌缺乏预测力，甚至可能因信息逐步扩散而呈现动量。把它们纳入反转组合，等于在组合里掺入了一个方向不明的成分，削弱了反转因子的表现。

**「可知性」是什么意思**：这一概念来自经典的行为金融观察（「球队硬币」），指**投资者对某资产未来前景的可知程度**。可知性高的公司，其价值变化有稳定的基本面路径，价格变动更可能是真实信息；可知性低的公司，其前景本身难以判断，价格变动更多是噪声。研报用**低波动**或**低换手变化**作为「可知性高」的代理——因为波动与换手变化小，说明交易行为平稳、没有频繁的预期重新定价。

**为什么对低波动股票翻转符号**：本范式的一个重要洞察是——低波动（高可知性）并不必然意味着反转更强，而是意味着**价格变动更可能具有方向性**（无论是持续上涨还是持续下跌）。研报的判断是这类股票「更可能发生动量」，因此对其日内收益**取相反数**，相当于把它们的信号从「反转」切换为「动量」方向。这样处理之后，整个因子的构成被**按可知性分流**：高可知性股票贡献动量信号、低可知性股票贡献反转信号，两类各得其所，整体表现提升。

**与同族骨架的关系**：本范式与 [[paradigms/修正的振幅|修正的振幅]]、[[paradigms/修正的隔夜反转|修正的隔夜反转]] 共享「**可知性条件翻转**」骨架——「算基础量 → 用条件判断可信度 → 在特定区间翻转符号」。三者的差别只在条件（波动率 / 跳跃度 / 距离波动）与被修正对象（日内收益 / 振幅 / 隔夜距离）。

## 构造要点

1. **日度日内收益 $= \text{Close}/\text{Open} - 1$**（[[patterns/fields/日内收益|日内收益]]）。
   以开盘价为基准，与隔夜收益正交分解（见 [[paradigms/日内收益率|日内收益率]] 的说明）。
2. **月末对最近 20 日序列求均值与标准差**（[[patterns/agg/均值聚合|均值聚合]]、[[patterns/agg/标准聚合|标准聚合]]）。
   均值是主信号（当月日内收益的平均方向），标准差既是输出的一部分也常被用作下一步的「可知性代理」——**标准差小 = 波动低 = 可知性高**。
3. **若波动率 < 截面均值，则将当月日内收益均值取相反数**（[[patterns/ops/点算子/条件派生|条件派生]]）。
   用**截面**均值作阈值：判断标准是「相对同期其他股票，这只股票的波动是否偏低」，而非「相对自身历史」。这一步实现了「按可知性分流」。
4. **变异**：波动率 → 换手率变化量低于截面均值；日内收益 → 日间收益。
   研报给出两种可知性代理，二者可互为验证——波动率刻画**价格**的稳定性，换手变化刻画**交易行为**的稳定性。

## 可变异维度

- 可知性代理：收益波动 → 换手变化量（价格视角 ↔ 交易行为视角）
- 收益对象：日内 → 日间（配合 [[paradigms/修正的隔夜反转\|修正的隔夜反转]] 的分工）
- 窗口：20 → 10 / 60
- 阈值：低于截面均值 → 低于截面分位（更灵活的状态边界）

## 因子表现基准

源称低波动/低换手可知性更高、更可能动量；翻转后可提高反转因子表现。manifest 未含回测时以复现为准。

## 收益来源

本页归属 [[alpha/可知性分流定价|可知性分流定价]]

**赚什么钱**：主要赚**反转**的钱（对低可知性股票）——其日内价格变动中过度反应成分占比高，修正后捕捉其回吐。同时按可知性翻转后，**在高可知性股票上转为赚动量的钱**——其价格变动更可能由真实信息驱动，方向具有延续性。因此本范式是「一个因子内含两种收益来源，按可知性分流」，这也解释了它为何比原始反转更稳健。

**对手方**：低可知性股票上追涨杀跌的情绪型交易者（过度反应方）；高可知性股票上对信息反应滞后的投资者（动量的对手方）。

**理论支撑**：[[concepts/球队硬币与可知性|球队硬币与可知性]]（可知性决定价格变动的信息含量）；[[concepts/隔夜与日内收益拔河|隔夜与日内收益拔河]]（日内段的反转特性）。

**失效条件**：

- **可知性代理失真**：低波动也可能是流动性枯竭或长期停牌造成的假象，此时「高可知性」的判断错误，翻转方向被误用；
- **市场整体动量/反转格局切换**：当市场从反转主导转为动量主导（或反之），按固定条件分流的假设不再匹配当期结构；
- **阈值边界频繁穿越**：波动率恰在截面均值附近波动的股票会在相邻期反复翻转符号，引入不稳定噪声。
