## 金融解释

**衡量什么**：最优卖价与最优买价之差，除以中间价 $\text{mid} = (BP_1 + SP_1)/2$：$\text{rel\_spread} = \dfrac{SP_1 - BP_1}{\text{mid}}$。它把绝对价差标准化为**相对报价宽度**，剔除了股价水平的量纲差异，使不同价格的股票可比。

**为什么有信息量**：买卖价差是做市 / 流动性提供者索取的**即时交易成本**，也是市场流动性的教科书级代理。价差越宽，说明流动性提供者要求的补偿越高——这种补偿来自两处：一是持有库存、等待对手方的成本，二是被知情者逆向选择的风险。因此相对价差同时携带**流动性成本**与**信息不对称**两种成分，是执行成本、流动性风险、微观结构毒性研究的核心输入。

**与相邻字段的区别**：

- [[patterns/fields/最优档深度|最优档深度]]：从**数量**维度刻画即时流动性缓冲；相对价差从**价格**维度刻画成本。二者构成流动性的二维画像：价差宽 + 深度厚（成本高但容量大）与价差窄 + 深度薄（成本低但容量小）含义不同。
- [[patterns/fields/深度冲击|深度冲击]] / [[patterns/fields/深度变化|深度变化]]：度量挂单厚度的时间变化；相对价差是即时的价格宽度存量。
- [[patterns/fields/微价格偏离|微价格偏离]]：把最优档挂单量不平衡映射为价格偏离，是价差内部的方向结构；相对价差只看价差绝对宽度。
- [[patterns/fields/非流动性|非流动性]]：从「单位成交额推动的价格变动」度量流动性；相对价差是事前的报价成本，非流动性是事后的价格冲击，二者相关但视角不同。
- 有效价差不是本字段：它用成交价相对中间价的偏离，再乘买卖方向，见 [[paradigms/流动性成本与投资注意力|流动性成本与投资注意力]]。本字段只比较卖一价和买一价，没有成交价。
- 收盘委托价差的分子就是本字段在收盘时点的取值，再除以当日成交额仍在同一范式页，不另建「收盘相对价差」。
- 高低价隐含价差不是本字段：没有买一卖一时，用两日最高价和最低价按 Corwin–Schultz 反推价差，再除以当日成交额。公式在 [[paradigms/流动性成本与投资注意力|流动性成本与投资注意力]]。
- 边际交易成本也不是本字段：它用五档报单的加权均价相对中间价的偏离，再除以该侧报单金额，不是卖一减买一。
- 盘口价差是同一宽度的另一种写法：$2(a_1-b_1)/(a_1+b_1)$。中间价是 $(a_1+b_1)/2$，所以它等于 $(a_1-b_1)/\text{mid}$。日内取均值，再做 20 个交易日指数移动平均，得到月度因子；也可以对日内序列求标准差，看价差当天是否均匀。不另建字段。见 [[paradigms/流动性成本与投资注意力|流动性成本与投资注意力]]。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]]

**赚什么钱**：赚**流动性溢价**。相对价差是提供即时流动性所索取的价格补偿：愿意在买卖价差中挂单、承担库存与逆向选择风险的做市方，通过价差获得收入；对应地，需要即时成交、跨越价差的交易者支付这一成本。截面与时间序列上，价差越宽（流动性越差）的资产，其预期收益中应包含越高的流动性补偿。

**对手方**：以市价单跨越价差、支付即时交易成本的急躁交易者；以及在价差走阔的流动性紧张期被迫成交的持仓者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（价差中的逆向选择成分）。

**失效条件**：

- **限价单主导、做市竞争充分**：价差被压到最小报价单位，宽度不再反映流动性差异，区分度消失；
- **信息不对称被消除**：信息披露充分、知情交易占比低时，价差中的逆向选择成分趋近于零；
- **隐藏流动性替代**：大量成交在价差内通过隐藏单 / 暗池完成，报价价差与实际执行成本脱钩。

## 加工公式

```
rel_spread = ratio(SP_1 - BP_1, mid)     # mid = (BP_1 + SP_1)/2
# 零价差（SP_1 == BP_1）时置 null；分母近零置 null
```

## 适用场景

- 作为**交易成本 / 执行成本**的即时代理：回测换手成本、评估策略容量时的标准输入；
- 作为**流动性因子**的横截面暴露：流动性溢价、非流动性异象的常用度量；
- 与 [[patterns/fields/最优档深度|最优档深度]]、[[patterns/fields/微价格偏离|微价格偏离]] 组合成微观结构画像；
- 需要**跨股票可比**时，相对口径优于绝对价差；日频研究可取日内均值或中位数聚合。

## 可变异维度

- 频率：可调
- 口径：绝对价差 → 相对价差
