## 金融解释

**衡量什么**：市场实际的主动成交总量（主动买量 + 主动卖量）除以挂单总量（买量 + 卖量）。比值越高，说明挂出来的单子里真正成交的比例越高、被撤回的越少；比值越低，说明大量委托挂出后又撤走，名义盘口与真实成交之间存在明显落差。

**为什么有信息量**：它是**撤单强度**的镜像——执行率低等价于撤单率高。撤单不需要付出成交成本，却能改变盘口的名义供需，因此「撤了多少」是观察**虚假委托**与**流动性可信度**的关键。执行率把这一信息正向表达：执行率高的市场，盘口的挂单更「实」，名义深度更接近可成交量，流动性更可信；执行率低的市场，挂单更「虚」，依据盘口做决策的风险更大。它同时也刻画**交易意愿的实现程度**——在恐慌或亢奋时，参与者更倾向于挂单再撤，执行率下降；在平稳时执行率上升。因此执行率是一个天然的**市场质量/焦虑度**指标。

**与相邻字段的区别**：

- [[patterns/fields/撤单强度时序单位比率|撤单强度时序单位比率]]：把撤单量除以挂单量，是本字段（成交/挂单）的**互补口径**，两者之和约为 1（在不考虑部分成交等复杂情形时）；
- [[patterns/fields/净撤单压力|净撤单压力]]：把撤单量除以**实际成交量**并区分买卖侧，度量撤单的**方向**，本字段只度量**总量比例**；
- [[patterns/fields/成交额单位比率|成交额单位比率]]：把成交额规格化为当日相对量能，度量**活跃度**而非执行质量。

## 收益来源

本页归属 [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：主要赚**信息不对称**的钱。执行率低意味着盘口存在大量策略性撤单，做市方/大资金在用不可成交的挂单影响他人判断，而一般投资者无法识别这些虚单；识别出「名义流动性不可信」并据此调整成交预期，本身就是一种信息优势。此外，执行率的变化也反映市场参与者对流动性风险的共同感知。

**对手方**：依据名义盘口挂单做交易决策、被虚单误导的投资者；以及在低执行率环境中付出超额冲击成本的流动性需求方。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（策略性委托与逆向选择）。

**失效条件**：

- **改价单口径**：若数据把「改价」计为撤单，执行率会系统性偏低且含义偏移；
- **算法拆单改变分母含义**：挂单总量被算法拆分后，挂单与撤单的口径不再对应真实意愿；
- **集合竞价与大宗交易**：这些机制下的挂单与成交关系不同，执行率会被制度成分主导。

## 加工公式

```
成交执行率 = (主动买量 + 主动卖量) / (买量 + 卖量)
# 分母挂单总量近零置 null
```

## 适用场景

- **市场质量/焦虑度监测**：横截面或时序上识别挂单可信度低的标的与时段；
- **与撤单强度配对**：两者互为镜像，同向解读可相互验证口径与数据质量；
- **作为流动性因子的条件变量**：在执行率低的样本上，盘口深度类因子的信号可信度须打折。
