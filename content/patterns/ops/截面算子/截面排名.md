## 金融解释

**做什么**：在每个时点的横截面上对取值排序，归一化为 0~1 的百分位。它把「绝对水平」转成「相对强弱序数」，对量纲、分布形态与极端值都不敏感。

**为什么单列一页**：这是因子工程里使用最广的标准化。相比 [[patterns/ops/截面算子/截面z得分|截面z得分]]，rank 只依赖序、不被离群值主导，天然稳健；代价是丢弃「差多少」的距离信息，对任何单调变换都不变。把它单独成页，是为了让「稳健标准化 vs 保距标准化」的取舍有明确落点。

**它操作化了什么**：相对强弱 / 分位位置。等权因子组合、分位分组、非参信号检验都以它为底座。分组内 rank（行业 / 市值桶内）还能在标准化的同时剔除组间水平差。

## 算子定义

```
rank(x) = percentile_rank over cross-section    # 逐截面，映射到 [0,1]
# 可先按分组键做组内 rank
```

## 适用场景

- **厚尾、含离群因子的稳健标准化**，合成前统一尺度；
- **非参思路**：只利用排序信息，避免对收益分布形状做假设；
- **分位分组 / 组合构造的前置**（[[patterns/ops/点算子/分位分桶|分位分桶]] 的输入）；
- **组内排名**：行业内、市值桶内，在剔除组间差异的同时保留组内强弱。

## 边界与陷阱

- **丢弃距离**：rank 对单调变换不变，若收益差在尾部显著更大（厚尾），等距 rank 会低估尾部区分度，此时 z 或分位映射更贴合；
- **平局处理**：大量并列值（涨跌停、零成交）时 rank 的分配方式（平均序 / 首序）会影响结果，须全库统一；
- **小截面分辨率低**：截面标的少时 rank 只能取到很粗的档位，跨期可比性下降；
- **rank 后线性合成隐含等权**：对 rank 做线性加权等价于分位组合，隐含「相邻分位收益差相等」的假设，与真实尾部结构可能不符；
- **与 z 的易混**：两者都做截面标准化，但 z 保留距离、不抗离群，rank 抗离群、丢距离；选哪个取决于「信号强度是否携带信息」与「离群是否可信」。

## 可变异维度

- 排名方式：percentile → ordinal
- 分组键：无 → 行业 / 市值桶
- 方向：升序 → 降序（反向排名）
