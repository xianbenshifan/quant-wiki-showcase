## 金融解释

**衡量什么**：把每天切成上午与下午两段，每段分别做「个股收益 ~ 市场收益」回归，取该时段不能被市场共同因素解释的个股残差，再取两段残差之差 $\delta = \varepsilon_{am} - \varepsilon_{pm}$。残差代表**剥离市场涨跌后**的个股特有表现，δ 则把两时段的信息差压成单日一个标量，方向为正表示上午相对更强。

**为什么有信息量**：核心假设是**知情交易者的时段偏好**——具备信息优势的交易者更倾向在上午处理隔夜信息并集中下单，因为上午流动性更好、且能抢在信息于下午与次日扩散之前建仓。若如此，上午的价格行为承载更多增量信息，下午更多是噪声与跟随交易。于是同一只股票「上午相对强、下午相对弱」的形态，就成了信息尚未被充分定价的代理，其 20 日统计量（如 $\mu(\delta)/(\sigma(\delta)/\sqrt{N})$）可作日频选股信号（见 [[paradigms/APM因子|APM因子]]）。

**与相邻字段的区别**：

- [[patterns/fields/超额收益|超额收益]]：只做截面去中位数，不区分时段、不做回归；时段残差差是**分段回归残差之差**，剔除的是「市场 × 时段」的联合成分。
- [[patterns/ops/截面算子/截面残差|截面残差]]：通用的「回归取残差」算子；本字段是该算子在「上午 / 下午两段对比」这一特定判定基准上的产物。
- [[patterns/fields/隔夜收益|隔夜收益]] / [[patterns/fields/日内收益|日内收益]]：按**时间边界**切分收益；本字段按**回归残差**切分，并额外要求两段分别为上午与下午。
- 与动量高度相关，构造时通常需再对动量做截面回归取残差，剥离共同成分。

## 收益来源

本页归属 [[alpha/时段信息扩散|时段信息扩散]]

**赚什么钱**：赚**信息不对称**的钱。知情交易者的时段偏好使上午价格包含更多私有信息；当这部分信息尚未在下午与次日被充分定价时，买入「上午相对强、下午相对弱」的股票，可获得信息逐步扩散带来的收益。本质上捕捉的是**信息扩散的时间结构**，而非单纯预测方向。

**对手方**：信息获取与反应滞后的交易者——尤其在下午与次日才跟随的人，他们为已被上午定价的信息买单；以及机械按全天收益决策、忽略时段结构的动量交易者。

**理论支撑**：[[alpha/知情时段意图|知情时段意图]]、[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **信息释放时点迁移**：市场结构变化使信息在隔夜或集合竞价集中释放（如开盘集合竞价权重提高），上午的相对信息优势被削弱；
- **高流动性大盘股**：知情交易占比低、信息扩散快，时段差异被迅速套利抹平，区分度下降；
- **风格剧烈切换期**：时段差与动量、反转的相关结构不稳定，去动量后残留成分可能主要来自风格而非信息。

## 加工公式

```
eps_am = cs_resi(r_am, R_am)      # 上午个股收益对市场收益截面回归的残差
eps_pm = cs_resi(r_pm, R_pm)      # 下午同理
delta  = eps_am - eps_pm          # 时段残差差
```

## 适用场景

- 构造 **APM 类知情交易时段因子**：δ 的均值 / 信噪比统计量作为日频信号；
- 作为**信息含量代理**，与其它知情交易度量（放量形态、开盘后净主买强度）交叉验证；
- 与 [[patterns/mask/时段掩码|时段掩码]] 配合切出上午 / 下午窗口，并剔除开收盘竞价噪声；
- 需要在**中高换手、散户占比高**的池子里区分度更强；大盘蓝筹上信息扩散快，时段差稀薄。

## 可变异维度

- 时段对：上午/下午 → 隔夜/日内（改进版）
- 回归基准：指数收益 → 市场截面均值
- 残差口径：OLS → 截距项剔除
