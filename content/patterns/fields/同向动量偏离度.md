## 金融解释

**衡量什么**：每分钟先在**上涨组**与**下跌组**内分别求收益均值，作为「同向动量基准」；再取个股分钟收益与该基准之差：上涨股的偏离度为正表示涨得比同类更多，下跌股的正值表示跌得比同类更少。收益为零或当日无同向股票时置 0。

**为什么有信息量**：单看个股收益无法区分「它自己强」与「整个市场同方向都强」。减去同向基准后，剩下的是**相对同类群体的额外强度**——它剔除了市场共同方向，使信号在截面上可比。之所以叫「偏锋」，是因为高偏离意味着该股在其自身方向上明显跑赢同类，属于**离群过强**：这类脉冲式领先往往由短期资金集中推动而非基本面改善，因此后续容易回吐；低偏离（相对同类偏弱）则可能是被错杀的落后标的。需要强调：偏离度本身只是一个**相对强度的度量**，其多空方向由后续使用的范式（如按截面偏度切出动量时刻后取标准差）决定，本字段不内含方向结论，因此本页不标注 `return_source`。

**与相邻字段的区别**：

- [[patterns/fields/超额收益|超额收益]]：减去的是**全市场**（截面去中心）基准，剔除市场共同涨跌；本字段减去的是**同向子群体**基准，剔除的是「同方向个股的普遍强度」，度量的是组内离群度。
- [[patterns/agg/偏度聚合|偏度聚合]]：月度低频化时衡量偏离度的分布不对称；本字段是逐分钟的原始偏离。
- [[patterns/fields/收益率|收益率]]：本字段的输入，本身不含相对信息。
- [[patterns/fields/换手率|换手率]]：活跃度度量，与相对强度正交。

## 加工公式

```
正向基准_t = mean( r_j,t | r_j,t > 0 )      # 上涨组等权均值
负向基准_t = mean( r_j,t | r_j,t < 0 )      # 下跌组等权均值
偏离度_i,t = r_i,t − 同向基准_t             # 方向随 r_i,t；无同向股票或 r=0 时置 0
```

## 可变异维度

- 基准：同向等权均值 → 中位数 / 市值加权
- 零收益处理：置 0 → 置空

## 适用场景

- **动量脉冲中的离群识别**：作为 [[paradigms/偏锋涨跌幅|偏锋涨跌幅]] 类范式的输入，先分离「自身强势」与「随大流」；
- **相对强度分组**：在截面内按偏离度分组，研究离群强势股的事后回吐；
- **短周期、分钟级框架**：需要逐分钟刻画个股相对同类的额外强度时；
- **基准稳健性检验**：同向均值易被组内极端值牵引，必要时换成同向中位数。
