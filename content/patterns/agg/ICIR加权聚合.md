## 金融解释

**做什么**：把 $n$ 个因子的 IC 序列当作 $n$ 条「预测力流」，按其**预测力均值与波动**分配权重，再对各因子的截面标准化值加权求和，输出一个**单一合成因子**。源报告与库内两个来源给了同一基准下的两种求权重口径：

**口径一 · 简单 ICIR 归一化**（低成本）：

$$\text{ICIR}_k=\frac{\operatorname{mean}(\text{IC}_k)}{\operatorname{std}(\text{IC}_k)},\qquad v_k=\frac{\text{ICIR}_k}{\sum_j|\text{ICIR}_j|},\qquad F_t=\sum_k v_k f^k_t$$

**口径二 · 均值—方差最优（最大化 IC_IR）**：把期望 IC 当收益、IC 协方差当共同风险，求使组合信息比率最大的权重：

$$\arg\max_{w}\ \text{IC\_IR}(w)=\frac{w^{T}E(\text{IC})}{\sqrt{w^{T}\Sigma^{*}w}},\qquad \text{s.t.}\ \sum_i w_i=1,\ -1\le w_i\le 1$$

**为什么用 ICIR 而不是 IC 或等权**：IC 只度量预测力的**均值**；ICIR 度量「每单位预测波动换来的预测力」，即**稳定性调整后**的预测力。IC 高但波动剧烈（ICIR 低）的因子时好时坏，按 IC 或等权加权都会被近期高 IC 误导。ICIR 加权天然给「持续有效」的因子更高权重，并利用「哪些因子近期更管用」的动态信息。

**口径二的增量**：简单归一化只用一阶信息（各因子自身的 $E(\text{IC})$ 与波动），**忽略因子之间 IC 的相关性**。而合成的共同风险恰恰来自相关性——高度相关的两个因子被当成两条独立信息，等价于对同一方向下注两次。口径二把 **IC 协方差矩阵 $\Sigma^{*}$** 纳入分母，奖励「期望 IC 高且彼此不高度相关」的组合，因此在等权与简单归一化之上进一步改善合成 ICIR。代价是需要稳健的协方差估计（见 [[concepts/协方差收缩|协方差收缩]]）。

**为什么允许负权重**：约束 $w_i\in[-1,1]$ 允许 IC 显著为负的因子被反向纳入。合成因子值只表示相对大小，故**负权重仅代表权重、不代表做空**。

**解析解与数值解**：仅等式约束时口径二有解析解，形如 $w\propto\Sigma^{*-1}E(\text{IC})$（再乘标度常数），本质是均值—方差最优组合；叠加箱式约束后用**顺序最小二乘规划（SLSQP）**迭代，初值取等权。

**与相邻构件的区别**：

- 等权 / IC 均值加权：只用一阶信息，不惩罚因子间共同波动；
- [[patterns/ops/截面算子/截面z得分|截面z得分]]：单因子截面标准化，是加权**之前**的预处理；
- [[patterns/ops/其他算子/主成分分析|主成分分析]]：用统计降维消除相关（正交基后等权）；本页在**保留原因子方向**的前提下用权重抵消共同风险。

## 聚合方式

```
输入：n 个因子的截面标准化值 + 各自历史 IC 序列（回看窗口内）

口径一（简单归一化）：
  1. 逐因子对截面值标准化 + 缩尾
  2. icir_k = mean(ic_k) / std(ic_k)
  3. v_k = icir_k / sum_j |icir_j|
  4. F(t) = sum_k v_k(t) * f_k(t)

口径二（均值—方差最优）：
  1. 同前；另估 IC 协方差 Σ*（样本 / 收缩）
  2. 解 max wᵀE(IC) / sqrt(wᵀΣ*w), s.t. Σwᵢ=1, -1≤wᵢ≤1
     （仅等式约束时 w ∝ Σ*⁻¹E(IC)；含箱约束用 SLSQP，初值等权）
  3. 用 w* 对各因子截面值加权求和 → 合成因子

落盘：每个截面对应一个合成因子值（跨因子聚合，输出单列）
```

- 权重按**滚动窗口**滚动重估，故权重随时间变化；防前视（只用当期及之前数据）；
- IC 口径（Pearson / Rank）必须与分母一致。

## 适用场景

- **多因子合成**：因子数量较多、彼此存在共线性时的加权合成；
- **自动挖掘产物收口**：把自动化搜索出的多条表达式因子压缩为一个稳健信号；
- **对负向因子的利用**：允许负权重时可把显著反向因子纳入而非丢弃；
- **需要跨期稳定**：滚动重估权重，跟随因子有效性漂移；
- **指数增强/多因子选股**的收益预测模型打分环节。

## 边界与陷阱

- **样本协方差有偏**：样本量不足、共线高、特征数远大于观察数或冷启动时，样本协方差与总体差异大，直接代入会使口径二的优化失真——须用收缩修正（见 [[concepts/协方差收缩|协方差收缩]]）；
- **目标函数非凸与初值**：叠加箱式约束后非凸，SLSQP 结果依赖初值与迭代次数，复现须固定设置；
- **IC 口径混用**：Pearson IC 与 Rank IC 的方差、量纲不同，分母口径必须与分子一致；
- **权重病态**：协方差近奇异时 $\Sigma^{*-1}$ 数值不稳，权重可能极端；须检查条件数；
- **窗口选择两难**：太短则协方差噪声大、权重抖动；太长则跨越因子有效性切换期，均值不再代表未来期望；
- **滚动窗口暖机期**：起始阶段样本不足，权重不稳，须设暖机期或退化为等权。

## 可变异维度

- **权重求法**：简单 ICIR 归一化 → 均值—方差最优（含协方差）
- IC 口径：Pearson IC → Rank IC
- 回看窗口：滚动 12 期 → 滚动 3 年 / 6 期 / 指数加权
- 约束：仅和为一 → 叠加 $[-1,1]$ → 进一步非负约束
- 协方差估计：样本 → 收缩（基本收缩 / Ledoit-Wolf / OAS / 交叉验证最优）
- 求解：SLSQP → 解析解 / 其它约束优化
