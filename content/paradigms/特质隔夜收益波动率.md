## 范式概述

特质隔夜收益波动率因子在**隐式因子框架**下构造：先对全部股票过去 20 天的**隔夜收益率**序列做截面 PCA，提取第一主成分 F1 作为隐式共同因子溢价（若 F1 解释力度不足 20%，则取解释力最大的前两个主成分）；再对每只股票以隔夜收益率为 y、以 F1 序列为 x 做时序回归，取**回归残差序列的标准差**作为因子值。它刻画的是——把隔夜收益中的「全市场共同波动」剥离之后，个股**特有**的隔夜波动强度。

**为什么要在「隔夜」口径上做**：隔夜收益 $OvernightRet_t = Open_t/Close_{t-1} - 1$ 度量昨收到今开的价格跳变，其间市场**没有连续交易**，价格无法被日内订单流逐步「平滑」。因此隔夜收益天然浓缩了**信息冲击**——公告、外盘、行业消息等发生在非交易时段的事件，会在开盘被一次性定价。这与日内收益的性质不同：经验上隔夜偏弱动量、日内偏反转，二者常显著负相关（见 [[concepts/隔夜与日内收益拔河|隔夜与日内收益拔河]]）。把窗口限定在隔夜，等于把「信息驱动的跳变」与「日内交易噪声」分开，让特质波动更接近**个股对独特信息冲击的敏感度**，而不是日内买卖博弈的残留。

**为什么用隐式（PCA）而非显式多因子模型**：传统做法用 Fama-French、Barra 之类显式风险模型剥离共同风险，但显式模型必须**预先指定因子结构**——一旦遗漏了真实的共同风险源，残差里就会混入系统性成分；而且因子载荷（beta）随时间变动，逐期估计本身也带误差。PCA 不假设因子结构，直接让数据「说出」共同波动的方向：第一主成分即承载最大共同方差的方向。这样得到的共同因子虽然缺乏经济学标签，但**漏掉共同风险的概率更低、估计更稳**，代价只是可解释性变差。这正是 [[concepts/隐式因子框架|隐式因子框架]] 的核心主张。

**为什么残差标准差就是「特质波动」**：把每只股票的隔夜收益对 F1 回归，$\beta_i^{F1}$ 度量它对隐式共同因子的暴露，残差 $\varepsilon_i$ 就是「不能被共同因子解释」的部分；对残差取标准差，得到的是个股特有波动的**强度**（而非方向）。这与 [[concepts/特异波动异象|特异波动异象]] 的直觉一致：个股特有的、无法被共同风险解释的波动，本身就是一个独立于市场/风格风险的横截面定价维度，其高低对应不同的风险暴露与信息环境。

**机制链条**：隔夜时段的信息冲击 → 个股对冲击的敏感度差异（有的股票跳得厉害，有的平稳） → 剥离共同波动后剩下的残差强度，即「这只股票身上有多少不可被共同风险解释的独特波动」 → 独特波动越大的股票，越暴露于个股特有信息风险（潜在的知情交易冲击、流动性事件），因而是一个需要被定价的风险维度。

## 构造要点

1. **对每只股票 i 计算目标序列（收益 / 换手率），取过去 20 天**。
   目标是「时序上可回归」的同一标的序列。**为什么用 20 天**：这是估计精度与结构稳定性的权衡——窗口太短（如 5 天），残差标准差被单次极端跳变主导、抽样噪声大；窗口太长（如 60 天），会把早已失效的旧信息卷入，并隐含「特质波动在两个月内不变」的强假设。20 天约等于一个月交易日长度，与月度调仓频率对齐，是同类研究的通行取法。
2. **在截面上对全部股票目标序列做 PCA，取第一主成分 F1 作为隐式因子溢价**；若 F1 解释力度 < 20%，则取解释力最大的前两个主成分。
   **为什么在「截面」上做**：PCA 的输入是「所有股票 × 过去 20 天」的收益矩阵，提取出的第一方向是**全市场共同变化**的主方向，其对应的时间序列就是隐式共同因子溢价的代理。**为什么设 20% 阈值**：解释力度衡量 F1 是否真的代表共同波动；若不足 20%，说明单个主成分承载的共同信息太少，此时补入第二个主成分，避免系统性成分残留在残差里、把「共同风险」误记成「特质风险」。
3. **对每只股票 i：$Target_{i,t} = \alpha_{i,t} + \beta_i^{F1} F1 + \cdots + \varepsilon_i$ 做时序回归，得残差序列 $\varepsilon_i$**。
   **为什么用回归而非直接相减**：回归会同时估计个股对共同因子的敏感度 $\beta_i^{F1}$ 与截距，只有 beta 被正确剔除后残差才是纯净的特质部分。若直接「收益减共同收益」，等于隐含所有股票 beta 均为 1，对高/低 beta 股会产生系统性偏差。
4. **特质波动率 $IV = std(\varepsilon_i)$**。
   **为什么用标准差而非方差**：标准差与收益同量纲，便于跨股比较与后续合成；方差对极端残差更敏感，会把个别异常跳变的权重放大。
5. **变体**：特异度因子 $IVR = 1 - R^2$；特质偏度因子 $IS = \sum \varepsilon_i^3 / IV^3$。
   三者刻画的是同一残差的不同侧面——$IV$ 是波动的**强度**，$IVR$ 是「共同因子解释不了的比重」，$IS$ 是残差分布的**不对称形状**。同一个隐式框架换个残差统计量就得到一族因子，这是该框架复用成本低的原因。

## 派生形态

- **基于 PCA 的特质波动率（日度收益口径）**：以过去 20 天**日度收益率**序列为 y、F1 序列为 x 回归，残差 std 即特质波动率；逻辑与隔夜版完全同构 → 基于PCA的特质波动率因子。换口径不换机制——共同波动的估计方式与残差定义都不变，只是目标序列从隔夜收益换成全日收益。
- **特质日内收益波动率（日内收益口径）**：$IntradayRet=Close/Open-1$，以过去 20 天日内收益率序列为 y、F1 序列为 x 回归，残差 std 即 IntradayRetIV → 特质日内收益波动率因子。与隔夜版互补：隔夜版捕捉非交易时段的信息冲击，日内版捕捉交易时段的信息消化。
- **特质换手波动率（换手率口径）**：以过去 20 天**日度换手率**序列为 y、F1 序列为 x 回归，残差 std 即 TurnoverIV；对换手活跃度互文特征提取特质波动 → 特质换手波动率因子。把目标从「价格」换成「换手」后，残差波动刻画的是**交易活跃度的特有波动**，而非价格风险。

## 可变异维度

- 窗口：20 天 → 10/60 天
- PCA 主成分：F1 → 前 2 个主成分（解释力 < 20% 自动扩展）
- 残差统计量：std → IVR(1−R²) / IS(特质偏度)
- 目标口径：隔夜收益 → 日内（收盘/开盘−1） / 日度收盘收益 / 日度换手率

## 收益来源

本页归属 [[alpha/隔夜特质波动|隔夜特质波动]]

**赚什么钱**：主要赚**波动与尾部风险溢价**的钱——回归残差被剥离了共同风险，剩下的正是个股**特有**的风险暴露（无法用市场/风格对冲掉的那部分）。持有特质波动更高的股票需要承担更大的个股特有风险与潜在的极端跳变，若市场对这一风险定价，就应有相应的风险补偿。次要赚**信息不对称**的钱——隔夜跳变多由非交易时段的信息事件驱动，个股隔夜特有波动越大，越可能对应部分参与者先于市场消化了信息；特质波动因此也携带一份「信息冲击强度」的读数。需要说明的是，特质波动率究竟以正向（风险补偿）还是负向（异象高估）影响收益，源页未给出方向结论，此处按机制记录、不预设符号。

**对手方**：在隔夜跳变中被动持有、承担个股特有风险而未能对冲的一方；以及因信息落后而在开盘一次性承受不利价格的一方。

**理论支撑**：[[concepts/隐式因子框架|隐式因子框架]]（共同波动的降维估计）；[[concepts/特异波动异象|特异波动异象]]（特异波动作为独立定价维度）；[[concepts/隔夜与日内收益拔河|隔夜与日内收益拔河]]（隔夜口径的信息学动机）。

**失效条件**：

- **共同因子退化为共同噪声**：若隔夜收益的共同波动主要由某项制度性因素（如同步的流动性干涸、统一的涨跌停约束）主导，F1 就不再是「共同风险因子」，剥离它得到的残差不再代表个股特有风险，机制解读失效。
- **特质波动的风险补偿被定价消除**：当特质波动成为被广泛交易与对冲的风险因子后，其风险溢价会被套利活动压缩，残差强度不再预测收益。
- **隔夜信息通道被削弱**：若交易制度变化使价格能在夜间或连续时段被消化（隔夜不再是信息集中释放的窗口），隔夜口径与日内口径的信息分工消失，隔夜特质的独立增量信息随之减弱。
