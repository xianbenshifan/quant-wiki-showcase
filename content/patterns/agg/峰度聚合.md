## 金融解释

**做什么**：对窗口内序列输出峰度（样本四阶标准化中心矩），衡量分布的**尾部厚度**——极端取值出现的概率相对正态分布是更高还是更低。采用 fisher 常态口径时，正态分布的峰度为 0，正值表示厚尾 / 尖峰（极端值更频繁）。

**为什么有信息量**：波动率只给出「平均波动多大」，不区分「平静中有几次剧烈跳跃」与「持续温和波动」。峰度补上这一维：高峰度意味着收益更多由少数大冲击构成，对应**尾部风险更高**。与偏度（不对称方向）合起来，构成对尾部形状的完整画像——「往哪偏」×「尾有多厚」。在风险定价与崩盘概率的刻画中，这两个量是波动率之外的关键补充。

**零方差守卫的含义**：峰度分母含 $\sigma^4$，窗口内取值恒定时 $\sigma=0$ 会除零。约定 $n\ge 4$ 且方差为 0 时输出 0，语义是「无尾部信息」。

## 聚合方式

```
kurt(x, window, mask=None)
# 零方差且 n>=4 -> 0
```

语义：窗口内样本峰度（fisher 常态，即超额峰度）；可选掩码限定状态子集。

## 适用场景

- **尾部风险度量**：与波动率配合，区分「高斯式波动」与「厚尾式波动」，后者更接近崩盘风险；
- **极端事件倾向**：高峰度标的在相同波动率下有更高的极端收益概率；
- **分布形状画像**：与偏度、标准差组成三维描述；
- **状态内尾部变化**：在掩码子集中比较峰度，观察某状态下尾部是否变厚。

## 边界与陷阱

- **对极端值比偏度更敏感**：峰度按偏差的四次方加权，单根极端 bar 几乎可以单独决定整个窗口的数值——统计量本身被它要度量的对象主导；
- **收敛极慢**：四阶矩的估计方差很大，需要很长的窗口才有意义。经验上短窗口（几十根以内）的峰度基本是噪声，须显著长于偏度所需的窗口；
- **近零方差爆炸**：守卫只覆盖严格 $\sigma=0$，低波动序列上比值仍不稳定；
- **口径必须明确**：是否减 3（fisher 常态）、是否做小样本修正，不同库数值差异大，跨库比较前须对齐；
- **跨 regime 混合**：长窗口跨越波动状态切换时，峰度反映的是混合分布而非单一状态；
- **与波动率混淆**：高峰度不等于高波动，两者度量不同维度，不可互相替代。

## 可变异维度

- 窗口：可调（因收敛慢，通常取比偏度更长）
- 口径：fisher 常态（减 3）/ raw 峰度 / 稳健峰度
