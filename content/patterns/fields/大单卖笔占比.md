## 金融解释

**衡量什么**：卖出侧成交笔数中，被划入大额档（超大单 + 大单）的那些笔数所占的比例。它回答的是「卖盘是由大额资金在下单，还是由大量小额资金在下单」——一个**参与结构**问题，而不是方向问题。

**为什么有信息量**：卖出笔数的规模构成，反映了卖方人群的结构。大单卖笔占比高，说明当日的抛压主要由少数大额资金贡献，卖盘集中、可能带有明确的减仓意图；占比低则说明卖出是大量散户小额挂单的集合行为，分散且情绪化。这一结构本身不指示方向，但它决定了同一段「净流出」的性质：是机构在派发，还是散户在恐慌。因而它常作为**条件变量或权重**，去调节其他方向性字段（净流入、溢价等）的解释力，而不是单独作为多空信号。

**与相邻字段的区别**：

- [[patterns/fields/大单买笔占比|大单买笔占比]]：买入侧的对应物，二者相除或相减可得到「买卖两侧的大单参与是否对称」；
- [[patterns/fields/小单卖笔占比|小单卖笔占比]]：以「剩余法」定义的散户卖单笔占比，与本字段互补（大单占比高通常意味着小单占比低，但两者的分母口径需一致）；
- [[patterns/fields/个人投资者交易比|个人投资者交易比]]：同样刻画参与结构，但用**金额阈值（小额成交额占比）**而非笔数档位，且针对散户而非大单；
- [[patterns/fields/大单净流入|大单净流入]]：给出大单的**方向**，本字段给出大单在卖盘中的**份额**，两者是正交的两个维度。

## 加工公式

```
大单卖笔数 = 超大单卖笔数 + 大单卖笔数
大单卖笔占比 = 大单卖笔数 / 卖笔数
# 分母卖笔数为 0 时置 null
```

## 可变异维度

- 规模档：Mega+Large → 仅 Large
- 口径：笔数 → 量

## 适用场景

- **为大单方向字段提供「集中度」背景**：同样的净流出，若大单卖笔占比高，更可能是机构派发而非散户噪声，方向信号的可信度更高；
- **刻画投资者结构**：在机构化程度不同、或不同市值/流动性分层的股票池中，该占比的截面分布差异本身可作为分组或中性化维度；
- **作为条件掩码**：只在大单卖笔占比高的样本上交易方向性因子，以过滤掉散户噪声主导的时段。
