## 金融解释

**衡量什么**：最优档深度相对上一期的一阶变化率，再取负号，使**正值代表深度下降**：$\text{depth\_shock} = -\left(\dfrac{\text{best\_depth}_t}{\text{best\_depth}_{t-1}} - 1\right)$，最后做 1% 时序缩尾。

**为什么有信息量**：深度冲击刻画的是「盘口承接力在瞬间被抽走」的幅度。最优档是成交的第一道缓冲，它骤降意味着即时流动性供给发生了**负向冲击**——可能来自主动单集中吃单、也可能来自流动性提供者集体撤单。这类冲击是典型的**流动性事件**：它本身预测短期的价格脆弱性（同样一笔成交会推动价格更远），并在冲击后要求更高的流动性补偿。取负号是为了让「深度被抽走」在数值上为正，便于识别与分组。

**与相邻字段的区别**：

- [[patterns/fields/深度变化|深度变化]]：度量的是**总深度**（五档合计）的对称相对变化，可正可负，描述整段盘口变厚或变薄；深度冲击只盯最优档、且翻符号，专门刻画「承接力被抽走」的压力事件。
- [[patterns/fields/最优档深度|最优档深度]]：存量水平；深度冲击是它的变化率，是流量 / 事件概念，二者一个是状态、一个是冲击。
- [[patterns/fields/相对价差|相对价差]]：从价格宽度刻画交易成本；深度冲击从数量缓冲刻画瞬时脆弱性，角度互补。
- [[patterns/fields/浅档订单流失衡|浅档订单流失衡]]：OFI 同时考虑买、卖两侧的净增量方向；深度冲击只看两侧合计厚度的变化，不带方向。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]]

**赚什么钱**：赚**流动性溢价**。深度冲击度量的是流动性供给被瞬时抽走的程度；在被冲击、流动性变薄的时点，剩余流动性提供者承担了更高的价格冲击与被动成交风险，理应获得补偿。流动性冲击越频繁、幅度越大，持有者要求的预期收益越高，这是流动性风险补偿的典型形态。

**对手方**：在深度被抽走、冲击成本抬升时仍需即时成交的急躁交易者；以及在流动性事件中被迫以不利价格变现的持仓者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]。

**失效条件**：

- **隐藏流动性补位**：冲击后冰山单与场外流动性迅速补入，可见最优档深度未恢复但真实缓冲已修复，冲击的定价含义消失；
- **高频做市快速回补**：算法在毫秒级重建最优档，「深度冲击」只是技术性快照噪声，不含真实流动性事件；
- **流动性整体充裕期**：市场层面流动性宽松时，深度冲击被迅速吸收，溢价收窄甚至消失。

## 加工公式

```
depth_shock = -ratio(best_depth_t - best_depth_{t-1}, best_depth_{t-1})
depth_shock = ts_winsorize(depth_shock, 1%)
# 前值近零置 null；缩尾参数可调
```

## 适用场景

- 作为**流动性事件探测器**：识别最优档被抽走的时点，研究其后的价格冲击与反转；
- 用于**短周期脆弱性**度量：与 [[patterns/fields/相对价差|相对价差]] 组合，价差走阔叠加深度骤降是最典型的脆弱状态；
- 与 [[patterns/fields/深度变化|深度变化]] 配合，区分「最优档被抽走」与「整段盘口变薄」；
- 在**分钟级、tick 数据完整**的活跃标的上更能捕捉真实事件。
