## 金融解释

**衡量什么**：最优买价 $BP_1$ 与最优卖价 $SP_1$ 的算术中点 $\text{mid} = (BP_1 + SP_1)/2$。它是盘口两侧报价的对称基准，代表「若买卖双方各让一步」的即时均衡价。

**为什么值得单独抽出成构件**：中间价本身不是因子，而是整个盘口字段族的**坐标原点**。相对价差以它为分母把价差标准化为报价宽度；微价格偏离以它为基准，度量挂单量不对称被映射到价格空间的偏离；中间价收益以它为价格序列构造订单簿层面的动量 / 反转。先把它定义清楚，下游每个字段「相对谁而言」才不会含混。

**为什么用中点而非最新成交价**：最新成交价带有成交时点与主动方向的信息，会被单笔交易瞬时推离均衡；中点只依赖当前最优报价，对单笔成交不敏感，更适合作为**时点上**的报价基准。代价是它完全不反映盘口数量结构。

**与相邻字段的区别**：

- [[patterns/fields/成交均价|成交均价]]：以成交量加权的事后成交基准，代表「已经成交的价格」；中间价代表「报价世界的均衡」，两者分别对应成交与报价；
- [[patterns/fields/微价格偏离|微价格偏离]]：用最优档挂单量加权买卖价，把数量信息编码进价格，比中间价更接近均衡，而中间价正是其基准；
- [[patterns/fields/中间价收益|中间价收益]]：本字段的时序变化率；
- 收盘价：最后一笔成交价，含收盘集合竞价机制，不宜作为盘口基准。

> 说明：本字段为**中性价格构造**——它把最优买卖报价映射为对称基准价，本身不携带收益方向，按知识库对「收益 / 价格变换」类的标注标准不标 `return_source`。

## 加工公式

```
mid = (BP1 + SP1) / 2
# 若 BP1 或 SP1 缺失 / 为零，回退为收盘价；其余档位用上一档回落
```

## 适用场景

- **作为盘口字段的基准价**：价差、失衡、微价格类字段的分母或参照；
- **高频价格序列**：需要剔除成交噪声的订单簿价格路径时；
- **执行基准**：作为即时公允价的粗略代理。
