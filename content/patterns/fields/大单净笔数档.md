## 金融解释

**衡量什么**：只取 Large 档（不含 Mega）的买卖笔数，做归一化失衡——正值表示大单以主动买入的**笔数**占优，负值表示大单以主动卖出的笔数占优。它把「大额资金在往哪个方向下注」这件事，从量、额维度搬到了**笔数**维度。

**为什么值得单独抽出来**：笔数与量额度量的是不同东西。量额失衡会被**单笔金额大小**主导——一笔超大单就能把当日的量额失衡推向极端，反映的是「一次冲击」；笔数失衡对**下单频率**更敏感，反映的是「持续、反复的进场意图」。当一个资金方在若干分钟内连续下出多笔大单，往往是执行一个既定计划（建仓/派发），这种「重复性」在笔数维度比在量额维度更干净。只取 Large 而不含 Mega，是为了剔除 Mega 档中事件性极强的个别巨单（机构专用席位、指数调整、大宗搬单），让指标更接近大资金的**常态化**参与方向。

**与相邻字段的区别**：

- [[patterns/fields/大单净笔数|大单净笔数]]：Mega+Large 合并档，事件性更强、单日波动更大；本页是剔除 Mega 后的「纯 Large」口径；
- [[patterns/fields/超大单净笔数|超大单净笔数]]：仅 Mega 档，最接近机构专用行为；
- [[patterns/fields/大单净流入|大单净流入]]：同族但为量口径，受单笔大小影响，与本页可互为稳健性检验；
- [[patterns/fields/成交笔数压力|成交笔数压力]]：不分档的全部主动成交笔数净失衡，度量「全市场平均方向」，不含规模区分。

## 收益来源

本页归属 [[alpha/普通大单信息延续|普通大单信息延续]]

**赚什么钱**：主要赚**信息不对称**的钱——大单档的净方向被普遍视为资金/信息优势方的态度：Large 档持续主动净买入，意味着有信息的一方在吸筹，而价格尚未反映其信息，因此未来收益偏正。笔数口径比量额口径更贴近「持续性建仓」，噪声更低。

**对手方**：在相反方向上被动成交、以限价单承接的一方（多为散户与小单）；以及在信息扩散后才追入的滞后交易者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（知情委托的方向含量）；[[alpha/知情卖出信号|知情卖出信号]]（成交结构中的知情主导度）。

**失效条件**：

- **拆单算法普及**：机构把大额订单拆成小单执行时，档位（按单笔金额划分）与投资者类型脱钩，Large 档不再等价于机构，方向信息被稀释；
- **流动性需求而非信息**：大额净买入也可能来自被动跟踪资金的申赎、ETF 申赎或调仓，这类交易不携带个股私有信息，其方向不预测收益；
- **反转占主导的短周期**：在极短持有期上，大单冲击后的过度反应回落可能压过信息延续，方向符号翻转。

## 加工公式

```
大单净笔数(Large) = 归一化失衡(LargeBuyNum, LargeSellNum)
                 = (LargeBuyNum − LargeSellNum) / (LargeBuyNum + LargeSellNum)
# 归一化失衡(a,b) = (a−b)/(a+b)，分母近零置 null
```

## 可变异维度

- 口径：笔数 → 量/额
- 规模档：Large → Mega+Large

## 适用场景

- **剔除极端事件后的机构方向度量**：当样本里混有指数调整、大宗交易、机构专用席位等一次性巨单时，Large-only 口径比 Mega+Large 更稳；
- **短持有期、拆单普遍的市场**：笔数维度对高频拆单更敏感，适合分钟—日频的短周期信号；
- **与量额口径做交叉验证**：若笔数与量额两种口径给出同号，信号更可信；若相悖，往往说明是单笔巨单在主导量额，应降权处理。
