## 金融解释

**衡量什么**：$\text{cancel\_num\_imbalance} = \dfrac{\text{买撤单笔数} - \text{卖撤单笔数}}{\text{买撤单笔数} + \text{卖撤单笔数}}$，取值落在 $[-1,1]$。正值表示买侧撤单笔数占优，负值表示卖侧占优。

**为什么有信息量**：挂单代表交易意愿，撤单代表意愿的撤回。买侧集中撤单意味着买方在收回支撑、需求边际转弱；卖侧集中撤单则相反。更重要的是，撤单方向暴露了**订单流的意图侧**：策略性参与者（知情者、幌骗者）需要先挂出再撤销来隐藏真实方向，其操作侧会在撤单笔数上留下方向痕迹。选「笔数」而非「量」的意义在于它侧重刻画**参与笔数**的撤单行为——少数大单撤走主要改变量口径，而大量散单撤走更集中体现在笔数口径上，两者互补。

**与相邻字段的区别**：

- [[patterns/fields/撤单失衡|撤单失衡]]：量口径的方向失衡，反映撤单「股数」方向；本页是笔数口径，反映「撤单次数」方向。拆单算法会放大笔数口径而压低量口径。
- [[patterns/fields/净撤单压力|净撤单压力]]：撤单量 / 成交量，衡量撤单相对真实成交的「虚假程度」；本页只比较两侧撤单笔数，不带成交基准。
- 撤单熵差：撤单规模分布的集中度形状差，与方向无关，可与本页正交使用。
- [[patterns/fields/订单流失衡|订单流失衡]]：度量盘口挂单的**净增量**方向（新增挂单的买卖失衡）；本页度量**撤单行为**的方向。二者结合可区分「新增挂单变少」与「既有挂单被撤走」这两种不同的流动性变化。

## 收益来源

本页归属 [[alpha/非流动性与冲击补偿|非流动性与冲击补偿]] [[alpha/知情卖出信号|知情卖出信号]]

**赚什么钱**：主要服务于两类逻辑。其一为**流动性溢价**——一侧集中撤单等同于该侧流动性被抽走，剩下的流动性提供者承担更大风险，理应获得补偿，撤单失衡刻画的是流动性供给的即时压力；其二为**信息不对称**——知情或策略性参与者借「挂出再撤」隐藏真实意图，撤单笔数的方向失衡暴露其操作侧，是订单流毒性的代理。

**对手方**：在撤单造成的虚假深度上误判供需、以不利价格成交的被动方；以及被幌骗单诱导后接盘的跟随者。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]、[[alpha/大小单博弈|大小单博弈]]。

**失效条件**：

- **算法撤单常态化**：做市与拆单算法天然高撤单率，撤单失衡与真实意图脱钩，方向信息被稀释；
- **制度性撤单集中**：涨跌停、停复牌、集合竞价等规则使撤单在特定时点集中出现，方向含义被制度因素覆盖；
- **交易机制变化**：最小报价单位、撮合规则调整会整体改变撤单模式，历史关系失效。

## 加工公式

```
cancel_num_imbalance = ratio(buy_cancel_num - sell_cancel_num, buy_cancel_num + sell_cancel_num)
# ratio 分母近零置 null
```

## 适用场景

- 作为**流动性压力 / 订单流毒性**的即时方向度量，配合 [[patterns/fields/订单流失衡|订单流失衡]]、[[patterns/fields/净撤单压力|净撤单压力]] 构建微观结构复合信号；
- 在**知情交易占比高、散户结构明显**的池子里区分度更强：这类池子的撤单更可能携带意图，而非纯做市噪声；
- 与 [[patterns/mask/时段掩码|时段掩码]] 配合，剔除开盘 / 尾盘集合竞价等制度性撤单集中时段；
- 作为条件变量：只在撤单失衡与订单流失衡同向时放大信号。

## 可变异维度

- 口径：笔数 → 量
- 频率：可调
