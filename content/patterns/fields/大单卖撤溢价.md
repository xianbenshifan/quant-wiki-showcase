## 金融解释

**衡量什么**：先求被撤回的大额卖单的**委托均价**（撤卖额 / 撤卖量），再与当日全市场成交均价 VWAP 比较，取相对偏差并做有符号对数压缩。正值表示撤回的大卖单原本挂在**高于**市场均价的位置，负值表示挂在低于均价的位置。

**为什么有信息量**：一笔挂单在成交前被撤回，本身不产生成交量，却暴露了**报价意图**。对于大额卖委托，挂价位置是意图的关键线索：

- 挂在**远高于** VWAP 的位置（大幅溢价）而随后撤单，往往是「挂而不成」的**虚张声势**——用远离市场的卖压制造抛售假象，或为掩护真实方向而下出的幌子单；
- 挂在接近甚至低于 VWAP 的位置（贴价、折价）再撤单，则更像**真实想卖但临时改变主意**（或已被更高优先级订单抢先），其撤单可能预示供给意愿仍在。

因此该字段把「撤单发生了没有」升级为「撤单发生在什么价位」，是对撤单行为方向与意图的更细粒度刻画。

**与相邻字段的区别**：

- [[patterns/fields/大单卖溢价|大单卖溢价]]：同公式结构，但分子用**已成交**的大单卖单均价，度量的是**成交**的折/溢价；本页分子是**被撤回**的委托，度量的是**未成交**的报价位置。二者并列可对照「成交的紧迫」与「挂单的姿态」；
- [[patterns/fields/大单买撤溢价|大单买撤溢价]]：镜像的买方版本，衡量被撤回买委托的报价位置；
- [[patterns/fields/撤单失衡|撤单失衡]]：只看撤单的**量向**（买撤多还是卖撤多），不看**报价位置**，是粗粒度的方向度量。

## 收益来源

本页归属 [[alpha/普通大单信息延续|普通大单信息延续]]

**赚什么钱**：主要赚**信息不对称**的钱。撤单溢价是「意图暴露」类信号：大额卖单撤在远离市场的高位，可能指向虚假卖压（利多）或掩护派发（利空），其方向需要结合其他撤单字段共同解读；无论哪种，它都揭示了一般投资者看不到的、做市方/大资金的报价策略，形成信息优势。

**对手方**：依据盘口挂单做决策、却被「挂而不成」的虚单误导的交易者——他们把撤单前的名义卖压当作真实供给，从而错误定价。

**理论支撑**：[[concepts/信息不对称与PIN|信息不对称与PIN]]（订单流中的策略性行为与逆向选择）。

**失效条件**：

- **报价策略被算法化**：做市与执行算法大规模使用撒单/幌骗（spoofing）后，撤单溢价成为普遍噪声而非异质信息，截面区分度下降；
- **监管收紧**：对频繁撤单、幌骗的监管处罚会抑制虚假委托，该字段所捕捉的操纵性意图随之减弱；
- **真实报价被误读**：小幅溢价撤单也可能只是正常的限价单改价或抢跑，未必携带方向性信息，符号含义不稳定。

## 加工公式

```
撤卖均价 = 大单卖撤额 / 大单卖撤量
VWAP = 成交额 / 成交量
大单卖撤溢价 = signed_log( 撤卖均价 / VWAP − 1 )
# signed_log(x) = sign(x)·ln(1+|x|)，压缩厚尾；分母近零置 null
```

## 适用场景

- **识别策略性挂单**：在撤单率高的标的或时段，用报价位置区分「虚挂」与「真撤」，作为撤单类因子的价位维度补充；
- **与撤单量向字段联合使用**：先看撤单失衡判断哪一侧撤得多，再用本字段判断撤单挂在什么价位，形成「量向 + 价位」的二维刻画；
- **高频微观结构研究**：5min 以下频率、盘口数据完整时，报价位置的区分度最高。
