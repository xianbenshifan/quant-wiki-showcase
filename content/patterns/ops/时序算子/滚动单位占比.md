## 金融解释

**做什么**：以滚动窗口和作分母，度量最新一期在窗口总量中的占比：

$$u_t=\frac{x_t}{\sum_{s=t-w+1}^{t} x_s}.$$

**为什么有信息量**：它把「当前这一期放了多少量」表达为**相对近期总量的份额**，天然量纲无关、跨标的可比。份额显著偏高说明当前期在近期活动中异常突出，是放量、资金集中、事件冲击的轻量代理；由于分母只含近期窗口，它对结构变化比整窗口版更敏感。用占比而不是绝对量，关键是把「标的规模」与「单期活跃」分开——大盘股成交额天然更大，占比则让不同规模的标的可比。

**与相邻构件的分工**：[[patterns/ops/时序算子/整窗口单位占比|整窗口单位占比]] 的分母是整段，尺度更大、更平滑；本页分母是滚动和，聚焦近期。[[patterns/ops/时序算子/滚动求和|滚动求和]] 给总量、本页给份额（规模 vs 结构）。分母含当前值，存在轻微内生性：单期越大，分母也被抬高，占比被压缩——这也是它一般小于 1 的原因。

## 算子定义

```
rolling_unit_ratio(x, window)   # x_t / 窗口求和
```

- 分母 = 窗口内有效样本之和；分母近零 → null；
- 对象须恒正（量 / 额）；含负值序列的占比无意义。

## 适用场景

- **放量 / 缩量的相对度量**；
- **资金流单期集中度**；
- **规模与结构配对**：与滚动求和并列使用；
- **量类事件掩码**的轻量条件；
- **事件识别**：占比突然跳升可作为单期冲击、大宗交易或资金异动的信号。

## 边界与陷阱

- **分母趋零**：低流动性窗口和极小，占比数值爆炸，须设下限或置空；
- **内生性**：当前值进入分母，短窗口下占比被系统性压缩，极值被低估；
- **窗口长度依赖**：窗口越短单期占比越大，跨窗口不可比；
- **与整窗口版混淆**：分母基准不同，回答的时间尺度不同；
- **与滚动求和的共线性**：占比与总量互补，但都受当前值影响，同时用作因子时须注意信息重叠。

## 可变异维度

- 窗口：可调
- 对象：量 / 额
- 分母：滚动 → 整段 / 扩张
